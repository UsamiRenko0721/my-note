# 集团分解原理

直到现在，我们还没有对哈密顿量算符 $H$ 的详细结构进行深入讨论。这个算符可以通过给出它在两个粒子数任意的态之间的所有矩阵元来定义。等价地，任何这样的算符也可以表示为某些产生或湮灭单粒子的算符的函数。

用产生和湮灭算符构建哈密顿量有更深层次的原因——如果我们将哈密顿量表达成产生和湮灭算符乘积的和，并有恰当且不奇异的系数，那么 $S$-矩阵会自动满足一个关键的物理要求：**集团分解原理**（Cluster Decomposition Principle），即相距甚远的实验产生的结果不相关。

在相对论量子理论中，集团分解原理在使场论成为必需的过程中扮演了关键角色。曾有过很多不用定域场论形式化一个相对论不变理论的尝试——对于两体散射确实可能构建出一个非场论的理论却依旧得到 Lorentz 不变的 $S$-矩阵——但是这样的努力总在粒子数超过两个时陷入困境：要么 3-粒子的 $S$-矩阵不是 Lorentz 不变的，要么就违背了集团分解原理。

# 玻色子与费米子

## 全同粒子的对称性

物理态的 Hilbert 空间由包含 $0,1,2,\dots$ 个自由粒子的态张成。我们现在必须对[[散射理论]]中忽略的一个问题做深入研究：**态的对称性**。

就目前我们所知道的，所有的粒子不是玻色子就是费米子，二者的差异是：态在两个全同玻色子的交换下不变，而在两个全同费米子的交换下要变一个符号：

$$\Phi_{\cdots \mathbf{p}\sigma n \cdots \mathbf{p}'\sigma' n \cdots} = \pm \Phi_{\cdots \mathbf{p}'\sigma' n \cdots \mathbf{p}\sigma n \cdots} \tag{4.1.1}$$

其中 $n$ 是玻色子取正号，是费米子取负号。省略号代表该态中可能出现的其它粒子。这两种情况通常指代为玻色或费米"统计"。

> [!info] 自旋-统计定理
> 我们将在下一章看到，整数自旋或半整数自旋的粒子只能分别对应玻色统计和费米统计，但在本章中我们并不需要知道这件事。

## 为什么只有玻色子和费米子？

首先注意到，如果分别具有动量和自旋 $\mathbf{p},\sigma$ 和 $\mathbf{p}',\sigma'$ 的两个粒子属于同一种类 $n$，那么态矢 $\Phi_{\cdots \mathbf{p}\sigma n \cdots \mathbf{p}'\sigma' n \cdots}$ 与 $\Phi_{\cdots \mathbf{p}'\sigma' n \cdots \mathbf{p}\sigma n \cdots}$ 代表同一物理态。既然两个态矢在物理上是不可区分的，它们必属于同一射线：

$$\Phi_{\cdots \mathbf{p}\sigma n \cdots \mathbf{p}'\sigma' n \cdots} = \alpha_n \Phi_{\cdots \mathbf{p}'\sigma' n \cdots \mathbf{p}\sigma n \cdots} \tag{4.1.2}$$

其中 $\alpha_n$ 是绝对值为 $1$ 的复数。问题的关键是确定相因子 $\alpha_n$ 由什么决定。再一次交换两个粒子：

$$\Phi_{\cdots \mathbf{p}\sigma n \cdots \mathbf{p}'\sigma' n \cdots} = \alpha_n^2 \Phi_{\cdots \mathbf{p}\sigma n \cdots \mathbf{p}'\sigma' n \cdots}$$

这使得 $\alpha_n^2 = 1$，表明 $\alpha_n = \pm 1$ 正是仅有的两种可能性。

>[!solution]- $\alpha_n$ 还能依赖什么？
>
>1. **依赖态中其它粒子的数目与种类**：这会导致地球上的态矢在粒子交换下的对称性依赖于出现在宇宙别处的粒子——集团分解原理就是要排除这类情况。
>
>2. **依赖自旋**：如果这样，这些依赖自旋的相位因子将构成旋转群的一个表示，而三维旋转群的非平庸表示没有一个是一维表示（即相位因子）。
>
>3. **依赖动量**：Lorentz 不变性要求 $\alpha_n$ 只能依赖于标量 $p_1^\mu p_{2\mu}$——这是在交换粒子 $1$ 和 $2$ 下的对称性，因而不会影响 $\alpha_n^2 = 1$ 的论证。
>
>4. **路径依赖的相位**（例外）：态可能会携带依赖动量空间路径的相位因子。在这种情况下，交换两个粒子两次也可能使态变化一个相位，使得 $\alpha_n^2 \neq 1$。这在**二维空间**中是可能的（见 9.7 节），但三维及维数更高的空间则不存在这种可能性。

## 跨种类的约定

交换不同种类的粒子会怎样呢？为了处理类似同位旋对称性这样涉及不同种类粒子的对称性，采取如下约定是方便的：在任何情况下，无论粒子的种类是否相同，态矢取为：

- 在任意玻色子之间、或者在任意玻色子与任意费米子之间的交换下对称
- 在任意两个费米子之间的交换下反对称

## 多粒子态的归一化

为了节省篇幅，用一个指标 $q$ 标记单粒子的所有量子数：动量 $\mathbf{p}$，自旋 $z$-分量 $\sigma$（对于无质量粒子则是螺旋度），以及粒子种类 $n$。

**真空态**（$N=0$）：

$$(\Phi_0, \Phi_0) = 1 \tag{4.1.3}$$

**单粒子态**（$N=1$）——对称性问题不会出现：

$$(\Phi_{q'}, \Phi_q) = \delta(q' - q) \tag{4.1.4}$$

其中 $\delta(q'-q)$ 是粒子量子数的所有 $\delta$-函数与克罗内克 $\delta$-符号的乘积：

$$\delta(q'-q) \equiv \delta^3(\mathbf{p}'-\mathbf{p})\delta_{\sigma'\sigma}\delta_{n'n} \tag{4.1.5}$$

**两粒子态**（$N=2$）——态 $\Phi_{q_1' q_2'}$ 与 $\Phi_{q_2' q_1'}$ 在物理上是相同的：

$$(\Phi_{q_1' q_2'}, \Phi_{q_1 q_2}) = \delta(q_1'-q_1)\delta(q_2'-q_2) \pm \delta(q_2'-q_1)\delta(q_1'-q_2) \tag{4.1.6}$$

符号 $\pm$ 在两个粒子都是费米子时取 $-$ 号，其它情况取 $+$ 号。

**一般 $N$-粒子态**：

$$\boxed{(\Phi_{q_1' q_2' \cdots q_M'}, \Phi_{q_1 q_2 \cdots q_N}) = \delta_{NM} \sum_{\mathcal{P}} \delta_{\mathcal{P}} \prod_i \delta(q_i - q'_{\mathcal{P}i})} \tag{4.1.7}$$
^eq-417

- 求和对整数 $1,2,\dots,N$ 的所有置换 $\mathcal{P}$ 求和
- $\delta_{\mathcal{P}}$ 是符号因子：如果 $\mathcal{P}$ 包含费米子的奇置换（奇数次的费米子交换），则 $\delta_{\mathcal{P}} = -1$，否则等于 $+1$
- 在 $q_i$ 的交换下，或者在 $q_j'$ 的交换下，方程 $(4.1.7)$ 有着所需的对称性和反对称性

> [!summary] 本章路线图
> 在 4.1 节建立了多粒子态的对称性基础之后：
> - **4.2 节**：定义产生和湮灭算符 $a^\dagger(q), a(q)$ 及其对易/反对易关系
> - **4.3 节**：集团分解原理的严格表述
> - **4.4 节**：基本定理——任何满足集团分解原理的算符都可写成产生湮灭算符的正规编序形式
>
> 本章的核心结论是：**产生和湮灭算符的形式体系不是量子化经典场的偶然产物，而是集团分解原理这一物理要求的必然结果。**

# 产生和湮灭算符

## 定义

产生和湮灭算符通过它们在 [[#多粒子态的归一化|归一化多粒子态]] 上的作用效果来定义。

**产生算符** $a^\dagger(q)$（更详细地，$a^\dagger(\mathbf{p},\sigma,n)$）被定义成在态中粒子队列前面增加一个量子数为 $q$ 的粒子：

$$\boxed{a^\dagger(q) \Phi_{q_1 q_2 \cdots q_N} \equiv \Phi_{q q_1 q_2 \cdots q_N}} \tag{4.2.1}$$

特别地，将 $N$ 个产生算符作用在真空态上就可以获得 $N$-粒子态：

$$a^\dagger(q_1) a^\dagger(q_2) \cdots a^\dagger(q_N) \Phi_0 = \Phi_{q_1 \cdots q_N} \tag{4.2.2}$$

**湮灭算符** $a(q)$ 是 $a^\dagger(q)$ 的共轭，可以从归一化条件 [[#^eq-417|(4.1.7)]] 中计算出来。当粒子 $q, q_1, \dots, q_N$ 全是玻色子或全是费米子时：

$$\boxed{a(q) \Phi_{q_1 q_2 \cdots q_N} = \sum_{r=1}^{N} (\pm)^{r+1} \delta(q - q_r) \Phi_{q_1 \cdots q_{r-1} q_{r+1} \cdots q_N}} \tag{4.2.3}$$

其中对玻色子和费米子分别取 $+1$ 和 $-1$。

>[!solution]- 证明 (4.2.3)
>计算 $a(q)\Phi_{q_1 q_2 \cdots q_N}$ 与任意态 $\Phi_{q_1' \cdots q_M'}$ 的标量积。利用 $a(q)$ 是 $a^\dagger(q)$ 的共轭和定义 (4.2.1)：
>
>$$(\Phi_{q_1' \cdots q_M'}, a(q)\Phi_{q_1 \cdots q_N}) \equiv (a^\dagger(q)\Phi_{q_1' \cdots q_M'}, \Phi_{q_1 \cdots q_N}) = (\Phi_{q q_1' \cdots q_M'}, \Phi_{q_1 \cdots q_N})$$
>
>使用归一化方程 [[#^eq-417|(4.1.7)]]。对 $1,2,\dots,N$ 的置换 $\mathcal{P}$ 的求和可以写为对置换到第一个位置上的整数 $r$（即 $\mathcal{P}r=1$）和对剩余整数的映射 $\bar{\mathcal{P}}$ 求和。符号因子关系为 $\delta_{\mathcal{P}} = (\pm)^{r-1}\delta_{\bar{\mathcal{P}}}$。使用 (4.1.7) 两次：
>
>$$\begin{align}
(\Phi_{q_1' \cdots q_M'}, a(q)\Phi_{q_1 \cdots q_N}) &= \delta_{N,M+1} \sum_{r=1}^{N} \sum_{\bar{\mathcal{P}}} (\pm)^{r-1}\delta_{\bar{\mathcal{P}}}\delta(q-q_r) \prod_{i=1}^{M} \delta(q_i' - q_{\mathcal{P}i}) \\
&= \delta_{N,M+1} \sum_{r=1}^{N} (\pm)^{r-1}\delta(q-q_r) (\Phi_{q_1' \cdots q_M'}, \Phi_{q_1 \cdots q_{r-1} q_{r+1} \cdots q_N})
\end{align}$$
>
>两边对所有态 $\Phi_{q_1' \cdots q_M'}$ 的矩阵元相同，因此算符相等，得证。

作为 (4.2.3) 的特殊情况，无论玻色子还是费米子，$a(q)$ 均**湮灭真空**：

$$a(q) \Phi_0 = 0 \tag{4.2.4}$$

## 对易与反对易关系

用算符 $a(q')$ 作用 (4.2.1)，并利用 (4.2.3)，给出：

$$a(q') a^\dagger(q) \Phi_{q_1 \cdots q_N} = \delta(q'-q) \Phi_{q_1 \cdots q_N} + \sum_{r=1}^{N} (\pm)^{r+2} \delta(q'-q_r) \Phi_{q q_1 \cdots q_{r-1} q_{r+1} \cdots q_N}$$

用算符 $a^\dagger(q)$ 作用 (4.2.3) 给出：

$$a^\dagger(q) a(q') \Phi_{q_1 \cdots q_N} = \sum_{r=1}^{N} (\pm)^{r+1} \delta(q'-q_r) \Phi_{q q_1 \cdots q_{r-1} q_{r+1} \cdots q_N}$$

相减或相加，得：

$$\boxed{a(q') a^\dagger(q) \mp a^\dagger(q) a(q') = \delta(q' - q)} \tag{4.2.5}$$

另外，(4.2.2) 立即给出：

$$\boxed{a^\dagger(q') a^\dagger(q) \mp a^\dagger(q) a^\dagger(q') = 0} \tag{4.2.6}$$

$$\boxed{a(q') a(q) \mp a(q) a(q') = 0} \tag{4.2.7}$$

其中上面的符号（$-$，对易子）对应玻色子，下面的符号（$+$，反对易子）对应费米子。

> [!info] 跨种类的约定
> 对于两个不同种类的粒子：如果其中一个是玻色子，产生/湮灭算符**对易**；如果两个都是费米子，则**反对易**。

>[!solution]- 历史路径 vs Weinberg 路径
>以上的讨论也可以按照相反的顺序来讲（在大多数教科书中通常是这样的）：从对易/反对易关系 (4.2.5)—(4.2.7) 出发，从某些给定场论的正则量子化开始推导。那么多粒子态由 (4.2.2) 定义，而标量积 (4.1.7) 由对易/反对易关系导出。
>
>Weinberg 这里不沿着历史的途径，因为他想**摆脱对预设场论的依赖**，而更希望理解场论为什么是它们现在所呈现的形式。

## 基本定理：算符的产生湮灭展开

任何算符 $\mathcal{O}$ 都可以表示为产生和湮灭算符乘积的和：

$$\boxed{\mathcal{O} = \sum_{N=0}^{\infty} \sum_{M=0}^{\infty} \int dq_1' \cdots dq_N' \, dq_1 \cdots dq_M \; a^\dagger(q_1') \cdots a^\dagger(q_N') \, a(q_M) \cdots a(q_1) \; C_{NM}(q_1' \cdots q_N' \, q_1 \cdots q_M)} $$

>[!solution]- 数学归纳法证明
>希望证明通过选择系数 $C_{NM}$，可以赋予这个表达式的矩阵元以任意想要的值。
>
>**基础步**：无论 $N>0$ 和/或 $M>0$ 的 $C_{NM}$ 值是多少，通过正确选择 $C_{00}$，可以给 $(\Phi_0, \mathcal{O}\Phi_0)$ 任何所需的值。由 (4.2.4)，$(\Phi_0, \mathcal{O}\Phi_0) = C_{00}$。
>
>**归纳步**：假定对 $N < L, M \leq K$ 或 $N \leq L, M < K$，通过对相应系数 $C_{NM}$ 的恰当选择，这些矩阵元已被赋予了希望的值。计算：
>
>$$(\Phi_{q_1' \cdots q_L'}, \mathcal{O}\Phi_{q_1 \cdots q_K}) = L! K! \, C_{LK}(q_1' \cdots q_L' \, q_1 \cdots q_K) + \text{包含 } C_{NM} \text{ 的项，其中 } N<L, M\leq K \text{ 或 } N\leq L, M<K$$
>
>无论已给 $N<L, M\leq K$ 或 $N\leq L, M<K$ 的 $C_{NM}$ 什么值，显然可以通过选择 $C_{LK}$ 赋予这个矩阵元任何所需的值。$\square$
>
>**推论**：一个算符不需要一定以"所有产生算符在湮灭算符左边"（正规编序）的形式表示。如果以其它方式排列，通过反复应用对易/反对易关系，用 (4.2.5) 的 $\delta$-函数挑出新的项，总可以将产生算符移至湮灭算符的左边。

## 加性算符与自由哈密顿量

考察任何形式的**加性算符** $F$（像动量、荷等），其在多粒子态上有：

$$F \Phi_{q_1 \cdots q_N} = \big(f(q_1) + \cdots + f(q_N)\big) \Phi_{q_1 \cdots q_N} \tag{4.2.9}$$

这样的算符可以写为 (4.2.8) 中仅 $N=M=1$ 的项：

$$F = \int dq \, a^\dagger(q) a(q) f(q) \tag{4.2.10}$$

特别地，**自由粒子哈密顿量**总是：

$$\boxed{H_0 = \int dq \, a^\dagger(q) a(q) E(q)} \tag{4.2.11}$$

其中 $E(q)$ 是单粒子能量：

$$E(\mathbf{p}, \sigma, n) = \sqrt{\mathbf{p}^2 + m_n^2}$$

## 产生算符的 Lorentz 变换性质

回忆 [[散射理论#^eq-311|$N$-粒子态的 Lorentz 变换性质]]，态可以像 (4.2.2) 中那样用产生算符表示：

$$\Phi_{\mathbf{p}_1 \sigma_1 n_1, \mathbf{p}_2 \sigma_2 n_2, \cdots} = a^\dagger(\mathbf{p}_1 \sigma_1 n_1) a^\dagger(\mathbf{p}_2 \sigma_2 n_2) \cdots \Phi_0$$

其中 $\Phi_0$ 是 Lorentz 不变的真空态 $U_0(\Lambda, a)\Phi_0 = \Phi_0$。为了使态做正确的变换，产生算符需要如下充要的变换规则：

$$\boxed{U_0(\Lambda, \alpha) a^\dagger(\mathbf{p}\sigma n) U_0^{-1}(\Lambda, \alpha) = e^{-i(\Lambda p)\cdot\alpha} \sqrt{\frac{(\Lambda p)^0}{p^0}} \sum_{\bar{\sigma}} D^{(\,j)}_{\bar{\sigma}\sigma}\!\big(W(\Lambda, p)\big) \, a^\dagger(\mathbf{p}_\Lambda \bar{\sigma} n)} \tag{4.2.12}$$

其中：
- $\mathbf{p}_\Lambda$ 是 $\Lambda p$ 的 3-矢部分
- $D^{(\,j)}_{\bar{\sigma}\sigma}(R)$ 是三维旋转群自旋-$j$ 幺正表示
- $W(\Lambda, p) \equiv L^{-1}(\Lambda p) \Lambda L(p)$ 是 Wigner 旋转（见[[量子力学#小群的不可约表示]]）

> 这里讨论针对 $m \neq 0$ 的情况；无质量粒子将在下一章讨论。

## 离散对称性的作用

对那些在自由粒子态上诱导出离散变换的算符 $\mathrm{C}, \mathrm{P}, \mathrm{T}$：

| 变换 | 作用 | 方程 |
|:----:|------|:----:|
| **荷共轭** $\mathrm{C}$ | $\mathrm{C} a^\dagger(\mathbf{p}\sigma n) \mathrm{C}^{-1} = \xi_n a^\dagger(\mathbf{p}\sigma n^c)$ | (4.2.13) |
| **空间反演** $\mathrm{P}$ | $\mathrm{P} a^\dagger(\mathbf{p}\sigma n) \mathrm{P}^{-1} = \eta_n a^\dagger(-\mathbf{p}\sigma n)$ | (4.2.14) |
| **时间反演** $\mathrm{T}$ | $\mathrm{T} a^\dagger(\mathbf{p}\sigma n) \mathrm{T}^{-1} = \zeta_n (-1)^{j-\sigma} a^\dagger(-\mathbf{p}, -\sigma, n)$ | (4.2.15) |

其中 $\xi_n, \eta_n, \zeta_n$ 是各粒子种类的内禀相位（$|\xi_n|=|\eta_n|=|\zeta_n|=1$），$n^c$ 标记反粒子。

> [!info] "in" 和 "out" 算符
> 尽管我们所处理的算符产生和湮灭的是自由态中的粒子，但整个形式体系可以应用于"入"态和"出"态。在这种情况下引入算符 $a_{\text{in}}$ 与 $a_{\text{out}}$，它们以相同的方式通过在态上的作用定义。这些算符满足类似 (4.2.12) 的 Lorentz 变换规则，但要用真正的 Lorentz 变换算符 $U(\Lambda, a)$ 替代自由粒子算符 $U_0(\Lambda, a)$。
