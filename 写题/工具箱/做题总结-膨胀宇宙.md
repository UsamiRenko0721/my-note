## 二、正则量子化（I.1–I.2）

### 有质量场的模展开

与无质量场的唯一区别：$\omega_k = \sqrt{k^2+m^2}$ 替代 $|k|$。其余流程完全一致——反转法求 $[a_k, a_{k'}^\dagger]=\delta(k-k')$，归一化因子从 $\sqrt{|k|}$ 变为 $\sqrt{\omega_k}$。

### $[N,H]=0$ 的条件

静态 Minkowski 时空中 $[N,H]=0$，粒子数守恒。但含时背景（FLRW 膨胀 → $\omega_k(\eta)$ 含时）或相互作用会破坏此对易关系——这正是 Part III 的物理基础。

---

## 三、含时谐振子与 Bogoliubov 变换的预演（I.3）

### 核心技巧：用 $x,p$ 作为不变量

在不同时刻 $t$，产生/湮灭算符的定义 $a(t) = \sqrt{\frac{\omega}{2}}x + \frac{i}{\sqrt{2\omega}}p$ 随 $\omega(t)$ 变化，但 $x,p$ 不依赖这个分解。反解：
$$x = \sqrt{\frac{2}{\omega}}(a^\dagger + a), \quad p = -i\sqrt{2\omega}(a^\dagger - a)$$

比较初末态的 $x,p$ 表达式 → 直接读出 Bogoliubov 系数：
$$\alpha = \frac{1}{2}\left( \sqrt{\frac{\omega_{\text{out}}}{\omega_{\text{in}}}} + \sqrt{\frac{\omega_{\text{in}}}{\omega_{\text{out}}}} \right), \quad \beta = \frac{1}{2}\left( \sqrt{\frac{\omega_{\text{out}}}{\omega_{\text{in}}}} - \sqrt{\frac{\omega_{\text{in}}}{\omega_{\text{out}}}} \right)$$

粒子数：$|\beta|^2 = (\omega_{\text{out}}-\omega_{\text{in}})^2/(4\omega_{\text{in}}\omega_{\text{out}})$ 

**物理：** $\omega_{\text{in}}=\omega_{\text{out}} \Rightarrow |\beta|^2=0$，无粒子产生；$\omega_{\text{in}}\neq\omega_{\text{out}} \Rightarrow$ 粒子产生。

## 四、Hamiltonian 推导（I.4）⚠️ 易错

### 正确流程

$$\mathcal{H} = \pi\partial_t\phi - \mathcal{L} = \pi^2 - \frac{1}{2}(\pi^2 - (\partial_x\phi)^2 - m^2\phi^2) = \frac{1}{2}(\pi^2 + (\partial_x\phi)^2 + m^2\phi^2)$$

> ❌ 我犯的错：直接从 $\mathcal{L} = \frac{1}{2}(\partial_\mu\phi\partial^\mu\phi - m^2\phi^2)$ 写 $\mathcal{H} = \frac{1}{2}(\partial_\mu\phi\partial^\mu\phi + m^2\phi^2)$，丢了 $(\partial_x\phi)^2$ 前应有的 $+$ 号。

### 简化视角

不需要冗长积分。每个 $k$ 模是独立谐振子：
$$H_k = \frac{1}{2}\pi_k^2 + \frac{1}{2}\omega_k^2\phi_k^2$$
量子化后直接 $H_k = \omega_k a_k^\dagger a_k$。

## 五、FLRW 度规（II.1）

### 共形时间

$$d\eta = \frac{dt}{a(t)}, \quad ds^2 = a^2(\eta)(d\eta^2 - dx^2)$$

FLRW 度规**共形等价于** Minkowski 度规。在 $1+1$ 维和 $3+1$ 维均成立（将 $dx^2$ 替换为 $d\mathbf{x}^2$）。

### Ricci 标量（$1+1$ 维）

$$R = -\frac{2}{a^2}\frac{a''}{a} \quad (\text{共形时间 }\eta)$$

### $a(\eta)$ 为常数

→ $R=0$，度规退化为静态 Minkowski（乘以常数因子）。

## 六、标量场在 FLRW 中（II.2–II.3）

### 关键的抵消

$$\sqrt{-g} = a^2, \quad g^{\mu\nu} = a^{-2}\eta^{\mu\nu}$$

两者乘积 $\sqrt{-g}\,g^{\mu\nu} = \eta^{\mu\nu}$ —— 与 $a(\eta)$ 无关！因此动能项与 Minkowski 完全相同，只有质量/曲率耦合项带 $a^2$ 因子：

$$S = -\frac{1}{2} \int d\eta dx \left[ (\partial_\eta\phi)^2 - (\partial_x\phi)^2 + a^2(m^2 + \xi R)\phi^2 \right]$$

### 模方程

Fourier 变换后：
$$\chi_k'' + \omega_k^2(\eta)\chi_k = 0, \quad \omega_k^2(\eta) = k^2 + a^2(\eta)(m^2 + \xi R(\eta))$$

这是**时间依赖频率的谐振子**——与 I.3 的模型一一对应。

### 共形耦合 = 最小耦合（$1+1$ 维）

$$\xi_c = \frac{D-2}{4(D-1)} \;\Rightarrow\; D=2\text{ 时 } \xi_c = 0$$

因此 $\xi=0$、$m=0$ 时 $\omega_k^2 = k^2$（常数）→ **无粒子产生**。

→ 最小耦合恰好是共形耦合，共形不变性保护了真空。

### 有质量 → 粒子产生

$\xi=0$、$m>0$ 时，$\omega_k^2 = k^2 + m^2 a^2(\eta)$ 含时 → **质量打破了共形不变性** → 粒子产生。

## 七、骤胀模型（III.1–III.2）

### 模型设定

$a(\eta)$ 在 $\eta=0$ 处阶跃：$a_1 \to a_2$。$\omega_k$ 随之跳变：
$$\omega_k^{\text{in}} = \sqrt{k^2+m^2a_1^2}, \quad \omega_k^{\text{out}} = \sqrt{k^2+m^2a_2^2}$$

### 模式匹配

利用 $\chi_k$ 和 $\chi_k'$ 在 $\eta=0$ 连续 → Bogoliubov 系数：

$$A_k = \frac{1}{2}\left( \sqrt{\frac{\omega_k^{\text{out}}}{\omega_k^{\text{in}}}} + \sqrt{\frac{\omega_k^{\text{in}}}{\omega_k^{\text{out}}}} \right), \quad B_k = \frac{1}{2}\left( \sqrt{\frac{\omega_k^{\text{out}}}{\omega_k^{\text{in}}}} - \sqrt{\frac{\omega_k^{\text{in}}}{\omega_k^{\text{out}}}} \right)$$

### 粒子谱

$$n_k = |B_k|^2 = \frac{(\omega_k^{\text{out}} - \omega_k^{\text{in}})^2}{4\omega_k^{\text{in}}\omega_k^{\text{out}}}$$

极限行为：
- $k\to\infty$：$n_k \to 0$（高频模绝热适应）
- $k\to 0$：$n_k \to (a_1-a_2)^2/(4a_1a_2)$ 
- $a_2\to a_1$：$n_k \to 0$（无膨胀 → 无粒子）

### Bogoliubov 逆变换 ⚠️ 易错

正确形式（利用 $|A|^2-|B|^2=1$）：
$$a_k^{\text{in}} = A_k a_k^{\text{out}} + B_k^* a_k^{\text{out}\dagger}$$

## 八、总粒子数与能量密度（III.3）

### 小膨胀近似

$a_2 = a_1(1+\epsilon),\; \epsilon \ll 1$：
$$n_k \approx \frac{\epsilon^2 m^4 a_1^4}{4(k^2 + m^2 a_1^2)^2}$$
$$\mathcal{N} = \frac{\epsilon^2 m a_1}{16}, \quad \mathcal{E} = \frac{\epsilon^2 m^2 a_1^2}{4\pi}$$

两者均**收敛**，无需正规化。

### 绝热定理

骤胀近似高估了紫外粒子产生。真实平滑变化中：
- $\omega_k \tau \lesssim 1$：非绝热，粒子被激发
- $\omega_k \tau \gg 1$：绝热，粒子数指数压低

> 骤胀近似只能定性描述红外（长波）模的粒子产生，对紫外模不可靠。

## 九、宇宙学意义（III.4）

### 暴胀与量子涨落

de Sitter 暴胀：$a(\eta) = -1/(H\eta)$（$\eta<0$），$\eta\to 0^-$ 时物理动量 $p = k/a \to 0$，模的物理波长被拉伸到远超 Hubble 视界 → 量子真空涨落"冻结"为经典扰动 → CMB 各向异性的种子。

### 骤胀 vs 预热

| | 骤胀粒子产生 | 预热（preheating） |
|---|---|---|
| 机制 | 单次非绝热变化 | 参数共振（周期性驱动） |
| 粒子数 | $n_k \sim \mathcal{O}(\epsilon^2)$ | 指数增长 $n_k \sim e^{2\mu_k t}$ |
| 效率 | 低 | 极高（数十次振荡即可转化全部能量） |
| 驱动源 | 度规阶跃 | inflaton 场在势能底部的相干振荡 |

### 共形不变性在 $3+1$ 维

模方程（$3+1$ 维，共形重标度后）：
$$\chi_k'' + \left( k^2 + m^2 a^2 + (6\xi - 1)\frac{a''}{a} \right) \chi_k = 0$$

- $(6\xi-1)a''/a$ 项来自 $\xi R$ 与共形重标度的组合
- $\xi = 1/6$ 时，该项消失 → 共形耦合
- 无质量 + 共形耦合 → $\omega_k^2 = k^2$ 常数 → **无粒子产生**

> **核心洞察：** 共形对称性是弯曲时空 QFT 中保持粒子数守恒的对称性。任何破坏共形不变性的因素（质量 $m\neq0$、非共形耦合 $\xi\neq\xi_c$、量子反常）都会导致粒子产生。

## 十一、易错点清单

| 错误 | 正确 |
|------|------|
| $\mathcal{H} = \frac{1}{2}(\partial_\mu\phi\partial^\mu\phi + m^2\phi^2)$ | $\mathcal{H} = \frac{1}{2}(\pi^2 + (\partial_x\phi)^2 + m^2\phi^2)$ |

## 十二、核心技巧

1. **$x,p$ 不变量法**：不同时刻的产生/湮灭算符通过不变的 $x,p$ 联系起来——比直接解 Bogoliubov 系数更直观
2. **共形时间 + Fourier 变换**：将弯曲时空场方程化为含时谐振子 → 与 I.3 直接类比
3. **模式匹配（骤胀）**：阶跃近似下连续性条件 → 代数方程 → 手算 $A_k, B_k$
4. **$\sqrt{-g}\,g^{\mu\nu} = \eta^{\mu\nu}$ 的抵消**：$1+1$ 维 FLRW 中关键的简化
