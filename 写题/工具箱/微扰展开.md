# 一. 微扰展开简介

微扰展开 = 把一个复杂问题拆成：可解的主问题 + 小修正的系统方法

数学形式上：

$$Q = Q_{0} + \varepsilon Q_{1} + \varepsilon^{2}Q_{2} + \dots $$

其中
- $Q_{0}$ 是完全会解的“零阶问题”
- $\varepsilon$ 是小参数
- $Q_{n}$ 是逐阶修正


# 二. 正常流程

找到零阶的问题，并判断出小参数

>[!example]
>考虑这样一个非谐哈密顿量
>$$H = \frac{1}{2m} p^{2} + \frac{1}{2}m\omega^{2} x^{2} + \lambda x^{4} - \mu x^{6} $$
>其中
>$$H_{0} = \frac{1}{2m}p^{2} + \frac{1}{2}m\omega^{2}x^{2} $$
>是我们会解的零阶问题，我们可以在这个模型下计算出振幅、周期、相空间等特征量。而 $\lambda,\mu$ 作为小参数，在后续中按阶展开。

然后展开 Ansatz 

>[!example]
>比如我们想要求振幅 (给定系统的能量) 显然在零阶问题下，这个是可以严格求解的
>$$H=E \implies A = \sqrt{ \frac{2E}{m\omega^{2}} } $$
>我们在有小参数时，对其展开，这里有两个小参数 $\lambda,\mu$ 所以我们考虑实际的振幅是它们的函数
>$$A\to A(\lambda,\mu) $$
>然后在零点附近幂级数展开
>$$A = A_{0} + c_{1}\lambda + c_{2}\mu + c_{11}\lambda^{2} + c_{12}\lambda \mu + c_{22}\mu^{2} + \dots $$
>这样我们能够严格看到小参数对振幅的影响度。另一个小技巧是进行无量纲化，即令 $\xi=\frac{A}{A_{0}}$ 类似的 $\alpha = \frac{\lambda}{m^{2}\omega^{4}}E,\beta=\frac{\mu}{m^{3}\omega^{6}}E$ 这样 $\xi$ 所满足的方程是
>$$\xi^{2} - 2\alpha \xi^{4} + 2\beta \xi^{6} = 1 $$

然后逐阶的匹配阶，因为我们这样子展开就像幂级数，而由幂级数的独立性，各阶的系数必须匹配

>[!example]
>这里就是把 $\xi^{2}=1+c_{1}\alpha+c_{2}\beta+\dots$ 代入即可，这里演示到二阶
>$$左 = 1 + (c_{1}-2)\alpha + (c_{2}+2)\beta + (c_{11} - 2c_{1}^{2} )\alpha^{2} + (c_{12}+2c_{1}+2c_{2})\alpha \beta + (c_{22} + 2c_{2}^{2} )\beta^{2} $$
>$$右 = 1 $$
>所以按照 $\alpha,\beta$ 的幂级数，各项前系数必须匹配所以
>$$c_{1}=2,\quad c_{2}=-2 ,\quad c_{11} = 6 ,\quad c_{12} = -20 ,\quad c_{22}=15 $$
>注意这里 “$左=\dots$” 的意思是基于截断的，也就是这个等号建立在略去二阶以上的小量的基础上的，故严谨的说 $$左 = 1 + (c_{1}-2)\alpha + (c_{2}+2)\beta + (c_{11} - 2c_{1}^{2} )\alpha^{2} + (c_{12}+2c_{1}+2c_{2})\alpha \beta + (c_{22} + 2c_{2}^{2} )\beta^{2}+\mathcal{O}(\alpha^{3},\dots)$$
>所以说
>$$\xi^{2} = 1 + 2\alpha - 2\beta + 6\alpha^{2} - 20 \alpha \beta + 15\beta^{2} + o(\alpha^{2},\alpha \beta,\beta^{2}) $$

# 三. 反常/限制

微扰展开是极其常用的方法，其核心使用到的数学是估阶分析。但是有时是不能使用这样的方法的，可能会遇到发散的问题。

>[!error]
>依旧使用上面的结果，这次使用它来计算周期到一阶
>$$T = \frac{2}{\omega} \oint \frac{dx}{\sqrt{ E - V }} = \frac{4}{\omega} \int_{0}^{\xi} \frac{dy}{\sqrt{ 1-y^{2} + 2\alpha y^{4} - 2\beta y^{6} }} $$
>这次如果我们延续微扰展开的想法，我们发现积分上界 $\xi$ 是关于 $\alpha,\beta$ 的，被积函数也是关于 $\alpha,\beta$ 的，倘若我们先对上界采取展开，也就是说 $\xi =1 +\alpha-\beta+o(\alpha,\beta)$ 将积分看作 $\alpha,\beta$ 的函数然后按幂级数展开则使用公式
>$$\int_{0}^{1+\varepsilon} f(x)dx = \int_{0}^{1} f(y)dy + \varepsilon \int_{0}^{1}[f(y) + yf'(y)]dy + + \mathcal{O}(\varepsilon^{2}) $$
>其中的 $\varepsilon$ 就是这里的 $\alpha-\beta$ 于是看起来很好，第一部分的积分要估阶到 $\mathcal{O}(\alpha,\beta)$ 第二部分要估阶到 $\mathcal{O}(1)$ 而后面的一概不用管了。但是问题出现在第一部分，我们要积分
>$$\int_{0}^{1} \frac{dy}{\sqrt{ 1-y^{2}+2\alpha y^{4} - 2\beta y^{6} }} $$
>按照微扰展开的思想，我们也要把这个被积函数展开为 $\alpha,\beta$ 的幂级数
>$$f(y;\alpha,\beta) = \frac{1}{\sqrt{ 1-y^{2} }}-\frac{y^{4}}{(1-y^{2})^{3/2}}\alpha+\frac{y^{6}}{(1-y^{2})^{3/2}}\beta + \mathcal{O}(\alpha^{2},\alpha \beta,\beta^{2}) $$
>其中
>$$\int_{0}^{1} \frac{y^{4}}{(1-y^{2})^{3/2}} dy = \infty $$
>这就是问题

问题出在哪里呢？实际上我们是要保留这个积分的，在后面计算 $\int[f+yf']dy$ 时对应阶会相互抵消的，但是在这个部分是完全看不出来的。实际上这样的事是很常见的，因为**微扰展开本质是一种渐进展开**，不一定收敛。


## 陷阱
而这也就是微扰展开的三个陷阱

### ① 非解析性

某些量在参数 = 0 处不是解析函数  

### ② 展开与极限不可交换

$$\lim_{\epsilon\to 0}\int f(x,\epsilon)\neq \int \lim_{\epsilon\to 0} f(x,\epsilon)$$
### ③ 渐近级数发散

系数 ~ n! → Borel summation
