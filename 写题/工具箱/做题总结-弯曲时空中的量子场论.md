## 一、知识框架

本题从 Minkowski 时空的普通 QFT → Rindler 弯曲时空几何 → Bogoliubov 变换将两者结合，导出 Unruh 效应。

| 部分 | 知识域 | 核心概念 |
|------|--------|----------|

## 二、正则量子化（I.1–I.2）

### 范式：反转法求对易子

> ❌ **错误做法**：直接把 $[\phi,\pi]=i\delta$ 两边模展开，写成未知 $[a_p,a_k^\dagger]$ 的 Fourier 积分再反解。
> 
> ✅ **正确流程**：先 Fourier 变换反解 $a_k$，再用已知的场对易关系推 $[a_k,a_{k'}^\dagger]$。

1. 写 $t=0$ 时的模展开：
$$\phi(x) = \int \frac{dk}{\sqrt{4\pi|k|}}(a_k e^{ikx} + a_k^\dagger e^{-ikx}), \quad \pi(x) = -i\int \frac{dk}{\sqrt{4\pi|k|}}|k|(a_k e^{ikx} - a_k^\dagger e^{-ikx})$$

2. Fourier 变换：
$$\tilde{\phi}(k) = \sqrt{\frac{\pi}{|k|}}(a_k + a_{-k}^\dagger), \quad \tilde{\pi}(k) = -i\sqrt{\pi|k|}(a_k - a_{-k}^\dagger)$$

3. 消去 $a_{-k}^\dagger$：
$$a_k = \frac{1}{2\sqrt{\pi}} \int dx\, e^{-ikx} \left[ \sqrt{|k|}\,\phi(x) + \frac{i}{\sqrt{|k|}}\,\pi(x) \right]$$

4. 用 $[\phi,\pi]=i\delta$ 计算 $[a_k,a_{k'}^\dagger]=\delta(k-k')$。关键：括号 $\left(\sqrt{\frac{|k|}{|k'|}}+\sqrt{\frac{|k'|}{|k|}}\right)$ 被 $\delta(k-k')$ 截为 $2$

## 三、两点函数与因果性（I.3）

### Wightman 函数

$$G^+(x;x') = \langle 0_M|\phi(x)\phi(x')|0_M\rangle = \int \frac{dk}{4\pi|k|} e^{ik\Delta x} e^{-i|k|\Delta t}$$

> ❌ **我犯的错**：试图对 $1/|k|$ 用留数定理。$1/|k|$ 在 $k=0$ 非孤立奇点，留数定理不适用。
>
> ✅ **正确方法**：拆分 $k>0$ 和 $k<0$，用 Frullani 积分 $\int_0^\infty \frac{dk}{k}e^{-ak} = -\ln a + \text{const}$，或 Schwinger 参数化。

结果：$G^+(x,x') = -\frac{1}{4\pi}\ln[-(\Delta t-i\epsilon)^2 + \Delta x^2] + \text{const}$

### 对易子与微观因果性

$$[\phi(x),\phi(x')] = \frac{i}{4}[\text{sgn}(\Delta x - \Delta t) - \text{sgn}(\Delta x + \Delta t)]$$

当 $|\Delta x| > |\Delta t|$（类空分离）时两个 sgn 相等 → 对易子为零 → **微观因果性**。

## 四、真空能与正规序（I.4）

$$H = \int dk\,|k|\left(a_k^\dagger a_k + \frac{1}{2}\delta(0)\right)$$

- $\frac{1}{2}\delta(0)$：无穷空间体积 × 每模零点能 → **紫外发散**
- 正规序 $:H:$：所有 $a^\dagger$ 移到 $a$ 左边 → 丢弃真空能
- ⚠️ **Flat spacetime** 正规序是数学技巧；**Curved spacetime** 真空能有引力效应，不能随意丢弃

## 五、Rindler 时空（II.1–II.2）

### 坐标与度规

$$t = \xi\sinh\eta,\; x = \xi\cosh\eta \quad (\xi>0)$$
$$ds^2 = \xi^2 d\eta^2 - d\xi^2$$

- 仅覆盖右 Rindler 楔形 $x > |t|$
- **视界**：$x = \pm t$（即 $\xi \to 0$）
- $\xi = \text{const}$ → 双曲线 $x^2 - t^2 = \xi^2$（匀加速世界线）
- $\eta = \text{const}$ → 过原点的辐射线（空间切片）

### 共形性

Rindler 度规与 Minkowski 度规**不是全局共形的**（$\Omega \sim \xi$ 与 $\Omega = \text{const}$ 矛盾）。在大 $\xi$ 近似下可视为共形。

### Killing 矢量

$$\partial_\eta = t\partial_x + x\partial_t$$

- Minkowski 中 = boost 生成元
- Rindler 中 = 时间平移生成元 → Rindler 能量守恒
- ⚠️ $\partial_\eta \neq \partial_t$ → 不同的时间坐标 → 不同的正频分解 → 不同的真空

### 匀加速观测者

四加速度：$a^\mu = \frac{1}{\xi_0}(\sinh\eta, \cosh\eta)$，$a^\mu a_\mu = -1/\xi_0^2$ → $a = 1/\xi_0$

### 引力红移

本征时 $\tau = \xi_0\eta$，光源在 $\xi_0$ 处。沿光测地线 Killing 能量守恒 → $\omega' = \omega e^{-\eta}$。对应均匀引力场中的引力红移。

## 六、Rindler 场的量子化（II.3–II.4）

### 关键洞察

取 $\rho = \ln\xi$，场方程化为：
$$(-\partial_\eta^2 + \partial_\rho^2)\phi = 0$$

**Rindler 时空本质是平直时空**——它只是 Minkowski 的坐标变换。弯曲的不是时空，是观测者参考系。这就是为什么 Unruh 效应不需要真正的引力。

### 模展开

$$\phi(\eta,\rho) = \int_0^\infty \frac{d\Omega}{\sqrt{4\pi\Omega}} \left[b_\Omega^R e^{-i\Omega(\eta-\rho)} + b_\Omega^{R\dagger} e^{i\Omega(\eta-\rho)} + b_\Omega^L e^{-i\Omega(\eta+\rho)} + b_\Omega^{L\dagger} e^{i\Omega(\eta+\rho)}\right]$$

与 Minkowski 模展开的关键区别：

|      | Minkowski              | Rindler               |
| ---- | ---------------------- | --------------------- |
| 积分   | $k\in(-\infty,\infty)$ | $\Omega\in(0,\infty)$ |
| 左右行波 | 隐式（$k$ 正负）             | 显式分离 $R/L$            |
| 时间坐标 | $t$                    | $\eta$                |
| 真空   | $\vert 0_M\rangle$     | $\vert 0_R\rangle$    |

### 真空不等价

两套真空由不同的 Killing 矢量定义正频 → 正频分解不同 → $|0_R\rangle \neq |0_M\rangle$。

## 七、Bogoliubov 变换（III.1–III.2）

### 基本关系

$$b_\Omega = \int dk \left[ \alpha_{\Omega k} a_k + \beta_{\Omega k} a_k^\dagger \right]$$

- $\alpha_{\Omega k}$：Minkowski **粒子**模在 Rindler 粒子模中的投影
- $\beta_{\Omega k}$：Minkowski **反粒子**模混入 Rindler 粒子湮灭算符的幅度
- $\beta \neq 0 \iff$ 两真空不等价

**归一化条件**：$\int dk(|\alpha_{\Omega k}|^2 - |\beta_{\Omega k}|^2) = 1$（来自 $[b_\Omega, b_{\Omega'}^\dagger] = \delta(\Omega-\Omega')$）

### Minkowski 真空中的 Rindler 粒子数

$$N_\Omega = \langle 0_M|b_\Omega^\dagger b_\Omega|0_M\rangle = \int dk\,|\beta_{\Omega k}|^2$$

推导：$b_\Omega|0_M\rangle = \int dk\,\beta_{\Omega k}\,a_k^\dagger|0_M\rangle$（$\alpha$ 项湮灭真空），再内积。

### 为什么 $\beta_{\Omega k} \neq 0$？

Minkowski 正频模 $u_k \propto e^{-i|k|t+ikx}$ 代入 Rindler 坐标：
$$u_k \propto e^{-i|k|\xi\sinh\eta + ik\xi\cosh\eta}$$

做关于 $\eta$ 的 Fourier 变换 → 同时出现 $e^{-i\Omega\eta}$（正频）和 $e^{+i\Omega\eta}$（负频）分量。非线性坐标变换不保持正频分解。

## 八、Unruh 效应（III.3–III.4）

### Unruh 温度

Bogoliubov 系数经围道积分后（本题给结果不要求算）：
$$|\beta_{\Omega k}|^2 = \frac{1}{e^{2\pi\Omega/a} - 1} \cdot \delta(\Omega-k) \cdot \text{(体积因子)}$$

粒子数密度满足 Planck 分布 → **Unruh 温度**：

$$T_U = \frac{a}{2\pi}, \quad T_U = \frac{\hbar a}{2\pi k_B c}\;\text{(SI)}$$

### 数值感受

| 加速度 | Unruh 温度 | 说明 |
|--------|-----------|------|
| $g = 9.8$ m/s² | $\sim 4 \times 10^{-20}$ K | 远低于任何可测温度 |
| $10^{21}$ m/s² | $\sim 4$ K | 液氦温区，但需要极端加速度 |
| $10^{25}$ m/s² | $\sim 4 \times 10^4$ K | 极高 |

日常感受不到不是因为 $4$ K 绝对小，而是日常加速度太小（$g \sim 10$ m/s²）。

### 粒子概念的观测者依赖性

```
正频分解 → 依赖时间坐标 → 依赖观测者运动状态
⟹ "粒子"不是绝对的，是观测者依赖的。
```

Minkowski 观测者用 $\partial_t$ 定义正频 → 真空 $|0_M\rangle$ → 粒子数为零
Rindler 观测者用 $\partial_\eta$ 定义正频 → 真空 $|0_R\rangle$ → 粒子数不为零

场的量子态 $|0_M\rangle$ 是唯一的物理实在，不同观测者用不同基去分解它，得到不同的粒子诠释。

### Unruh → Hawking

```
Unruh 效应：匀加速观测者在 Minkowski 真空中看到热辐射 T_U = a/2π
    ↓ 等效原理
静止于均匀引力场的观测者也应看到热辐射
    ↓ 强引力场
黑洞视界附近的观测者（抵抗引力而加速）应看到热辐射
    ↓
远处观测者也收到辐射 → Hawking 辐射，T_H = κ/2π
```

**对应：** Rindler 视界 ↔ 黑洞事件视界，匀加速 ↔ 黑洞外静止，$a \leftrightarrow \kappa$（表面引力）

## 九、Minkowski 真空的纠缠结构

$$|0_M\rangle \propto \exp\left( \int d\Omega\, e^{-\pi\Omega/a}\, b_\Omega^{R\dagger} b_\Omega^{L\dagger} \right) |0_R\rangle$$

这是 **Thermofield Double State** 的连续版本。求迹掉左楔形自由度 → 右楔形约化密度矩阵是温度为 $T_U$ 的热态。

## 十、易错点清单

| 错误 | 正确做法 |
|------|----------|
| 对 $1/\vert k\vert$ 用留数定理 | 非亚纯函数，拆分正负 $k$ 分别处理 |
| 直接展开 $[\phi,\pi]$ 反解对易子 | 先 Fourier 反解 $a_k$，再算 $[a_k,a_{k'}^\dagger]$ |
| 认为 Rindler 度规全局共形于 Minkowski | 不是共形，大 $\xi$ 近似共形；真正原因是场的共形不变性 |
| 混淆 $\partial_\eta$ 和 $\partial_t$ | 不同的 Killing 矢量 → 不同的正频分解 |
| $\beta_{\Omega k}$ 是"负频粒子占比" | $\beta$ 是 Bogoliubov 系数（反粒子模混入粒子模的幅度） |
| 正规序在弯曲时空也适用 | 弯曲时空真空能有引力效应，不能随意丢弃 |

## 十一、核心技巧

1. **反转法求对易子**：$\phi,\pi \xrightarrow{\text{Fourier}} a_k \xrightarrow{[\phi,\pi]=i\delta} [a_k,a_{k'}^\dagger]$
2. **坐标变换化简场方程**：$\rho = \ln\xi$ 化 Rindler 方程为标准波动方程
3. **对易子归一化求 Bogoliubov 条件**：$[b_\Omega, b_{\Omega'}^\dagger] = \delta \implies \int(|\alpha|^2 - |\beta|^2) = 1$
4. **$i\epsilon$ 正规化**：定义传播子因果结构，不是可选项
