## 6.11

设矢量算符 $\boldsymbol{\sigma}$ 在任何方向上的投影的本征值只能取 $\pm 1$ 求 $\boldsymbol{\sigma}$ 各分量间的代数关系

>[!S]
>设 $\mathbf{n}$ 是某个方向的单位向量，$\sigma_{n}$ 是该方向上的投影
>$$\sigma_{n} = \mathbf{n}\cdot \boldsymbol{\sigma} $$
>记它的本征值是 $\ket{\pm,\mathbf{n}}$ 即 $\sigma_{n}\ket{\pm,\mathbf{n}}=\pm \ket{\pm,\mathbf{n}}$ 则
>$$\sigma_{n}^{2}\ket{\pm,\mathbf{n}} =\ket{\pm,\mathbf{n}}  $$
>对于任何态 $\ket{\psi}$ 都能写成 $\ket{\pm,\mathbf{n}}$ 的线性组合，因为这两个本征态构成该二维希尔伯特空间的一组完备基。所以
>$$(\sigma_{n}^{2} - 1)\ket{\psi} = 0 $$
>于是 $\sigma_{n}$ 满足代数方程
>$$\sigma_{n}^{2} = 1 $$
>取 $\mathbf{n}$ 分别取为笛卡尔坐标系三条坐标轴，则
>$$\sigma_{x}^{2} = \sigma_{y}^{2} = \sigma_{z}^{2} = 1 $$
>一般的 $\sigma_{n}=\sigma_{x}n_{x} + \sigma_{y}n_{y} + \sigma_{z}n_{z}$ 则
>$$1 = \sigma_{n}^{2} = (\sigma_{x}^{2}n_{x}^{2} + \sigma_{y}^{2}n_{y}^{2} + \sigma_{z}^{2}n_{z}^{2}) + \sum_{\text{cyc}}(\sigma_{x}\sigma_{y} + \sigma_{y}\sigma_{z})n_{x}n_{y} $$
>$$\implies \sum_{\text{cyc}}(\sigma_{x}\sigma_{y} + \sigma_{y}\sigma_{z})n_{x}n_{y} = 0 $$
>而其中的 $n_{x}n_{y},n_{y}n_{z},n_{z}n_{x}$ 是独立的，所以其系数为零，即有代数关系
>$$\sigma_{x}\sigma_{y} = -\sigma_{y}\sigma_{x} ,\quad \dots $$
>$\boldsymbol{\sigma}$ 和 $1$ 构成封闭代数结构，故可设
>$$\sigma_{x}\sigma_{y} = a\sigma_{x} + b\sigma_{y} + c\sigma_{z} + d $$
>则
>$$\sigma_{y} = \sigma_{x}^{2}\sigma_{y} = a\sigma_{x}^{2} + b\sigma_{x}\sigma_{y} + c\sigma_{x}\sigma_{y} + d\sigma_{x} = a + d\sigma_{x} - b\sigma_{x}\sigma_{y} - c\sigma_{x}\sigma_{z}  $$
>$$-\sigma_{y} = a + d\sigma_{x} + b\sigma_{y}\sigma_{x} + c\sigma_{z}\sigma_{x} $$
>$$a+d\sigma_{x} = 0 $$
>而 $\sigma_{x}^{2} = 1$ 所以 $a=d=0$ 于是
>$$\sigma_{x}\sigma_{y} = b\sigma_{y} + c\sigma_{z} $$
>$$\sigma_{x}\sigma_{y}\sigma_{z}=b\sigma_{y}\sigma_{z} + c ,\quad \sigma_{z}\sigma_{x}\sigma_{y} = b\sigma_{z}\sigma_{y} + c $$
>而 $\sigma_{z}\sigma_{x}\sigma_{y}=-\sigma_{x}\sigma_{z}\sigma_{y}=\sigma_{x}\sigma_{y}\sigma_{z}$ 所以 $b=0$ 即 $\sigma_{x}\sigma_{y}\sigma_{z}=c$ 所以
>$$1 = \sigma_{z}\sigma_{y}\sigma_{x}\sigma_{x}\sigma_{y}\sigma_{z} = (-c)\cdot c = -c^{2} \implies c=i $$
>所以
>$$\sigma_{x}\sigma_{y}\sigma_{z} = i $$
>$$\sigma_{i}\sigma_{j} = i\varepsilon_{ijk}\sigma^{i}\sigma^{j} + \delta_{ij} $$
>

## 6.12

给定方向 $(\theta,\phi)$ 的单位向量
$$\mathbf{n} = (\sin \theta \cos \phi,\sin \theta \sin \phi,\cos \theta) $$
求 $\sigma_{n}=\boldsymbol{\sigma}\cdot \mathbf{n}$ 的本征值和本征函数，取 $\sigma_{z}$ 表象

>[!S]
>在 $\sigma_{z}$ 的表象下，基为 $\ket{\uparrow},\ket{\downarrow}$ ，泡利算符的三个分量的表示为
>$$\sigma_{x} = \begin{pmatrix}0 & 1\\1 & 0\end{pmatrix},\quad \sigma_{y}=\begin{pmatrix}0 & -i\\i & 0\end{pmatrix},\quad \sigma_{z}=\begin{pmatrix}1 & 0\\0 & -1\end{pmatrix} $$
>所以 $\sigma_{n}$ 的表示为
>$$\sigma_{n} = \boldsymbol{\sigma}\cdot \mathbf{n} = \begin{pmatrix}\cos \theta & \sin \theta e^{ -i\phi }\\sin \theta e^{ i\phi } & -\cos \theta\end{pmatrix} $$
>不妨设它的本征态为 $\ket{n}=C_{1}\ket{\uparrow} + C_{2}\ket{\downarrow}$ 则
>$$\sigma_{n}\ket{n} = C_{1}\sigma_{n}\ket{\uparrow} + C_{2}\sigma_{n}\ket{\downarrow} = \lambda C_{1}\ket{\uparrow} + \lambda C_{2}\ket{\downarrow} =\lambda \ket{n}  $$
>对应本征方程 $(\sigma_{n}-\lambda)\ket{n}=0$ 久期方程为
>$$\det\begin{pmatrix}\cos \theta-\lambda & \sin \theta e^{ -i\phi }\\sin \theta e^{ i\phi } & -\cos \theta-\lambda\end{pmatrix} = 0 $$
>$$\lambda=\pm 1 $$
>对于 $\lambda=1$ 的情况
>$$\begin{pmatrix}\cos \theta-1 & \sin \theta e^{ -i\phi }\\sin \theta e^{ i\phi } & -\cos \theta-1\end{pmatrix}\begin{pmatrix}C_{1} \\ C_{2}\end{pmatrix} = 0 $$
>$$\frac{C_{1}}{C_{2}} = \frac{1+\cos \theta}{\sin \theta}e^{ -i\phi } $$
>故其对应的本征函数为
>$$\braket{ \theta,\phi | n,+ } =C_{1}\braket{ \theta,\phi | \uparrow } + C_{2}\braket{ \theta,\phi | \downarrow } = C\begin{pmatrix} \cos \frac{\theta}{2}e^{ -i\phi/2 } \\ \sin \frac{\theta}{2}e^{ i\phi/2 } \end{pmatrix} $$
>对于 $\lambda=-1$ 的情况
>$$\begin{pmatrix}\cos \theta+1 & \sin \theta e^{ -i\phi }\\sin \theta e^{ i\phi } & -\cos \theta+1\end{pmatrix}\begin{pmatrix}C_{1} \\ C_{2}\end{pmatrix} = 0 $$
>$$\frac{C_{1}}{C_{2}} = - \frac{1-\cos \theta}{\sin \theta}e^{ -i\phi } $$
>故
>$$\braket{ \theta,\phi | n , - } = C \begin{pmatrix} \sin \frac{\theta}{2}e^{ -i\phi/2 } \\ -\cos \frac{\theta}{2}e^{ i\phi/2 } \end{pmatrix} $$


## 6.13

(a) 对于电子的自旋态 $\chi_{\frac{1}{2}}(\sigma_{z}=1)$ 求 $\sigma_{n}$ 的可能测得的值和概率
(b) 对于 $\sigma_{n}=1$ 的自旋态，求 $\sigma$ 各分量的可能测量值和概率，以及 $\boldsymbol{\sigma}$ 的期望值

>[!S]
>(a) 初态为 $\ket{\uparrow}=\begin{pmatrix} 1 \\ 0 \end{pmatrix}$ 而 $\sigma_{n}$ 在该基下的表达是
>$$\sigma_{n} = \begin{pmatrix}\cos \theta & \sin \theta e^{ -i\phi }\\sin \theta e^{ i\phi } & -\cos \theta\end{pmatrix} $$
>它的本征态是
>$$\ket{\pm,\mathbf{n}} = \begin{pmatrix}\cos \frac{\theta}{2}e^{ -i\phi/2 }\\ \pm \sin \frac{\theta}{2}e^{ i\phi/2 } \end{pmatrix} ,\quad \lambda=\pm 1 $$
>当 $\sigma_{n}\ket{+,\mathbf{n}}=\ket{+,\mathbf{n}}$ 时概率为
>$$|\braket{ \uparrow | +,\mathbf{n} } |^{2} = \cos^2 \frac{\theta}{2} $$
>当 $\sigma_{n}\ket{-,\mathbf{n}}=-\ket{-,\mathbf{n}}$ 时概率为
>$$|\braket{ \uparrow | -,\mathbf{n} } |^{2} = \sin^2 \frac{\theta}{2} $$
>(b) 初态为 $\ket{+,\mathbf{n}}$ ，仍然以 $\ket{\uparrow},\ket{\downarrow}$ 为基。测量 $\sigma_{x,y,z}$ 时的值仍然只可能是 $\pm 1$ 。测量 $\sigma_{z}$ 
>$\sigma_{z}=1$ 时 $|\braket{ +,\mathbf{n} | \uparrow }|^{2}=\cos^2 \frac{\theta}{2}$ 与上衣问一致，同理 $\sigma_{z}=-1$ 时 $|\braket{ +,\mathbf{n} | \downarrow }|^{2}=\sin^2 \frac{\theta}{2}$ 可以表示为
>$$P(\sigma_{z}=1) = \frac{1}{2}(1+n_{z}) ,\quad P(\sigma_{z}=-1)=\frac{1}{2}(1-n_{z}) $$
>轮换即可得到
>$$\begin{align}
P(\sigma_{y}=1) = \frac{1}{2}(1+n_{y}) ,\quad P(\sigma_{y}=-1)=\frac{1}{2}(1-n_{y}) \\ P(\sigma_{x}=1) = \frac{1}{2}(1+n_{x}) ,\quad P(\sigma_{x}=-1)=\frac{1}{2}(1-n_{x}) 
\end{align}$$


## 6.14

(a) 证明泡利矩阵和单位矩阵构成 $2\times 2$ 矩阵的完备基
(b) 将任意的 $2\times 2$ 的矩阵表示为泡利矩阵和单位矩阵的线性叠加

>[!S]
>(a) 假设它们线性相关，即存在不全为零的 $C_{1},C_{2},C_{3},C_{4}$ 使得
>$$C_{1}\sigma_{x} + C_{2}\sigma_{y} + C_{3}\sigma_{z} + C_{4}I = 0 $$
>则 $\mathrm{Tr}(C_{1}\sigma_{x} + C_{2}\sigma_{y} + C_{3}\sigma_{z} + C_{4}I )=0$ 而 $\mathrm{Tr}(\sigma_{i})=0,\mathrm{Tr}(I)=2$ 故 $C_{4}=0$ 于是
>$$C_{1}\sigma_{x} + C_{2}\sigma_{y} + C_{3}\sigma_{z}  = 0  $$
>这与 $\sigma_{x,y,z}$ 独立相矛盾，故泡利矩阵和单位矩阵相互独立，所以构成一个 $2\times 2$ 矩阵的完备基
>(b) 设
>$$M = M_{1}\sigma_{x} + M_{2}\sigma_{y} + M_{3}\sigma_{z} + M_{4}I ,\quad M_{i}\in \mathbb{C} $$
>则 $\mathrm{Tr}(M)=2M_{4}$ 而
>$$M\sigma_{x} = M_{1}I - iM_{2}\sigma_{z} + iM_{3}\sigma_{y} + M_{4}\sigma_{x} $$
>$$\mathrm{Tr}(M\sigma _{x}) = 2M_{1} $$
>类似的可得 $M_{i}=\frac{1}{2}\mathrm{Tr}(M\sigma_{i})$ 所以
>$$M = \frac{1}{2}[ \mathrm{Tr}(M)I + \mathrm{Tr}(M\boldsymbol{\sigma})\cdot \boldsymbol{\sigma} ] $$


## 6.15

证明与 $\boldsymbol{\sigma}$ 的三个分量都对易的非零二维矩阵必定是常矩阵

>[!S]
>由题意这样的矩阵满足
>$$M\boldsymbol{\sigma} = \boldsymbol{\sigma}M $$
>而
>$$M = \frac{\mathrm{Tr}(M)I + \mathrm{Tr}(M\boldsymbol{\sigma})\cdot \boldsymbol{\sigma}}{2} $$
>所以
>$$\mathrm{Tr}(M)\boldsymbol{\sigma} + [\mathrm{Tr}(M\boldsymbol{\sigma})\cdot \boldsymbol{\sigma}]\boldsymbol{\sigma} = \mathrm{Tr}(M)\boldsymbol{\sigma} + \boldsymbol{\sigma}[\mathrm{Tr}(M\boldsymbol{\sigma})\cdot \boldsymbol{\sigma}] $$
>即 $\boldsymbol{\sigma}$ 与 $\mathrm{Tr}(M\boldsymbol{\sigma})\cdot \boldsymbol{\sigma}$ 对易，而 $[\sigma_{i},\sigma_{j}]=2i\varepsilon_{ijk}\sigma^{k}$ 所以其系数必定为零，于是
>$$M = \frac{\mathrm{Tr}(M)}{2}I $$
>是常数矩阵


## 6.16

证明不存在与三个泡利矩阵都反对易的非零二维矩阵

>[!S]
>设 $A$ 与 $\boldsymbol{\sigma}$ 反对易
>$$A\sigma_{x} = -\sigma_{x}A ,\quad \dots $$
>则
>$$A\sigma_{x}\sigma_{y} = iA\sigma_{z} = -\sigma_{x}A\sigma_{y} $$
>于是
>$$-i\sigma_{z}A = -\sigma_{x}A\sigma_{y} = \sigma_{x}\sigma_{y}A = i\sigma_{z}A $$
>所以
>$$-A = A \implies A=0 $$

## 6.22

设 $\lambda \in \mathbb{R}$ 证明
$$e^{ i\lambda \sigma_{z} } = \cos \lambda + i\sigma_{z}\sin \lambda $$

>[!S]
>由定义
>$$e^{ i\lambda \sigma_{z} } = \sum_{n=0}^{\infty} \frac{(i\lambda)^{n}}{n!} (\sigma_{z})^{n} $$
>而 $(\sigma_{z})^{2k}=1,(\sigma_{z})^{2k+1}=\sigma_{z}$ 故
>$$e^{ i\lambda \sigma_{z} } = \sum_{k=0}^{\infty} \frac{(i\lambda)^{2k}}{(2k)!} + \sum_{k=0}^{\infty} \frac{(i\lambda)^{2k+1}}{(2k+1)!}\sigma_{z} = \cos \lambda + i\sigma_{z}\sin \lambda $$


>[!S]
>考虑到 $e^{ i\lambda \sigma_{z} }$ 是 $\sigma_{z}$ 的函数，而 $\sigma_{z}$ 的本征值为 $\pm 1$ 所以 $e^{ i\lambda \sigma_{z} }$ 的本征值为 $e^{ \pm i\lambda }$ 也就是说在 $\sigma_{z}$ 的表象下 $e^{ i\lambda \sigma_{z} }$ 的表示是
>$$ \begin{pmatrix} e^{ i\lambda } & 0 \\ 0 & e^{ -i\lambda } \end{pmatrix} = \begin{pmatrix} \cos \lambda+i\sin \lambda & 0 \\ 0 & \cos \lambda - i\sin \lambda\end{pmatrix} = \cos \lambda I + i\sigma_{z}\sin \lambda $$


## 6.24

化简
$$e^{ i\lambda \sigma_{z} }\sigma_{i}e^{ -i\lambda \sigma_{z} } ,\quad i=x,y$$

>[!S]
>由 6.22 可知 $e^{ i\lambda \sigma_{z} }=\cos \lambda +i\sigma_{z}\sin \lambda$ 于是
>$$\begin{align}
e^{ i\lambda \sigma_{z} }\sigma_{i}e^{ -i\lambda \sigma_{z} } & = (\cos \lambda+i\sigma_{z}\sin \lambda)\sigma_{i}(\cos \lambda-i\sigma_{z}\sin \lambda) \\ & = \cos^2\lambda \sigma_{i} + i\cos \lambda \sin \lambda (\sigma_{z}\sigma_{i}-\sigma_{i}\sigma_{z}) + \sin^2\lambda \sigma_{z}\sigma_{i}\sigma_{z} \\ & = \cos^2\lambda \sigma_{i} \mp2 \cos \lambda \sin \lambda \sigma_{j} - \sin^2\lambda \sigma_{i} \\ & = \sigma_{i}\cos 2\lambda \mp \sigma_{j}\sin 2\lambda
\end{align}$$
>对于 $i=x$ 取负号，对于 $i=y$ 取正号


>[!S]
>令
>$$f(\lambda) = e^{ i\lambda \sigma_{z} }\sigma_{x}e^{ -i\lambda \sigma_{z} } ,\quad g(\lambda) = e^{ i\lambda \sigma_{z} }\sigma_{y}e^{ -i\lambda \sigma_{z} } $$
>则 $f(0)=\sigma_{x},g(0)=\sigma_{y}$ 而
>$$\frac{df}{d\lambda} = ie^{ i\lambda \sigma_{z} }(\sigma_{z}\sigma_{x}-\sigma_{x}\sigma_{z})e^{ -i\lambda \sigma_{z} } = -2e^{ i\lambda \sigma_{z} }\sigma_{y}e^{ -i\lambda \sigma_{z} } = -2g(\lambda) $$
>$$\frac{dg}{d\lambda} = -2f(\lambda) $$
>解得
>$$f(\lambda) = \sigma_{x}\cos 2\lambda - \sigma_{y}\sin 2\lambda ,\quad g(\lambda) = \sigma_{x}\cos 2\lambda + \sigma_{y}\sin 2\lambda $$


## 6.25

定义
$$\sigma_{\pm} = \sigma_{x} \pm i\sigma_{y} ,\quad \sigma_{-} = (\sigma_{+})^{\dagger} $$
(a) 计算 $[\sigma_{+},\sigma_{-}],[\sigma_{z},\sigma_{\pm}]$ 证明 $(\sigma_{+}^{2})=(\sigma_{-}^{2})=0$
(b) 证明 $e^{ \xi \sigma_{z} }\sigma_{\pm}=\sigma_{\pm}e^{ \xi \sigma_{z} }e^{ \pm 2\xi }$
(c) 化简 $e^{ \xi \sigma_{z} }\sigma_{x}e^{ -\xi \sigma_{z} }$

>[!S]
>(a)
>$$\begin{align}
[\sigma_{+},\sigma_{-}] & = (\sigma_{x}+i\sigma_{y})(\sigma_{x}-i\sigma_{y}) - (\sigma_{x}-i\sigma_{y})(\sigma_{x}+i\sigma_{y}) \\ & = 1 -i\sigma_{x}\sigma_{y} + i\sigma_{y}\sigma_{x} + 1 - ( 1 -i\sigma_{x}\sigma_{y} + i\sigma_{y}\sigma_{x} + 1 ) \\ & = 4\sigma_{z}
\end{align} $$
>$$\begin{align}
[\sigma_{z},\sigma_{\pm}] & = \sigma_{z}(\sigma_{x}\pm i\sigma_{y}) - (\sigma_{x}\pm i\sigma_{y})\sigma_{z} \\ & = i\sigma_{y} \mp ii\sigma_{x} + i\sigma_{y} \mp ii\sigma_{x} \\ & = \pm 2\sigma_{\pm}
\end{align}  $$
>$$\sigma_{+}^{2} = (\sigma_{x}+i\sigma_{y})^{2} = 1 -1 +i(\sigma_{x}\sigma_{y}+\sigma_{y}\sigma_{x}) = 0 $$
>(b)
>由 $[\sigma_{z}\sigma_{\pm}]=\pm 2\sigma_{\pm}$ 知 $\sigma_{z}\sigma_{\pm} = \sigma_{\pm}(\sigma_{z}\pm 2)$ 所以
>$$\sigma_{z}^{n}\sigma_{\pm} = \sigma_{\pm}(\sigma_{z}\pm 2)^{n} $$
>$$f(\sigma_{z})\sigma_{\pm} = \sigma_{\pm}f(\sigma_{z}\pm 2) $$
>于是
>$$e^{ \xi \sigma_{z} }\sigma_{\pm} = \sigma_{\pm}e^{ \xi(\sigma_{z}\pm 2) } = \sigma_{\pm}e^{ \xi \sigma_{\pm} }e^{ \pm 2\xi } $$
>(c)
>由定义知
>$$\sigma_{x} = \frac{\sigma_{+}+\sigma_{-}}{2} $$
>所以
>$$e^{ \xi \sigma_{z} }\sigma_{x} = \frac{1}{2}(e^{ \xi \sigma_{z} }\sigma_{+}+e^{ \xi \sigma_{z} }\sigma_{-}) = \frac{1}{2}(\sigma_{+}e^{ \xi \sigma_{z} }e^{ 2\xi }+\sigma_{-}e^{ \xi \sigma_{z} }e^{ -2\xi }) $$
>$$e^{ \xi \sigma_{z} }\sigma_{x}e^{ -\xi \sigma_{z} } = \frac{1}{2}(\sigma_{+}e^{ 2\xi } + \sigma_{-}e^{ -2\xi }) $$

## 6.26

设 $\lambda \in \mathbb{R}$ ，$\mathbf{n}$ 是方向 $(\theta,\phi)$ 的单位向量，证明
$$e^{ i\lambda \sigma_{n} }\boldsymbol{\sigma}e^{ -i\lambda \sigma_{n} } = \mathbf{n}\sigma_{n} + (\mathbf{n}\times \boldsymbol{\sigma})\times \mathbf{n}\cos 2\lambda + \mathbf{n}\times \boldsymbol{\sigma} \sin 2\lambda $$

>[!S]
>令
>$$f(\lambda) = e^{ i\lambda \sigma_{n} }\boldsymbol{\sigma}e^{ -i\lambda \sigma_{n} } $$
>则 $f(0)=\boldsymbol{\sigma},\mathbf{n}\cdot f=e^{ i\lambda \sigma_{n} }\sigma_{n}e^{ -i\lambda \sigma_{n} }$ 
>$$\frac{df}{d\lambda} = ie^{ i\lambda \sigma_{n} }[\sigma_{n},\boldsymbol{\sigma}]e^{ -i\lambda \sigma_{n} } $$
>其中 $[\sigma_{n},\boldsymbol{\sigma}]=[\boldsymbol{\sigma}\cdot \mathbf{n},\boldsymbol{\sigma}]=-2i\mathbf{n}\times \boldsymbol{\sigma}$ 所以
>$$\frac{df}{d\lambda} = 2\mathbf{n}\times f $$
>$$\mathbf{n}\times \frac{df}{d\lambda} = 2(\mathbf{n}\cdot f)\mathbf{n} - 2f = 2\mathbf{n}\sigma_{n} - 2f $$
>$$\frac{d}{d\lambda}(f + i\mathbf{n}\times f) = -2i(f + i\mathbf{n}\times f - \mathbf{n}\sigma_{n}) $$
>解得
>$$f(\lambda) = \boldsymbol{\sigma}\cos 2\lambda + \mathbf{n}\times \boldsymbol{\sigma}\sin 2\lambda + \mathbf{n}\sigma_{n}(1-\cos 2\lambda) $$
