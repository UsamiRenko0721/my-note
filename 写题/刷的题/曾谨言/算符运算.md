# 含参算符

## 3.13

从谐振子的升降算符 $a^{\dagger},a$ 出发由基本对易关系 $[a^{\dagger},a]=1$ 证明
$$e^{ \lambda a^{\dagger}a } a e^{ -\lambda a^{\dagger}a } = e^{ -\lambda } a $$
对于 $\lambda>0$ 计算
$$T(\lambda) = \mathrm{Tr}e^{ -\lambda a^{\dagger}a } $$
并以此讨论 $a^{\dagger}a$ 的本征值谱

>[!S]
>令 $f(\lambda)=e^{ \lambda a^{\dagger}a }ae^{ -\lambda a^{\dagger}a }$ 则
>$$f(0) = a ,\quad \frac{df}{d\lambda} = e^{ \lambda a^{\dagger}a }(a^{\dagger}aa - aa^{\dagger}a)e^{ -\lambda a^{\dagger}a } = -f(\lambda) $$
>解这个微分方程得到
>$$f(\lambda) = f(0)e^{ -\lambda } = e^{ -\lambda }a $$
>即
>$$e^{ \lambda a^{\dagger}a } a e^{ -\lambda a^{\dagger}a } = e^{ -\lambda } a $$
>所以 $ae^{ -\lambda a^{\dagger}a }=e^{ -\lambda }e^{ -\lambda a^{\dagger}a }a$ 
>$$\begin{align}
\frac{dT}{d\lambda} & = \mathrm{Tr}(-a^{\dagger}ae^{ -\lambda a^{\dagger}a }) \\ &  = \mathrm{Tr}(-a^{\dagger}e^{ -\lambda }e^{ -\lambda a^{\dagger}a }a) \\ &  = -e^{ -\lambda }\mathrm{Tr}(aa^{\dagger}e^{ -\lambda a^{\dagger}a })  \\ & = -e^{ -\lambda }\mathrm{Tr}((1+a^{\dagger}a)e^{ -\lambda a^{\dagger}a }) \\ & = e^{-\lambda}[ -\mathrm{Tr}(e^{ -\lambda a^{\dagger}a }) - \mathrm{Tr}(a^{\dagger}ae^{ -\lambda a^{\dagger}a }) ] \\ & = e^{ -\lambda }\left( -T( \lambda) + \frac{dT}{d\lambda}  \right)
\end{align}$$
>解得
>$$T(\lambda) = \frac{C}{1-e^{ -\lambda }} $$
>而
>$$T(\lambda) = \mathrm{Tr}(e^{ -\lambda a^{\dagger}a }) = \sum_{n}e^{ -\lambda k_{n} } ,\quad k_{n}\text{ 是本征值} $$
>所以必有 $k_{0}=0$ 否则 $T(\infty)=0$ 与 $T(\infty)=C\neq 0$ 矛盾，不妨令 $C=1$ 则
>$$T(\lambda) = 1 + e^{ -\lambda } + e^{ -2\lambda } + \dots $$
>所以可知 $a^{\dagger}a$ 的本征谱是 $0,1,2,\dots$


## 4.14

设 $A$ 为无量纲算符，$\xi,\eta$ 是参变量，定义
$$e^{ \xi A } = \sum_{n=0}^{\infty} \frac{\xi^{n}}{n!}A^{n} = 1 + \xi A + \frac{\xi^{2}}{2}A^{2} + \dots $$
试证明
$$\begin{gather}
e^{ (\xi+\eta)A } = e^{ \xi A }e^{ \eta A }  \\
\frac{d}{d\xi}e^{ \xi A } = Ae^{ \xi A }
\end{gather} $$

>[!S]
>由定义
>$$e^{ (\xi+\eta)A } = \sum_{k=0}^{\infty} \frac{(\xi+\eta)^{k}}{k!}A^{k} ,\quad (\xi+\eta)^{k} = \sum_{m=0}^{k} {{k}\choose{m}} \xi^{m}\eta^{k-m} $$
>于是
>$$\begin{align} e^{ (\xi+\eta)A } & = \sum_{k=0}^{\infty}\sum_{m=0}^{k} {{k}\choose{m}} \frac{\xi^{m}\eta^{k-m}}{k!} A^{k} \\ & = \sum_{k=0}^{\infty}\sum_{k-m=0}^{\infty} \frac{\xi^{m}\eta^{k-m}}{k!(k-m)!}A^{m+(k-m)} \\ & = \sum_{m=0}^{\infty}\sum_{n=0}^{\infty} \frac{\xi^{m}\eta^{n}}{m!n!}A^{m+n} \\ & = e^{ \xi A }e^{ \eta A } \end{align} $$
>而
>$$\frac{d}{d\xi}e^{ \xi A } = \sum_{n=0}^{\infty} \frac{d}{d\xi} \frac{\xi^{n}}{n!} A^{n} = \sum_{n=1}^{\infty} \frac{\xi^{n-1}}{(n-1)!} A^{n} = A\sum_{n-1=0}^{\infty} \frac{\xi^{n-1}}{(n-1)!} A^{n-1} = Ae^{ \xi A } $$


## 4.17

如果算符 $A(\xi)$ 是参数 $\xi$ 的函数，定义 $A(\xi)$ 对 $\xi$ 的求导为
$$\frac{d}{d\xi}A(\xi) = \lim_{ \varepsilon \to 0 } \frac{A(\xi+\varepsilon)-A(\xi)}{\varepsilon} $$
(a) 证明
$$\frac{d}{d\xi}( A(\xi)B(\xi) ) = \frac{dA}{d\xi}B + A \frac{dB}{d\xi} $$
(b) 若 $A^{-1}$ 存在，证明
$$\frac{d}{d\xi}A^{-1} = -A^{-1} \frac{dA}{d\xi} A^{-1} $$

>[!S]
>(a) 由定义
>$$A(\xi+\varepsilon) = A(\xi) + \varepsilon\frac{dA}{d\xi} + \mathcal{O}(\varepsilon^{2}) $$
>$$\begin{align}
\frac{d}{d\xi}( AB ) & = \lim_{ \varepsilon \to 0 } \frac{( A(\xi+\varepsilon)B(\xi+\varepsilon) ) - ( A(\xi)  B(\xi) )}{\varepsilon} \\ &  = \lim_{ \varepsilon \to 0 } \frac{1}{\varepsilon}\left[  \left(A( \xi) + \varepsilon  \frac{dA}{d\xi} \right)\left( B(\xi) + \varepsilon  \frac{dB}{d\xi}  \right) -A(\xi)B(\xi) \right] \\ & = \lim_{ \varepsilon \to 0 } \varepsilon  \frac{dA}{d\xi} \frac{dB}{d\xi} + A \frac{dB}{d\xi} + \frac{dA}{d\xi} B\\ & = A \frac{dB}{d\xi} + \frac{dA}{d\xi} B
\end{align}$$
>(b) 由逆算符定义
>$$A(\xi)A^{-1}(\xi) = 1 $$
>应用 (a) 的公式得到
>$$0 = A \frac{dA^{-1}}{d\xi} + \frac{dA}{d\xi} A^{-1} $$
>所以
>$$\frac{dA^{-1}}{d\xi} = A^{-1} \frac{dA}{d\xi}A^{-1} $$


## 4.18 BCH

给定算符 $A,B$ 定义
$$C_{0}=B ,\quad C_{1} = [A,B] ,\quad C_{n} = [A,C_{n-1}] $$
证明
$$e^{ A }Be^{ -A } = \sum_{n=0}^{\infty} \frac{C_{n}}{n!} $$

>[!S]
>引入参数 $\xi$ :
>$$f(\xi) = e^{ \xi A }Be^{ -\xi A } $$
>则
>$$f(0) = B ,\quad f(1) = e^{ \xi A }Be^{ -\xi A } ,\quad \frac{df}{d\xi} = e^{ \xi A }(AB - BA)e^{ -\xi A } = e^{ \xi A }C_{1}e^{ -\xi A } $$
>故递推得
>$$f^{(n)}(\xi) = e^{ \xi A }C_{n}e^{ -\xi A } $$
>又泰勒公式得
>$$f(1) = f(0) + \sum_{n=1}^{\infty} \frac{1}{n!}f^{(n)}(1) $$
>所以
>$$e^{ A }Be^{ -A } = \sum_{n=0}^{\infty} \frac{C_{n}}{n!} $$


## 4.20 Glauber

设算符 $A,B$ 不对易 $[A,B]=C$ 且 $C$ 分别与 $A,B$ 对易，证明
$$e^{ A+B } = e^{ A }e^{ B }e^{ -C/2 } = e^{ B }e^{ A }e^{ C/2 } $$

>[!S]
>引入参数
>$$f(\lambda) = e^{ \lambda A }e^{ \lambda B } $$
>则
>$$f(0) = 1 ,\quad f(1) = e^{ A }e^{ B } ,\quad \frac{df}{d\lambda} = e^{ \lambda A }(A+B)e^{ \lambda B } $$
>而考虑到 BCH 公式，我们有 $e^{ \lambda A }Be^{ -\lambda A }=B+[\lambda A,B] + [\lambda A,[\lambda A,B]] + \dots$ 而又高阶对易子为零故 $$e^{ \lambda A }Be^{ -\lambda A } = B + \lambda C $$
>类似的 $e^{ \lambda B }Ae^{ -\lambda B }=A+\lambda C$ 由此
>$$\begin{align}
\frac{df}{d\lambda} & = e^{ \lambda A }Ae^{ -\lambda B } + e^{ \lambda A }Be^{ -\lambda B } \\ & = e^{ \lambda A }e^{ \lambda B }(A+\lambda C) + e^{ \lambda A }e^{ \lambda B }(B+\lambda C) \\ & = e^{ \lambda A }e^{ \lambda B }(A+B+2\lambda C) \\ & = f(\lambda)(A+B+2\lambda C)
\end{align}$$
>解得 
>$$f(\lambda) = f(0)\exp\left[ \lambda A+\lambda B + \frac{\lambda^{2}}{2}C \right] = \exp\left[ \lambda A+\lambda B + \frac{\lambda^{2}}{2}C \right] $$
>于是 $f(1)=e^{ A }e^{ B }=e^{ A+B+C/2 }$ 即
>$$e^{ A+B } = e^{ A }e^{ B }e^{ -C/2 } $$


## 6.24

化简
$$e^{ i\lambda \sigma_{z} }\sigma_{i}e^{ -i\lambda \sigma_{z} } ,\quad i=x,y$$

>[!S]
>令
>$$f(\lambda) = e^{ i\lambda \sigma_{z} }\sigma_{x}e^{ -i\lambda \sigma_{z} } ,\quad g(\lambda) = e^{ i\lambda \sigma_{z} }\sigma_{y}e^{ -i\lambda \sigma_{z} } $$
>则 $f(0)=\sigma_{x},g(0)=\sigma_{y}$ 而
>$$\frac{df}{d\lambda} = ie^{ i\lambda \sigma_{z} }(\sigma_{z}\sigma_{x}-\sigma_{x}\sigma_{z})e^{ -i\lambda \sigma_{z} } = -2e^{ i\lambda \sigma_{z} }\sigma_{y}e^{ -i\lambda \sigma_{z} } = -2g(\lambda) $$
>$$\frac{dg}{d\lambda} = -2f(\lambda) $$
>解得
>$$f(\lambda) = \sigma_{x}\cos 2\lambda - \sigma_{y}\sin 2\lambda ,\quad g(\lambda) = \sigma_{x}\cos 2\lambda + \sigma_{y}\sin 2\lambda $$


## 6.26

设 $\lambda \in \mathbb{R}$ ，$\mathbf{n}$ 是方向 $(\theta,\phi)$ 的单位向量，证明
$$e^{ i\lambda \sigma_{n} }\boldsymbol{\sigma}e^{ -i\lambda \sigma_{n} } = \mathbf{n}\sigma_{n} + (\mathbf{n}\times \boldsymbol{\sigma})\times \mathbf{n}\cos 2\lambda + \mathbf{n}\times \boldsymbol{\sigma} \sin 2\lambda $$

>[!S]
>令
>$$f(\lambda) = e^{ i\lambda \sigma_{n} }\boldsymbol{\sigma}e^{ -i\lambda \sigma_{n} } $$
>则 $f(0)=\boldsymbol{\sigma},\mathbf{n}\cdot f=e^{ i\lambda \sigma_{n} }\sigma_{n}e^{ -i\lambda \sigma_{n} }$ 
>$$\frac{df}{d\lambda} = ie^{ i\lambda \sigma_{n} }[\sigma_{n},\boldsymbol{\sigma}]e^{ -i\lambda \sigma_{n} } $$
>其中 $[\sigma_{n},\boldsymbol{\sigma}]=[\boldsymbol{\sigma}\cdot \mathbf{n},\boldsymbol{\sigma}]=-2i\mathbf{n}\times \boldsymbol{\sigma}$ 所以
>$$\frac{df}{d\lambda} = 2\mathbf{n}\times f $$
>$$\mathbf{n}\times \frac{df}{d\lambda} = 2(\mathbf{n}\cdot f)\mathbf{n} - 2f = 2\mathbf{n}\sigma_{n} - 2f $$
>$$\frac{d}{d\lambda}(f + i\mathbf{n}\times f) = -2i(f + i\mathbf{n}\times f - \mathbf{n}\sigma_{n}) $$
>解得
>$$f(\lambda) = \boldsymbol{\sigma}\cos 2\lambda + \mathbf{n}\times \boldsymbol{\sigma}\sin 2\lambda + \mathbf{n}\sigma_{n}(1-\cos 2\lambda) $$

## 6.11

设 $\boldsymbol{\sigma}$ 在任何方向的投影本征值只能取 $\pm 1$ 求 $\boldsymbol{\sigma}$ 各个分量间的代数关系

>[!S]
>记 $\sigma_{n}=\boldsymbol{\sigma}\cdot \mathbf{n}$ 其本征态记为 $\ket{\mathbf{n},\pm}$ 即
>$$\sigma_{n}\ket{\mathbf{n},\pm} =\pm \ket{\mathbf{n},\pm}  $$
>于是
>$$\sigma_{n}^{2}\ket{\mathbf{n},\pm} =\ket{\mathbf{n},\pm}  $$
>所以 $\sigma_{n}$ 满足代数关系
>$$\sigma_{n}^{2} - 1 = 0 \tag{a}$$
>取 $\mathbf{n}$ 分别取为三个坐标轴，则分别得到
>$$\sigma_{x}^{2} = \sigma_{y}^{2} = \sigma_{z}^{2} = 1 $$
>将 (a) 按方向展开得到
>$$\sum_{\text{cyc}}\sigma_{x}^{2}n_{x}^{2} + \sum_{\text{cyc}} (\sigma_{x}\sigma_{y}+\sigma_{y}\sigma_{x})n_{x}n_{y} = 1 $$
>由于 $\mathbf{n}$ 是任意的，而 $\sum_{\text{cyc}}\sigma_{x}^{2}n_{x}^{2}=\sum_{\text{cyc}}n_{x}^{2}\equiv 1$ 所以第二项的系数必为零，即
>$$\sigma_{x}\sigma_{y}=-\sigma_{y}\sigma_{x} ,\quad \text{轮换} $$
>由于 $\sigma$ 和 $1$ 构成了封闭代数结构，见 6.14，故可设
>$$\sigma_{x}\sigma_{y} = a\sigma_{x} + b\sigma_{y} + c\sigma_{z} + d $$
>于是
>$$\sigma_{x}^{2}\sigma_{y} = \sigma_{y} = a + b\sigma_{x}\sigma_{y} + c\sigma_{x}\sigma_{z} + d\sigma_{x} $$
>$$\sigma_{x}\sigma_{y}\sigma_{x} = -\sigma_{y} = a + b\sigma_{y}\sigma_{x} + c\sigma_{z}\sigma_{x} + d\sigma_{x} $$
>$$2a + 2d\sigma_{z} = 0 $$
>而 $\sigma_{z},1$ 相互独立，所以 $a=d=0$ 于是
>$$\sigma_{x}\sigma_{y} = b\sigma_{y} + c\sigma_{z} $$
>于是
>$$\sigma_{x}\sigma_{y}\sigma_{z} = b\sigma_{y}\sigma_{z} + c $$
>$$\sigma_{z}\sigma_{x}\sigma_{y} = \sigma_{x}\sigma_{y}\sigma_{z} = b\sigma_{z}\sigma_{y} + c $$
>所以 $\sigma_{x}\sigma_{y}\sigma_{z}=c$ 即 $b=0$ 所以
>$$c^{2} = \sigma_{x}\sigma_{y}\sigma_{z}\sigma_{x}\sigma_{y}\sigma_{z} = -1,\quad c=i $$
>即
>$$\sigma_{x}\sigma_{y} = i\sigma_{z} $$
>轮换得到剩下的关系，综上所述
>$$\boxed{\sigma_{a}\sigma_{b} = i\varepsilon_{abc}\sigma^{c} + \delta_{ab}} $$


## 6.14

(a) 证明泡利矩阵和单位矩阵构成 $2\times 2$ 矩阵的完备基
(b) 将任意的 $2\times 2$ 的矩阵表示为泡利矩阵和单位矩阵的线性叠加

>[!S]
>(a) 假设它们线性相关，即存在不全为零的 $C_{1},C_{2},C_{3},C_{4}$ 使得
>$$C_{1}\sigma_{x} + C_{2}\sigma_{y} + C_{3}\sigma_{z} + C_{4}I = 0 $$
>则 $\mathrm{Tr}(C_{1}\sigma_{x} + C_{2}\sigma_{y} + C_{3}\sigma_{z} + C_{4}I )=0$ 而 $\mathrm{Tr}(\sigma_{i})=0,\mathrm{Tr}(I)=2$ 故 $C_{4}=0$ 于是
>$$C_{1}\sigma_{x} + C_{2}\sigma_{y} + C_{3}\sigma_{z}  = 0  $$
>这与 $\sigma_{x,y,z}$ 独立相矛盾，故泡利矩阵和单位矩阵相互独立，所以构成一个 $2\times 2$ 矩阵的完备基
>(b) 设
>$$M = M_{1}\sigma_{x} + M_{2}\sigma_{y} + M_{3}\sigma_{z} + M_{4}I ,\quad M_{i}\in \mathbb{C} $$
>则 $\mathrm{Tr}(M)=2M_{4}$ 而
>$$M\sigma_{x} = M_{1}I - iM_{2}\sigma_{z} + iM_{3}\sigma_{y} + M_{4}\sigma_{x} $$
>$$\mathrm{Tr}(M\sigma _{x}) = 2M_{1} $$
>类似的可得 $M_{i}=\frac{1}{2}\mathrm{Tr}(M\sigma_{i})$ 所以
>$$M = \frac{1}{2}[ \mathrm{Tr}(M)I + \mathrm{Tr}(M\boldsymbol{\sigma})\cdot \boldsymbol{\sigma} ] $$

## 6.20

计算 $\mathrm{Tr}(\boldsymbol{\sigma}\cdot \mathbf{A})$ 、 $\mathrm{Tr}[(\boldsymbol{\sigma}\cdot \mathbf{A})(\boldsymbol{\sigma}\cdot \mathbf{B})]$ 和 $\mathrm{Tr}[(\boldsymbol{\sigma}\cdot \mathbf{A})(\boldsymbol{\sigma}\cdot \mathbf{B})(\boldsymbol{\sigma}\cdot \mathbf{C})]$ 其中 $\mathbf{A},\mathbf{B},\mathbf{C}$ 与 $\boldsymbol{\sigma}$ 对易

>[!S]
>显然的
>$$\mathrm{Tr}(\boldsymbol{\sigma}\cdot \mathbf{A}) = \sum_{\text{cyc}}\mathrm{Tr}(A_{x}\sigma_{x}) = 0 $$
>而
>$$(\boldsymbol{\sigma}\cdot \mathbf{A})(\boldsymbol{\sigma}\cdot \mathbf{B}) = \mathbf{A}\cdot \mathbf{B} + i\boldsymbol{\sigma}\cdot(\mathbf{A}\times \mathbf{B}) $$
>$$\mathrm{Tr}[(\boldsymbol{\sigma}\cdot \mathbf{A})(\boldsymbol{\sigma}\cdot \mathbf{B})] = \mathrm{Tr}(\mathbf{A}\cdot \mathbf{B}) + i\mathrm{Tr}[\boldsymbol{\sigma}\cdot(\mathbf{A}\times \mathbf{B})]$$
>其中第一部分为 $2\mathbf{A}\cdot \mathbf{B}$ 第二部分和第一个计算没区别，所以结果是零。
>$$(\boldsymbol{\sigma}\cdot \mathbf{A})(\boldsymbol{\sigma}\cdot \mathbf{B})(\boldsymbol{\sigma}\cdot \mathbf{C}) = (\mathbf{A}\cdot \mathbf{B})(\boldsymbol{\sigma}\cdot \mathbf{C}) + i[\boldsymbol{\sigma}\cdot(\mathbf{A}\times \mathbf{B})](\boldsymbol{\sigma}\cdot \mathbf{C}) $$
>第一项是 $\boldsymbol{\sigma}$ 线性项求迹自动为零，剩下第二项，其还是 6.19 的形式，所以求迹就是对 $(\mathbf{A}\times \mathbf{B})\cdot \mathbf{C}$ 求迹，所以
>$$\mathrm{Tr}[(\boldsymbol{\sigma}\cdot \mathbf{A})(\boldsymbol{\sigma}\cdot \mathbf{B})(\boldsymbol{\sigma}\cdot \mathbf{C})]=2i(\mathbf{A}\times \mathbf{B})\cdot \mathbf{C}$$

## 6.26

设 $\lambda \in \mathbb{R}$ ，$\mathbf{n}$ 是方向 $(\theta,\phi)$ 的单位向量，证明
$$e^{ i\lambda \sigma_{n} }\boldsymbol{\sigma}e^{ -i\lambda \sigma_{n} } = \mathbf{n}\sigma_{n} + (\mathbf{n}\times \boldsymbol{\sigma})\times \mathbf{n}\cos 2\lambda + \mathbf{n}\times \boldsymbol{\sigma} \sin 2\lambda $$

>[!S]
>令
>$$f(\lambda) = e^{ i\lambda \sigma_{n} }\boldsymbol{\sigma}e^{ -i\lambda \sigma_{n} } $$
>则 $f(0)=\boldsymbol{\sigma},\mathbf{n}\cdot f=e^{ i\lambda \sigma_{n} }\sigma_{n}e^{ -i\lambda \sigma_{n} }$ 
>$$\frac{df}{d\lambda} = ie^{ i\lambda \sigma_{n} }[\sigma_{n},\boldsymbol{\sigma}]e^{ -i\lambda \sigma_{n} } $$
>其中 $[\sigma_{n},\boldsymbol{\sigma}]=[\boldsymbol{\sigma}\cdot \mathbf{n},\boldsymbol{\sigma}]=-2i\mathbf{n}\times \boldsymbol{\sigma}$ 所以
>$$\frac{df}{d\lambda} = 2\mathbf{n}\times f $$
>$$\mathbf{n}\times \frac{df}{d\lambda} = 2(\mathbf{n}\cdot f)\mathbf{n} - 2f = 2\mathbf{n}\sigma_{n} - 2f $$
