## 6.5

记 $(\mathbf{l}^{2},l_{z})$ 的共同本征函数为 $Y_{lm}(\theta,\phi)$ , $(\mathbf{l}^{2},l_{x})$ 的共同本征函数为 $Z_{lm}(\theta,\phi)$ , $(\mathbf{l}^{2},l_{y})$ 的共同本征函数为 $X_{lm}(\theta,\phi)$ , 本题只讨论 $l=1$ 的情况

(a) 直接写出 $Y_{11},Y_{10},Y_{1-1}$ 的函数形式，并将它们用直角坐标 $(x,y,z)$ 表示出来，验证升降算符 $(l_{x}\pm il_{y})$ 对它们的作用效果

(b) 用 $x,y,z$ 轮换的方式得出 $Z_{11},Z_{10},Z_{1-1}$ 和 $X_{11},X_{10},X_{1-1}$ 并将 $X_{lm}$ 表示为 $Y_{lm}$ 的线性叠加

>[!S]
>(a)
>由 $Y_{lm}(\theta,\phi) = \sqrt{ \frac{2l+1}{4\pi} \frac{(l-m)!}{(l+m)!} } e^{ im\phi }P_{l}^{m}(\cos \theta)$ 知道
>$$\begin{gather} Y_{11} = \sqrt{ \frac{3}{8\pi} }\sin \theta e^{ i\phi } = \sqrt{ \frac{3}{8\pi} } \frac{x+iy}{r} \\ Y_{10} = \sqrt{ \frac{3}{4\pi} } \cos \theta = \sqrt{ \frac{3}{4\pi} } \frac{z}{r} \\ Y_{1-1} = \sqrt{ \frac{3}{8\pi} }\sin \theta e^{ -i\phi } = \sqrt{ \frac{3}{8\pi} } \frac{x-iy}{r} \end{gather} $$
>在直角坐标表象下
>$$(l_{x}\pm il_{y})\ket{\mathbf{r}}  = \left[ (\mp x - iy)\frac{\partial }{\partial z} + z\left( \pm \frac{\partial }{\partial x} + i\frac{\partial }{\partial y} \right) \right]\ket{\mathbf{r}}  $$
>于是
>$$l_{+}Y_{1-1} = z\left( \frac{\partial }{\partial x} + i\frac{\partial }{\partial y} \right)\sqrt{ \frac{3}{8\pi} } \frac{x+iy}{r} = \sqrt{ \frac{3}{4\pi} } \frac{z}{r} = Y_{10} $$
>类似的
>$$l_{+}Y_{10}=Y_{11} , \quad l_{+}Y_{11} = 0 $$
>$$l_{-}Y_{11} = Y_{10} ,\quad l_{-}Y_{10} = Y_{1-1} ,\quad l_{-}Y_{1-1} = 0 $$
>(b)
>由轮换对称性
>$$\begin{gather} Z_{11} = \sqrt{ \frac{3}{8\pi} } \frac{y+iz}{r} ,& X_{11} = \sqrt{ \frac{3}{8\pi} } \frac{z+ix}{r} \\ Z_{10} = \sqrt{ \frac{3}{4\pi} } \frac{x}{r} , & X_{10} = \sqrt{ \frac{3}{4\pi} } \frac{y}{r} \\ Z_{1-1} = \sqrt{ \frac{3}{8\pi} } \frac{y-iz}{r} , & X_{1-1} = \sqrt{ \frac{3}{8\pi} } \frac{z-ix}{r} \end{gather}  $$
>于是
>$$\begin{gather} X_{11} = \frac{i}{2}(Y_{11} + \sqrt{ 2 }iY_{10} + Y_{1-1}) \\ X_{10} = \frac{i}{\sqrt{ 2 }}(Y_{11} + Y_{1-1}) \\ X_{1-1} = \frac{i}{2}(Y_{11} - \sqrt{ 2 }iY_{10} + Y_{1-1}) \end{gather}  $$

ps. 书中所说的 $\braket{ Y_{11} | Z_{11} }$ 我猜大概意思是
$$\int d\Omega \braket{ l=1,l_{z}=1 | \theta,\phi }\braket{ \theta,\phi | l=1,l_{x}=1 } = \int d\Omega\ Y^{*}_{11}(\theta,\phi)Z_{11}(\theta,\phi)$$


## 6.6 

对于 $(\mathbf{l}^{2},l_{z})$ 的1共同本征态 $Y_{10}$ ，求 $l_{x}$ 所有可能的测量值及其概率

>[!S]
>对于态 $\ket{l=1,l_{z}=1}$ $l_{x}$ 可能的取值只有 $0,\pm \hbar$ 所以分别计算即可
>$$\braket{ l=1,l_{x}=1 | 10 } = \int d\Omega\ Z_{10}^{*}Y_{10} = \frac{i}{\sqrt{ 2 }} \int d\Omega\ Z_{10}(Z_{11} + Z_{1-1}) = \frac{i}{\sqrt{ 2 }} $$
>类似的计算得到：在态 $Y_{10}$ 下 $l_{x}$ 的可能值为 $\pm \hbar$ 概率各为 $\frac{1}{ 2}$
>
>另解：
>设本征值为 $\hbar,0,-\hbar$ 的概率为 $w_{1},w_{0},w_{-1}$ 则
>$$w_{1}+w_{0}+w_{-1}=1 $$
>已知在 $Y_{10}$ 态下 $l_{x}$ 的期望值是零，$l_{x}^{2}$ 的期望值是 $\hbar^{2}$，所以
>$$\braket{ l_x } = w_{1}\hbar + w_{0}\cdot 0 - w_{2}\hbar = 0 $$
>$$\braket{ l_{x}^{2} } = \hbar^{2}w_{1} + \hbar^{2}w_{-1} = \hbar^{2} $$
>解得 $w_{1}=w_{-1}=\frac{1}{2},w_{0}=0$

## 6.7

粒子处于状态
$$\psi(x,y,z) = C(x+y+2z)e^{ -\alpha r } ,\quad \alpha>0 $$
(a) 求 $\mathbf{l}^{2}$ 的取值
(b) 求 $l_{z}$ 的期望值
(c) 求 $l_{z}=\hbar$ 的概率
(d) 求 $l_{x}$ 的可能取值及概率

>[!S]
>考虑将多项式按照球谐函数展开即可
>(a)
>显然 $\mathbf{l}^{2}$ 的取值是 $l(l+1)\hbar^{2}$ 也就是 $\mathbf{l}^{2}=2\hbar^{2}$ 
>(b)
>$$x+y+2z = \sqrt{ \frac{8\pi}{3} }r\left[  \left( \frac{1}{2} + \frac{1}{2i} \right)Y_{11} + \left( \frac{1}{2}-\frac{1}{2i} \right)Y_{1-1} + \frac{1}{\sqrt{ 2 }}Y_{10} \right] $$
>$$\psi(x,y,z) = C\sqrt{ \frac{8\pi}{3} }re^{ -\alpha r }\left[  \frac{1-i}{2}Y_{11} + \frac{1}{\sqrt{ 2 }}Y_{10} + \frac{1+i}{2}Y_{1-1} \right] $$
>所以
>$$\braket{ \psi |l_{z}| \psi }  \propto |\frac{1-i}{2}|^{2}\braket{ 11 |l_{z}| 11 } + |\frac{1}{\sqrt{ 2 }}|^{2}\braket{ 10 |l_{z}| 10 } + |\frac{1+i}{2}|^{2}\braket{ 1-1 |l_{z}| 1-1 } $$
>系数比分别为 $|C_{1}|:|C_{2}|:|C_{3}|=1:4:1$
>$$\braket{ l_{z} } = \frac{1}{6}\cdot \hbar + \frac{4}{6}\cdot{0} + \frac{1}{6}\cdot(-\hbar) = 0 $$
>(c)
>由上可知，$\ket{\psi}$ 处于 $\ket{11}$ 的概率为
>$$\frac{1}{6} $$
>(d)
>类似的，可以将多项式按照 $(H,\mathbf{l}^{2},l_{x})$ 的本征函数展开
>$$\psi = Cre^{ -\alpha r }\sqrt{ \frac{4\pi}{3} }\left[  \frac{2i-1}{\sqrt{ 2 }}Z_{11} + Z_{10} + \frac{1+2i}{\sqrt{ 2 }}Z_{1-1} \right] $$
>所以 $l_{x}=\hbar,0,-\hbar$ 的概率的比分别为 $\frac{5}{2}:1: \frac{5}{2}=\frac{5}{12} :\frac{1}{6} :\frac{5}{12}$  
>


## 6.8

将 $(H,\mathbf{l}^{2},l_{z})$ 的共同本征态记作 $\ket{lm}$ 共同本征函数为 $Y_{lm}$ 证明
$$\sum_{m} \left|\left\langle  00| \frac{\mathbf{r}}{r}| 1 m \right\rangle\right|^{2} = \sum_{m} | \int Y_{00}^{*} \frac{\mathbf{r}}{r}Y_{1m} d\Omega |^{2} = 1 $$

>[!S]
>可以考虑直接把球谐函数代入积分计算：
>$$\frac{\mathbf{r}}{r} = \sqrt{ \frac{2\pi}{3} }(Y_{1-1}-Y_{11})\hat{x} + i\sqrt{ \frac{2\pi}{3} }(Y_{1-1}+Y_{11})\hat{y} + \sqrt{ \frac{4\pi}{3} }Y_{10}\hat{z} $$
>$x$ 方向为
>$$\begin{align} \int d\Omega\ \frac{1}{\sqrt{ 4\pi }} \sqrt{ \frac{2\pi}{3} } (Y_{1-1}-Y_{11})Y_{1m}\hat{x}d\Omega\end{align} = \sqrt{ \frac{1}{6} }(\delta_{-1,m}-\delta_{1,m})\hat{x} $$
>$y$ 方向为
>$$\begin{align} \int d\Omega\ \frac{1}{\sqrt{ 4\pi }} i\sqrt{ \frac{2\pi}{3} } (Y_{1-1}+Y_{11})Y_{1m}\hat{x}d\Omega\end{align} = i\sqrt{ \frac{1}{6} }(\delta_{-1,m}+\delta_{1,m})\hat{y} $$
>$z$ 方向为
>$$\begin{align} \int d\Omega\ \frac{1}{\sqrt{ 4\pi }} \sqrt{ \frac{4\pi}{3} } Y_{10}Y_{1m}\hat{x}d\Omega\end{align} = \sqrt{ \frac{1}{3} }\delta_{0,m}\hat{z}  $$
>所以
>$$\sum_{m} | \int Y_{00}^{*} \frac{\mathbf{r}}{r}Y_{1m} d\Omega |^{2} = \sum_{m}\left( \frac{(\delta_{-1,m}-\delta_{1,m})^{2}}{6} + \frac{(\delta_{-1,m}+\delta_{1,m})^{2}}{6} + \frac{{\delta_{0,m}}^{2}}{3} \right) = 1 $$
>曾谨严给了另一个方法：
>$$\frac{\mathbf{r}}{r}Y_{00} \to Y_{1m} $$
>所以
>$$\langle lm| \frac{\mathbf{r}}{r}| 00\rangle = \delta_{1l} $$
>所以
>$$\begin{align} 1 & =\braket{ 00 | 00 } \\ & = \braket{ 00 | \frac{\mathbf{r}}{r}\cdot \frac{\mathbf{r}}{r}| 00 } \\ & =\sum_{l,m} \braket{ 00 | \frac{\mathbf{r}}{r}| lm  } \braket{ lm | \frac{\mathbf{r}}{r}| 00 } \\ & = \sum_{m} \braket{ 00 | \frac{\mathbf{r}}{r}| 1m } \braket{ 1m | \frac{\mathbf{r}}{r}| 00 } \\ & =\sum_{m} \left| \braket{ 00 | \frac{\mathbf{r}}{r}| 1m }  \right|^{2}   \end{align} $$
