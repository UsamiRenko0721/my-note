# 单自旋
## 6.27

有一个定域电子(不考虑轨道运动)受到均匀磁场 $B$ 作用，其方向为 $\hat{x}$，磁作用势能为
$$H = \frac{eB}{\mu c}s_{x} = \frac{e\hbar B}{2\mu c}\sigma_{x} $$
设 $t=0$ 时电子自旋为“向上”，求 $t>0$ 时 $\mathbf{s}$ 的期望值

>[!S]
>取 $\sigma_{z}$ 的表象，则哈密顿量表示为
>$$ \frac{e\hbar B}{2\mu c} \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix} = \hbar \omega\begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix} $$
>设
>$$\ket{\chi(t)}  = C_{1}(t)\ket{\uparrow} + C_{2}(t)\ket{\downarrow}  $$
>则初态为 $\ket{\chi(0)}=\ket{\uparrow}$ ，由薛定谔方程
>$$i\hbar \frac{d}{dt}\ket{\chi} = i\hbar \left( \frac{dC_{1}\ket{\uparrow}}{dt} + \frac{dC_{2}\ket{\downarrow}}{dt}    \right) = H\ket{\chi} = \hbar \omega(C_{2}\ket{\uparrow} +C_{1}\ket{\downarrow} ) $$
>由基的独立性知
>$$i\dot{C}_{1} = \omega C_{2} ,\quad i\dot{C}_{2}=\omega C_{1} $$
>解得
>$$C_{1} = \cos \omega t ,\quad C_{2} = -i\sin \omega t $$
>所以
>$$\ket{\chi} = \cos \omega t\ket{\uparrow} - i\sin \omega t\ket{\downarrow}  $$
>于是
>$$\begin{gather} \braket{ s_{z} } = \frac{\hbar}{2} \braket{ \chi |\sigma_{z}| \chi } = \frac{\hbar}{2}\cos 2\omega t \\ \braket{ s_{x} } = \frac{\hbar}{2} \braket{ \chi |\sigma_{x}| \chi } = 0 \\ \braket{ s_{y} } = \frac{\hbar}{2} \braket{ \chi |\sigma_{y}| \chi } = -\frac{\hbar}{2}\sin 2\omega t \end{gather} $$

$x$ 方向磁矩绕磁场进动，当然守恒了

## 6.28

有一个自旋 1/2 的粒子，磁矩 $\boldsymbol{\mu}=\mu_{0}\boldsymbol{\sigma}$ ，置于均匀磁场 $\mathbf{B}$ 中，$\mathbf{B}$ 的方向是 $(\theta,\phi)$ . 不考虑轨道运动，设 $t=0$ 时粒子沿 $\hat{z}$ 方向极化 $\sigma_{z}=1$ 求 $t>0$ 时粒子极化方向 $\braket{ \boldsymbol{\sigma} }$

>[!S]
>哈密顿量为，取 $\sigma_{z}$ 表象
>$$H = -\boldsymbol{\mu}\cdot \mathbf{B} = -\mu_{0}B\sigma_{n} = -\hbar \omega\begin{pmatrix}n_{3} & n_{1}-in_{2} \\ n_{1}+in_{2} & -n_{3} \end{pmatrix} $$
>设粒子自旋态为 $\ket{\chi}$ 取 $\sigma_{z}$ 表象，可以将 $\ket{\chi}$ 展开为
>$$\ket{\chi} = C_{1}\ket{\uparrow} + C_{2}\ket{\downarrow}  $$
>由薛定谔方程
>$$i\hbar \frac{d}{dt}\ket{\chi} = H\ket{\chi} \implies \begin{gather} i\dot{C}_{1} = -\omega n_{3}C_{1} - \omega(n_{1}-in_{2})C_{2} \\ i\dot{C}_{2} = -\omega(n_{1}+in_{2})C_{1} + \omega n_{3}C_{2} \end{gather} $$
>解得
>$$C_{1}=A(1+n_{3})e^{ i\omega t } + B(n_{1}-in_{2})e^{ -i\omega t },\quad C_{2} = A(n_{1}+in_{2})e^{ i\omega t } - B(1+n_{3})e^{ -i\omega t } $$
>$$\ket{\chi} = C_{1}e^{ i\omega t }[(1+n_{3})\ket{\uparrow} +(n_{1}+in_{2})\ket{\downarrow} ] + C_{2}e^{ -i\omega t }[ (n_{1}-in_{2})\ket{\uparrow} - (1+n_{3})\ket{\downarrow}  ] $$
>代入初始条件 $\ket{\chi(0)}=\ket{\uparrow}$ 则 $C_{1}=\sqrt{ \frac{1+n_{3}}{2} },C_{2}=\frac{n_{1}+in_{2}}{\sqrt{ 2(1+n_{3}) }}$ 所以
>$$\ket{\chi} = (\cos \omega t +in_{3}\sin \omega t)\ket{\uparrow} + (in_{1}-n_{2})\sin \omega t\ket{\downarrow}  $$
>于是
>$$\braket{ \sigma_{z} } = \braket{ \chi |\sigma_{z}| \chi } = n_{3}^{2} + (1-n_{3}^{2})\cos 2\omega t $$
>类似的 $\braket{ \sigma_{x} }=n_{1}n_{3}(1-\cos 2\omega t)-n_{2}\sin 2\omega t$ 和 $\braket{ \sigma_{y} }=n_{2}n_{3}(1-\cos 2\omega t)+n_{2}\sin 2\omega t$
>


## 6.29

有一个自旋 1/2 的粒子，磁矩 $\boldsymbol{\mu}=\mu_{0}\boldsymbol{\sigma}$ ，$t<0$ 时置于均匀磁场 $\mathbf{B}_{0}$ 中其方向为 $\hat{z}$，在 $t\geq 0$ 时再加入一个旋转磁场 $\mathbf{B}_{1}(t)$ 其方向和 $\hat{z}$ 垂直，
$$\mathbf{B}_{1}(t) = B_{1}\cos 2\omega_{0} t \mathbf{e}_{1} - B_{1}\sin 2\omega_{0} t\mathbf{e}_{2} $$
其中 $\omega_{0}=\mu_{0}B_{0} /\hbar$ . 已知 $t\leq 0$ 时体系处于 $s_{z}=\hbar /2$ 的本征态 $\chi_{\frac{1}{2}}$ 求 $t>0$ 时体系的自旋波函数以及自旋反转所需的时间

>[!S]
>加入旋转磁场后哈密顿量为 (在 $\sigma_{z}$ 表象下)
>$$H(t) = -\boldsymbol{\mu}\cdot(\mathbf{B}_{0} + \mathbf{B}_{1}) = -\mu_{0}\begin{pmatrix} B_{0} & B_{1}e^{ 2i\omega_{0} t } \\ B_{1}e^{ -2i\omega_{0} t } & -B_{0} \end{pmatrix} $$
>$$\ket{\chi} = C_{1}\ket{\uparrow} + C_{2}\ket{\downarrow}  $$
>代入薛定谔方程 $i\hbar \frac{d}{dt}\ket{\chi}=H\ket{\chi}$ 得到
>$$\begin{gather} \dot{C}_{1} = i\omega_{0}a + i\omega_{1}be^{ 2i\omega_{0}t } \\ \dot{C}_{2} =-i\omega_{0}b + i\omega_{1}ae^{ -2i\omega_{0}t } \end{gather} $$
>考虑到初始条件 $\ket{\chi(0)}=\ket{\uparrow}$ 解得
>$$C_{1} = \cos \omega_{1}te^{ i\omega_{0}t } ,\quad C_{2} = i\sin \omega_{1}te^{ -i\omega_{0}t } $$
>所以
>$$\ket{\chi} = \cos \omega_{1}e^{ i\omega_{0}t }\ket{\uparrow} + i\sin \omega_{1}te^{ -i\omega_{0}t }\ket{\downarrow}  $$
>可见，当 $t=\frac{n\pi}{2\omega_{1}}$ 时体系自旋向下


## 6.30

对于自旋 1/2 的粒子 $\braket{ \boldsymbol{\sigma} }$ 成为极化矢量常常用符号 $\mathbf{P}$ 代指，也就是自旋角动量的空间指向。
(a) 在初始时刻自旋波函数在 $\sigma_{z}$ 的表象是
$$\chi(0) = \begin{pmatrix}
\cos\delta e^{ -i\alpha } \\
\sin\delta e^{ i\alpha }
\end{pmatrix} $$
其中 $\delta,\alpha\geq 0$ 且 $\delta\leq \frac{\pi}{2},\alpha\leq \pi$ 确定 $\mathbf{P}(0)$ 的空间方向 $(\theta,\phi)$

(b) 设粒子是定域的，且受到沿 $z$ 方向单强度随时间变换的磁场 $\mathbf{B}(t)$ 的作用，作用势为
$$H = -\mu_{0}\sigma_{z}B(t) $$
求极化矢量随时间的变化规律。

>[!S]
>(a)
>实际上在以 $\sigma_{z}$ 表象里，$\sigma_{n}=1$ 的本征函数是
>$$\phi_{1}(\theta,\phi) = \begin{pmatrix}\cos \frac{\theta}{2}e^{ -i\phi/2 }\\ \sin \frac{\theta}{2}e^{ i\phi/2 } \end{pmatrix} $$
>对比得到
>$$\theta=2\delta,\quad\phi=2\alpha $$
>(b)
>在 $\sigma_{z}$ 的表象里，哈密顿量和波函数是
>$$H = -\mu_{0}B \begin{pmatrix}1 & 0 \\ 0 & -1 \end{pmatrix} ,\quad \chi(t) = \begin{pmatrix} C_{1} \\ C_{2} \end{pmatrix} $$
>代入薛定谔方程 $i\hbar \frac{d}{dt}\chi=H\chi$ 得到
>$$\dot{C}_{1} = i \frac{\mu_{0}B(t)}{\hbar}C_{1} ,\quad \dot{C}_{2} = -i \frac{\mu_{0}B(t)}{\hbar}C_{2} $$
>于是
>$$C_{1} = C_{1}(0)\exp\left( i \frac{\mu_{0}}{\hbar}\int_{0}^{t} B(\tau)d\tau \right) ,\quad C_{2} = C_{2}(0)\exp\left( -i \frac{\mu_{0}}{\hbar}\int_{0}^{t} B(\tau)d\tau \right) $$
>代入 $C_{1}(0)=\cos\delta e^{ i\alpha },C_{2}(0)=\sin\delta e^{ -i\alpha }$ 即可


# 自旋-轨道、自旋-自旋耦合

## 6.31

以 $\mathbf{S},\mathbf{L},\mathbf{J}$ 表示电子的自旋、轨道角动量和总角动量，取 $\hbar=1$，$\mathbf{J}$ 和 $\mathbf{J}^{2}$ 可以表示为
$$\begin{gather}
\mathbf{J} = \mathbf{S} + \mathbf{L} = \frac{1}{2} \boldsymbol{\sigma} + \mathbf{L} \\
\mathbf{J}^{2} = \mathbf{L}^{2} + \mathbf{S}^{2} + 2\mathbf{L}\cdot \mathbf{S} = \frac{3}{4} + \mathbf{L}^{2} + \boldsymbol{\sigma}\cdot \mathbf{L}
\end{gather} $$
(a) 计算 $[\boldsymbol{\sigma},\boldsymbol{\sigma}\cdot \mathbf{L}],[\mathbf{L},\boldsymbol{\sigma}\cdot \mathbf{L}],[\mathbf{J},\boldsymbol{\sigma}\cdot \mathbf{L}],[\mathbf{J},\mathbf{L}^{2}]$
(b) 求 $\boldsymbol{\sigma}\cdot \mathbf{L}$ 和 $\mathbf{J}^{2}$ 的本征值

>[!S]
>(a)
>$$\begin{align}
[\boldsymbol{\sigma},\boldsymbol{\sigma}\cdot \mathbf{L}] & = \boldsymbol{\sigma}(\boldsymbol{\sigma}\cdot \mathbf{L}) - \boldsymbol{\sigma}\cdot \mathbf{L}\boldsymbol{\sigma}\\ & = \sigma_{a}\mathbf{e}^{a}\sigma_{b}L^{b} - \sigma_{c}L^{c}\sigma_{a}\mathbf{e}^{a}\\ & = (\delta_{ab} + i\varepsilon_{abd}\sigma^{d})L^{b}\mathbf{e}^{a} - (\delta_{ca}+i\varepsilon_{cae}\sigma^{e})L^{c}\mathbf{e}^{a}\\ & =L_{a}\mathbf{e}^{a} + i\varepsilon_{abd}\mathbf{e}^{a}L^{b}\sigma^{d} - L_{a}\mathbf{e}^{a} + i\varepsilon_{ace} \mathbf{e}^{a}L^{c}\sigma^{e}\\ & = 2i\varepsilon_{abc}L^{a}\sigma^{b}\mathbf{e}^{c}\\ & =2i\mathbf{L}\times \boldsymbol{\sigma}
\end{align} $$
>$$[\mathbf{L},\boldsymbol{\sigma}\cdot \mathbf{L}] = [L^{a},\boldsymbol{\sigma}\cdot \mathbf{L}]\mathbf{e}_{a} = (\sigma_{b}[L^{a},L^{b}] + \sigma_{c}[L^{a},L^{c}])\mathbf{e}_{a} = i(\sigma_{b}L^{c}-\sigma_{c}L^{b})\mathbf{e}_{a} = i\boldsymbol{\sigma}\times \mathbf{L} $$
>$$[\mathbf{J},\boldsymbol{\sigma}\cdot \mathbf{L}] = \frac{1}{2}[\boldsymbol{\sigma},\boldsymbol{\sigma}\cdot \mathbf{L}] + [\mathbf{L},\boldsymbol{\sigma}\cdot \mathbf{L}] = i\mathbf{L}\times \boldsymbol{\sigma} + i\boldsymbol{\sigma}\times \mathbf{L} = 0 $$
>$$[\mathbf{J},\mathbf{L}^{2}] = [\mathbf{S},\mathbf{L}^{2}] + [\mathbf{L},\mathbf{L}^{2}] = 0 $$
>(b)
>由上可知 $(\mathbf{J}^{2},\mathbf{J},\boldsymbol{\sigma}\cdot \mathbf{L},\mathbf{L}^{2})$ 相互对易，有共同本征态，记作 $\ket{l,s,j,m}$ 则
>$$\mathbf{J}^{2}\ket{l,s,j,m} = j(j+1)\ket{l,s,j,m}  $$
>$$\boldsymbol{\sigma}\cdot \mathbf{L}\ket{l,s,j,m} = \left(  \mathbf{J}^{2} - \mathbf{L}^{2} - \frac{3}{4}  \right)\ket{l,s,j,m} = \left(j(j+1)-l( l+1)- \frac{3}{4} \right) \ket{l,s,j,m} $$
>当 $j=l+\frac{1}{2}$ 时本征值为 $l$；当 $j=l-\frac{1}{2}$ 时本征值为 $-(l+1)$


## 6.32

对于电子，$(\mathbf{L}^{2},\mathbf{J}^{2},J_{z})$ 的共同本征函数记为 $\phi_{ljm_{j}}$ 相应于本征值，取 $\hbar=1$
$$\begin{gather}
\mathbf{L}^{2}\ket{l,j,m} = l(l+1)\ket{l,j,m}  \\
\mathbf{J}^{2}\ket{l,j,m} = j(j+1)\ket{l,j,m}  \\
J_{z}\ket{l,j,m} = m\ket{l,j,m} 
\end{gather} $$
在同一个 $l$ 的态矢量子空间中，定义算符
$$\Lambda ^{\dagger} = \frac{1}{2l+1}(l+1+\boldsymbol{\sigma}\cdot \mathbf{L}),\quad \Lambda = \frac{1}{2l+1}(l-\boldsymbol{\sigma}\cdot \mathbf{L}) $$
求这两个算符的代数关系，以及作用到 $\phi_{l,j,m}$ 上的规则

>[!S]
>显然的 $\Lambda+\Lambda ^{\dagger}=1$ 并且
>$$\begin{align}
(\Lambda ^{\dagger})^{2}\ket{l,j,m} & = \frac{(l+1)^{2} + 2(l+1)\boldsymbol{\sigma}\cdot \mathbf{L} + (\boldsymbol{\sigma}\cdot \mathbf{L})^{2}}{(2l+1)^{2}}\ket{l,j,m} \\ & = \frac{(l+1)^{2} + 2(l+1)\boldsymbol{\sigma}\cdot \mathbf{L} + l(l+1) - \boldsymbol{\sigma}\cdot \mathbf{L}}{(2l+1)^{2}}\ket{l,j,m} \\ & = \frac{l+1+\boldsymbol{\sigma}\cdot \mathbf{L}}{2l+1}\ket{l,j,m}  \\
\Lambda^{2}\ket{l,j,m}  & = \frac{l^{2} - l\boldsymbol{\sigma}\cdot \mathbf{L}+(\boldsymbol{\sigma}\cdot \mathbf{L})^{2}}{(2l+1)^{2}}\ket{l,j,m} \\ & =\frac{l^{2}-l\boldsymbol{\sigma}\cdot \mathbf{L} +l(l+1)-\boldsymbol{\sigma}\cdot \mathbf{L}}{(2l+1)^{2}}\ket{l,j,m} \\ & = \frac{l-\boldsymbol{\sigma}\cdot \mathbf{L}}{2l+1}\ket{l,j,m} 
\end{align} $$
>故 $(\Lambda ^{\dagger})^{2}=\Lambda ^{\dagger},\Lambda^{2}=\Lambda$ 以及
>$$\Lambda ^{\dagger}\Lambda = \frac{l(l+1) + \boldsymbol{\sigma}\cdot \mathbf{L} - (\boldsymbol{\sigma}\cdot \mathbf{L})^{2}}{(2l+1)^{2}} = \frac{l(l+1) + \boldsymbol{\sigma}\cdot \mathbf{L} - (l(l+1)-\boldsymbol{\sigma}\cdot \mathbf{L})}{(2l+1)^{2}} = 0 $$
>下面直接计算其本征值
>$$\begin{align}
\Lambda \ket{l,j,m} & = \frac{l+1+\boldsymbol{\sigma}\cdot \mathbf{L}}{2l+1}\ket{l,j,m} \\ &  = \frac{l+1+j(j+1)-l(l+1)-3 /4}{2l+1}\ket{l,j,m} \\ & = \frac{j(j+1)-l^{2} + 1 /4}{2l+1}\ket{l,j,m} 
\end{align} $$
>考虑到自旋是 1/2 所以只考虑 $j=l\pm \frac{1}{2}$ 
>$$\Lambda \ket{l,l-\frac{1}{2},m} =\ket{l,l-\frac{1}{2},m}  ,\quad \Lambda \ket{l,l+\frac{1}{2},m} =0  $$
>同理
>$$\Lambda ^{\dagger}\ket{l,l-\frac{1}{2},m} =0,\quad \Lambda ^{\dagger}\ket{l,l+\frac{1}{2},m} = \ket{l,l+\frac{1}{2},m}  $$


## 6.33

对于自旋 1/2 的粒子，求算符 $\sigma_{r}=\boldsymbol{\sigma}\cdot \mathbf{r} /r$ 对 $(\mathbf{L}^{2},\mathbf{J}^{2},J_{z})$ 的共同本征函数 $\phi_{l,j,m}$ 的作用结果，取 $\hbar=1$

>[!S]
>设 $\mathbf{r}$ 的方向是 $(\theta,\phi)$ 则在 $\sigma_{z}$ 的表象下其表示是
>$$\sigma_{r} = \begin{pmatrix}\cos \theta & \sin \theta e^{ -i\phi } \\ \sin \theta e^{ i\phi } & -\cos \theta \end{pmatrix} $$
>而我们想要求得
>$$\braket{ \theta,\phi |\sigma_{r}| l,j,m } = \langle \theta,\phi|\sigma_{r}\sum_{m_{l},m_{s}} C^{j,m}_{l,m_{l},s,m_{s}}\ket{l,m_{l}} \otimes \ket{s,m_{s}}    $$
>我们的 $\sigma_{r}$ 是作用在 $\ket{\uparrow},\ket{\downarrow}$ 上的，所以其实就是一个球谐函数 $\braket{ \theta,\phi | l,m_{l} }$ 处于自旋空间不同分量的样子，为此我们先计算 [[CG系数]] 得到
>
>对于 $j=l+\frac{1}{2}$ 得到
>$$\boxed{\ket{j,m} = \sqrt{ \frac{j+m+ 1 /2}{2l+1} }\ket{l,m_{j}-\frac{1}{2}} \otimes \ket{\uparrow} + \sqrt{ \frac{l-m+1 /2}{2l+1} }\ket{l,m_{j} + \frac{1}{2}} \otimes  \ket{\downarrow}  } $$
>$$\braket{ \theta,\phi | l,j,m } = \sqrt{ \frac{j+m+ 1 /2}{2l+1} }Y_{l,m-1 /2}\ket{\uparrow} + \sqrt{ \frac{l-m+1 /2}{2l+1} }Y_{l,m+1 /2} \ket{\downarrow}  $$
>对于 $j=l-\frac{1}{2}$ 得到
>$$\boxed{\ket{j,m} = -\sqrt{ \frac{l-m+ 1 /2}{2l+1} }\ket{l,m_{j}-\frac{1}{2}} \otimes \ket{\uparrow} + \sqrt{ \frac{j+m+1 /2}{2l+1} }\ket{l,m_{j} + \frac{1}{2}} \otimes  \ket{\downarrow}  }  $$
>$$\braket{ \theta,\phi | l,j,m } = -\sqrt{ \frac{l-m+ 1 /2}{2l+1} }Y_{l,m-1 /2}\ket{\uparrow} + \sqrt{ \frac{j+m+1 /2}{2l+1} }Y_{l,m+1 /2} \ket{\downarrow}   $$>而
>$$\sigma_{r}\ket{\uparrow} = \cos \theta \ket{\uparrow} + \sin \theta e^{ -i\phi }\ket{\downarrow} ,\quad\sigma_{r}\ket{\downarrow} = \sin \theta e^{ i\phi }\ket{\uparrow} - \cos \theta \ket{\downarrow}  $$
>于是
>$$\braket{ \theta,\phi |\sigma_{r}| l,j=l+\frac{1}{2},m } = -\braket{ \theta,\phi | l+1,j=l-\frac{1}{2},m } $$
>$$\braket{ \theta,\phi |\sigma_{r}| l,j=l-\frac{1}{2},m } = -\braket{ \theta,\phi | l+1,j=l-\frac{1}{2},m }   $$


## 6.34

对于自旋 1/2 的粒子，$s_{z}$ 的本征态记作 $\alpha,\beta$ 电子波函数记作
$$\psi(r,\theta,\phi,s_{z}) = \alpha Y_{l 0}(\theta,\phi)R(r) $$
求其总角动量 $\mathbf{J}^{2},J_{z}$ 的取值和期望值，取 $\hbar=1$

>[!S]
>只取 $(\theta,\phi,s_{z})$ 部分，显然 $Y_{l 0}$ 说明了 $\mathbf{L}^{2}=l(l+1),L_{z}=0$ 而 $\alpha$ 说明了 $s_{z}=\frac{1}{2}$ 所以 $j_{z}=\frac{1}{2}$，所以测得 $J_{z}=\frac{1}{2}$ 的概率是 1.对于 $\mathbf{J}^{2}$ ，我们必须求出来耦合基下的量子数
>
>而我们知道的
>$$\braket{ \theta,\phi | l,l+\frac{1}{2}, \frac{1}{2} } = \sqrt{ \frac{l+1}{2l+1} }Y_{l 0}\alpha + \sqrt{ \frac{l}{2l+1} }Y_{l 1}\beta $$
>$$\braket{ \theta,\phi | l,l-\frac{1}{2}, \frac{1}{2} } =-\sqrt{ \frac{l}{2l+1} }Y_{l 0}\alpha + \sqrt{ \frac{l+1}{2l+1} }Y_{l 1}\beta $$
>所以
>$$\braket{ \theta,\phi | l,0;\uparrow } = \sqrt{ \frac{l+1}{2l+1} }\braket{ \theta,\phi | l,l+\frac{1}{2}, \frac{1}{2} } - \sqrt{ \frac{l}{2l+1} }\braket{ \theta,\phi | l,l-\frac{1}{2}, \frac{1}{2} } $$
>所以对于 $\mathbf{J}^{2}$ 可以有 $\left( l+\frac{1}{2} \right)\left( l+\frac{3}{2} \right)$ 和 $\left( l-\frac{1}{2} \right)\left( l+\frac{1}{2} \right)$ 的本征值，取到的概率分别是 $\frac{l+1}{2l+1}$ 和 $\frac{l}{2l+1}$


## 6.35

自旋 1/2 粒子，处于 $(\mathbf{L}^{2},\mathbf{J}^{2},J_{z})$ 的共同本征态 $\ket{l,j,m_{j}}$ ，证明
$$\braket{ \boldsymbol{\sigma} } = \braket{ \mathbf{J} } \left[  \frac{j(j+1)-l(l+1)+3 /4}{j(j+1)}  \right] $$
取 $\hbar=1$

>[!S]
>对于那坨系数，显然的
>$$j(j+1) = \braket{ \mathbf{J}^{2} } ,\quad j(j+1) - l(l+1) + \frac{3}{4} = \braket{ \mathbf{J}^{2} - \mathbf{L}^{2} + \frac{3}{4} }  $$
>其中 $\mathbf{L}^{2}=\mathbf{J}^{2}-\mathbf{S}^{2}-2\mathbf{S}\cdot \mathbf{L}$ 所以
>$$\braket{ \mathbf{J}^{2} } - \braket{ \mathbf{L}^{2} } = \braket{ \mathbf{S}^{2} } - \braket{ \boldsymbol{\sigma}\cdot \mathbf{J} } - 2\braket{ \mathbf{S}^{2} } = -\frac{3}{4} - \braket{ \boldsymbol{\sigma}\cdot \mathbf{J} }   $$
>所以
>$$j(j+1) - l(l+1) + \frac{3}{4} = \braket{ \boldsymbol{\sigma}\cdot \mathbf{J} }  $$
>所以题目即证明
>$$\braket{ \boldsymbol{\sigma} } = \frac{\braket{ \boldsymbol{\sigma}\cdot \mathbf{J} }}{\braket{ \mathbf{J}^{2} } }\braket{ \mathbf{J} }   $$
>此即 [[角动量投影定理]] 于是得证


## 6.36

由两个自旋 1/2 粒子组成的体系，令 $\mathbf{s}_{1}=\frac{\hbar}{2}\boldsymbol{\sigma}_{1},\mathbf{s}_{2}=\frac{\hbar}{2}\boldsymbol{\sigma}_{2}$ 考虑算符
$$H = \frac{1}{2}(\sigma_{1x}\sigma_{2y}-\sigma_{1y}\sigma_{2x}) $$
求其本征函数和本征值

>[!S]
>由于两套泡利算符是不同粒子的，属于不同子空间，所以
>$$\sigma_{1x}\sigma_{2y} = \sigma_{x}\otimes \sigma_{y},\quad\sigma_{1y}\sigma_{2x}=\sigma_{y}\otimes \sigma_{x} $$
>考虑这两个泡利算符在 $\sigma_{z}$ 表象下的表示，则该算符可以表示为
>$$\sigma_{x}\otimes \sigma_{y} = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix} \otimes \begin{pmatrix} 0 & -i \\ i & 0 \end{pmatrix} = \begin{pmatrix} 0 & 0 & 0 & -i \\ 0 & 0 & i & 0 \\ 0 & -i & 0 & 0 \\ i & 0 & 0 & 0 \end{pmatrix} $$
>$$H = \begin{pmatrix} 0 & 0 & 0 & 0 \\ 0 & 0 & -i & 0 \\ 0 & i & 0 & 0 \\ 0 & 0 & 0 & 0 \end{pmatrix} $$
>所以其本征系统显然为
>$$\lambda=0,\quad (1,0,0,0)^{T}\text{ and }(0,0,0,1)^{T} $$
>$$\lambda=1,\quad \frac{1}{\sqrt{ 2 }}(1,0,0,1)^{T} $$
>$$\lambda=-1,\quad \frac{1}{\sqrt{ 2 }}(0,1,1,0)^{T} $$


## 6.38

对两个自旋 1/2 的粒子组成的系统，考虑自旋单态和三重态，研究算符 $\sigma_{1x}\sigma_{2x},\sigma_{1y}\sigma_{2y},\sigma_{1z}\sigma_{2z}$ 对它们的作用

>[!S]
>
>总自旋基，参考[[CG系数#实例：两个自旋 1/2 的耦合|自旋-自旋耦合]]：
>$$\begin{aligned}

|0,0\rangle &= \frac{1}{\sqrt{2}}\bigl(|\uparrow\downarrow\rangle |\downarrow\uparrow\rangle\bigr)
\end{aligned}$$
>
>泡利矩阵作用
>$$\sigma_x|\uparrow\rangle = |\downarrow\rangle, \sigma_x|\downarrow\rangle = |\uparrow\rangle\quad\sigma_y|\uparrow\rangle=i|\downarrow\rangle,\sigma_y|\downarrow\rangle = -i|\uparrow\rangle\quad\sigma_z|\uparrow\rangle = |\uparrow\rangle,\sigma_z|\downarrow\rangle = -|\downarrow\rangle$$

>

> 3. 算符 $\sigma_{1z}\sigma_{2z}$
>$$\begin{aligned}\sigma_{1z}\sigma_{2z}|1,1\rangle &= |\uparrow\uparrow\rangle = |1,1\rangle, \\ \sigma_{1z}\sigma_{2z}|1,0\rangle &= \frac{1}{\sqrt{2}}\bigl(-|\uparrow\downarrow\rangle - |\downarrow\uparrow\rangle\bigr) = -|1,0\rangle, \\ \sigma_{1z}\sigma_{2z}|1,-1\rangle &= ( -|\downarrow\rangle)(-|\downarrow\rangle) = |\downarrow\downarrow\rangle = |1,-1\rangle, \\\sigma_{1z}\sigma_{2z}|0,0\rangle &= \frac{1}{\sqrt{2}}\bigl(-|\uparrow\downarrow\rangle + |\downarrow\uparrow\rangle\bigr) = -|0,0\rangle.\end{aligned}$$


## 6.42

对于两个自旋 1/2 的粒子组成的体系，令
$$\mathbf{r}=\mathbf{r}_{1}-\mathbf{r}_{2} ,\quad \mathbf{n}=\frac{\mathbf{r}}{r} $$
取 $\hbar=1$ 定义
$$S_{12} = 3(\boldsymbol{\sigma}_{1}\cdot \mathbf{n})(\boldsymbol{\sigma}_{2}\cdot \mathbf{n}) - \boldsymbol{\sigma}_{1}\cdot \boldsymbol{\sigma}_{2} $$
(a) 证明 $(S_{12})^{2} = 4\mathbf{S}^{2}-2S_{12}$ 其中 $\mathbf{S}=\mathbf{s}_{1}+\mathbf{s}_{2}$ 并证明 $S_{12}$ 的任意正整数次幂都能表示为 $\mathbf{S}^{2}$ 和 $S_{12}$ 的线性组合

>[!S]
>不妨取 $\mathbf{n}=\hat{z}$ 则
>$$S_{12} = 2\sigma_{1z}\sigma_{2z} - \sigma_{1x}\sigma_{2x} - \sigma_{1y}\sigma_{2y} $$
>于是在耦合基下的表达是
>$$S_{12} = \begin{pmatrix} 2 & 0 & 0 & 0 \\ 0 & -4 & 0 & 0 \\ 0 & 0 & 2 & 0 \\ 0 & 0 & 0 & 0 \end{pmatrix} $$
>类似的
>$$\mathbf{S}^{2} = \begin{pmatrix} 2 & 0 & 0 & 0 \\ 0 & 2 & 0 & 0 \\ 0 & 0 & 2 & 0 \\ 0 & 0 & 0 & 0 \end{pmatrix} ,\quad (S_{12})^{2} = \begin{pmatrix} 4 & 0 & 0 & 0 \\ 0 & 16 & 0 & 0 \\ 0 & 0 & 4 & 0 \\ 0 & 0 & 0 & 0 \end{pmatrix} $$
>所以
>$$(S_{12})^{2} = 4\mathbf{S}^{2} - 2S_{12} $$
>对于更高次幂，由其矩阵表达可知其满足代数方程
>$$S_{12}(S_{12}+4)(S_{12}-2)^{2} = 0 $$
>所以任意高于 $2$ 的次幂都能降次到 $2$ 次，从而表示为 $\mathbf{S}^{2},S_{12}$ 的线性组合

(b) 求 $S_{12}$ 的本征值

>[!S]
>由上可知，$S_{12}$ 有本征值 $0,-4$ (一重)和 $2$ (二重)

(c) 令 $\mathbf{n}$ 遍历各个方程，求 $S_{12}$ 的平均(量子期望+统计平均)

>[!S]
>$$(S_{n})^{2} = \sum_{\text{cyc}} n_{x}^{2}S_{x}^{2} + \sum_{\text{cyc}} n_{x}n_{y}S_{x}S_{y} $$
>而在统计平均下
>$$\braket{ n_{i}n_{j} } = \frac{1}{3} \delta_{ij} $$
>所以
>$$\braket{ S_{n}^{2} } = \frac{1}{3}\mathbf{S}^{2} \implies \braket{ S_{12} } = 0 $$
