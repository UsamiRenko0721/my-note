## 3.9 

对于意味谐振子，求湮灭算符 $a$ 的本征态，将其表示为各能量本征态 $\ket{n}$ 的线性组合。

>[!S]
>由定义
>$$a\ket{\alpha} = \alpha \ket{\alpha}  $$
>设
>$$\ket{\alpha} = \sum_{n} C_{n}\ket{n}  $$
>而 $a\ket{n} = \sqrt{ n }\ket{n-1}$ 故
>$$a\ket{\alpha} = \sum C_{n}a\ket{n} = \sum C_{n}\sqrt{ n }\ket{n-1} = \sum \alpha C_{n}\ket{n}  $$
>由 $\ket{n}$ 的线性无关性知 $C_{n}\sqrt{ n }=\alpha C_{n-1}$ 于是
>$$C_{n} = \frac{\alpha^{n}}{\sqrt{ n! }}C_{0} $$
>$$\ket{\alpha} = C_{0}\sum_{n} \frac{\alpha^{n}}{\sqrt{ n! }} \ket{n}  $$
>考虑到 $\braket{ \alpha | \alpha }=1$ 可得归一化系数 $C_{0}:=e^{ -|\alpha|^{2}/2 }$ (其实可以差一个相位 $e^{ i\delta }$ 但是取为零也无所谓) 

## 3.10

在相干态 $\ket{\alpha}$ 中计算 $\hat{n},H,x,p$ 的平均值和涨落

>[!S]
>$$\braket{ \alpha |\hat{n}| \alpha } = \braket{ \alpha |a^{\dagger}a| \alpha } = |a\ket{\alpha} |^{2} = |\alpha \ket{\alpha }|^{2} = |\alpha|^{2}  $$
>$$\braket{ \alpha |H| \alpha } = \hbar \omega\braket{ \alpha |\left( \hat{n}+\frac{1}{2} \right)| \alpha } = \hbar \omega\left( |\alpha|^{2} + \frac{1}{2} \right)  $$
>$$\braket{ \alpha |x| \alpha } = \sqrt{ \frac{\hbar}{2m\omega} }\braket{ \alpha |(a^{\dagger}+a)| \alpha } = \sqrt{ \frac{\hbar}{2m\omega} }(\alpha^{*}+\alpha)   $$
>$$\braket{ \alpha |p| \alpha } = \sqrt{ \frac{m\omega \hbar}{2} }\braket{ \alpha |(a^{\dagger}-a)| \alpha } = \sqrt{ \frac{m\hbar \omega}{2} }(\alpha^{*}-\alpha) $$
>$$\braket{ \alpha |x^{2}| \alpha } = \frac{\hbar}{2m\omega}\braket{ \alpha |(a^{\dagger}+a)^{2}|\alpha  } = \frac{\hbar}{2m\omega}((\alpha^{*})^{2} + \alpha^{2}+2\alpha^{*}\alpha + 1) $$
>$$\braket{ \alpha |p^{2}| \alpha } = \frac{m\omega \hbar}{2}\braket{ \alpha |(a^{\dagger}-a)^{2}| \alpha } = \frac{m\omega \hbar}{2}(2\alpha^{*}\alpha + 1 - \alpha^{2} - (\alpha^{*})^{2})  $$
>$$\Delta x = \sqrt{ \braket{ x^{2} } - \braket{ x }^{2}   } = \sqrt{ \frac{\hbar}{2m\omega} } ,\quad \Delta p = \sqrt{ \braket{ p^{2} } - \braket{ p } ^{2} } = \sqrt{ \frac{m\omega \hbar}{2} } $$


## 3.11

证明谐振子的相干态可以表示为
$$\ket{\alpha} = e^{ \alpha a^{\dagger} - \alpha^{*}a }\ket{0}  $$
并求出 $\braket{ x | \alpha }$ 

>[!S]
>由 3.9 知道
>$$\ket{\alpha} = C_{0}\sum_{n} \frac{\alpha^{n}}{\sqrt{ n! }} \ket{n} ,\quad C_{0}=e^{ -|\alpha|^{2}/2 } $$
>而能量本征态可以用产生算符生成
>$$\ket{n} = \frac{(a^{\dagger})^{n}}{\sqrt{ n! }}\ket{0}  $$
>于是
>$$\ket{\alpha} = C_{0} \sum_{n} \frac{(\alpha a^{\dagger})^{n}}{n!} \ket{0} = C_{0} e^{ \alpha a^{\dagger} }\ket{0}  $$
>由于 $a\ket{0}=0$ 所以
>$$e^{ -\alpha^{*}a }\ket{0}  = \ket{0}  $$
>$$\ket{\alpha} = e^{ -|\alpha|^{2}/2 } e^{ \alpha a^{\dagger} }e^{ -\alpha^{*}a }\ket{0}  $$
>由 BCH 公式，考虑到 $[a,a^{\dagger}]=1$ 所以
>$$e^{ \alpha a^{\dagger} - \alpha^{*}a } = e^{ \alpha a^{\dagger} }e^{ -\alpha^{*}a }e^{ [\alpha a^{\dagger},-\alpha^{*}a]/2 } = e^{ -|\alpha|^{2}/2 } e^{ \alpha a^{\dagger} }e^{ -\alpha^{*}a } $$
>$$\ket{\alpha} = e^{ \alpha a^{\dagger} - \alpha^{*}a }\ket{0}  $$
>将它投影到 $\ket{x}$ 上得到
>$$\braket{ x | \alpha } = C_{0}\sum_{n} \frac{\alpha^{n}}{\sqrt{ n! }} \braket{ x | n } = C_{0}\sum_{n} \frac{\alpha^{n}}{\sqrt{ n! }} \frac{1}{\sqrt{ 2^{n}n!\sqrt{ \pi } }}H_{n}(x)e^{ -x^{2}/2 } $$
>考虑到厄米多项式的生成函数
>$$e^{ 2xt - t^{2} } = \sum_{n} \frac{H_{n}(x)}{n!}t^{n} $$
>$$\sum_{n} \frac{H_{n}(x)}{n!} \left( \frac{\alpha}{\sqrt{ 2 }} \right)^{n} = e^{ 2x\alpha/\sqrt{ 2 } - \alpha^{2}/2 } $$
>于是
>$$\braket{ x | \alpha } = \frac{C_{0}}{\pi^{1/4}}e^{ -x^{2}/2 +2x\alpha/\sqrt{ 2 } -\alpha^{2}/2 } $$
