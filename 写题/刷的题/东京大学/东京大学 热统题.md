## 2.
设单粒子存在两个不同的轨道波函数 $\varphi_a(\mathbf{r})$ 和 $\varphi_b(\mathbf{r})$。考虑两个相同粒子分别处于 $\varphi_a$ 或 $\varphi_b$ 状态时的两粒子波函数。

- 对于两个费米子、两个玻色子，分别说明所要求的对称性；
- 写出所有可能的两粒子波函数形式。

设：
- 粒子1的位置为 $\mathbf{r}_1$，粒子2的位置为 $\mathbf{r}_2$；
- 每个费米子的自旋为 $1/2$；
- 粒子1的自旋态为 $\alpha_1, \beta_1$（上、下）；
- 粒子2的自旋态为 $\alpha_2, \beta_2$；
- 每个玻色子的自旋为 $0$。
波函数不需要归一化。

>[!S]
>对于费米子其需要满足反交换对称性，对于玻色子需要满足交换对称性。空间部分与自旋部分无耦合，可分离。空间部分可能的构造有
>$$\Psi_{1} = \varphi_{a}(\mathbf{r}_{1})\varphi_{b}(\mathbf{r}_{2}) + \varphi_{b}(\mathbf{r}_{1})\varphi_{a}(\mathbf{r}_{2}) ,\quad \Psi_{2} = \varphi_{a}(\mathbf{r}_{1})\varphi_{b}(\mathbf{r}_{2}) - \varphi_{b}(\mathbf{r}_{1})\varphi_{a}(\mathbf{r}_{2}) $$
>其它的类型可以通过这两种组合而来。类似的自旋部分可能的构造有
>$$\chi_{1} = \alpha_{1}\alpha_{2} ,\quad \chi_{2} = \beta_{1}\beta_{2} ,\quad \chi_{3} = \alpha_{1}\beta_{2} + \alpha_{2}\beta_{1} , \quad \chi_{4} = \alpha_{1}\beta_{2} - \alpha_{2}\beta_{1} $$
>分别的自旋为 $\pm 1,0,0$ 
>由此可以构造两粒子的波函数分别为：
>费米子
>$$\Psi_{F} = \Psi_{1}\chi_{4} + \Psi_{2}\chi_{3} + \Psi_{2}\chi_{1} + \Psi_{2}\chi_{2} $$
>玻色子
>$$\Psi_{B} = \Psi_{1}\chi_{3} + \Psi_{2}\chi_{4} $$

## 3.

设单粒子的轨道波函数为三维自由空间中的本征态。考虑边长为 $L$ 的立方体盒子，并施加周期性边界条件。

1. 求单粒子的本征态及对应能量本征值；
2. 由此求态密度 $D(E)$，使得能量在 $E \sim E + dE$ 之间的态数为 $D(E),dE$。

设：

- 每个粒子的质量为 $m>0$；
- 取最低能量为能量零点；
- $L$ 足够大。

>[!S]
>周期边界条件限制 $\psi(x,y,z)=\psi(x+n_{1}L,y+n_{2}L,z+n_{3}L)$ 其中 $n_{1},n_{2},n_{3}\in \mathbb{Z}$ 盒内无势分布，解为平面波解设为
>$$\psi(x,y,z) = A \exp(-i(k_{1}x+k_{2}y+k_{3}z)) $$
>代入周期边界条件得 $k_{i}=\frac{2\pi}{L}n_{i}$ 于是单粒子的本征态为
>$$\psi_{n_{1},n_{2},n_{3}}(x,y,z) = A \exp\left[  -\frac{2\pi i}{L}(n_{1}x+n_{2}y+n_{3}z)  \right] $$
>能量本征值为
>$$H\psi_{n_{1},n_{2},n_{3}} = -\frac{\hbar^{2}}{2m}\nabla^{2}\psi_{n_{1},n_{2},n_{3}} = \left( \frac{2\pi}{L} \right)^{2} \frac{\hbar^{2}}{2m}(n_{1}^{2}+n_{2}^{2}+n_{3}^{2})\psi_{n_{1},n_{2},n_{3}} $$
>$$E_{n_{1},n_{2},n_{3}} = \frac{n_{1}^{2}+n_{2}^{2}+n_{3}^{2}}{2m}\left( \frac{2\pi \hbar}{L} \right)^{2} $$
>假定粒子非相对论性，$E=\frac{p^{2}}{2m}$ 于是在 $p\sim p+dp$ 的动量大小范围内相空间体积和能量范围为
>$$d\Gamma = V 4\pi p^{2}dp,\quad dE = \frac{p}{m}dp $$
>故该范围内的量子态数为
>$$dN =  \frac{d\Gamma}{h^{3}} $$
>态密度为
>$$D(E) = \frac{dN}{dE} = \frac{1}{h^{3}} \frac{d\Gamma}{dE} = \frac{1}{h^{3}} \frac{V 4\pi p^{2}}{p /m} = \frac{4\pi L^{3}m}{h^{3}}p = \frac{4\pi L^{3}m}{h^{3}} \sqrt{ 2mE } $$
>

## 4.

将 $N$ 个相同粒子组成的**理想气体**放入上述盒中。讨论 $T=0$ 时系统的状态：

- 对于费米气体、玻色气体分别说明；
- 求系统的总能量。

系统哈密顿量为：  
$$  
H = \sum_{i=1}^{N} \frac{p_i^2}{2m}  
$$

其中 $p_i$ 为第 $i$ 个粒子的动量，且 $N$ 足够大。

>[!S]
>对于费米子，在零温时
>$$N = \int_{0}^{E_{F}} gD(E)dE = \frac{4\pi gL^{3}m\sqrt{ 2m }}{h^{3}} \int_{0}^{E_{F}}\sqrt{ E }dE = \frac{8\pi gL^{3}m\sqrt{ 2m }E_{F}^{3/2}}{3h^{3}} $$
>于是费米能为
>$$E_{F} = \left[  \frac{N}{L^{3}} \frac{3h^{3}}{8\pi gm\sqrt{ 2m }} \right]^{2/3} $$
>于是总能量为
>$$\begin{align}
U &  = \int_{0}^{E_{F}} gED(E)dE = \frac{4\pi gL^{3}m\sqrt{ 2m }}{h^{3}} \int_{0}^{E_{F}}E^{3/2}dE = \frac{8\pi gL^{3}m\sqrt{ 2m }}{5h^{3}}E_{F}^{5/2} \\ & = \frac{8\pi gL^{3}m\sqrt{ 2m }}{5h^{3}} \left[  \frac{N}{L^{3}} \frac{3h^{3}}{8\pi gm\sqrt{ 2m }} \right]^{5/3}
\end{align}$$
>对于玻色子，在零温时所有粒子在最低能级态，故总能量为 $U=0$

在巨正则系综（grand canonical ensemble）中，巨配分函数为：  
$$  
\Xi(T,\mu) = \sum_{N} \sum_{j} e^{-\beta (E_j - \mu N)}  
$$

其中：

- $T$ 为温度，$\mu$ 为化学势；
- $\beta = \frac{1}{k_B T}$；
- $E_j$ 是 $N$ 粒子系统的第 $j$ 个能级（这里假设其不显含 $N$）。

# 题2

考虑一个处于温度 $T$ 热平衡状态、具有自旋 $1/2$ 的系统。自旋与外磁场 $H$ 的相互作用由哈密顿量  
$$
H_1 = -\mu H \sigma  
$$ 
给出。这里，$\sigma$ 是取值为 $\pm 1$ 的变量，用来表示自旋方向；$\mu$ 是表示磁矩大小的常数。设玻尔兹曼常数为 $k_B$，回答以下问题。

---

## 1.

在外磁场 $H$ 下，求：

- $\sigma = +1$ 的概率 $p_+$
- $\sigma = -1$ 的概率 $p_-$

>[!S]
>$$Z = \exp(-\beta \mu H) + \exp(\beta \mu H) $$
>$$p_{+} = \frac{\exp(\beta \mu H)}{Z} = \frac{\exp(\beta \mu H)}{\exp(-\beta \mu H) + \exp(\beta \mu H)} $$
>$$p_{-} = \frac{\exp(-\beta \mu H)}{\exp(-\beta \mu H) + \exp(\beta \mu H)} $$


---

## 2.

在外磁场 $H$ 下，证明自旋的期望值满足：  
$$
\langle \sigma \rangle = \tanh\left(\frac{\mu H}{k_B T}\right)  
$$

>[!S]
>期望是
>$$\braket{  \sigma  } = \frac{+1\exp(\beta \mu H) + (-1)\exp(-\beta \mu H)}{Z} = \frac{\sinh(\beta \mu H)}{\cosh(\beta \mu H)} = \tanh\left( \frac{\mu H}{k_{B}T} \right) $$

接下来，考虑如图1所示的正方晶格上的伊辛模型，其中相邻自旋之间存在交换相互作用 $J$。其哈密顿量为：  
$$
H_2 = J \sum_{\langle i,j \rangle} \sigma_i \sigma_j - \mu H \sum_i \sigma_i  
$$
这里：
- $\sigma_i (= \pm 1)$ 表示格点 (i) 上的自旋变量
- $\sum_{\langle i,j \rangle}$ 表示对相邻格点对求和
- 假设为**反铁磁相互作用**$(J > 0)$
- 在**平均场近似**下处理该模型

## 3.

如图1所示，正方晶格可以分为两个子晶格 A 和 B。在平均场近似下，A、B 子晶格的自旋分别受到有效磁场：  
$$
\mu H_{\text{eff},A} = -zJ \langle \sigma_B \rangle + \mu H  
$$
$$
\mu H_{\text{eff},B} = -zJ \langle \sigma_A \rangle + \mu H  
$$
其中：
- $\langle \sigma_A \rangle, \langle \sigma_B \rangle$ 分别为子晶格 A、B 上自旋的期望值
- $z$ 是最近邻数（正方晶格中 $z=4$）
在该有效磁场下，子晶格 A、B 上自旋的期望值满足（自洽方程）：  
$$  
\langle \sigma_A \rangle = f(\langle \sigma_B \rangle), \quad  
\langle \sigma_B \rangle = f(\langle \sigma_A \rangle)  
$$
求函数 $f(x)$。

>[!S]
>期望值由 (2) 知
>$$\braket{ \sigma_{A} } = \tanh(\beta \mu H_{\text{eff},A}) = \tanh(-\beta zJ\braket{ \sigma_{B} } + \beta \mu H )  $$
>$$\braket{ \sigma_{B} } = \tanh(\beta \mu H_{\text{eff},B}) = \tanh(-\beta zJ\braket{ \sigma_{A} } + \beta \mu H )   $$
>于是
>$$f(x) = \tanh(-4\beta Jx + \beta \mu H) $$
>

---
## 4.

在 $H = 0$ 的情况下，考虑存在反铁磁有序解（即 $\langle \sigma_A \rangle = - \langle \sigma_B \rangle \neq 0$）的条件。通过考察 $y = f(x)$ 的图像，说明该解在临界温度 $T_N$ 以下存在，并求出该临界温度。

>[!S]
>在 $H=0$ 的情况下，(3) 给出
>$$\begin{gather}
\braket{ \sigma_{A} } = \tanh(-4\beta J\braket{ \sigma_{B} } )   \\
\braket{ \sigma_{B} } = \tanh(-4\beta J\braket{ \sigma_{A} } )  
\end{gather} $$
>不妨设 $\braket{ \sigma } := \braket{ \sigma_{A} } = -\braket{ \sigma_{B} } > 0$ 得到
>$$\braket{ \sigma } = \tanh(4\beta J\braket{ \sigma } ) $$
>令 $g(x)=\tanh(4\beta Jx)-x$ 则
>$$g'(x) = \frac{4\beta J}{\cosh^2(4\beta Jx)} - 1 ,\quad g''(x) < 0 $$
>考虑到 $g(0)=0$ 所以想要此状态存在，必须有 $g'(0)>0$ 即
>$$4\beta J > 1 \implies T_{c} = \frac{4J}{k_{B}} $$

## 5.

利用自洽方程，求在 $T > T_N$ 时，每个自旋的磁化率：  
$$
\chi = \lim_{H \to 0} \frac{d}{dH} \left( \mu \frac{\langle \sigma_A \rangle + \langle \sigma_B \rangle}{2} \right)  
$$

>[!S]
>由 (3) 知
>$$\begin{gather}
\braket{ \sigma_{A} } = \tanh(-4\beta J\braket{ \sigma_{B} } + \beta \mu H ) \\
\braket{ \sigma_{B} } = \tanh(-4\beta J\braket{ \sigma_{A} } + \beta \mu H )
\end{gather} $$
>由 (4) 知当 $T>T_{N}$ 时，系统无反铁磁有序解，于是当 $H\to 0$ 时 $\braket{ \sigma_{A} } = \braket{ \sigma_{B} }=0$ 考虑在零点处泰勒展开
>$$\braket{ \sigma_{A} } = -4\beta J\braket{ \sigma_{B} } + \beta \mu H + \mathcal{O}(H^{2}) ,\quad (A\leftrightarrow B)  $$
>于是可以解得
>$$\braket{ \sigma_{A} } = \braket{ \sigma_{B} }  = \frac{\beta \mu H}{1-4\beta J} + \mathcal{O}(H^{2}) $$
>代入得
>$$\chi = \lim_{H \to 0} \frac{d}{dH} \left( \mu \frac{\langle \sigma_A \rangle + \langle \sigma_B \rangle}{2} \right) = \frac{\beta \mu^{2}}{1-4\beta J} $$
>

## 6.

与问题3类似，将晶格分为 A、B 两个子晶格，在平均场近似下：

1. 写出 $H=0$ 时的自洽方程
2. 求满足 $\langle \sigma_A \rangle = -\langle \sigma_B \rangle \neq 0$ 的反铁磁相变温度
3. 证明在极限 $J' \to J$ 时，相变温度趋于 0

>[!S]
>1.
>就是说现在还要考虑对角线上相同原子产生的磁场，于是有效磁场是
>$$\mu H_{\text{eff},A} = -4J\braket{ \sigma_{B} } - 4J'\braket{ \sigma_{A} } + \mu H   $$

>$$\mu H_{\text{eff},A} = -4J\braket{ \sigma_{B} } - 4J'\braket{ \sigma_{A} } $$

>$$\begin{gather}
\braket{ \sigma } = \tanh( 4\beta J\braket{ \sigma } - 4\beta J'\braket{ \sigma } )
\end{gather} $$
