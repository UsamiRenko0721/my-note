## SET

- 内球半径 $a$ ，外球壳内半径 $b$ ，两球心距离 $x$ （ $x \ll a,\; x < b-a$ ）。
- 内球带电荷 $Q$ ，外球壳接地（电势为零）。
- 取坐标系：原点固定于 **内球中心** ，外球中心位于 $(0,0,x)$ （ $x>0$ ），极轴沿 $z$ 轴。

## Solution

系统沿 $z$ 轴有轴对称性，可以将势按勒让德级数展开，考虑保留到 $l=0,1$ 阶

$$\phi(r,\theta) = A + \frac{Q}{4\pi\varepsilon_{0}r} + Br\cos \theta + \frac{C\cos\theta}{r^{2}}\tag{1} $$

在内球边界上 $r=a$ 处为等势面，$\frac{\partial \phi(r,\theta)}{\partial \theta}=0$ 所以

$$Ba + \frac{C}{a^{2}} = 0\tag{2} $$

在外球边界上 $r\approx b+x\cos \theta$ 处为零势面，$\phi(b+x\cos \theta,\theta)=0$ 所以

$$ A + \frac{Q}{4\pi\varepsilon_{0}} \frac{1}{b+x\cos \theta} + B(b+x\cos \theta)\cos \theta + \frac{C\cos\theta}{(b+x\cos \theta)^{2}} = 0 $$
$$ \left( A + \frac{Q}{4\pi\varepsilon_{0}b} \right) + \left(  -\frac{Q}{4\pi\varepsilon_{0}} \frac{x}{b} + bB + \frac{C}{b^{2}}  \right)\cos \theta + (\dots)\cos ^{2} \theta = 0 $$
$$\begin{gather}
A + \frac{Q}{4\pi\varepsilon_{0}b} = 0\tag{3} \\
-\frac{Q}{4\pi\varepsilon_{0}} \frac{x}{b} + bB + \frac{C}{b^{2}} \tag{4}
\end{gather}$$

由 (2)(3)(4) 解得

$$\begin{gather}
A = -\frac{Q}{4\pi\varepsilon_{0}b} ,\quad B = -\frac{Q}{4\pi\varepsilon_{0}b} \frac{x}{a^{3}-b^{3}} ,\quad C = \frac{Q}{4\pi\varepsilon_{0}} \frac{a^{3}x}{a^{3}-b^{3}}
\end{gather} $$

所以

$$\phi = -\frac{Q}{4\pi\varepsilon_{0}b} + \frac{Q}{4\pi\varepsilon_{0}r} -\frac{Q}{4\pi\varepsilon_{0}b} \frac{x}{a^{3}-b^{3}}r\cos \theta + \frac{Q}{4\pi\varepsilon_{0}} \frac{a^{3}x}{a^{3}-b^{3}}\frac{\cos\theta}{r^{2}} $$
$$\Delta \phi = 0 - \phi(a,\theta) = \frac{Q}{4\pi\varepsilon_{0}}\left( \frac{1}{a}- \frac{1}{b} \right) $$
$$C^{{(1)}} = \frac{4\pi\varepsilon_{0}ab}{b-a} $$

可见需要将勒让德展开到更高一阶

$$\phi(r,\theta) = A + \frac{B}{r} + \left( Cr+\frac{D}{r^{2}} \right)\cos \theta + \left( Er^{2} + \frac{F}{r^{3}} \right)(3\cos ^{2}\theta-1) \tag{5} $$

内球的边界条件

$$\begin{gather}
Ca + \frac{D}{a^{2}} = 0 \tag{6} \\
Ea^{2} + \frac{F}{a^{3}} = 0 \tag{7}
\end{gather} $$

外球的边界条件，此时对外球的边界的描述要精确到 $\cos ^{2}\theta$ 阶，$r=b+x\cos \theta - \frac{x^{2}}{2b}(1-\cos ^{2}\theta)$ 

$$\begin{align}
&\quad \left[ A + \frac{B}{b}\left(  1 + \frac{x}{b}\cos \theta - \frac{x^{2}}{2b^{2}}(1-\cos ^{2}\theta)  \right)^{-1} \right]P_{0} \\ & 
+ \left[  C\left( b+x\cos \theta+\frac{x^{2}}{2b}(1-\cos ^{2}\theta) \right)+ D\left( b+x\cos \theta+\frac{x^{2}}{2b}(1-\cos ^{2}\theta) \right)^{-2}  \right]P_{1} \\ & 
+ \left[  E\left( b+x\cos \theta+\frac{x^{2}}{2b}(1-\cos ^{2}\theta) \right)^{2}+ F\left( b+x\cos \theta+\frac{x^{2}}{2b}(1-\cos ^{2}\theta) \right)^{-3}  \right] P_{2} \\ & 
=0
\end{align}$$

其中 $P_{0}=1,P_{1}=\cos \theta,P_{2}=3\cos ^{2}\theta-1$ 于是

$$\begin{align}
  &\quad A + \left( \frac{1}{b} + \frac{x^{2}}{2 b^{3}} \right) B + \left(\right. x^{2} - b^{2} \left.\right) E - \left( \frac{1}{b^{3}} + \frac{3 x^{2}}{2 b^{5}} \right) F  \\ &  + \left[ - \frac{x}{b^{2}} B + \left( b - \frac{x^{2}}{2 b} \right) C + \left( \frac{1}{b^{2}} + \frac{x^{2}}{b^{4}} \right) D - 2 x b E + \frac{3 x}{b^{4}} F \right]\cos \theta  \\ &  + \left[ \frac{x^{2}}{2 b^{3}} B + x C - \frac{2 x}{b^{3}} D + \left(\right. 3 b^{2} - 5 x^{2} \left.\right) E + \frac{3}{b^{3}} F \right]\cos ^{2} \theta \\ & 
  +\dots = 0
\end{align} $$

$$\begin{align}
A + \left( \frac{1}{b} + \frac{x^{2}}{2 b^{3}} \right) B + \left(\right. x^{2} - b^{2} \left.\right) E - \left( \frac{1}{b^{3}} + \frac{3 x^{2}}{2 b^{5}} \right) F=0\tag{8} \\
- \frac{x}{b^{2}} B + \left( b - \frac{x^{2}}{2 b} \right) C + \left( \frac{1}{b^{2}} + \frac{x^{2}}{b^{4}} \right) D - 2 x b E + \frac{3 x}{b^{4}} F=0\tag{9} \\
\frac{x^{2}}{2 b^{3}} B + x C - \frac{2 x}{b^{3}} D + \left(\right. 3 b^{2} - 5 x^{2} \left.\right) E + \frac{3}{b^{3}} F = 0\tag{10}
\end{align} $$

最后考虑到 $Q = \iint_{r=a}\sigma dS = \iint_{r=a}\left( -\varepsilon_{0}\frac{\partial \phi}{\partial r} \right)dS$ 得到

$$B = \frac{Q}{4\pi\varepsilon_{0}} \tag{11} $$

于是由 (6)~(11) 解得

$$\begin{gather}
A = - \frac{Q}{4 \pi \epsilon_{0} b} - \frac{b^{2} \left(\right. a^{3} + b^{3} \left.\right) Q \delta^{2}}{8 \pi \epsilon_{0} \left(\right. a^{3} - b^{3} \left.\right) \left(\right. a^{5} - b^{5} \left.\right)} + \frac{a^{5} \left(\right. a^{3} + b^{3} \left.\right) Q x^{2}}{8 \pi \epsilon_{0} b^{3} \left(\right. a^{3} - b^{3} \left.\right) \left(\right. a^{5} - b^{5} \left.\right)} - \frac{Q x^{2}}{8 \pi \epsilon_{0} b^{3}} \\
E = - \frac{\left(\right. a^{3} + b^{3} \left.\right) Q x^{2}}{8 \pi \epsilon_{0} \left(\right. a^{3} - b^{3} \left.\right) \left(\right. a^{5} - b^{5} \left.\right)} \\
F = \frac{a^{5} \left(\right. a^{3} + b^{3} \left.\right) Q \delta^{2}}{8 \pi \epsilon_{0} \left(\right. a^{3} - b^{3} \left.\right) \left(\right. a^{5} - b^{5} \left.\right)} \\
\end{gather}$$

所以

$$\phi(a,\theta) = \frac{Q}{4 \pi \epsilon_{0}} \frac{b - a}{a b} + \frac{Q x^{2}}{4 \pi \epsilon_{0} \left(\right. a^{3} - b^{3} \left.\right)} $$
$$C^{{(2)}} = \frac{Q}{\Delta \phi} = \frac{4 \pi \epsilon_{0} a b \left(\right. b^{3} - a^{3} \left.\right)}{\left(\right. b^{3} - a^{3} \left.\right) \left(\right. b - a \left.\right) - a b x^{2}} $$
