# 统计物理核心知识点

> 基于 Yau Mathematical Physics 2022-2025 热统真题提炼

---

## 一、配分函数与热力学量

### 1.1 配分函数 (Partition Function)

正则系综的核心量，定义：

$$Z = \sum_{\{\sigma\}} e^{-\beta E(\{\sigma\})}, \quad \beta = \frac{1}{k_B T}$$

**计算技巧**：
- 直接枚举（小系统）：列出所有构型及其能量，直接求和
- 因子化（独立自由度）：$Z = \prod_i Z_i$
- 简并度分组法：按某个量子数（如总磁化 $M$）分组，$Z = \sum_M g(M) e^{-\beta E(M)}$

> **例**：三角 Ising 模型用 $M = \sigma_1+\sigma_2+\sigma_3$ 分组，$M \in \{\pm3, \pm1\}$，简并度分别为 $1,3$

### 1.2 核心热力学关系

从配分函数出发可导出全部热力学量：

| 物理量 | 公式 |
|--------|------|
| **Helmholtz 自由能** | $F = -k_B T \ln Z$ |
| **熵** | $S = -\frac{\partial F}{\partial T} = k_B \ln Z + k_B T \frac{\partial \ln Z}{\partial T}$ |
| **内能** | $U = -\frac{\partial \ln Z}{\partial \beta}$ |
| **热容** | $C = \frac{\partial U}{\partial T}$ |
| **磁化强度** | $M = \frac{1}{\beta} \frac{\partial \ln Z}{\partial h}$ |
| **磁化率** | $\chi = \frac{\partial M}{\partial h}$ |

> **记忆法**：$F$ 来自 $\ln Z$，$U,S$ 来自对温度求导，$M$ 来自对外场求导

### 1.3 涨落

$$\langle (\Delta X)^2 \rangle = \langle X^2 \rangle - \langle X \rangle^2$$

磁化涨落与磁化率的关系：
$$\langle (\Delta M)^2 \rangle = k_B T \chi$$

## 二、Ising 模型

### 2.1 哈密顿量

$$E = -J \sum_{\langle i,j \rangle} \sigma_i \sigma_j - h \sum_i \sigma_i, \quad \sigma_i = \pm 1$$

- $J > 0$：铁磁耦合（相邻自旋同向能量低）
- $J < 0$：反铁磁耦合
- $h$：外磁场

### 2.2 三角 Ising 模型（精确可解小系统）

三个自旋在三角形上，两两相互作用：

$$E = -J(\sigma_1\sigma_2 + \sigma_2\sigma_3 + \sigma_3\sigma_1) - h(\sigma_1+\sigma_2+\sigma_3)$$

**状态分类**：

| $M$ | $\sigma_1\sigma_2+\sigma_2\sigma_3+\sigma_3\sigma_1$ | $E$ | 简并度 |
|-----|--------------------------------------------------------|-----|--------|
| $+3$ | $3$ | $-3J-3h$ | 1 |
| $+1$ | $-1$ | $J-h$ | 3 |
| $-1$ | $-1$ | $J+h$ | 3 |
| $-3$ | $3$ | $-3J+3h$ | 1 |

**配分函数**：
$$Z = 2e^{3\beta J}\cosh(3\beta h) + 6e^{-\beta J}\cosh(\beta h)$$

**物理启示**：低温下两个全对齐态（$M=\pm 3$）主导，涨落大 → 铁磁序的有限尺寸信号

### 2.3 低温与高温极限分析

**$h=0$ 时的配分函数**：
$$Z = 2e^{3\beta J} + 6e^{-\beta J}$$

**低温极限 ($T \ll J$)**：$e^{-\beta J} \approx 0$，$Z \approx 2e^{3\beta J}$
- $U \approx -3J$（两个基态各占一半）
- $C \approx \dfrac{12J^2}{T^2} e^{-4J/T}$ → 指数衰减，无能隙激发

**高温极限 ($T \gg J$)**：展开 $e^{-\beta J} \approx 1 - \beta J$
- $C \approx \dfrac{3J^2}{T^2}$ → 代数衰减

## 三、平均场理论 (Mean-Field Theory)

### 3.1 基本思想

将相互作用自旋的问题化为"每个自旋在平均场中"的独立问题：

$$H_{\text{MF}} = \frac{1}{2}NJm^2 - (Jm + h)\sum_i \sigma_i$$

其中 $m = \langle \sigma_i \rangle$ 是序参量（order parameter）。

**关键**：$m$ 本身出现在哈密顿量中 → 需要自洽求解

### 3.2 平均场配分函数

自旋之间无相互作用 → 求和可因子化：

$$Z = e^{-\beta NJm^2/2} \left[ \sum_{\sigma=\pm 1} e^{\beta(Jm+h)\sigma} \right]^N = 2^N e^{-\beta NJm^2/2} \cosh^N[\beta(Jm+h)]$$

**每个自旋的自由能**：
$$f(m) = \frac{1}{2}Jm^2 - k_B T \ln[2\cosh(\beta(Jm+h))]$$

### 3.3 自洽方程

对 $m$ 极小化自由能（或直接计算 $\langle \sigma_i \rangle$）得到：

$$m = \tanh[\beta(Jm + h)]$$

**$h=0$ 时**：$m = \tanh(\beta J m)$

**图解求解**：画 $y=m$ 和 $y=\tanh(\beta J m)$
- $\beta J \leq 1$：仅 $m=0$ 解 → **顺磁相**
- $\beta J > 1$：$m=0$ 和 $m=\pm m_0 \neq 0$ 三个解 → **铁磁相**

### 3.4 临界温度

$$T_c = \frac{J}{k_B}$$

- $T > T_c$：热涨落破坏有序，净磁化为零
- $T < T_c$：自发磁化，对称性自发破缺
- $T = T_c$：二级相变点

### 3.5 临界指数

定义 $t = \dfrac{T-T_c}{T_c}$，近临界点展开 $\tanh x \approx x - x^3/3$：

$$m \approx \beta J m - \frac{1}{3}(\beta J m)^3 + \beta h$$

化简得到状态方程：
$$t m + \frac{1}{3}m^3 = \frac{h}{k_B T_c}$$

三种临界指数：

| 指数 | 定义 | 平均场值 | 推导 |
|------|------|----------|------|
| $\beta_c$ | $m \sim \|t\|^{\beta_c}$ ( $h=0, T<T_c$ ) | $1/2$ | $m = \sqrt{-3t}$ |
| $\gamma_c$ | $\chi \sim \|t\|^{-\gamma_c}$ ( $h=0$ ) | $1$ | $\chi = 1/[k_B T_c(t+m^2)]$ |
| $\alpha_c$ | $C \sim \|t\|^{-\alpha_c}$ | $0$ | $U \propto m^2$，$C$ 有限跃变 |

> **记忆**：平均场给出经典临界指数 $(\alpha,\beta,\gamma) = (0, 1/2, 1)$

### 3.6 Landau 展开

将自由能在 $m=0$ 附近展开（$h=0$）：

$$f(m) \propto \frac{1}{2}J(1-\beta J)m^2 + \frac{1}{12}\beta^3 J^4 m^4 + \cdots$$

- 二次项系数在 $T=T_c$ 变号 → 相变的 Landau 范式
- 四次项为正 → 有序相稳定

## 四、低维系统的热容

### 4.1 一维自由玻色子

色散 $\varepsilon_k = v|k|$，化学势 $\mu = 0$

**能量密度**：
$$\frac{U}{L} = \int_{-\infty}^{\infty} \frac{dk}{2\pi} \frac{v|k|}{e^{\beta v|k|} - 1} = \frac{\pi}{6} \frac{(k_B T)^2}{v}$$

**热容**：
$$\frac{C}{L} = \frac{\pi}{3} \frac{k_B^2 T}{v}$$

> **关键积分**：$\int_0^\infty \frac{x}{e^x-1}dx = \frac{\pi^2}{6}$

### 4.2 一维无自旋费米子

色散 $\varepsilon_k = \hbar^2 k^2/2m$，$\mu$ 远在能带底之上

**低能有效理论**：仅在两个 Fermi 点附近有激发，线性化

$$\varepsilon_k - \mu \approx \pm v_F (k \mp k_F), \quad v_F = \frac{\hbar k_F}{m}$$

**态密度（每个 Fermi 点）**：
$$\nu(\mu) = \frac{1}{\pi v_F}$$

**Sommerfeld 展开**：
$$\frac{C}{L} = \frac{\pi^2}{3} k_B^2 T \nu(\mu) = \frac{\pi}{3} \frac{k_B^2 T}{v_F}$$

### 4.3 普适性启示

尽管微观统计不同（Bose vs Fermi），一维无能隙模的低能理论给出相同的 $C \propto T$ 标度律！区别仅在于传播速度 $v$ vs $v_F$。

## 五、、方法总结

### 5.1 计算配分函数的策略

| 策略 | 适用场景 |
|------|----------|
| 直接枚举 | 小系统（如三角 Ising, $N=3$） |
| 按量子数分组 | 存在好量子数时利用简并度 |
| 独立自由度因子化 | 平均场、无相互作用系统 |
| 连续极限化 | 大系统，求和→积分 |

### 5.2 低温展开技巧

- **分离主导项**：识别基态，将配分函数写为 $Z = Z_0(1 + \text{小量})$
- **展开对数**：$\ln(1+\epsilon) \approx \epsilon$
- **指数衰减**：有能隙系统 $C \sim e^{-\Delta/T}$

### 5.3 平均场方法论

1. 写出平均场哈密顿量（引入序参量 $m$）
2. 计算配分函数 → 自由能 $f(m)$
3. $\partial f/\partial m = 0$ → 自洽方程
4. 图解或解析求解自洽方程
5. 近 $T_c$ 展开求临界指数

### 5.4 关键数学工具

- $\tanh x \approx x - x^3/3 + \cdots$（近临界展开）
- $\cosh x = (e^x+e^{-x})/2$（双曲函数恒等式）
- $\int_0^\infty \frac{x}{e^x-1}dx = \frac{\pi^2}{6}$（Bose 积分）
- Sommerfeld 展开：$\int_{-\infty}^\infty \frac{H(\varepsilon)}{e^{\beta(\varepsilon-\mu)}+1}d\varepsilon$ 的低温展开
- $\zeta(2) = \pi^2/6$（Riemann zeta 函数出现在 Bose 积分中）
