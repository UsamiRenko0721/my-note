# 量子场论知识点

> 整理自 Yau 量子场论真题（22–25年）及模拟题。按主题模块组织。

---

## 一、共形对称性与弯曲时空标量场

> 来源：25年真题、模拟题1

### 1.1 刚性标度不变性 (Rigid Scale Invariance)

- **定义**：度规 $\eta^{\mu\nu} \to \Omega^2 \eta^{\mu\nu}$（$\Omega$ 常数），场按 $\phi \to \Omega^\Delta \phi$ 变换
- **核心操作**：代入作用量，令变换后作用量等于原作用量，解出标度维数 $\Delta$
- **4 维标量场**：$S = -\frac{1}{2}\int d^4 x (\partial_\mu \phi)^2$，得 $\Delta = -1$（或约定不同时为 $+1$）
- **$d$ 维标量场**：$S = \frac{1}{2}\int d^d x (\partial_\mu \phi)^2$，得 $\Delta = \frac{d-2}{2}$
- **关键技巧**：统计 $\Omega$ 的幂次 — 来自 $d^d x$（不变）、$\eta^{\mu\nu}$（$+2$）、$\phi$ 的导数（$2\Delta+2$），令总和为 0

### 1.2 局域 Weyl 变换 (Local Weyl Transformation)

- **定义**：$g^{\mu\nu} \to \Omega^2(x) g^{\mu\nu}$，$\Omega$ 是时空坐标的函数
- **度规行列式变换**：$\sqrt{-g} \to \Omega^{-d} \sqrt{-g}$（$d$ 维）
- **关键区别 vs 刚性**：$\partial_\mu \Omega \neq 0$，产生额外项
- **场的局域变换**：$\phi \to \Omega^\Delta \phi$
  - $\partial_\mu \phi \to \Omega^\Delta (\partial_\mu \phi + \Delta \phi \,\partial_\mu \ln\Omega)$
  - 导数产生 $\partial_\mu \ln\Omega$ 项，这是最小耦合失败的根本原因

### 1.3 最小耦合的失败

- **最小耦合作用量**：$S = -\frac{1}{2} \int d^d x \sqrt{-g} \, g^{\mu\nu} \partial_\mu \phi \partial_\nu \phi$
- **选 $\Delta$ 使整体因子为 1**：$2\Delta + 2 - d = 0$ → $\Delta = \frac{d-2}{2}$
- **剩余破坏项**：$\sim \phi \partial_\mu \phi \,\partial^\mu \ln\Omega$ 和 $\sim \phi^2 (\partial_\mu \ln\Omega)^2$
- 这些项**不能**写成全导数 → 最小耦合无法实现局域 Weyl 不变
- **考点**：清楚为什么 $\Delta$ 的选取只能消除整体因子，消除不了 $\partial\Omega$ 项

### 1.4 Ricci 标量的 Weyl 变换

- **4 维结果**（需掌握推导或牢记）：
  $$\tilde{R} = \Omega^2\big[R + 6\Box\ln\Omega - 6(\nabla\ln\Omega)^2\big]$$
- **$d$ 维推广**：
  $$\tilde{R} = \Omega^2\big[R + 2(d-1)\Box\ln\Omega - (d-1)(d-2)(\nabla\ln\Omega)^2\big]$$
- **推导要点**（Christoffel 联络 → Riemann 张量 → Ricci 张量 → Ricci 标量）：
  $$\tilde{\Gamma}^\lambda_{\mu\nu} = \Gamma^\lambda_{\mu\nu} - \delta^\lambda_\mu \partial_\nu\ln\Omega - \delta^\lambda_\nu \partial_\mu\ln\Omega - g_{\mu\nu}\partial^\lambda\ln\Omega$$

### 1.5 共形耦合 (Conformal Coupling)

- **非最小耦合作用量**：
  $$S = \int d^d x \sqrt{-g} \left[\frac{1}{2}g^{\mu\nu}\partial_\mu\phi\partial_\nu\phi - \frac{1}{2}\xi R\phi^2\right]$$
- **核心思路**：$R\phi^2$ 的变换产生 $\Box\ln\Omega$ 项，通过分部积分转为 $\phi\partial_\mu\phi\,\partial^\mu\ln\Omega$，与动能项的破坏项相消
- **4 维结果**：$\xi = -\frac{1}{6}$（此时 $\Delta = 1$）
- **$d$ 维结果**：$\xi = -\dfrac{d-2}{4(d-1)}$（此时 $\Delta = \frac{d-2}{2}$）
- **共形标量场定义**：满足此 $\xi$ 值的标量场
- **考点**：变分后分别收集 $\phi\partial_\mu\phi\,\partial^\mu\ln\Omega$ 项和 $\phi^2(\partial\ln\Omega)^2$ 项的系数，令其为零，两者应给出一致的 $\xi$

### 1.6 de Sitter 时空中的应用

- **de Sitter 度规**（共形时间坐标）：
  $$ds^2 = \frac{-d\tau^2 + d\mathbf{x}^2}{(H\tau)^2}, \quad \tau \in (-\infty,0)$$
- **度规与平直时空的关系**：$g_{\mu\nu} = \Omega^{-2}(\tau) \eta_{\mu\nu}$，$\Omega(\tau) = H\tau$
- **场重定义**：$\chi = \Omega^{-1}\phi$（在 4 维中，因 $\Delta=1$）
- **有效质量**：变换后作用量变为平直时空中的有质量标量场：
  $$S = \int d^4 x \left[\frac{1}{2}(\partial_\mu\chi)^2 - \frac{1}{2}m_{\text{eff}}^2 \chi^2\right]$$
  其中 $m_{\text{eff}}^2$ 来自 $\frac{\Omega''}{\Omega}$ 项
- **$d$ 维推广**：$m_{\text{eff}}^2 \propto H^2$，具体系数由 $d$ 和 $\xi$ 决定

## 二、不同场的共形性质对比

> 来源：模拟题2、模拟题1

### 2.1 标量场 vs 麦克斯韦场 vs 狄拉克场

|     场类型      | $d=4$ 标度维数 $\Delta$ |   局域 Weyl 不变性    |   需要共形耦合？    |
| :----------: | :-----------------: | :--------------: | :----------: |
|  标量场 $\phi$  |         $1$         | 需加 $\xi R\phi^2$ | 是，$\xi=-1/6$ |
| 麦克斯韦 $A_\mu$ |         $0$         |     **自动满足**     |      否       |
|  狄拉克 $\psi$  |        $3/2$        | 自动满足（需 vierbein） |      否       |

### 2.2 麦克斯韦场的共形对称性

- **$d$ 维标度维数**：$S = -\frac{1}{4}\int d^d x F_{\mu\nu}F^{\mu\nu}$ → $\Delta = \frac{d-4}{2}$
- **$d=4$ 的特殊性**：$\Delta=0$，$A_\mu$ 在 Weyl 变换下不变
  - $F_{\mu\nu}$ 不含联络（$\nabla_{[\mu}A_{\nu]} = \partial_{[\mu}A_{\nu]}$），故 $F_{\mu\nu}$ 也不变
  - 麦克斯韦作用量**自动**局域 Weyl 不变，无需任何耦合项
- **$d\neq 4$**：$\Delta \neq 0$，需要引入 dilaton 场 $e^{\kappa\varphi}$ 来恢复 Weyl 不变性

### 2.3 麦克斯韦能动张量

- $$T_{\mu\nu} = F_{\mu\alpha}F_\nu{}^\alpha - \frac{1}{4}g_{\mu\nu}F_{\alpha\beta}F^{\alpha\beta}$$
- **无迹性**：$T^\mu{}_\mu = 0$（直接带入验证，利用 $g^{\mu\nu}g_{\mu\nu}=d$）
- **协变守恒**：$\nabla^\mu T_{\mu\nu} = 0$（利用运动方程和无源条件）

### 2.4 $d=3$ 的电磁-标量对偶

- $F_{\mu\nu} = \varepsilon_{\mu\nu\rho}\partial^\rho\chi$（Hodge 对偶）
- 麦克斯韦作用量 → 标量场作用量 $S = \frac{1}{2}\int d^3 x (\partial_\mu\chi)^2$
- 验证标度维数的一致性：标量场 $\Delta_\chi = \frac{3-2}{2} = \frac{1}{2}$

## 三、能动张量与对称性

> 来源：22年第二题

### 3.1 能动张量的基本性质

- $\theta^{\mu\nu}$ 对称：$\theta^{\mu\nu} = \theta^{\nu\mu}$
- $\theta^{\mu\nu}$ 守恒：$\partial_\mu \theta^{\mu\nu} = 0$（对应时空平移对称性）
- 这两个性质是构造标度流和共形流的前提

### 3.2 标度流 (Scale Current)

- **定义**：$s^\mu = x_\nu \theta^{\mu\nu}$
- **散度**：$\partial_\mu s^\mu = \theta^\mu{}_\mu$（利用守恒和对称性）
- **守恒条件**：$\theta^\mu{}_\mu = 0$（能动张量无迹）
- **物理意义**：无迹能动张量 → 经典标度不变性

### 3.3 共形流 (Conformal Current)

- **定义**：$K^{\lambda\mu} = x^2\theta^{\lambda\mu} - 2x^\lambda x_\rho \theta^{\rho\mu}$
- **守恒性**：$\partial_\mu K^{\lambda\mu} = 0$ 自动成立（假设 $\theta^{\mu\nu}$ 对称守恒）
- 对应特殊共形变换的守恒荷

### 3.4 标度变换与 dilaton

- **场的标度变换**：$\delta\phi = (1 + x^\lambda\partial_\lambda)\phi$（4 维标量场）
- **dilaton 的非线性实现**：$\delta\sigma = x^\lambda\partial_\lambda\sigma + f^{-1}$
  - 引入 $\chi = e^{f\sigma}$ 使其线性变换：$\delta\chi = (1 + x^\lambda\partial_\lambda)\chi$
- **证明标度不变的技巧**：
  1. 写出所有场的标度变换
  2. 计算 $\delta\mathcal{L}$
  3. 验证 $\delta\mathcal{L} = \partial_\mu(\cdots)$ 是全导数 → 作用量不变

### 3.5 量子层面的标度反常 (Scale Anomaly)

- **经典守恒**：$\theta^\mu{}_\mu = 0$
- **量子破缺原因**：重整化引入标度 $\mu$，$\mu \frac{dg}{d\mu} = \beta(g)$
- **迹反常 (Trace Anomaly)**：
  $$T^\mu{}_\mu = \beta(g)\frac{\partial\mathcal{L}}{\partial g} \neq 0$$
- **含义**：即使经典理论标度不变，量子修正可能破坏标度对称性
- **考点**：解释为什么需要重整化标度，以及 $\beta$ 函数非零意味着标度对称性反常

## 四、重整化理论

> 来源：24年、23年真题，模拟题3

### 4.1 表观发散度 (Superficial Degree of Divergence)

- **公式**（4 维）：
  $$D = 4 - B_E - \frac{3}{2}F_E + \sum_i n_i \delta_i$$
  - $B_E$：玻色子外线数
  - $F_E$：费米子外线数
  - $n_i$：第 $i$ 类顶角数
  - $\delta_i = b_i + \frac{3}{2}f_i + d_i - 4$：相互作用项的发散指标
- **解读**：
  - $D = 2$：二次发散 → 需 $\phi^2$, $(\partial\phi)^2$ 型抵消项
  - $D = 0$：对数发散 → 需 $\bar{\psi}\psi$, $\bar{\psi}\not{\partial}\psi$ 型抵消项
  - $D < 0$：表观收敛（但子图可能仍有发散）
- **考点**：会数外线、识别内线类型、计算发散指标、判断所需抵消项形式

### 4.2 抵消项 (Counterterms)

- **确定原则**：根据表观发散度 $D$，将自能 $\Pi(p^2)$ 对 $p$ 展开到 $D$ 阶
  - $D=2$：$\Pi(p^2) \approx \Pi(0) + p^2\Pi'(0) + \cdots$ → 抵消项 $A\phi^2 + B(\partial_\mu\phi)^2$
  - $D=0$：$\Sigma(\not{p}) \approx \Sigma(0) + \not{p}\Sigma'(0) + \cdots$ → 抵消项 $C\bar{\psi}\psi + D\bar{\psi}\not{\partial}\psi$
  - $D=-1$ 等：可重整（BPHZ 手续），无需新抵消项

### 4.3 可重整化性的判定

- **幂次计数 (Power Counting)**：相互作用项的 $\delta_i \geq 0$ → 不可重整
- **24年 Yukawa 理论**：$\delta_i = b_i + \frac{3}{2}f_i + d_i - 4 = 0$（$b_i=1, f_i=2, d_i=0$，$g\bar{\psi}\gamma^5\psi\phi$ 中玻色子 1 个、费米子 2 个、导数 0 个）→ 可重整
- **$\phi^3$ 理论**：$g$ 有正质量量纲 → 超可重整（super-renormalizable）

### 4.4 耦合常数的量纲分析

- **4 维自然单位**：$[\mathcal{L}] = 4$，$[\partial_\mu] = 1$
- **标量场**：$[\phi] = 1$
- **旋量场**：$[\psi] = 3/2$
- **量纲正规化中**：引入 $\mu$ 使耦合常数无量纲
  - $g \to g\mu^{\varepsilon}$（在 $d=4-\varepsilon$ 中）
- **考点**：给定拉氏量，能判断耦合常数在 4 维的量纲，进而判断理论的可重整化性

## 五、量纲正规化与单圈计算

> 来源：23年真题

### 5.1 动量空间 Feynman 规则

- **传播子**：$\widetilde{D}(p) = \dfrac{i}{p^2 - m^2 + i\varepsilon}$
- **顶角**：$\widetilde{\Gamma} = -ig(2\pi)^4\delta^{(4)}(\sum p)$（$\phi^3$ 理论）
- **对称因子**：单圈自能图 = 1/2

### 5.2 单圈积分的标准流程

1. **写出振幅**：含传播子乘积 + 顶角因子 + 圈动量积分
2. **Feynman 参数化**：
   $$\frac{1}{AB} = \int_0^1 \frac{dx}{[Ax + B(1-x)]^2}$$
3. **平移圈动量**：$k \to k + (1-x)p$，分母配方为 $k^2 + \Delta$
4. **Wick 转动**：$k^0 \to ik_E^0$，$k^2 \to -k_E^2$
5. **$d$ 维球坐标积分**：
   $$\int \frac{d^d k_E}{(2\pi)^d} \frac{1}{(k_E^2 + \Delta)^2} = \frac{1}{(4\pi)^{d/2}} \Gamma\!\left(2-\frac{d}{2}\right) \Delta^{d/2-2}$$
6. **$\varepsilon$ 展开**（$d=4-\varepsilon$）：
   - $\Gamma\!\left(2-\frac{d}{2}\right) = \Gamma\!\left(\frac{\varepsilon}{2}\right) = \frac{2}{\varepsilon} - \gamma + \mathcal{O}(\varepsilon)$
   - $\Delta^{-\varepsilon/2} = 1 - \frac{\varepsilon}{2}\ln\Delta + \mathcal{O}(\varepsilon^2)$
7. **提取发散**：$1/\varepsilon$ 极点 → 抵消项

### 5.3 Wick 转动技术细节

- 目的：将 Minkowski 积分转为 Euclidean 积分（指数衰减，方便球坐标处理）
- 步骤：
  1. 利用 $\frac{1}{k^2-\Delta+i\varepsilon}$ 的极点结构
  2. 逆时针旋转 $k^0$ 积分围道 90°
  3. $d^d k \to i\,d^d k_E$，$k^2 \to -k_E^2$
- **考点**：解释为什么可以 Wick 转动（被积函数解析性，极点不在第一、三象限）

### 5.4 常用公式速查

- **$d$ 维立体角**：$\Omega_d = \dfrac{2\pi^{d/2}}{\Gamma(d/2)}$
- **Schwinger 参数化**：$\dfrac{1}{A^n} = \dfrac{1}{\Gamma(n)}\int_0^\infty dy\, y^{n-1} e^{-yA}$
- **$\Gamma$ 函数展开**：$\Gamma(\varepsilon/2) \approx \frac{2}{\varepsilon} - \gamma$，$\Gamma(-1+\varepsilon/2) \approx -\frac{2}{\varepsilon} + \gamma - 1$

### 5.5 质量重整化

- **裸质量 vs 重整化质量**：$m^2 = m_R^2 + \delta m^2$
- **抵消项选取**：$\delta m^2 = -\dfrac{g^2}{(4\pi)^2}\dfrac{1}{\varepsilon}$（$\phi^3$ 理论单圈）
- **原则**：$\delta m^2$ 恰好抵消 $1/\varepsilon$ 发散

## 六、大 $N$ 展开

> 来源：22年第一题

### 6.1 O(N) 标量场理论

- **拉氏量**：$\mathcal{L} = \frac{1}{2}\partial_\mu\phi^a\partial^\mu\phi^a - \frac{1}{2}\mu_0^2\phi^a\phi^a - \frac{\lambda_0}{8}(\phi^a\phi^a)^2$
- **传播子**：$\widetilde{D}_{ab}(p) = \frac{i}{p^2-\mu_0^2+i\varepsilon}\delta_{ab}$
- **四顶角结构**：$-i\lambda_0(\delta_{ab}\delta_{cd} + \delta_{ac}\delta_{bd} + \delta_{ad}\delta_{bc})$ 
  - 三个通道：$s$, $t$, $u$（Mandelstam 变量）

### 6.2 $1/N$ 展开与 't Hooft 耦合

- **定义**：$g_0 \equiv \lambda_0 N$（'t Hooft 耦合，在大 $N$ 极限下固定）
- **$1/N$ 计数规则**：
  - 每个顶角贡献：$\lambda_0 \sim g_0/N$
  - 每个内线指标求和贡献：$N$
  - 树图：$\mathcal{M}_{\text{tree}} \sim \lambda_0 \sim g_0 N^{-1}$
  - 单圈泡图：$\lambda_0^2 N \sim g_0^2 N^{-1}$
- **大 $N$ 极限**：固定 $g_0$，$N\to\infty$，所有图同阶（$\mathcal{O}(N^{-1})$）
- **考点**：能正确数每张图的 $N$ 幂次和 $g_0$ 幂次

## 七、重整化群基础

> 来源：22年第二题(c)，模拟题3(e)

### 7.1 $\beta$ 函数

- **定义**：$\beta(g) = \mu \frac{dg}{d\mu}$（描述耦合常数随能标的变化）
- **物理含义**：
  - $\beta(g) < 0$：渐近自由（高能时耦合变弱，如 QCD）
  - $\beta(g) > 0$：红外自由（低能时耦合变弱，如 QED / $\phi^4$）
- **与迹反常的关系**：$T^\mu{}_\mu = \beta(g)\frac{\partial\mathcal{L}}{\partial g}$

### 7.2 渐近自由 vs 红外自由

|      性质       |      渐近自由      |     红外自由      |
| :-----------: | :------------: | :-----------: |
| $\beta(g)$ 符号 |      $<0$      |     $>0$      |
|     高能行为      | $g \to 0$（自由）  |    $g$ 增大     |
|     低能行为      |   $g$ 增大（禁闭）   | $g \to 0$（自由） |
|     典型理论      | 非阿贝尔规范理论 (QCD) | $\phi^4$, QED |

## 八、手征对称性与 Ward 恒等式

> 来源：24年真题、模拟题3(e)

### 8.1 Yukawa 理论中的手征结构

- **相互作用**：$-ig\bar{\psi}\gamma^5\psi\phi$（赝标量耦合）
- **$\gamma^5$ 性质**：$(\gamma^5)^2 = 1$，$\{\gamma^5, \gamma^\mu\} = 0$
- **手征变换**：$\psi \to e^{i\alpha\gamma^5}\psi$，$\bar{\psi} \to \bar{\psi}e^{i\alpha\gamma^5}$
- 质量项 $M\bar{\psi}\psi$ 破坏手征对称性

### 8.2 Ward 恒等式的应用

- 联系不同 Green 函数（如顶角函数与自能的关系）
- 对重整化的约束：某些抵消项之间有关系（如 QED 中 $Z_1 = Z_2$）
- **考点**：利用对称性简化重整化分析，判断哪些抵消项是独立的

## 九、各题型解题模板

### 9.1 "求标度维数 / 证明标度不变"题

1. 写出标度变换规则（$\eta^{\mu\nu}$、$\phi$ 等）
2. 代入作用量
3. 统计 $\Omega$ 的幂次
4. 令幂次和为零 → 解出 $\Delta$
5. （局域情况）收集破坏项 → 判断能否消除

### 9.2 "求共形耦合常数"题

1. 写出完整作用量（动能 + $\xi R\phi^2$）
2. 写出所有变换规则（度规、Ricci 标量、场）
3. 计算动能项的额外变化
4. 计算 $R\phi^2$ 项的额外变化（利用分部积分）
5. 收集 $\phi\partial\phi\,\partial\ln\Omega$ 和 $\phi^2(\partial\ln\Omega)^2$ 项
6. 令两项系数分别 → 解出 $\xi$

### 9.3 "表观发散度 + 抵消项"题

1. 画出所有 1PI 图
2. 对每张图算 $D = 4 - B_E - \frac{3}{2}F_E + \sum n_i\delta_i$
3. 根据 $D$ 判断发散类型
4. 将自能函数展开到 $D$ 阶
5. 写出对应抵消项（每阶导数对应一个抵消项）

### 9.4 "量纲正规化单圈计算"题

1. Feynman 规则 → 振幅表达式
2. Feynman 参数化
3. 平移圈动量
4. Wick 转动
5. $d$ 维球坐标积分
6. $\Gamma$ 函数化简
7. $\varepsilon$ 展开 → 提取发散
8. 确定抵消项

### 9.5 "有效质量"题（de Sitter 类）

1. 识别度规的共形因子 $\Omega(\tau)$
2. 场重定义 $\chi = \Omega^\Delta \phi$
3. 代入作用量，分部积分
4. 整理为标准形式：$\frac{1}{2}[(\partial\chi)^2 - m_{\text{eff}}^2\chi^2]$
5. 读取 $m_{\text{eff}}^2$（通常来自 $\Omega''/\Omega$ 项）

## 十、常考易错点

1. **符号约定**：作用量整体符号影响 $\Delta$ 和 $\xi$ 的符号，但最终物理量（$m_{\text{eff}}^2$、$\beta$ 函数符号等）与约定无关
2. **$\sqrt{-g}$ 的变换幂次**：$d$ 维下 $\sqrt{-g} \to \Omega^{-d}\sqrt{-g}$，容易和度规逆变的 $+2$ 搞混
3. **分部积分的边界项**：共形耦合推导中 $\int \phi^2\Box\ln\Omega$ 的分部积分至关重要，要记得负号和 $2\phi\partial\phi$ 因子
4. **$\Delta$ 的选取**：先令总体系数为 1，解出 $\Delta$，再做局域分析；不要在没有定 $\Delta$ 的情况下讨论局域不变性
5. **表观发散度公式**：费米子外线的系数是 $3/2$ 而非 $1$（来自费米子传播子 $\sim 1/p$）
6. **大 $N$ 计数**：内线封闭圈贡献因子 $N$（指标求和），不要漏数
7. **Wick 转动的 $i$ 因子**：$d^d k \to i d^d k_E$，遗漏会导致发散系数错误
