# APHO 模拟题：膨胀宇宙中的量子场论 —— 引力粒子产生

**总分：100 分 | 建议时间：3 小时**

> **命题思路：** 本题与 [[弯曲时空下的QFT|Unruh 效应题]] 互为对偶。Unruh 效应是同一时空、不同观测者；本题是同一类观测者（共动观测者）、不同时间（宇宙膨胀前后）。核心物理相同——时间依赖的背景导致正负频混合、真空不等价、粒子产生——但几何背景从 Rindler 换为 FLRW。

---

## 第 I 部分：含时背景中的标量场（30 分）

### 背景

考虑 $1+1$ 维 Minkowski 时空中的**有质量**实标量场 $\phi(t,x)$，质量 $m > 0$，度规 $\eta_{\mu\nu} = \operatorname{diag}(1,-1)$。自然单位制 $\hbar = c = 1$。

> **与[[弯曲时空下的QFT|Unruh 效应题]]的区别：** 上题 $m=0$ 且始终在静态时空中；本题 $m \neq 0$，且 Part I 的目的是为 Part III 中 FLRW 背景下的"等效含时质量"做铺垫。

---

### I.1 经典理论回顾（6 分）

**(a)** 写出有质量标量场的 Lagrangian 密度 $\mathcal{L} = \frac{1}{2}(\partial_\mu\phi\,\partial^\mu\phi - m^2\phi^2)$，导出 Klein-Gordon 方程：
$$(\partial_t^2 - \partial_x^2 + m^2)\phi = 0$$

>[!S]-
>$$\frac{\partial \mathcal{L}}{\partial \phi} = m\phi ,\quad \quad \frac{\partial \mathcal{L}}{\partial(\partial_{\mu}\phi)} = g^{\mu \nu}\partial_{\nu}\phi $$
>由 欧拉-拉格朗日 方程得到
>$$m\phi = \partial_{\mu}(g^{\mu \nu}\partial_{\nu}\phi) $$
>代入 Minkowski 度规 $g^{\mu \nu}=\text{diag}(1,-1)$ 得到
>$$(\partial_t^2 - \partial_x^2 + m^2)\phi = 0 $$

**(b)** 验证平面波解 $\phi_k(t,x) \propto e^{-i\omega_k t + ikx}$ 满足方程，其中 $\omega_k = \sqrt{k^2 + m^2}$。解释为什么 $\omega_k > 0$ 的解称为**正频模**，而 $\omega_k < 0$ 的解称为**负频模**。正频和负频模在量子化中各扮演什么角色？

>[!S]-
>将 $e^{ -i\omega_{k} t+ikx }$ 代入 Klein-Gordon 方程得
>$$\partial_{t}^{2}e^{ -i\omega_{k}t+ikx } = (-i\omega_{k})^{2}e^{ -i\omega_{k}t+ikx } = -\omega_{k}^{2}e^{ -i\omega_{k}t+ikx } = -(k^{2}+m^{2})e^{ -i\omega_{k}t+ikx } $$
>$$\partial_{x}^{2}e^{ -i\omega_{k}t+ikx } = (ik)^{2}e^{ -i\omega_{k}t+ikx } = -k^{2}e^{ -i\omega_{k}t+ikx } $$
>于是
>$$(\partial_{t}^{2} - \partial_{x}^{2} + m^{2})\phi = [-(k^{2}+m^{2}) + k^{2} +m^{2}]\phi = 0 $$
>即满足 Klein-Gordon 方程。$\omega_{k}>0$ 称为正频，因为相位随时间而减小，对应能量为正；反正则赛相位随时间增加，对应得能量为负。再正则量子化中实标量场量子化为算符，可以按照产生湮灭算符展开，而 $e^{ \pm i\omega_{k}t }$ 就是其对应系数
>$$\phi(t,x) = \int \frac{dk}{\sqrt{ 4\pi \omega_{k} }}[ a_{k}e^{ -i\omega_{k}t+kx } + a^{\dagger}_{k}e^{ i\omega_{k}t-ikx } ] $$

### I.2 模展开与 Fock 空间（8 分）

**(a)** 写出 $t=0$ 时的模展开：
$$\phi(0,x) = \int \frac{dk}{\sqrt{4\pi\omega_k}} \left( a_k e^{ikx} + a_k^\dagger e^{-ikx} \right)$$
$$\pi(0,x) = -i \int \frac{dk}{\sqrt{4\pi\omega_k}} \omega_k \left( a_k e^{ikx} - a_k^\dagger e^{-ikx} \right)$$

利用正则对易关系 $[\phi(x),\pi(y)] = i\delta(x-y)$，验证：
$$[a_k, a_{k'}^\dagger] = \delta(k - k'), \quad [a_k, a_{k'}] = [a_k^\dagger, a_{k'}^\dagger] = 0$$

*提示：参考上题 I.2(a) 的反转法，注意归一化因子从 $\sqrt{|k|}$ 变为 $\sqrt{\omega_k}$。*

>[!S]-
>将场算符进行傅里叶变换即可得到产生湮灭算符的表达，再代入正则对易关系即可。
>$$\begin{gather} a_{k} = \frac{1}{2} \int dx\ e^{ -ikx }\left( \sqrt{ \frac{\omega_{k}}{\pi} }\phi(x) + \frac{i}{\sqrt{ \omega_{k}\pi }}\pi(x) \right) \\ a_{k}^{\dagger} = \frac{1}{2} \int dx\ e^{ ikx }\left(  \sqrt{ \frac{\omega_{k}}{\pi} }\phi(x) - \frac{i}{\sqrt{ \omega_{k}\pi }}\pi(x)  \right) \end{gather} $$
>所以
>$$\begin{align} [a_{k},a_{k'}^{\dagger}] & = \frac{1}{4}\int dxdx'\ e^{ik'x'-ikx } \left[  \sqrt{ \frac{\omega_{k}}{\pi} }\phi(x) + \frac{i}{\sqrt{ \pi \omega_{k} }}\pi(x) , \sqrt{ \frac{\omega_{k'}}{\pi} }\phi(x') - \frac{i}{\sqrt{ \pi \omega_{k'} }}\pi(x')  \right]\\ & = \frac{1}{4}\int dxdx' e^{ik'x'-ikx } \left\{ -\frac{i}{\pi} \sqrt{ \frac{\omega_{k}}{\omega_{k'}} } [\phi(x),\pi(x')] + \frac{i}{\pi} \sqrt{ \frac{\omega_{k'}}{\omega_{k}} } [\pi(x),\phi(x')] \right\} \\ & = \frac{1}{4\pi}\int dxdx' \ e^{ik'x'-ikx } \left[  \sqrt{ \frac{\omega_{k}}{\omega_{k'}} }\delta(x-x') - \sqrt{ \frac{\omega_{k'}}{\omega_{k}} }\delta(x-x') \right] \\ & = \frac{1}{2\pi}\int dx\ ie^{ i(k-k')x } \\ & = \frac{1}{2\pi}(2\pi\delta(k-k')) \\ & = \delta(k-k') \end{align} $$
>$$\begin{align} [a_{k},a_{k'}] & = \frac{1}{4}\int dxdx'\ e^{ -ikx-ik'x' }\left[  \sqrt{ \frac{\omega_{k}}{\pi} }\phi(x) + \frac{i}{\sqrt{ \pi \omega_{k} }}\pi(x) , \sqrt{ \frac{\omega_{k}}{\pi} }\phi(x')+\frac{i}{\sqrt{ \pi \omega_{k} }}\pi(x')  \right] \\ & = \frac{1}{4}\int dxdx'\ e^{ -ikx-ik'x' } \left\{  \frac{i}{\pi}[\phi(x),\pi(x')] + \frac{i}{\pi}[\pi(x),\phi(x')]  \right\} \\ & =0 \end{align} $$
>最后一步是由于 $[\pi(x),\phi(x')]=-[\phi(x'),\pi(x)]=-i\delta(x-x')$ 而 $[\phi(x),\pi(x')]=i\delta(x-x')$ 想抵消，同理 $[a^{\dagger}_{k},a^{\dagger}_{k'}]=0$ 
>

**(b)** 定义粒子数算符 $N = \int dk\, a_k^\dagger a_k$。证明 $N$ 与 Hamiltonian $H = \int dk\, \omega_k\, a_k^\dagger a_k$（正规序后）对易：
$$[N, H] = 0$$
这说明了什么物理事实？在什么条件下 $[N, H] \neq 0$ 可能发生？

>[!S]-
>直接计算
>$$\begin{align} [N,H] & = \int dkdk'\ \omega_{k}^{2} [a^{\dagger}_{k}a_{k} , a^{\dagger}_{k'}a_{k'} ] \\ & = \int dkdk'\ \omega_{k}^{2}( a^{\dagger}_{k'}[a^{\dagger}_{k},a_{k'}]a_{k} + a^{\dagger}_{k}[a_{k},a^{\dagger}_{k'}]a_{k'} ) \\ & = \int dkdk'\ \omega_{k}^{2} ( -a^{\dagger}_{k'}a_{k}\delta(k-k') + a^{\dagger}_{k}a_{k'}\delta(k-k') ) \\ & = 0 \end{align} $$
>所以 $N$ 与 $H$ 是相容的，具有共同本征态，并且由于 $N$ 不显含时，所以
>$$\frac{dN}{dt} = [N,H] = 0 $$
>系统的粒子数是守恒的。当我们的哈密顿量含有相互作用项时，它们可能破坏这种对易关系了。

### I.3 含时谐振子 —— Bogoliubov 变换的预演（10 分）

考虑一个**时间依赖频率** $\omega(t)$ 的谐振子，其 Hamiltonian 为：
$$H(t) = \frac{1}{2}p^2 + \frac{1}{2}\omega^2(t)x^2$$

定义含时产生/湮灭算符：
$$a(t) = \sqrt{\frac{\omega(t)}{2}} x + \frac{i}{\sqrt{2\omega(t)}} p, \quad a^\dagger(t) = \sqrt{\frac{\omega(t)}{2}} x - \frac{i}{\sqrt{2\omega(t)}} p$$

**(a)** 验证 $[a(t), a^\dagger(t)] = 1$ 对任意 $t$ 成立。

>[!S]-
>$$\begin{align} [a(t),a^{\dagger}(t)] & = \left[  \sqrt{ \frac{\omega}{2} }x + \frac{i}{\sqrt{ 2\omega }}p , \sqrt{ \frac{\omega}{2} }x - \frac{i}{\sqrt{ 2\omega }}p  \right] \\ & = -\frac{i}{2}[x,p] + \frac{i}{2}[p,x] \\ & = -\frac{i}{2}\cdot i - \frac{i}{2}\cdot i \\ & = 1 \end{align} $$

**(b)** 设在 $t \to -\infty$ 时 $\omega(t) \to \omega_{\text{in}}$（常数），$t \to +\infty$ 时 $\omega(t) \to \omega_{\text{out}}$（常数）。定义两个**瞬时基态**：
$$a_{\text{in}}|0_{\text{in}}\rangle = 0, \quad a_{\text{out}}|0_{\text{out}}\rangle = 0$$
其中 $a_{\text{in}} = \lim_{t\to -\infty} a(t)$，$a_{\text{out}} = \lim_{t\to +\infty} a(t)$。证明 $a_{\text{out}}$ 与 $a_{\text{in}}$ 之间可以通过 Bogoliubov 变换联系：
$$a_{\text{out}} = \alpha\, a_{\text{in}} + \beta\, a_{\text{in}}^\dagger$$
求出 $\alpha, \beta$ 用 $\omega_{\text{in}}, \omega_{\text{out}}$ 表达的显式。验证归一化条件 $|\alpha|^2 - |\beta|^2 = 1$。

>[!S]-
>无论在哪个等时超平面上，产生湮灭算符的定义总是不变的，由此我们反解出 $x,p$ 作为不变量
>$$x = \sqrt{ \frac{2}{\omega} }(a^{\dagger}+a) ,\quad p=-i\sqrt{ 2\omega }(a^{\dagger}-a) $$
>于是对于终态与末态，自然有关系
>$$\sqrt{ \frac{2}{\omega_{\text{in}}} }(a^{\dagger}_{\text{in}}+a_{\text{in}}) = \sqrt{ \frac{2}{\omega_{\text{out}}} }(a^{\dagger}_{\text{out}}+a_{\text{out}}) ,\quad \sqrt{ 2\omega_{\text{in}} }(a^{\dagger}_{\text{in}}+a_{\text{in}}) = \sqrt{ 2\omega_{\text{out}} }(a^{\dagger}_{\text{out}}+a_{\text{out}}) $$
>解得
>$$a_{\text{out}} = \frac{1}{2}\left( \sqrt{ \frac{\omega_{\text{out}}}{\omega_{\text{in}}} } + \sqrt{ \frac{\omega_{\text{in}}}{\omega_{\text{out}}} } \right)a_{\text{in}} + \frac{1}{2}\left( \sqrt{ \frac{\omega_{\text{out}}}{\omega_{\text{in}}} } - \sqrt{ \frac{\omega_{\text{in}}}{\omega_{\text{out}}} } \right)a^{\dagger}_{\text{in}} $$
>所以
>$$\alpha = \frac{1}{2}\left( \sqrt{ \frac{\omega_{\text{out}}}{\omega_{\text{in}}} } + \sqrt{ \frac{\omega_{\text{in}}}{\omega_{\text{out}}} } \right) ,\quad \beta = \frac{1}{2}\left( \sqrt{ \frac{\omega_{\text{out}}}{\omega_{\text{in}}} } - \sqrt{ \frac{\omega_{\text{in}}}{\omega_{\text{out}}} } \right) $$
>$$|\alpha|^{2} - |\beta|^{2} = \frac{1}{4}\left(  \frac{\omega_{\text{out}}}{\omega_{\text{in}}} + \frac{\omega_{\text{in}}}{\omega_{\text{out}}} + 2 \right) - \frac{1}{4}\left( \frac{\omega_{\text{out}}}{\omega_{\text{in}}} + \frac{\omega_{\text{in}}}{\omega_{\text{out}}} - 2 \right) = 1 $$

**(c)** 若系统初始处于 $|0_{\text{in}}\rangle$，在 $t \to +\infty$ 时测量到的平均粒子数为：
$$\langle 0_{\text{in}} | a_{\text{out}}^\dagger a_{\text{out}} | 0_{\text{in}} \rangle = |\beta|^2$$
计算 $|\beta|^2$，讨论 $\omega_{\text{in}} = \omega_{\text{out}}$ 和 $\omega_{\text{in}} \neq \omega_{\text{out}}$ 两种情况下的结果。这个谐振子模型与宇宙学粒子产生有什么类比关系？

>[!S]-
>$$|\beta|^{2} = \frac{1}{4}\left( \frac{\omega_{\text{out}}}{\omega_{\text{in}}} + \frac{\omega_{\text{in}}}{\omega_{\text{out}}} - 2 \right) = \frac{(\omega_{\text{out}}-\omega_{\text{in}})^{2}}{4\omega_{\text{out}}\omega_{\text{in}}}$$
>在 $\omega_{\text{in}}=\omega_{\text{out}}$ 的情况下 $|\beta|^{2}=0$，代表没有粒子；反之表示会测量到粒子

### I.4 场的 Hamiltonian 作为无穷多谐振子（6 分）

**(a)** 证明场的 Hamiltonian（正规序后）可以写为：
$$H = \int dk\, \omega_k\, a_k^\dagger a_k = \int dk\, \omega_k\, N_k$$
这就是**无穷多个独立谐振子**的集合，每个模 $k$ 是一个频率为 $\omega_k$ 的谐振子。

>[!S]-
>由于场的拉式量是 $\mathcal{L} = \frac{1}{2}(\partial_\mu\phi\,\partial^\mu\phi - m^2\phi^2)$ 所以
>$$\pi(x) = \frac{\partial \mathcal{L}}{\partial(\partial_{0}\phi)} = \partial_{0}\phi $$
>$$\mathcal{H}(x) = \pi(x)\partial_{0}\phi(x) - \mathcal{L} = \frac{1}{2}(\partial_\mu\phi\,\partial^\mu\phi + m^2\phi^2) $$
>$$H = \int dx\ \mathcal{H} = \frac{1}{2} \int dx\ (\partial_{\mu}\phi\partial^{\mu}\phi + m^{2}\phi^{2}) $$
>考虑场得傅里叶展开
>$$\phi(0,x) = \int \frac{dk}{\sqrt{4\pi\omega_k}} \left( a_k e^{ikx} + a_k^\dagger e^{-ikx} \right)$$
>代入得
>$$\begin{align}H & = \int dx \int \frac{dkdk'}{4\pi \sqrt{ \omega_{k}\omega_{k'} }}( (ika_{k}e^{ ikx }-ika^{\dagger}_{k}e^{ -ikx })(ik'a_{k'}e^{ ik'x }-ik'a^{\dagger}_{k'}e^{ -ik'x }) + m^{2}(k)(k') ) \\ & = \int\dots\ (kk'(-a_{k}a_{k'}e^{ i(k+k')x } + a_{k}a^{\dagger}_{k'}e^{ i(k'-k)x } + a^{\dagger}_{k}a_{k'}e^{ i(k'-k)x } - a^{\dagger}_{k}a^{\dagger}_{k'}e^{ -i(k+k')x }) \\ & \quad + m^{2}(-a_{k}a_{k'}e^{ i(k+k')x } + a_{k}a^{\dagger}_{k'}e^{ i(k'-k)x } + a^{\dagger}_{k}a_{k'}e^{ i(k'-k)x } - a^{\dagger}_{k}a^{\dagger}_{k'}e^{ -i(k+k')x })) \\ & = \int \frac{dkdk'}{4\pi \sqrt{ \omega_{k}\omega_{k'} }}\int dx (kk'+m^{2})(-a_{k}a_{k'}e^{ i(k+k')x } + a_{k}a^{\dagger}_{k'}e^{ i(k'-k)x } \\ & \quad + a^{\dagger}_{k}a_{k'}e^{ i(k'-k)x } - a^{\dagger}_{k}a^{\dagger}_{k'}e^{ -i(k+k')x }) \\ & = \int \frac{dkdk'}{2 \sqrt{ \omega_{k}\omega_{k'} }} (-a_{k}a_{k'}\delta(k+k') + a_{k}a^{\dagger}_{k'}\delta(k-k') + a^{\dagger}_{k}a_{k'}\delta(k-k') - a^{\dagger}_{k}a^{\dagger}_{k'}\delta(k+k')) \\ & \quad\cdot(kk'+m^{2}) \\ & = \int \frac{dk}{2\omega_{k}}(-a_{k}a_{-k} + a_{k}a^{\dagger}_{-k} + a^{\dagger}_{k}a_{-k} - a^{\dagger}_{k}a^{\dagger}_{-k})\omega_{k}^{2} \\ & = \frac{1}{2}\int dk\ \omega_{k}(a^{\dagger}_{k}a_{k} + a_{k}a^{\dagger}_{k})  \end{align} $$
>经过正规序后
>$$H = \int dk\ \omega_{k}a^{\dagger}_{k}a_{k} = \int dk\ \omega_{k}N_{k} $$
>最后对于任意时刻的哈密顿量，考虑到时间演化算符与其对易，所以
>$$H(t) = U^{\dagger}(t)H(0)U = H(0)U^{\dagger}U = H(0) = \frac{1}{2}\int dk\ \omega_{k}(a^{\dagger}_{k}a_{k} + a_{k}a^{\dagger}_{k}) $$

**(b)** 结合 I.3 的结果推测：如果 $\omega_k$ 随时间缓慢变化（例如因为宇宙膨胀导致 $m_{\text{eff}}(t)$ 变化），将会发生什么物理现象？为什么这种效应在静态 Minkowski 时空中不会出现？

>[!S]-
>由 I.3 知，如果 $\omega_{k}$ 随时间缓慢变化，则可能导致真空态不再是无粒子的。在 I.4 中可以看出如果 $\omega_{k}$ 含时，则可能导致 $H$ 是显含时间的。在静态 Minkowski 时空中度规为 $\eta^{\mu \nu}=(+ ---)$ 不存在膨胀/收缩效应，其得到的频率 $\omega_{k}=\sqrt{ k^{2} + m^{2} }$ 是与时间无关的，自然不会产生上述效应。

## 第 II 部分：FLRW 宇宙学（30 分）

### 背景

我们的宇宙在大尺度上是均匀且各向同性的，由 **Friedmann-Lemaître-Robertson-Walker (FLRW)** 度规描述。在 $1+1$ 维简化模型中：
$$ds^2 = dt^2 - a^2(t) dx^2$$
其中 $a(t) > 0$ 是**尺度因子**，描述宇宙的膨胀（$\dot{a} > 0$）或收缩（$\dot{a} < 0$）。

---

### II.1 几何基础（8 分）

**(a)** 引入**共形时间** $\eta$：
$$d\eta = \frac{dt}{a(t)}, \quad \eta = \int \frac{dt}{a(t)}$$
证明 FLRW 度规在共形时间下变为：
$$ds^2 = a^2(\eta)(d\eta^2 - dx^2)$$
即 FLRW 度规**共形等价于** Minkowski 度规。这在 $1+1$ 维是否总是成立？在 $3+1$ 维呢？

>[!S]-
>$$ds^{2} = dt^{2} - a^{2}dx^{2} = a^{2}d \eta^{2} - a^{2}dx^{2} = a^{2}(\eta)(d \eta^{2} - dx^{2}) $$
>可见 FLRW 度规共形等价于 Minkowski 度规，在 $3+1$ 维时也是如此，只需要将 $dx^{2}$ 替换为 $dx^{2}+dy^{2}+dz^{2}$ 即可

**(b)** 计算 $1+1$ 维 FLRW 度规的 Ricci 标量 $R$：
$$R = -\frac{2}{a^2}\frac{a''}{a}$$
其中 $a'' = d^2a/d\eta^2$。

*提示：对于 $g_{\mu\nu} = a^2(\eta)\eta_{\mu\nu}$ （共形平直度规），$R = -2\Box\ln a / a^2$（$1+1$ 维），其中 $\Box = \partial_\eta^2 - \partial_x^2$。*

>[!S]-
>由提示
>$$R = -\frac{2}{a^{2}}\Box\ln a = -\frac{2}{a^{2}}\partial_{\eta}^{2}\ln a = -\frac{2}{a^{2}}\partial_{\eta}\left( \frac{a'}{a} \right) = -\frac{2}{a^{2}} \frac{a''}{a} + \frac{2a'^{2}}{a^{4}}$$
>若略去 $a'^{2}$ 即可得到题目中所需的形式

**(c)** 写出 $a(\eta)$ 为常数的特殊情况。此时 FLRW 度规还原为什么？这对应什么物理情况？

>[!S]-
>当 $a(\eta)$ 为常数的时候，$R=0$ 且此时 FLRW 度规还原为
>$$ds^{2} = C(d \eta^{2} - dx^{2}) $$
>这对应于静态平坦宇宙

### II.2 标量场在 FLRW 背景中（10 分）

**(a)** 在弯曲时空中，有质量标量场的作用量为：
$$S = -\frac{1}{2} \int d^2x \sqrt{-g} \left( g^{\mu\nu} \partial_\mu\phi\, \partial_\nu\phi + m^2\phi^2 + \xi R \phi^2 \right)$$
其中 $\xi$ 是曲率耦合常数。$\xi = 0$ 称为**最小耦合**（即不显含曲率项）。一般 $D$ 维时空的共形耦合常数为 $\xi_c = \frac{D-2}{4(D-1)}$。在 $1+1$ 维（$D=2$）中，$\xi_c = 0$ ——**最小耦合恰好就是共形耦合**。在 $3+1$ 维（$D=4$）中，$\xi_c = 1/6$。

在 FLRW 度规下（使用共形时间 $\eta$），写出作用量的显式。证明：
$$S = -\frac{1}{2} \int d\eta\,dx \left[ (\partial_\eta\phi)^2 - (\partial_x\phi)^2 + a^2(\eta)\left(m^2 + \xi R\right)\phi^2 \right]$$

*注意：$1+1$ 维中 $\sqrt{-g} = a^2$，$g^{\mu\nu} = a^{-2}\eta^{\mu\nu}$，两者恰好抵消！这大大简化了问题。*

>[!S]-
>在 FLRW 度规下
>$$\sqrt{ -g }=a^{2} ,\quad g^{\mu \nu} =a^{-2}\eta^{\mu \nu} ,\quad \eta^{\mu \nu} = \text{diag}(1,-1) $$
>于是
>$$\begin{align} S & = -\frac{1}{2} \int d \eta dx\ a^{2}(a^{-2}\eta^{\mu \nu}\partial_{\mu}\phi \partial_{\nu}\phi + m^{2}\phi^{2} + \xi R\phi^{2}) \\ & = -\frac{1}{2}\int d \eta dx( \partial_{\eta}\phi \partial_{\eta}\phi - \partial_{x}\phi \partial_{x}\phi + a^{2}m^{2}\phi^{2} + a^{2}\xi R\phi^{2} ) \end{align} $$
>

**(b)** 由作用量导出运动方程：
$$\partial_\eta^2\phi - \partial_x^2\phi + a^2(\eta)(m^2 + \xi R)\phi = 0$$
将其与 Minkowski 时空中的 Klein-Gordon 方程对比，$a^2(m^2 + \xi R)$ 扮演了什么角色？

>[!S]-
>拉式量可以读出来是
>$$\mathcal{L} = -\frac{1}{2}\partial_{\mu}\phi \partial^{\mu}\phi - \frac{a^{2}(\eta)}{2}(m^{2}+\xi R)\phi^{2} $$
>于是
>$$\frac{\partial \mathcal{L}}{\partial \phi} = -a^{2}\left( \eta \right)(m^{2}+\xi R)\phi ,\quad \frac{\partial \mathcal{L}}{\partial(\partial_{\mu}\phi)} = -g^{\mu \nu}\partial_{\nu}\phi $$
>由欧拉-拉格朗日方程得到
>$$-a^{2}(\eta)(m^{2}+\xi R)\phi = -g^{\mu \nu}\partial_{\mu}\partial_{\nu}\phi $$$$\partial_{\eta}^{2}\phi - \partial_{x}^{2}\phi + a^{2}(\eta)(m^{2}+\xi R)\phi = 0 $$
>对比 Minkowski 时空中的 Klein-Gordon 方程，可见其质量项变化了，$a^2(m^2 + \xi R)$ 扮演了新的时空中标量场的质量。
>

### II.3 模分解与含时谐振子（12 分）

**(a)** 对空间坐标做 Fourier 变换：
$$\phi(\eta, x) = \int \frac{dk}{\sqrt{2\pi}} e^{ikx} \chi_k(\eta)$$
证明每个模函数 $\chi_k(\eta)$ 满足：
$$\chi_k''(\eta) + \omega_k^2(\eta) \chi_k(\eta) = 0$$
其中含时频率为：
$$\omega_k^2(\eta) = k^2 + a^2(\eta)\left(m^2 + \xi R(\eta)\right)$$
这是一个**时间依赖频率的谐振子方程**

>[!S]-
>将模展开的场代入上一问中的方程：
>$$\partial_{\eta}^{2}\phi = \int \frac{dk}{\sqrt{ 2\pi }}e^{ ikx }\partial_{\eta}^{2}\chi_{k}(\eta) = \int \frac{dk}{\sqrt{ 2\pi }}e^{ ikx }\chi''_{k}(\eta) $$
>$$\partial_{x}^{2}\phi = \int \frac{dk}{\sqrt{ 2\pi }}(\partial_{x}^{2}e^{ ikx })\chi_{k}(\eta) = \int \frac{dk}{\sqrt{ 2\pi }}(-k^{2})e^{ ikx }\chi_{k}(\eta) $$
>于是
>$$\partial_\eta^2\phi - \partial_x^2\phi + a^2(\eta)(m^2 + \xi R)\phi = \int \frac{dk}{\sqrt{ 2\pi }}e^{ ikx }[ \chi''_{k} + (k^{2} + a^{2}(m^{2}+\xi R))\chi_{k} ] = 0 $$
>可见对于每个模式都有
>$$\chi''_{k} + (k^{2} + a^{2}(m^{2}+\xi R))\chi_{k} = 0 $$

**(b)** 取**最小耦合**（$\xi = 0$）和**无质量**（$m = 0$）。证明：
$$\omega_k^2(\eta) = k^2 \quad\text{（常数）}$$
即 $\chi_k'' + k^2 \chi_k = 0$，与 Minkowski 时空中的模方程**完全一致**。这意味着什么物理结论？为什么这种情况不会产生粒子？

> 在 $1+1$ 维中最小耦合 $\xi=0$ 恰好就是共形耦合（$\xi_c = \frac{D-2}{4(D-1)}\big|_{D=2} = 0$），所以此处的"无粒子产生"实际上是共形平凡性的体现。作为对比：若 $m \neq 0$ 或 $\xi \neq 0$（如在 $3+1$ 维中），则 $\omega_k$ 会随时间变化。

>[!S]-
>取 $\xi=0,\;m=0$，代入 $\omega_k^2 = k^2 + a^2(m^2 + \xi R)$：
>$$\omega_k^2 = k^2 + a^2(0 + 0 \cdot R) = k^2$$
>$$\chi_k'' + k^2 \chi_k = 0$$
>模方程与 Minkowski 时空完全一致 → 正频模 $e^{-ik\eta}$ 不随时间混合 → 无 Bogoliubov 变换 → 无粒子产生。
>
>这说明在 $1+1$ 维中，**最小耦合就是共形耦合**：$\xi_c = \frac{D-2}{4(D-1)}\big|_{D=2} = 0$。无质量共形耦合场在 Weyl 变换 $g_{\mu\nu} \to \Omega^2 g_{\mu\nu}$ 下运动方程不变，因此 FLRW 度规 $a^2(\eta)\eta_{\mu\nu}$ 中的膨胀因子 $a(\eta)$ 被共形不变性完全吸收——物理上等同于静态 Minkowski 时空。

**(c)** 对于**最小耦合**（$\xi = 0$）的**有质量**（$m > 0$）标量场，$\omega_k^2(\eta) = k^2 + m^2 a^2(\eta)$。解释为什么宇宙膨胀（$a(\eta)$ 随时间增大）会导致 $\omega_k(\eta)$ 随时间变化，从而可能产生粒子。将这一情况与 I.3 中的含时谐振子模型做类比。

>[!S]-
>宇宙膨胀就是 $a(\eta)$ 随时间增大，由关系 $\omega^{2}_{k}(\eta) = k^{2} + m^{2}a^{2}(\eta)$ 知道 $\omega_{k}(\eta)$ 也是随时间增大的，也即场的能量增加，也就意味着可能产生粒子。这与 I.3 中预言的结果相近。

## 第 III 部分：宇宙学粒子产生 —— 骤胀模型（40 分）

### 背景

则 $\omega_k(\eta)$ 也在 $\eta = 0$ 处发生跳变：
$$\omega_k(\eta) = \begin{cases} \omega_k^{\text{in}} \equiv \sqrt{k^2 + m^2 a_1^2}, & \eta < 0 \\ \omega_k^{\text{out}} \equiv \sqrt{k^2 + m^2 a_2^2}, & \eta > 0 \end{cases}$$

### III.1 渐近区域与模式匹配（10 分）

**(a)** 写出 $\eta < 0$（"in" 区域）的正频模函数：
$$\chi_k^{\text{in}}(\eta) = \frac{1}{\sqrt{2\omega_k^{\text{in}}}} e^{-i\omega_k^{\text{in}}\eta}, \quad \eta < 0$$

类似写出 $\eta > 0$（"out" 区域）的正频模函数 $\chi_k^{\text{out}}(\eta)$。

定义 "in" 真空 $|0_{\text{in}}\rangle$ 和 "out" 真空 $|0_{\text{out}}\rangle$。

>[!S]-
>$$\chi_{k}^{\text{out}}(\eta) = \frac{1}{\sqrt{ 2\omega_{k}^{\text{out}} }}e^{ -i\omega_{k}^{\text{out}}\eta } ,\quad \eta>0 $$
>而 in 真空由 $a^{\text{in}}$ 定义 $a^{\text{in}}\ket{0_{\text{in}}}=0$ 类似的 $a^{\text{out}}\ket{0_{\text{out}}}=0$ 

**(b)** 在 $\eta = 0$ 处，场 $\phi$ 及其共轭动量 $\pi = \partial_\eta\phi$ 应连续（骤胀近似下仍要求场和动量连续）。由于 $\chi_k$ 是 $\phi$ 的 Fourier 模，这意味着 $\chi_k$ 和 $\chi_k'$ 在 $\eta = 0$ 处连续。

将 $\eta > 0$ 区域的完全解写为 $\chi_k^{\text{out}}$ 和 $\chi_k^{\text{out}*}$ 的线性组合：
$$\chi_k^{\text{in}}(\eta) = A_k \chi_k^{\text{out}}(\eta) + B_k \chi_k^{\text{out}*}(\eta), \quad \eta > 0$$
其中 $A_k$ 和 $B_k$ 是常数。利用 $\eta = 0$ 处的连续性条件：
$$\chi_k^{\text{in}}(0^-) = \chi_k(0^+), \quad \chi_k^{\text{in}\prime}(0^-) = \chi_k'(0^+)$$
求 $A_k$ 和 $B_k$：
$$\boxed{A_k = \frac{1}{2}\left( \sqrt{\frac{\omega_k^{\text{out}}}{\omega_k^{\text{in}}}} + \sqrt{\frac{\omega_k^{\text{in}}}{\omega_k^{\text{out}}}} \right), \quad B_k = \frac{1}{2}\left( \sqrt{\frac{\omega_k^{\text{out}}}{\omega_k^{\text{in}}}} - \sqrt{\frac{\omega_k^{\text{in}}}{\omega_k^{\text{out}}}} \right)}$$
验证 $|A_k|^2 - |B_k|^2 = 1$。

>[!S]-
>由连续性条件知
>$$\frac{1}{\sqrt{ 2\omega^{in}_{k} }} = \frac{A_{k}}{\sqrt{ 2\omega^{\text{out}}_{k} }} + \frac{B_{k}}{\sqrt{ 2\omega^{\text{out}}_{k} }}$$
>$$-\frac{i\omega^{\text{in}}_{k}}{\sqrt{ 2\omega^{\text{in}}_{k} }} = -\frac{i\omega^{\text{out}}_{k}A_{k}}{\sqrt{ 2\omega^{\text{out}}_{k} }} + \frac{i\omega^{\text{out}}_{k}}{\sqrt{ 2\omega^{\text{out}}_{k} }} $$
>解得
>$${A_k = \frac{1}{2}\left( \sqrt{\frac{\omega_k^{\text{out}}}{\omega_k^{\text{in}}}} + \sqrt{\frac{\omega_k^{\text{in}}}{\omega_k^{\text{out}}}} \right), \quad B_k = \frac{1}{2}\left( \sqrt{\frac{\omega_k^{\text{out}}}{\omega_k^{\text{in}}}} - \sqrt{\frac{\omega_k^{\text{in}}}{\omega_k^{\text{out}}}} \right)}$$
>于是
>$$|A_{k}|^{2} - |B_{k}|^{2} = \frac{1}{4}\left( \frac{\omega^{\text{out}}}{\omega^{\text{in}}} + \frac{\omega^{\text{in}}}{\omega^{\text{out}}} + 2 \right) - \frac{1}{4}\left( \frac{\omega^{\text{out}}}{\omega^{\text{in}}} + \frac{\omega^{\text{in}}}{\omega^{\text{out}}} - 2 \right) = 1 $$

### III.2 Bogoliubov 变换与粒子产生（10 分）

**(a)** 在量子理论中，上式对应于 "in" 和 "out" 湮灭算符之间的 Bogoliubov 变换：
$$a_k^{\text{out}} = A_k^* a_k^{\text{in}} - B_k^* a_k^{\text{in}\dagger}$$
（符号约定来源于 Klein-Gordon 内积 $\beta = -(v, u^*)$ 的定义。）写出逆变换，并用 $a_k^{\text{in}}, a_k^{\text{in}\dagger}$ 表达 $a_k^{\text{out}\dagger}$。

>[!S]-
>由 $a_k^{\text{out}} = A_k^* a_k^{\text{in}} - B_k^* a_k^{\text{in}\dagger}$ 取共轭知
>$$a_k^{\text{out}\dagger} = A_k a_k^{\text{in}\dagger} - B_k a_k^{\text{in}} $$
>于是
>$$a^{\text{in}}_{k} = \frac{A^{*}_{k} + B_{k}}{|A_{k}|^{2} - |B_{k}|^{2}}a^{\text{out}}_{k} ,\quad a^{\text{in}{\dagger}}_{k} = \frac{A_{k} + B^{*}_{k}}{|A_{k}|^{2} - |B_{k}|^{2}}a^{\text{out}{\dagger}}_{k} $$
>

**(b)** "out" 区域观测者测量到的粒子数密度（每模 $k$）为：
$$n_k = \langle 0_{\text{in}} | a_k^{\text{out}\dagger} a_k^{\text{out}} | 0_{\text{in}} \rangle = |B_k|^2$$
计算 $n_k$ 的显式表达式：
$$\boxed{n_k = \frac{(\omega_k^{\text{out}} - \omega_k^{\text{in}})^2}{4\omega_k^{\text{in}}\omega_k^{\text{out}}}}$$
讨论 $n_k$ 在以下极限下的行为：
- $k \to \infty$（高动量/紫外极限）
- $k \to 0$（低动量/红外极限）
- $a_2 \to a_1$（无膨胀极限）

>[!S]-
>由 (a)(b) 可知
>$$n_{k} = \braket{ 0_{\text{in}} |a^{\text{out}{\dagger}}_{k}a^{\text{out}}_{k}| 0_{\text{in}} } = |B_{k}|^{2}\braket{ 0_{\text{in}} |a^{\text{in}{\dagger}}_{k}a^{\text{in}}_{k}| 0_{\text{in}} } = |B_{k}|^{2} $$
>其中
>$$B_{k} = \frac{1}{2}\left( \sqrt{\frac{\omega_k^{\text{out}}}{\omega_k^{\text{in}}}} - \sqrt{\frac{\omega_k^{\text{in}}}{\omega_k^{\text{out}}}} \right) $$
>于是
>$$n_{k} = \frac{1}{4}\left( \frac{\omega^{\text{out}}}{\omega^{\text{in}}} + \frac{\omega^{\text{in}}}{\omega^{\text{out}}} - 2 \right) = \frac{(\omega_k^{\text{out}} - \omega_k^{\text{in}})^2}{4\omega_k^{\text{in}}\omega_k^{\text{out}}} $$
>当 $k\to \infty$ 时，由于 $\omega^{\text{in/out}}_{k}\sim \sqrt{ k^{2} + a_{1,2} }$ 所以 $\omega^{\text{in/out}}_{k}\to \infty$ 具体地说
>$$n_{k} = \lim_{ k \to \infty } \frac{(\sqrt{ k^{2} + m^{2}a_{2}^{2} } - \sqrt{ k^{2} + m^{2}a_{1}^{2} })^{2}}{4\sqrt{ (k^{2}+m^{2}a_{1}^{2})(k^{2}+m^{2}a_{2}^{2}) }} = 0 $$
>当 $k\to 0$ 时 $\omega^{\text{in}}_{k}\to ma_{1},\omega^{\text{out}}_{k}\to ma_{2}$ 于是
>$$n_{k}\to\frac{(a_{1}-a_{2})^{2}}{4a_{1}a_{2}} $$
>当 $a_{1}\to a_{2}$ 时 $\omega^{\text{in}}\to \omega^{\text{out}}$ 于是
>$$n_{k} = \lim_{ a_{1} \to a_{2} } \frac{(\sqrt{ k^{2} + m^{2}a_{2}^{2} } - \sqrt{ k^{2} + m^{2}a_{1}^{2} })^{2}}{4\sqrt{ (k^{2}+m^{2}a_{1}^{2})(k^{2}+m^{2}a_{2}^{2}) }} = \lim_{ a_{1} \to a_{2} } \frac{m^{4}(a_{1}^{2}-a_{2}^{2})^{2}}{4\sqrt{ (\dots)(\dots) }(\sqrt{ \dots }+\sqrt{ \dots })^{2}} = 0 $$
>

### III.4 宇宙学意义与讨论（10 分）

**(a)** 在标准宇宙学中，尺度因子 $a(t)$ 的行为由 Friedmann 方程决定。对于辐射主导的宇宙，$a(t) \propto t^{1/2}$，即 $a(\eta) \propto \eta$。在暴胀（inflation）模型中，$a(t) \propto e^{Ht}$（de Sitter 膨胀），即 $a(\eta) = -1/(H\eta)$（$\eta < 0$）。

在 de Sitter 膨胀中，共形时间 $\eta$ 从 $-\infty$ 演化到 $0^-$。证明对于固定的物理动量 $p = k/a(\eta)$，当 $\eta \to 0^-$ 时 $p \to -\infty$（即模的物理波长被拉伸到远超 Hubble 视界）。这对暴胀中量子涨落放大为经典密度扰动有何启示？

*提示：暴胀期间，量子真空涨落的模被拉出视界后"冻结"为经典扰动——这正是 CMB 各向异性的种子。*

>[!S]-
>在 de Sitter 暴胀模型中，尺度因子为 $a(\eta) = -1/(H\eta)$，其中 $\eta < 0$ 且 $\eta \to 0^-$ 时 $a \to +\infty$。对于固定的共动波数 $k$，物理动量 $p = k/a(\eta) = -Hk\eta$。由于 $\eta$ 为负值（例如 $\eta = -|\eta|$），则 $p = Hk|\eta|$。当 $\eta \to 0^-$ 时，$|\eta| \to 0$，因此 $p \to 0$（而非 $-\infty$，可能原题笔误）。这意味着物理波长 $\lambda_{\text{phys}} = 2\pi/p \to \infty$，即模式被拉伸到远超哈勃视界 $H^{-1}$ 的尺度。
>
>暴胀期间，量子真空涨落的共动模被指数膨胀拉出视界。一旦物理波长大于哈勃半径（即 $p < H$），模的演化由曲率主导，其振幅“冻结”为经典扰动。这些超视界扰动在暴胀结束后重新进入视界，成为宇宙微波背景辐射（CMB）温度各向异性和大尺度结构形成的种子。这正是暴胀理论的核心预言之一。

**(b)** 你刚在 III.3 中计算的粒子产生对应的是**膨胀结束后**残留的粒子。在真实的暴胀宇宙学中，暴胀结束时 inflaton 场的相干振荡会产生大量粒子——这一过程称为**预热**（preheating）。比较"骤胀粒子产生"与"预热"的异同。为什么骤胀模型中只产生少量粒子，而预热可以极其高效？

*提示：预热涉及参数共振（parametric resonance），$n_k$ 指数增长而非单次产生。*

>[!S]-
>骤胀模型假设背景在极短时间内一次性变化。粒子数由 $∣β_{k}∣^{2}$ 给出，对于小膨胀 $ϵ≪1$ 有 $n_{k}∼ϵ^{2}$，即使 $ϵ∼1$，$n_{k}$​ 也仅为量级 $\mathcal{O}(1)$，不会指数增长。这是因为单次非绝热变化只能产生有限粒子，没有正反馈放大机制。
>
>预热中，inflaton 场在势能最小值附近振荡，导致与之耦合的其它场的有效质量或频率产生周期性调制。这种周期驱动可使某些动量模式进入参数共振，即 Floquet 指数 μk>0μk​>0，使得每一振荡周期粒子数呈指数增长。因此，即使初始涨落很小，经过数十次振荡后粒子数可暴增，迅速将 inflaton 能量转化为辐射，实现高效再加热。

**(c)** 本题在 $1+1$ 维中讨论。在 $3+1$ 维中，标量场的模函数 $\chi_k(\eta)$（共形重标度后）满足：
$$\chi_k'' + \left( k^2 + m^2 a^2 + (6\xi - 1)\frac{a''}{a} \right) \chi_k = 0$$
解释 $(6\xi - 1)a''/a$ 项的物理来源。对于共形耦合（$\xi = 1/6$，$3+1$ 维）的无质量场，会产生粒子吗？这说明了共形耦合在弯曲时空 QFT 中的什么特殊地位？

>[!S]-
>在 $3+1$ 维 FLRW 度规 $ds^2 = a^2(\eta)(d\eta^2 - d\mathbf{x}^2)$ 中，引入共形重标度场 $\chi = a\phi$（对于有质量场需注意），则作用量变分得到的模方程包含曲率耦合项。具体推导中，标量场的 Klein-Gordon 方程为：
>$$\Box \phi + m^2 \phi + \xi R \phi = 0$$
>其中 $\Box = \frac{1}{\sqrt{-g}} \partial_\mu (\sqrt{-g} g^{\mu\nu} \partial_\nu)$。在 FLRW 背景下，引入 $\chi_k = a \phi_k$（注意 $a^{1/2}$ 在 3+1 维应为 $a^{3/2}$? 实际上共形重标度通常取 $\chi = a \phi$ 只适用于 1+1 维；在 3+1 维中，正确的重标度是 $\chi = a \phi$ 仍可，但方程会多一项。更标准的是：设 $\phi = \chi / a$，则代入方程得到：
>$$\chi''_k + \left( k^2 + m^2 a^2 + \left( \xi - \frac{1}{6} \right) 6 \frac{a''}{a} \right) \chi_k = 0$$
>这里利用 $R = 6a''/a^3$（对于平坦 FLRW）。因此 $(6\xi - 1)\frac{a''}{a}$ 项正是来源于曲率耦合项 $\xi R \phi^2$ 与共形重标度后产生的 $a''/a$ 项的组合。当 $\xi = 1/6$ 时，该组合恰好抵消，即 $(6\cdot\frac16 - 1)=0$，从而方程变为：
>$$\chi_k'' + (k^2 + m^2 a^2) \chi_k = 0$$
>对于无质量场，则有 $\chi_k'' + k^2 \chi_k = 0$，即常数频率的简谐振荡。这意味着每个模的粒子数守恒，不会因宇宙膨胀而产生粒子。这是因为 $\xi = 1/6$ 的标量场在 3+1 维中是**共形不变**的（无质量时），其作用量在共形变换下不变。而 FLRW 度规共形于 Minkowski 度规，因此该场等价于平坦时空中的自由场，真空态保持为真空，没有粒子产生。
>
>**物理意义**：共形耦合保证了在共形平坦的时空背景中，无质量场的行为与平坦时空完全一致，膨胀效应被吸收到场的重新定义中。这强调了共形对称性在弯曲时空量子场论中的特殊地位：它是保持粒子数守恒的对称性，而任何破坏共形不变性的项（如质量或非共形耦合）都会导致粒子产生。
