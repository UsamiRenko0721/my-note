## 第一章 变分法与 Euler-Lagrange 方程

> 本章训练泛函变分的直接计算，以及从作用量导出运动方程的标准流程。

### 1.1 最速降线问题（Brachistochrone）

**(a)** 在竖直平面内，一质点从原点 $(0,0)$ 静止出发沿曲线 $y(x)$ 下滑至 $(x_1, y_1)$（$y$ 向下为正），仅受重力作用。写出到达终点所需时间的泛函表达式 $T[y] = \int_0^{x_1} \sqrt{\frac{1+y'^2}{2gy}}\,dx$。

**(b)** 利用 Euler-Lagrange 方程（被积函数不显含 $x$），导出 Beltrami 恒等式：
$$F - y'\frac{\partial F}{\partial y'} = C$$
并由此证明最速降线满足 $y(1+y'^2) = 2R$（$R$ 为常数）。

**(c)** 引入参数 $y = R(1-\cos\theta)$，证明最速降线是摆线（cycloid），并写出 $x(\theta)$ 的参数方程。

>[!s]- *(a) 时间泛函表达式*
>由能量守恒得到速率和 $y$ 的关系
>
>$$\frac{1}{2}mv^{2} = mgy \implies v = \sqrt{ 2gy } $$
>
>对于轨道 $y(x)$ 其切线方向为 $y'(x)$ 于是
>
>$$\dot{y} = v\cdot \frac{1}{\sqrt{ 1+y'^{2} }} $$
>
>所以
>
>$$T[y] = \int_{0}^{x_{1}} dt = \int_{0}^{x_{1}} (\dot{y})^{-1} dy = \int_{0}^{x_{1}} \sqrt{ \frac{1+y'^{2}}{2gy} }dy $$

>[!s]- *(b) Beltrami 恒等式*
>由欧拉-拉格朗日方程，我们记
>$$L = \sqrt{ \frac{1+y'^{2}}{2gy} } $$
>
>则
>
>$$\frac{\partial L}{\partial y} = -\frac{1}{2}\sqrt{ \frac{1+y'^{2}}{2gy^{3}} } ,\quad \frac{\partial L}{\partial y'} = \frac{y'}{\sqrt{ 2gy(1+y'^{2}) }} $$
>$$\frac{\partial L}{\partial y} - \frac{d}{dx}\frac{\partial L}{\partial y'} = 0 $$
>两边对 $y$ 积分即得 $F - y'\frac{\partial F}{\partial y'} = C$ 于是得到
>
>$$\sqrt{ \frac{1+y'^{2}}{2gy} } - \frac{y'^{2}}{\sqrt{ 2gy(1+y'^{2}) }} = \frac{1}{\sqrt{ 2g }} \frac{1}{\sqrt{ y(1+y'^{2}) }} = C $$
>$$y(1+y'^{2}) = C' := 2R$$

>[!s]- *(c) 证明最速降线是摆线*
>由上一问得到的
>
>$$y(1+y'^2) = 2R $$
>得到
>
>$$y' = \sqrt{ \frac{2R-y}{y} } $$
>$$dx = \frac{dy}{y'} = \sqrt{ \frac{y}{2R-y} }dy $$
>令 $y=R(1-\cos \theta)$ 得到 $dy=R\sin \theta d\theta$ 
>
>$$dx = \sqrt{ \frac{1-\cos \theta}{1+\cos \theta} } R\sin \theta d\theta = R(1-\cos \theta)d\theta $$
>
>积分得到
>
>$$x = R(\theta-\sin \theta) $$
>
>于是得到轨道的参数方程
>
>$$x = R(\theta-\sin \theta) ,\quad y = R(1-\cos \theta) , \quad 0<\theta<\pi $$
>
>这就是摆线的参数方程

### 1.2 极小旋转曲面（肥皂膜）

**(a)** 将连接两圆环 $(x_1, r_1)$ 和 $(x_2, r_2)$ 的曲线 $r(x)$ 绕 $x$ 轴旋转，形成的曲面面积为：
$$S[r] = 2\pi\int_{x_1}^{x_2} r\sqrt{1+r'^2}\,dx$$
写出该泛函的 Euler-Lagrange 方程。

**(b)** 被积函数不显含 $x$，利用 Beltrami 恒等式导出 $r\sqrt{1+r'^2} - r\cdot\frac{rr'^2}{\sqrt{1+r'^2}} = C$，简化得：
$$\frac{r}{\sqrt{1+r'^2}} = a$$
解出 $r(x) = a\cosh\left(\frac{x-b}{a}\right)$（悬链面，catenoid）。

**(c)** 讨论：对于给定的两圆环位置，是否总存在连接它们的悬链面？什么条件下无解（Goldschmidt 不连续解）？

>[!s]- *(a) 泛函的 Euler-Lagrange 方程*
>被积函数是
>
>$$F[r] = r\sqrt{ 1+r'^{2} } $$
>于是
>
>$$\frac{\partial F}{\partial r} = \sqrt{ 1+r'^{2} } ,\quad \frac{\partial F}{\partial r'} = \frac{2rr'}{\sqrt{ 1+r'^{2} }}  $$
>所以 Euler-Lagrange 方程给出
>
>$$\frac{d}{dx}\left(   \frac{2rr'}{\sqrt{ 1+r'^{2} }} \right) = \sqrt{ 1+r'^{2} } $$
>

>[!s]- *(b) 悬链面解*
>由于 $F$ 不显含 $x$ 所以 Euler-Lagrange 方程可以化简为 $F = r'\frac{\partial F}{\partial r'}$ 代入得
>
>$$r\sqrt{ 1+r'^{2} } = \frac{2rr'^{2}}{\sqrt{ 1+r'^{2} }} $$
>
>即
>
>$$\frac{r}{\sqrt{ 1+r'^{2} }} = a \implies r' = \sqrt{ \frac{r^{2}}{a^{2}} - 1 } \implies \int \frac{dr}{\sqrt{ (r /a)^{2} - 1 }} = \int dx \implies a\text{arccosh}\left( \frac{r}{a} \right) = x-b $$
>所以
>
>$$r(x) = a\cosh \left( \frac{x-b}{a} \right) $$
>

>[!s]- *(c) 存在性讨论*
>至少要满足边界条件，也就是说
>
>$$r_{1} = a\cosh\left( \frac{x_{1}-b}{a} \right) ,\quad r_{2} = a\cosh\left( \frac{x_{2}-b}{a} \right) $$
>
>

### 1.3 Fermat 原理与光线轨迹

**(a)** 在折射率分布 $n(y)$ 的二维介质中（$x$ 为水平方向，$y$ 为垂直方向），Fermat 原理给出光程泛函：
$$L[y] = \int n(y)\sqrt{1+y'^2}\,dx$$
写出 Euler-Lagrange 方程。

**(b)** 对于大气折射率随高度指数变化 $n(y) = n_0 e^{\kappa y}$，求光线轨迹 $y(x)$ 的表达式。

**(c)** $\star$ 对于球对称折射率分布 $n(r)$（如恒星大气），写出球坐标下的 Fermat 泛函，并导出光线满足的方程。验证在 $n(r)$ 为常数时，光线退化为直线。

>[!s]- *(a) Euler-Lagrange 方程*
>被积函数为
>
>$$F[y] = n(y)\sqrt{ 1+y'^{2} } $$
>
>于是
>
>$$\frac{\partial F}{\partial y} = n'(y)\sqrt{ 1+y'^{2} } ,\quad \frac{\partial F}{\partial y'} = \frac{n(y)y'}{\sqrt{ 1+y'^{2} }} $$
>于是
>
>$$n'(y)\sqrt{ 1+y'^{2} } = \frac{d}{dx}\left(  \frac{n(y)y'}{\sqrt{ 1+y'^{2} }}  \right) $$


>[!S]- *(b) 光线轨迹*
>代入方程得到
>
>$$n_{0}\kappa e^{ \kappa y }\sqrt{ 1+y'^{2} } = \frac{d}{dx}\left(  \frac{e^{ \kappa y }y'}{\sqrt{ 1+y'^{2} }}  \right) $$
>注意，我们要的是轨迹 $y(x)$ 所以说 $F$ 不显含 $x$ 可以考虑 Beltrami 恒等式化简为
>$$n_{0}\kappa e^{ \kappa y }\sqrt{ 1+y'^{2} } - \frac{e^{ \kappa y }y'^{2}}{\sqrt{ 1+y'^{2} }} = C $$
>$$y' = \sqrt{ \frac{e^{ 2\kappa y }}{C^{2}} - 1 } \implies y = \frac{1}{\kappa}\ln[C \sec(\kappa(x-x_{0}))] $$


>[!s]- *(c) 球坐标下的 Fermat 泛函*
>不妨取赤道上 $\theta=\frac{\pi}{2}$ 此时 $ds^{2} = dr^{2} + r^{2}d\phi^{2}$ 于是
>
>$$L[r] = \int n(r)ds = \int n(r)\sqrt{ r^{2} + \left( \frac{dr}{d\phi} \right)^{2} } d\phi := \int n(r)\sqrt{ 1+r'^{2} }d\phi $$
>
>被积函数
>
>$$G[r] = n(r)\sqrt{ 1+r'^{2} } $$
>
>于是
>
>$$\frac{\partial G}{\partial r} = n'(r)\sqrt{ 1+r'^{2} } ,\quad \frac{\partial G}{\partial r'} = \frac{n(r)r'}{\sqrt{ 1+r'^{2} }} $$
>
>同样的由于 $G$ 不显含 $\phi$ 所以利用 Beltrami 恒等式可以化简
>
>$$n'(r)\sqrt{ 1+r'^{2} } - \frac{n(r)r'^{2}}{\sqrt{ 1+r'^{2} }} = L\quad\text{=const} $$
>即
>
>$$r'^{2} = r^{2}\left(  \frac{n^{2}(r)r^{2}}{L^{2}} - 1 \right) $$

### 1.4 泛函的高阶导数

**(a)** 对于依赖二阶导数的泛函 $S[y] = \int_{x_1}^{x_2} F(x, y, y', y'')\,dx$，推导推广的 Euler-Lagrange 方程：
$$\frac{\partial F}{\partial y} - \frac{d}{dx}\!\left(\frac{\partial F}{\partial y'}\right) + \frac{d^2}{dx^2}\!\left(\frac{\partial F}{\partial y''}\right) = 0$$

**(b)** 应用：弹性杆的弯曲能量 $\propto \int \kappa^2 ds$（$\kappa$ 为曲率）。在小挠度近似下 $y' \ll 1$，$\kappa \approx y''$。写出使弯曲能最小的 Euler-Lagrange 方程，并证明解为三次多项式。

>[!s]- *(a) 推广的 Euler-Lagrange 方程*
>对于泛函 $S[y] = \int_{x_1}^{x_2} F(x, y, y', y'')\,dx$ 考虑变分 $y(x)\to y(x)+\varepsilon \eta(x)$ 其中 $\eta(x_{1})=\eta(x_{2})=\eta'(x_{1})=\eta'(x_{2})=0$ 对泛函变分得到
>
>$$\delta S[y] = \int_{x_{1}}^{x_{2}} \left[  \frac{\partial F}{\partial y}\delta y + \frac{\partial F}{\partial y'}\delta y' + \frac{\partial F}{\partial y''}\delta y'' \right] dx = 0 $$
>
>其中
>
>$$\int \frac{\partial F}{\partial y}\delta y\ dx = \int \frac{\partial F}{\partial y}\eta\ dx $$
>$$\int \frac{\partial F}{\partial y'}\delta y'dx = \int \frac{\partial F}{\partial y'}\eta'\ dx = \left[ \frac{\partial F}{\partial y'}\eta \right]_{\partial} - \int \frac{d}{dx}\left( \frac{\partial F}{\partial y'} \right)\eta\ dx = - \int \frac{d}{dx}\left( \frac{\partial F}{\partial y'} \right)\eta\ dx $$
>$$\int \frac{\partial F}{\partial y''}\eta''\ dx = -\int \frac{d}{dx}\left( \frac{\partial F}{\partial y''} \right)\eta'\ dx = \int \frac{d^{2}}{dx^{2}}\left( \frac{\partial F}{\partial y''} \right)\eta\ dx $$
>所以最小作用量原理告诉我们
>
>$$\frac{\partial F}{\partial y} - \frac{d}{dx}\left( \frac{\partial F}{\partial y'} \right) + \frac{d^{2}}{dx^{2}}\left( \frac{\partial F}{\partial y''} \right) = 0 $$

>[!S]- *(b) 弹性杆的弯曲*
>由题意，作用量 $S =C\int(y'')^{2}dx$ 被积函数 $F[y,y',y'']=(y'')^{2}$ 于是代入上述方程得到
>
>$$\frac{d^{2}}{dx^{2}}(2y'') = 0 \implies y = C_{1}x^{3} + C_{2}x^{2} + C_{3}x + C_{4} $$

### 1.5 变分法的直接方法 $\star$

简述 Ritz 方法的思路：用含参数的试探函数族 $y(x;\alpha_1,\ldots,\alpha_N)$ 将泛函 $S[y]$ 转化为多元函数 $S(\alpha_1,\ldots,\alpha_N)$，再对参数求极值。说明该方法的优缺点。

>[!s]- *Ritz 方法*
>1. **选择试探函数族**：选取一组满足边界条件的基函数 ${ϕ_{i}(x)}$，构造含参试探函数
>   $y(x;\alpha_{1},…,αN_{N})=i=1∑N​\alpha_{i}​\phi_{i}​(x)$或更一般的带参数形式.
>2. **代入泛函**：将 $y(x;α)$ 代入泛函 $S[y]=∫F(x,y,y′) dx$，得到关于参数 $α\implies(\alpha_{1},…,\alpha_{N})$ 的多元函数
>    $$S(\alpha_{1}​,…,α_{N})=S[y(⋅;α)].$$
>3. **求极值**：对 $S(α)$ 求偏导并令为零：$∂S/∂α_{i}=0$，得到 $N$ 个代数方程。解出最优参数 $α^{*}$，从而获得近似解 $y^{*}(x)=y(x;α^{*})$。当 $N→∞$ 且基函数完备时，近似解收敛于真实解。

## 第二章 约束与广义坐标

### 2.1 约束的数学分类

**(d)** 一个质点被约束在匀速膨胀的球面上：$x^2 + y^2 + z^2 = (R_0 + vt)^2$。

### 2.2 广义坐标的选取

为以下系统选择合适的广义坐标，写出 Cartesian 坐标与广义坐标的关系：

**(a)** 平面双摆：两根长 $l_1, l_2$ 的轻杆连接两个质点 $m_1, m_2$，在竖直平面内摆动。

**(b)** 一质点约束在抛物面 $z = k(x^2 + y^2)$ 上运动（无摩擦）。需几个广义坐标？

**(c)** 两个质点 $m_1, m_2$ 由一根长为 $l$ 的轻杆连接，在水平面上运动（无摩擦）。需几个广义坐标？给出合理的选择。

**(d)** 一个半径为 $R$ 的均匀圆环在竖直平面内沿一条水平直线无滑动地滚动。写出环心的坐标与环的转角之间的关系（约束方程）。

### 2.3 d'Alembert 原理与虚功 $\star$

**(a)** 写出 d'Alembert 原理的数学表达式：
$$\sum_i (\mathbf{F}_i - \dot{\mathbf{p}}_i) \cdot \delta\mathbf{r}_i = 0$$
解释 $\delta\mathbf{r}_i$（虚位移）与 $d\mathbf{r}_i$（实际位移）的区别。

**(b)** 对于理想约束（约束力不做虚功），证明 d'Alembert 原理可写为：
$$\sum_i (\mathbf{F}_i^{(a)} - \dot{\mathbf{p}}_i) \cdot \delta\mathbf{r}_i = 0$$
其中 $\mathbf{F}_i^{(a)}$ 为主动力（施加的外力）。

**(c)** $\star$ 用 d'Alembert 原理推导静力学中的虚功原理：$\sum_i \mathbf{F}_i^{(a)} \cdot \delta\mathbf{r}_i = 0$。并用该原理求解：一根长为 $L$、质量可忽略的杆，一端铰接于墙，杆上某点悬挂重物 $W$，杆的另一端由一绳拉住保持水平。求绳中张力。

## 第三章 Lagrange 方程

> 本章训练从 Lagrangian 建立运动方程；保守力、非保守力、广义势；以及 Lagrange 乘子法处理约束。

### 3.1 Lagrangian 的构造

为以下系统写出 Lagrangian $L = T - V$（或 $L = T - U$ 如有广义势），并导出运动方程：

**(a)** 质量为 $m$ 的质点，在重力场中用一根长为 $l$ 的轻杆悬挂（单摆）。

**(b)** 平面双摆（见 2.2(a)）：写出 Lagrangian 并导出运动方程。不要求解。

**(c)** 一质点约束在抛物面 $z = k\rho^2$（$\rho^2 = x^2+y^2$）上，受重力作用（$V=mgz$）。选取 $\rho$ 和 $\phi$ 为广义坐标，写出 Lagrangian。

**(d)** 质量为 $m$ 的质点在一个以匀角速度 $\Omega$ 绕竖直轴旋转的光滑直管中运动（管沿水平方向）。选取质点到转轴的距离 $r$ 为广义坐标，写出 Lagrangian——注意这是一个非定常约束（rheonomic）。

### 3.2 广义势与 Lorentz 力

**(a)** 证明 Lorentz 力 $\mathbf{F} = q(\mathbf{E} + \mathbf{v} \times \mathbf{B})$ 可以从广义势
$$U = q(\Phi - \mathbf{v}\cdot\mathbf{A})$$
导出，即验证：
$$\frac{d}{dt}\!\left(\frac{\partial U}{\partial \dot{x}_i}\right) - \frac{\partial U}{\partial x_i} = F_i$$
（注意：这里 $\Phi$ 是标势，$\mathbf{A}$ 是矢势。）

**(b)** 写出带电粒子在电磁场中的 Lagrangian：
$$L = \frac{1}{2}m\mathbf{v}^2 + q\mathbf{v}\cdot\mathbf{A} - q\Phi$$
用 Cartesian 坐标导出运动方程，验证其等价于 Lorentz 力定律。

### 3.3 循环坐标与守恒量

**(a)** 若 Lagrangian 不显含某广义坐标 $q_j$（$\partial L/\partial q_j = 0$），证明其对应的广义动量 $p_j = \partial L/\partial \dot{q}_j$ 是守恒量。

**(b)** 对有心力问题 $L = \frac{1}{2}m(\dot{r}^2 + r^2\dot{\phi}^2) - V(r)$：
- 指出循环坐标和对应的守恒量
- 写出该守恒量的显式并讨论其物理含义（Kepler 第二定律）

**(c)** $\star$ 对于轴对称势 $V(\rho,z)$（柱坐标），讨论哪些广义动量是守恒的，以及这些守恒量与系统对称性的关系。

### 3.4 Lagrange 乘子法处理约束

**(a)** 对于受 $k$ 个完整约束 $f_\alpha(q_1,\ldots,q_n,t) = 0$（$\alpha=1,\ldots,k$）的系统，写出推广的 Lagrange 方程：
$$\frac{d}{dt}\!\left(\frac{\partial L}{\partial \dot{q}_i}\right) - \frac{\partial L}{\partial q_i} = \sum_{\alpha=1}^k \lambda_\alpha \frac{\partial f_\alpha}{\partial q_i}$$
解释 $\lambda_\alpha$ 的物理含义（约束力）。

**(b)** 应用：一质点 $m$ 约束在光滑球面 $x^2+y^2+z^2 = R^2$ 上，受重力作用（$V = mgz$）。用 Lagrange 乘子法求质点脱离球面时的角度（即约束力为零的时刻）。

**(c)** 应用：一均质细杆，两端搁在光滑的竖直墙和水平地面上，在重力作用下滑动。用乘子法求杆在任意角度时的约束力。

## 第四章 对称性与 Noether 定理

> 本章训练对称性识别、守恒流计算、以及 Noether 定理在连续系统中的应用。

### 4.1 离散系统的 Noether 定理

**(a)** 对于 Lagrangian $L(q_i, \dot{q}_i, t)$，考虑无穷小连续变换：
$$t \to t + \epsilon T(q,\dot{q},t), \quad q_i \to q_i + \epsilon Q_i(q,\dot{q},t)$$
推导 Noether 定理：若在此变换下 $L$ 变为全导数 $\epsilon\,d\Lambda/dt$，则守恒量为：
$$J = \sum_i \frac{\partial L}{\partial \dot{q}_i}Q_i + \left(L - \sum_i \frac{\partial L}{\partial \dot{q}_i}\dot{q}_i\right)T - \Lambda$$

**(b)** 由空间平移不变性导出动量守恒；由空间旋转不变性导出角动量守恒；由时间平移不变性导出能量守恒（当 $\partial L/\partial t = 0$ 时 Jacobi 积分守恒）。

### 4.2 具体应用

**(a)** 对 Kepler 问题 $L = \frac{1}{2}m(\dot{r}^2 + r^2\dot{\phi}^2) + \frac{k}{r}$：
- 写出时间平移不变性对应的守恒量
- 写出 $\phi$ 旋转不变性对应的守恒量
- 验证 Runge-Lenz 矢量 $\mathbf{A} = \mathbf{p} \times \mathbf{L} - mk\hat{\mathbf{r}}$ 也是守恒量（需显式计算 $d\mathbf{A}/dt$）

**(b)** 两个质量分别为 $m_1, m_2$ 的质点由弹簧（劲度 $k$，自然长度 $l_0$）相连，在光滑水平面上运动。指出系统的所有 Noether 对称性和守恒量。

### 4.3 场论的 Noether 定理 $\star$

**(a)** 对于场 $\phi^a(x^\mu)$，在无穷小变换 $x^\mu \to x^\mu + \epsilon X^\mu$，$\phi^a \to \phi^a + \epsilon \Psi^a$ 下，推导 Noether 流：
$$j^\mu = \frac{\partial\mathcal{L}}{\partial(\partial_\mu\phi^a)}\Psi^a - \left[\frac{\partial\mathcal{L}}{\partial(\partial_\mu\phi^a)}\partial_\nu\phi^a - \delta^\mu_\nu\mathcal{L}\right]X^\nu$$
并证明 $\partial_\mu j^\mu = 0$（在场方程成立时）。

**(b)** 对实标量场 $\mathcal{L} = \frac{1}{2}\partial_\mu\phi\partial^\mu\phi - \frac{1}{2}m^2\phi^2$：由时空平移 $x^\mu \to x^\mu + a^\mu$ 导出正则能动张量 $T^{\mu\nu}$；由 $\phi$ 的空间旋转不变性导出角动量张量。

**(c)** $\star$ 对复标量场 $\mathcal{L} = \partial_\mu\phi^*\partial^\mu\phi - m^2|\phi|^2$：由全局 $U(1)$ 变换 $\phi \to e^{i\alpha}\phi$ 导出守恒的 Noether 流 $j^\mu = i(\phi^*\partial^\mu\phi - \phi\partial^\mu\phi^*)$。

## 第五章 有心力与 Kepler 问题

> 本章训练有心力问题的标准解法：约化质量、等效一维问题、轨道方程、以及微分散射截面。

### 5.1 约化质量与等效一维问题

**(a)** 将两体问题约化为质心运动和相对运动。写出相对运动的 Lagrangian：
$$L = \frac{1}{2}\mu(\dot{r}^2 + r^2\dot{\phi}^2) - V(r)$$
其中 $\mu = m_1 m_2/(m_1+m_2)$ 为约化质量。导出等效一维问题的能量方程：
$$\frac{1}{2}\mu\dot{r}^2 + V_{\text{eff}}(r) = E, \quad V_{\text{eff}}(r) = V(r) + \frac{l^2}{2\mu r^2}$$
其中 $l = \mu r^2\dot{\phi}$ 为角动量。

**(b)** 利用 $d\phi = (l/\mu r^2)dt$ 和 $dt = dr/\sqrt{2(E-V_{\text{eff}})/\mu}$，导出轨道方程：
$$\phi(r) = \int \frac{l\,dr}{r^2\sqrt{2\mu(E - V(r)) - l^2/r^2}} + \text{const.}$$

>[!s]- **(a) 两体问题约化与等效一维能量方程**
>
> **Step 1：两体 Lagrangian 与质心分离**
>
> 两个质点 $m_1,m_2$，位置 $\mathbf{r}_1,\mathbf{r}_2$，相互作用势 $V(|\mathbf{r}_1-\mathbf{r}_2|)$。总 Lagrangian：
> $$L = \frac{1}{2}m_1\dot{\mathbf{r}}_1^2 + \frac{1}{2}m_2\dot{\mathbf{r}}_2^2 - V(|\mathbf{r}_1-\mathbf{r}_2|)$$
>
> 引入质心坐标 $\mathbf{R} = (m_1\mathbf{r}_1 + m_2\mathbf{r}_2)/M$（$M=m_1+m_2$）和相对坐标 $\mathbf{r} = \mathbf{r}_1 - \mathbf{r}_2$。反解：
> $$\mathbf{r}_1 = \mathbf{R} + \frac{m_2}{M}\mathbf{r}, \quad \mathbf{r}_2 = \mathbf{R} - \frac{m_1}{M}\mathbf{r}$$
>
> 代入动能：
> $$T = \frac{1}{2}m_1\left(\dot{\mathbf{R}} + \frac{m_2}{M}\dot{\mathbf{r}}\right)^2 + \frac{1}{2}m_2\left(\dot{\mathbf{R}} - \frac{m_1}{M}\dot{\mathbf{r}}\right)^2$$
>
> 展开交叉项 $m_1\cdot 2\dot{\mathbf{R}}\cdot\frac{m_2}{M}\dot{\mathbf{r}} - m_2\cdot 2\dot{\mathbf{R}}\cdot\frac{m_1}{M}\dot{\mathbf{r}} = 0$。剩余：
> $$T = \frac{1}{2}(m_1+m_2)\dot{\mathbf{R}}^2 + \frac{1}{2}\frac{m_1m_2^2 + m_2m_1^2}{M^2}\dot{\mathbf{r}}^2 = \frac{1}{2}M\dot{\mathbf{R}}^2 + \frac{1}{2}\mu\dot{\mathbf{r}}^2$$
>
> 其中 $\boxed{\mu \equiv \frac{m_1 m_2}{m_1 + m_2}}$ 为**约化质量**。Lagrangian 分离为：
> $$L = \underbrace{\frac{1}{2}M\dot{\mathbf{R}}^2}_{\text{质心自由运动}} + \underbrace{\frac{1}{2}\mu\dot{\mathbf{r}}^2 - V(r)}_{\text{相对运动}}$$
>
> 质心运动是平凡的（匀速直线），可忽略。相对运动等效于一个质量为 $\mu$ 的粒子在固定力心 $V(r)$ 中运动。
>
> **Step 2：极坐标下的相对运动 Lagrangian**
>
> 取平面极坐标 $(r,\phi)$：
> $$\boxed{L = \frac{1}{2}\mu(\dot{r}^2 + r^2\dot{\phi}^2) - V(r)}$$
>
> **Step 3：循环坐标与守恒量**
>
> $\phi$ 是循环坐标（$\partial L/\partial\phi = 0$）→ 对应的广义动量（角动量）守恒：
> $$p_\phi = \frac{\partial L}{\partial\dot{\phi}} = \mu r^2\dot{\phi} \equiv l = \text{const}$$
>
> 这就是 **Kepler 第二定律**：面积速度 $\frac{1}{2}r^2\dot{\phi} = l/(2\mu)$ 为常数。
>
> **Step 4：能量守恒与等效一维约化**
>
> 总能量守恒（$L$ 不显含 $t$）：
> $$E = \frac{1}{2}\mu(\dot{r}^2 + r^2\dot{\phi}^2) + V(r)$$
>
> 用 $l = \mu r^2\dot{\phi}$ 消去 $\dot{\phi}$：$\frac{1}{2}\mu r^2\dot{\phi}^2 = \frac{l^2}{2\mu r^2}$。代入：
> $$\boxed{E = \frac{1}{2}\mu\dot{r}^2 + \underbrace{\left[V(r) + \frac{l^2}{2\mu r^2}\right]}_{V_{\text{eff}}(r)}}$$
>
> 这就是等效一维问题的能量方程。$V_{\text{eff}}(r) = V(r) + l^2/(2\mu r^2)$ 中，第二项是**离心势垒**——它来自于角动量守恒约束，阻止粒子落到 $r=0$（除非 $l=0$）。径向运动完全等价于一个质量为 $\mu$ 的粒子在有效势 $V_{\text{eff}}(r)$ 下的一维运动。

>[!s]- **(b) 轨道方程的积分推导**
>
> **Step 1：从时间参数到角度参数**
>
> 由能量方程：$\dot{r} = \pm\sqrt{\frac{2}{\mu}[E - V_{\text{eff}}(r)]}$。由角动量守恒：$dt = \frac{\mu r^2}{l}d\phi$。链式法则：
> $$\frac{dr}{d\phi} = \frac{\dot{r}}{\dot{\phi}} = \frac{\dot{r}}{l/(\mu r^2)} = \frac{\mu r^2}{l}\dot{r}$$
>
> 分离变量：
> $$d\phi = \frac{l\,dr}{\mu r^2\,\dot{r}} = \frac{l\,dr}{\mu r^2\sqrt{\frac{2}{\mu}[E - V_{\text{eff}}(r)]}}$$
>
> **Step 2：化简积分**
>
> 代入 $\mu r^2$ 和 $V_{\text{eff}}$：
> $$d\phi = \frac{l\,dr}{r^2\sqrt{2\mu[E - V(r)] - l^2/r^2}}$$
>
> 积分：
> $$\boxed{\phi(r) = \int_{r_0}^{r} \frac{l\,dr'}{r'^2\sqrt{2\mu[E - V(r')] - l^2/r'^2}} + \phi_0}$$
>
> **Step 3：积分限的确定**
>
> 对束缚态，积分从近日点 $r_{\min}$（或取适当的参考点）开始。径向运动在 $r_{\min} \leq r \leq r_{\max}$（转向点，根号内表达式为零处）之间进行。轨道方程是**隐式的**：给定 $E,l$，对任意 $V(r)$，上式给出极坐标轨道的积分表示。
>
> **Step 4：常见积分结果**
>
> 对 Kepler 势 $V = -k/r$，可通过变量代换 $u = 1/r$ 显式积分得到圆锥曲线方程。对一般势 $V(r)$，积分 $\propto \int dr/(r^2\sqrt{\cdots})$ 的显式形式取决于势的具体函数形式（见 5.2 Binet 公式的推广）。

>[!abstract]- 补充：等效 Lagrangian 与有效势的变分推导
>
> 上述推导从守恒量消去 $\dot{\phi}$ 得到了等效一维能量方程。这里提供一个更深刻的视角——**等效 Lagrangian 方法**。
>
> **方法一：Routh 约化**
>
> 由于 $\phi$ 是循环坐标，可以利用 Routh 函数 $R = L - l\dot{\phi}$（以 $l$ 替代 $\dot{\phi}$ 作为独立变量）：
> $$R(r,\dot{r};l) = \frac{1}{2}\mu\dot{r}^2 - \underbrace{\left[V(r) + \frac{l^2}{2\mu r^2}\right]}_{=V_{\text{eff}}(r)} = \frac{1}{2}\mu\dot{r}^2 - V_{\text{eff}}(r)$$
>
> Routh 函数对 $r$ 的运动方程等价于 Lagrangian $L_{\text{eff}} = \frac{1}{2}\mu\dot{r}^2 - V_{\text{eff}}(r)$ 给出的方程。Routh 方法将循环坐标的对称性"吸收"到有效势中，使问题降维。
>
> **方法二：直接构造等效 Lagrangian (错误示例)**
>
> 将 $\dot{\phi} = l/(\mu r^2)$ 代入原 Lagrangian（这是合法的，因为 $\phi$ 是循环坐标，$l$ 是第一积分）：
> $$L_{\text{eff}}(r,\dot{r}) \equiv L\big|_{l=\text{const}} = \frac{1}{2}\mu\dot{r}^2 - V(r) + \frac{l^2}{2\mu r^2}$$
>
> 注意符号！$L_{\text{eff}} = T_{\text{radial}} - V + T_{\text{angular}}$，即 $L_{\text{eff}} = \frac{1}{2}\mu\dot{r}^2 - V_{\text{eff}}(r) + \frac{l^2}{\mu r^2}$（离心项以不同符号出现）。对 $L_{\text{eff}}$ 写出径向 Euler-Lagrange 方程：
> $$\frac{d}{dt}\frac{\partial L_{\text{eff}}}{\partial\dot{r}} - \frac{\partial L_{\text{eff}}}{\partial r} = \mu\ddot{r} + V'(r) + \frac{l^2}{\mu r^3} = 0$$
>
> 这个方法看起来正确，实则错误！原因如下：
> 
> 在原始的变分问题中，$r$ 和 $ϕ$ 是 **独立** 的广义坐标，$\dot{r}$ 与 $\dot{\phi}$​ 也是独立的。当我们用一个运动常数代入 Lagrangian 时，实际上是在 **解空间** 上使用了方程的解（或首次积分）来消去一个变量。但 **变分运算是先于运动方程的**：将运动方程（或守恒量）代入作用量后再变分，相当于在 **约束流形** 上而不是在整个相空间上变分，这会改变变分问题的边界条件与拉格朗日方程的形式。
>
> **方法三：降维 Lagrangian（最安全）**
>
> 最保险的方式是直接写出一维径向 Lagrangian：
> $$L_{\text{1D}}(r,\dot{r}) = \frac{1}{2}\mu\dot{r}^2 - V_{\text{eff}}(r)$$
>
> 这不是从 $L(r,\phi,\dot{r},\dot{\phi})$ 直接代换得到的——代换后得到的是 $L_{\text{eff}}$。但 $L_{\text{1D}}$ 给出的运动方程 $\mu\ddot{r} = -V_{\text{eff}}'(r)$ 是正确的径向方程。两者的关系是：$L_{\text{eff}}$ 通过 Euler-Lagrange 正确地给出了径向方程（因其包含了两项抵消），而 $L_{\text{1D}}$ 是更直接的"等效描述"。
>
> **总结**：
>
> | 描述方式 | 表达式 | 用途 |
> |---------|--------|------|
> | 原 Lagrangian $L$ | $\frac{1}{2}\mu(\dot{r}^2+r^2\dot{\phi}^2)-V(r)$ | 完整动力学 |
> | 能量方程 | $\frac{1}{2}\mu\dot{r}^2 + V_{\text{eff}}(r) = E$ | 定性分析（转向点、轨道分类） |
> | Routh 函数 $R$ | $\frac{1}{2}\mu\dot{r}^2 - V_{\text{eff}}(r)$ | 降维变分原理 |
> | 等效 1D Lagrangian | $\frac{1}{2}\mu\dot{r}^2 - V_{\text{eff}}(r)$ | 径向运动方程 |
>
> 初学者最常见的错误：直接把 $\dot{\phi}=l/(\mu r^2)$ 代入 $L = T-V$ 中，得到 $L_{\text{eff}} = \frac{1}{2}\mu\dot{r}^2 + \frac{l^2}{2\mu r^2} - V(r)$，然后对 $r$ 做 Euler-Lagrange。这在代数上是正确的，但它将运动方程代回拉式量再变分，这破坏了变分的独立性。正确的做法是：要么使用 Routh 约化（$L_{\text{eff}} = \frac{1}{2}\mu\dot{r}^2 - V_{\text{eff}}$），要么直接使用能量守恒方程分析径向运动，要么用 Binet 公式绕过这个陷阱。

### 5.2 Kepler 问题：轨道

**(a)** 对引力势 $V(r) = -k/r$（$k=GMm$），引入 $u = 1/r$，推导 Binet 公式：
$$\frac{d^2u}{d\phi^2} + u = -\frac{F(1/u)}{\mu l^2 u^2}$$
对 $F(r) = -k/r^2$，解方程得圆锥曲线轨道：
$$u(\phi) = \frac{\mu k}{l^2}\left[1 + e\cos(\phi - \phi_0)\right]$$

**(b)** 写出离心率 $e$ 用能量 $E$ 和角动量 $l$ 表达的式子，并分类讨论：
- $e < 1$（椭圆，$E < 0$）
- $e = 1$（抛物线，$E = 0$）
- $e > 1$（双曲线，$E > 0$）

**(c)** 对于椭圆轨道（$e<1$），推导 Kepler 三定律：
1. 轨道是椭圆，太阳位于一个焦点上
2. 面积速度恒定（角动量守恒的直接推论）
3. 周期平方正比于半长轴立方：$T^2 = \frac{4\pi^2\mu}{k}a^3$

### 5.3 其他有心力势

**(a)** 求解各向同性谐振子势 $V(r) = \frac{1}{2}m\omega^2 r^2$ 的轨道方程。证明轨道是以原点为中心的椭圆（与 Kepler 椭圆的区别）。

**(b)** 对于势 $V(r) = -k/r^2$，求解轨道方程并讨论束缚轨道的存在条件。角动量足够大时，入射线是否会击中原点？

**(c)** $\star$ 对于势 $V(r) = -k/r^n$（$n \neq 1$），讨论 Bertrand 定理：只有 $n=1$（Kepler）和 $n=-2$（谐振子）时，所有束缚轨道都是闭合的。

### 5.4 微分散射截面

**(a)** 导出有心力散射中散射角 $\Theta$ 的积分表达式：
$$\Theta = \pi - 2\int_{r_{\min}}^\infty \frac{l\,dr}{r^2\sqrt{2\mu(E - V(r)) - l^2/r^2}}$$
其中 $r_{\min}$ 为最近点距离（转向点），满足 $\dot{r}(r_{\min}) = 0$。用 $l = \mu v_0 b$ 将 $\Theta$ 表达为碰撞参数 $b$ 的函数（$v_0$ 为入射速度）。

**(b)** 对刚球散射（$V(r) = 0$（$r > R$），$V(r) = \infty$（$r \leq R$）），计算 $\Theta(b)$，并证明微分散射截面为常数：
$$\frac{d\sigma}{d\Omega} = \frac{R^2}{4}$$

**(c)** 对 Rutherford 散射 $V(r) = \alpha/r$（$\alpha = q_1q_2/(4\pi\epsilon_0)$），计算微分散射截面：
$$\frac{d\sigma}{d\Omega} = \left(\frac{\alpha}{4E}\right)^2 \frac{1}{\sin^4(\Theta/2)}$$
并讨论 $\Theta \to 0$（小角度散射）时的发散及其物理来源（Coulomb 势的长程性）。

>[!s]- **(a) 散射角积分表达式与碰撞参数**
>
> **Step 1：散射几何**
>
> 在有心力散射中，粒子从无穷远以速度 $v_0$、碰撞参数 $b$ 入射。设 $r \to \infty$ 时 $V \to 0$。入射能量 $E = \frac{1}{2}\mu v_0^2$，角动量 $l = \mu v_0 b$。
>
> 粒子先接近力心到达最近点 $r = r_{\min}$，然后远离。散射角 $\Theta$ 定义为入射方向和出射方向之间的夹角。
>
> 对于排斥势（$\alpha > 0$），$0 < \Theta < \pi$；对于吸引势（$\alpha < 0$），可发生绕转（orbiting），甚至 $\Theta > \pi$。
>
> **Step 2：轨道积分与散射角**
>
> 由 5.1(b) 的轨道方程，从无穷远入射到最近点再出射到无穷远。粒子走过的总极角变化为：
> $$\Delta\phi = 2\int_{r_{\min}}^\infty \frac{l\,dr}{r^2\sqrt{2\mu(E - V(r)) - l^2/r^2}}$$
>
> 如果力心不存在，粒子将以碰撞参数 $b$ 沿直线经过力心，极角变化为 $\pi$。散射角 = 无偏转的极角变化 $-$ 实际的极角变化：
>
> $$\boxed{\Theta = \pi - 2\int_{r_{\min}}^\infty \frac{l\,dr}{r^2\sqrt{2\mu[E - V(r)] - l^2/r^2}}}$$
>
> 其中 $r_{\min}$ 是径向动能 $\frac{1}{2}\mu\dot{r}^2 = E - V(r) - l^2/(2\mu r^2)$ 首次为零的 $r$ 值（最大正根）：
> $$E - V(r_{\min}) - \frac{l^2}{2\mu r_{\min}^2} = 0$$
>
> **Step 3：用 $b$ 表达**
>
> 替换 $l = \mu v_0 b$ 和 $E = \frac{1}{2}\mu v_0^2$，被积函数：
> $$\frac{l}{r^2\sqrt{2\mu(E-V) - l^2/r^2}} = \frac{\mu v_0 b}{r^2\sqrt{\mu^2 v_0^2 - 2\mu V - \mu^2 v_0^2 b^2/r^2}} = \frac{b}{r^2\sqrt{1 - \frac{2V}{\mu v_0^2} - \frac{b^2}{r^2}}}$$
>
> $$\boxed{\Theta(b) = \pi - 2b\int_{r_{\min}}^\infty \frac{dr}{r^2\sqrt{1 - \frac{V(r)}{E} - \frac{b^2}{r^2}}}}$$
>
> 转向点条件：$1 - V(r_{\min})/E - b^2/r_{\min}^2 = 0$。
>
> **Step 4：微分散射截面的定义**
>
> 设粒子以碰撞参数 $b$ 入射，散射到角度 $\Theta$。入射通量为 $I$ 时，穿过环形面积 $2\pi b\,db$ 的粒子被散射到立体角 $d\Omega = 2\pi\sin\Theta\,d\Theta$ 中：
> $$I \cdot 2\pi b\,|db| = I \cdot \frac{d\sigma}{d\Omega} \cdot 2\pi\sin\Theta\,|d\Theta|$$
>
> $$\boxed{\frac{d\sigma}{d\Omega} = \frac{b}{\sin\Theta}\left|\frac{db}{d\Theta}\right|}$$
>
> 计算流程：$V(r) \to \Theta(b) \to b(\Theta) \to db/d\Theta \to d\sigma/d\Omega$。绝对值保证截面为正（$b$ 通常随 $\Theta$ 递减）。

>[!s]- **(b) 刚球散射**
>
> **Step 1：散射角 $\Theta(b)$**
>
> 刚球：$V(r) = 0 \;(r > R)$，$V = \infty \;(r \leq R)$。粒子沿直线运动，在 $r=R$ 处弹性反射。
>
> 几何分析：粒子以碰撞参数 $b$ 入射，在球面上发生镜面反射。连接球心到碰撞点的半径与入射方向之间的夹角记为 $\alpha$：
> $$\sin\alpha = \frac{b}{R}, \quad 0 \leq b \leq R \quad (b > R\text{ 不发生散射})$$
>
> 由几何关系，散射角（入射方向与出射方向夹角）：
> $$\Theta = \pi - 2\alpha$$
>
> $$\boxed{\Theta(b) = \pi - 2\arcsin\!\left(\frac{b}{R}\right) = 2\arccos\!\left(\frac{b}{R}\right)}$$
>
> 验证：$b=0$（正面碰撞）→ $\Theta = \pi$（反向散射）；$b=R$（擦边）→ $\Theta = 0$（不偏转）。
>
> **Step 2：反解 $b(\Theta)$**
>
> $$b = R\cos\!\left(\frac{\Theta}{2}\right), \quad 0 \leq \Theta \leq \pi$$
>
> **Step 3：微分散射截面**
>
> $$\frac{db}{d\Theta} = -\frac{R}{2}\sin\!\left(\frac{\Theta}{2}\right)$$
>
> $$\frac{d\sigma}{d\Omega} = \frac{b}{\sin\Theta}\left|\frac{db}{d\Theta}\right| = \frac{R\cos(\Theta/2)}{\sin\Theta} \cdot \frac{R}{2}\sin(\Theta/2)$$
>
> 利用 $\sin\Theta = 2\sin(\Theta/2)\cos(\Theta/2)$：
> $$\frac{d\sigma}{d\Omega} = \frac{R\cos(\Theta/2)}{2\sin(\Theta/2)\cos(\Theta/2)} \cdot \frac{R}{2}\sin(\Theta/2) = \frac{R^2}{4}$$
>
> $$\boxed{\frac{d\sigma}{d\Omega} = \frac{R^2}{4}}$$
>
> **各向同性散射！** 微分散射截面与角度无关。这符合几何直觉：入射粒子束均匀分布在碰撞参数 $b$ 上，刚球表面将均匀的 $b$ 分布映射为均匀的 $\Theta$ 分布。
>
> **总截面**：
> $$\sigma_{\text{tot}} = \int \frac{d\sigma}{d\Omega}\,d\Omega = \frac{R^2}{4} \cdot 4\pi = \pi R^2$$
>
> 恰好是球的几何截面——这是经典散射中"截面"一词的直观来源。

>[!s]- **(c) Rutherford 散射**
>
> **Step 1：$\Theta(b)$ 的计算**
>
> $V(r) = \alpha/r$（$\alpha$ 可正可负。对 Coulomb 斥力 $\alpha>0$，对引力 $\alpha<0$）。散射角积分：
> $$\Theta = \pi - 2b\int_{r_{\min}}^\infty \frac{dr}{r^2\sqrt{1 - \frac{\alpha}{Er} - \frac{b^2}{r^2}}}$$
>
> 这是标准积分。引入 $u = 1/r$，$du = -dr/r^2$：
> $$\Theta = \pi - 2b\int_0^{u_{\max}} \frac{du}{\sqrt{1 - \frac{\alpha}{E}u - b^2 u^2}}$$
>
> 其中 $u_{\max} = 1/r_{\min}$ 是被积函数分母为零的最大正根（对应最近点）：
> $$b^2 u^2 + \frac{\alpha}{E}u - 1 = 0 \quad \Rightarrow \quad u_{\max} = \frac{-\alpha/E + \sqrt{(\alpha/E)^2 + 4b^2}}{2b^2}$$
>
> 积分公式 $\int \frac{du}{\sqrt{A + Bu - Cu^2}} = \frac{1}{\sqrt{C}}\arccos\!\left(\frac{B - 2Cu}{\sqrt{B^2+4AC}}\right)$（$C>0$）。此处 $A=1$，$B=-\alpha/E$，$C=b^2$。
>
> 计算 $\int_0^{u_{\max}}$：
> $$\begin{aligned} \int_0^{u_{\max}} \frac{du}{\sqrt{1 - \frac{\alpha}{E}u - b^2 u^2}} &= \frac{1}{b}\left[\arccos\!\left(\frac{-\alpha/E - 2b^2 u}{\sqrt{(\alpha/E)^2 + 4b^2}}\right)\right]_{0}^{u_{\max}} \\ &= \frac{1}{b}\left[\arccos\!\left(\frac{-\alpha/E + \sqrt{(\alpha/E)^2+4b^2}}{\sqrt{(\alpha/E)^2+4b^2}}\right) - \arccos\!\left(\frac{-\alpha/E}{\sqrt{(\alpha/E)^2+4b^2}}\right)\right] \end{aligned}$$
>
> 第一项：$\arccos(-1) = \pi$。第二项：令 $\cos\phi_0 = \frac{-\alpha/E}{\sqrt{(\alpha/E)^2+4b^2}}$（$\phi_0 \in [0,\pi]$，取主值）。
>
> $$\Theta = \pi - 2b\cdot\frac{1}{b}(\pi - \phi_0) = \pi - 2(\pi - \phi_0) = 2\phi_0 - \pi$$
>
> 利用 $\cos\phi_0$ 表达式求 $\phi_0$。整理：
> $$\cot\phi_0 = \frac{-\alpha/E}{\sqrt{(\alpha/E)^2+4b^2 - (\alpha/E)^2}} = \frac{-\alpha/E}{2b}$$
>
> 所以 $\phi_0 = \operatorname{arccot}\!\left(\frac{-\alpha}{2Eb}\right)$。$\Theta = 2\phi_0 - \pi$：
> $$\tan\!\left(\frac{\Theta}{2}\right) = \tan\!\left(\phi_0 - \frac{\pi}{2}\right) = -\cot\phi_0 = \frac{\alpha}{2Eb}$$
>
> $$\boxed{b = \frac{\alpha}{2E}\cot\!\left(\frac{\Theta}{2}\right)}$$
>
> （取绝对值，$b>0$：$b = \frac{|\alpha|}{2E}\cot(\Theta/2)$。）
>
> **Step 2：微分散射截面**
>
> $$\frac{db}{d\Theta} = -\frac{|\alpha|}{4E}\csc^2\!\left(\frac{\Theta}{2}\right)$$
>
> $$\frac{d\sigma}{d\Omega} = \frac{b}{\sin\Theta}\left|\frac{db}{d\Theta}\right| = \frac{\frac{|\alpha|}{2E}\cot(\Theta/2)}{\sin\Theta} \cdot \frac{|\alpha|}{4E}\csc^2(\Theta/2)$$
>
> $\sin\Theta = 2\sin(\Theta/2)\cos(\Theta/2)$，$\cot(\Theta/2) = \cos(\Theta/2)/\sin(\Theta/2)$，$\csc(\Theta/2) = 1/\sin(\Theta/2)$：
>
> $$\frac{d\sigma}{d\Omega} = \frac{|\alpha|}{2E}\frac{\cos(\Theta/2)}{\sin(\Theta/2)} \cdot \frac{1}{2\sin(\Theta/2)\cos(\Theta/2)} \cdot \frac{|\alpha|}{4E}\frac{1}{\sin^2(\Theta/2)} = \frac{\alpha^2}{16E^2}\frac{1}{\sin^4(\Theta/2)}$$
>
> $$\boxed{\frac{d\sigma}{d\Omega} = \left(\frac{\alpha}{4E}\right)^2 \frac{1}{\sin^4(\Theta/2)}}$$
>
> **Step 3：$\Theta \to 0$ 发散**
>
> 当 $\Theta \to 0$，$\sin(\Theta/2) \to 0$，$d\sigma/d\Omega \propto 1/\Theta^4 \to \infty$。物理来源：
>
> Coulomb 势是**长程势**（$V \propto 1/r$，衰减极慢）。碰撞参数 $b$ 任意大的粒子都会感受到微弱的 Coulomb 力，从而发生小角度偏转。$b \to \infty$ 对应 $\Theta \to 0$，微分截面中的 $b\,|db|$ 在 $b \to \infty$ 时不收敛。
>
> 在真实的等离子体或导体中，Debye 屏蔽将 Coulomb 势截断为 Yukawa 势 $V \propto e^{-r/\lambda_D}/r$（$\lambda_D$ 为 Debye 长度），消除了长程发散。总截面变为有限。
>
> **实验意义**：Rutherford 公式精确描述了大角度 $\alpha$ 粒子散射，由此发现了原子核。小角度发散在实验中通过有限探测器角度范围自然规避——探测器总有最小分辨角 $\Theta_{\min}$。

### 5.5 Laplace-Runge-Lenz 矢量 $\star$

**(a)** 对于 Kepler 问题 $F = -k/r^2$，验证 Laplace-Runge-Lenz 矢量：
$$\mathbf{A} = \mathbf{p} \times \mathbf{L} - \mu k\,\hat{\mathbf{r}}$$
是守恒矢量（$d\mathbf{A}/dt = 0$）。

**(b)** 证明 $\mathbf{A}$ 的大小正比于轨道离心率 $e = |\mathbf{A}|/(\mu k)$，且 $\mathbf{A}$ 的方向指向近日点方向。

**(c)** 解释为什么 Kepler 问题比一般有心力问题具有额外的守恒量——这与其"隐藏对称性"（$SO(4)$ 对称性）有何关系？

>[!s]- **(a) Laplace-Runge-Lenz 矢量守恒性的验证**
>
> **Step 1：LRL 矢量的定义**
>
> $$\boxed{\mathbf{A} = \mathbf{p} \times \mathbf{L} - \mu k\,\hat{\mathbf{r}}}$$
>
> 其中 $\mathbf{p} = \mu\dot{\mathbf{r}}$（相对运动的动量），$\mathbf{L} = \mathbf{r} \times \mathbf{p}$（角动量），$\hat{\mathbf{r}} = \mathbf{r}/r$。对引力 $k=GMm$；对 Coulomb 斥力取 $k = |q_1q_2|/(4\pi\epsilon_0)$ 并添负号。
>
> **Step 2：逐项求导**
>
> $$\frac{d\mathbf{A}}{dt} = \underbrace{\frac{d}{dt}(\mathbf{p} \times \mathbf{L})}_{\text{第一项}} - \underbrace{\mu k\frac{d\hat{\mathbf{r}}}{dt}}_{\text{第二项}}$$
>
> **第一项**：$\dot{\mathbf{p}} \times \mathbf{L} + \mathbf{p} \times \dot{\mathbf{L}}$。$\dot{\mathbf{L}} = 0$（有心力 $\to$ 力矩为零）。$\dot{\mathbf{p}} = \mathbf{F} = -\frac{k}{r^2}\hat{\mathbf{r}}$。
>
> $$\dot{\mathbf{p}} \times \mathbf{L} = \left(-\frac{k}{r^2}\hat{\mathbf{r}}\right) \times (\mathbf{r} \times \mathbf{p})$$
>
> 矢量恒等式 $\mathbf{a} \times (\mathbf{b} \times \mathbf{c}) = \mathbf{b}(\mathbf{a}\cdot\mathbf{c}) - \mathbf{c}(\mathbf{a}\cdot\mathbf{b})$：
> $$\hat{\mathbf{r}} \times (\mathbf{r} \times \mathbf{p}) = \mathbf{r}(\hat{\mathbf{r}}\cdot\mathbf{p}) - \mathbf{p}(\hat{\mathbf{r}}\cdot\mathbf{r}) = \mathbf{r}p_r - \mathbf{p}r$$
>
> 其中 $p_r \equiv \hat{\mathbf{r}}\cdot\mathbf{p} = \mu\dot{r}$ 为径向动量：
> $$\dot{\mathbf{p}} \times \mathbf{L} = -\frac{k}{r^2}(\mathbf{r}p_r - \mathbf{p}r) = -\frac{k p_r}{r}\hat{\mathbf{r}} + \frac{k}{r}\mathbf{p}$$
>
> **第二项**：$\hat{\mathbf{r}} = \mathbf{r}/r$：
> $$\frac{d\hat{\mathbf{r}}}{dt} = \frac{\dot{\mathbf{r}}}{r} - \frac{\mathbf{r}\,\dot{r}}{r^2} = \frac{\mathbf{p}}{\mu r} - \frac{\mathbf{r}p_r}{\mu r^2}$$
>
> $$-\mu k\frac{d\hat{\mathbf{r}}}{dt} = -\frac{k}{r}\mathbf{p} + \frac{k p_r}{r}\hat{\mathbf{r}}$$
>
> **Step 3：两项相加**
>
> $$\frac{d\mathbf{A}}{dt} = \left[-\frac{k p_r}{r}\hat{\mathbf{r}} + \frac{k}{r}\mathbf{p}\right] + \left[-\frac{k}{r}\mathbf{p} + \frac{k p_r}{r}\hat{\mathbf{r}}\right] = \mathbf{0}$$
>
> $$\boxed{\frac{d\mathbf{A}}{dt} = 0}$$
>
> 第一项和第二项恰好逐对抵消。对一般幂律 $F \propto -1/r^n\;(n \neq 2)$，这种精巧抵消不会发生——$\dot{\mathbf{p}} \times \mathbf{L}$ 和 $-\mu k\,d\hat{\mathbf{r}}/dt$ 不再产生反号的对应项。

>[!s]- **(b) 离心率与近日点方向**
>
> **Step 1：$|\mathbf{A}|$ 的计算**
>
> 利用 $\mathbf{L} \perp \mathbf{p}$：
> $$\mathbf{A}^2 = p^2 L^2 + \mu^2 k^2 - 2\mu k\,\hat{\mathbf{r}}\cdot(\mathbf{p} \times \mathbf{L})$$
>
> 混合积轮换：$\hat{\mathbf{r}}\cdot(\mathbf{p} \times \mathbf{L}) = \mathbf{L}\cdot(\hat{\mathbf{r}} \times \mathbf{p})$。极坐标中 $\dot{\mathbf{r}} = \dot{r}\hat{\mathbf{r}} + r\dot{\phi}\hat{\boldsymbol{\phi}}$，$\hat{\mathbf{r}} \times \mathbf{p} = \mu r\dot{\phi}\,\hat{\mathbf{z}} = \frac{L}{r}\hat{\mathbf{z}}$。故 $\mathbf{L}\cdot(\hat{\mathbf{r}} \times \mathbf{p}) = L^2/r$：
> $$\mathbf{A}^2 = p^2 L^2 + \mu^2 k^2 - \frac{2\mu k L^2}{r}$$
>
> 由 $E = p^2/(2\mu) - k/r$ 得 $p^2 = 2\mu(E + k/r)$：
> $$\mathbf{A}^2 = 2\mu L^2\left(E + \frac{k}{r}\right) + \mu^2 k^2 - \frac{2\mu k L^2}{r} = 2\mu E L^2 + \mu^2 k^2$$
>
> $$\boxed{|\mathbf{A}| = \sqrt{\mu^2 k^2 + 2\mu E L^2} = \mu k\sqrt{1 + \frac{2E L^2}{\mu k^2}} = \mu k\,e}$$
>
> **Step 2：$\mathbf{A}$ 指向近日点**
>
> $$\mathbf{A}\cdot\mathbf{r} = (\mathbf{p}\times\mathbf{L})\cdot\mathbf{r} - \mu k r = L^2 - \mu k r$$
>
> 设 $\mathbf{A}$ 与 $\mathbf{r}$ 夹角为 $\phi$（$Ar\cos\phi = L^2 - \mu k r$）：
> $$r = \frac{L^2/(\mu k)}{1 + (A/(\mu k))\cos\phi} = \frac{L^2/(\mu k)}{1 + e\cos\phi}$$
>
> $\phi = 0$ 时 $r = r_{\min}$（近日点）$\to$ $\mathbf{r} \parallel \mathbf{A}$。$\mathbf{A}$ 指向近日点。
>
> **几何诠释**：LRL 矢量的**大小**编码离心率，**方向**编码近日点方向。它与 $\mathbf{L}$（编码轨道面取向）共同完全确定 Kepler 轨道的空间几何。

>[!s]- **(c) $SO(4)$ 隐藏对称性**
>
> **Step 1：超额守恒量**
>
> 三维运动 6 个相空间自由度 $\to$ 完全可积需 3 个独立守恒量。Kepler 问题有：
> - $H$（1 个）— 时间平移对称性
> - $\mathbf{L}$（3 个分量）— $SO(3)$ 旋转对称性
> - $\mathbf{A}$（3 个分量）— **不对应几何对称性**
>
> 7 个量中 2 个约束（$\mathbf{A}\cdot\mathbf{L} = 0$，$\mathbf{A}^2 = \mu^2 k^2 + 2\mu E L^2$）$\to$ 5 个独立 $\to$ 高度"超可积"。
>
> **Step 2：Poisson 括号代数 = $SO(4)$**
>
> 束缚态 $E<0$，定义 $\mathbf{D} \equiv \mathbf{A}/\sqrt{-2\mu E}$：
> $$\begin{aligned}
> \{L_i, L_j\} &= \epsilon_{ijk}L_k \\
> \{L_i, D_j\} &= \epsilon_{ijk}D_k \\
> \{D_i, D_j\} &= \epsilon_{ijk}L_k
> \end{aligned}$$
>
> 定义 $\mathbf{M} = \frac{1}{2}(\mathbf{L} + \mathbf{D})$，$\mathbf{N} = \frac{1}{2}(\mathbf{L} - \mathbf{D})$：
> $$\{M_i, M_j\} = \epsilon_{ijk}M_k,\quad \{N_i, N_j\} = \epsilon_{ijk}N_k,\quad \{M_i, N_j\} = 0$$
>
> $\mathbf{M}$ 和 $\mathbf{N}$ 各自生成互相独立的 $SO(3)$ $\to$ 代数同构于 $SO(3) \times SO(3) \cong SO(4)$。
>
> **Step 3：物理后果**
>
> | 后果 | 表现 |
> |------|------|
> | 能级简并 | $SO(4)$ 不可约表示维数 $n^2$ $\to$ 氢原子 $n^2$ 重简并 |
> | 轨道闭合 | $\nu_r = \nu_\phi = \nu_\theta$ $\to$ 所有束缚轨道闭合 |
> | Rutherford 截面 | $\sin^{-4}(\Theta/2)$ 极简形式源于 $SO(4)$ |
>
> **对比表**：
>
> | 系统 | 对称群 | 轨道闭合？ | 额外守恒量 |
> |------|--------|-----------|-----------|
> | 一般有心力 | $SO(3)$ | 否 | 无 |
> | Kepler | $SO(4)$ | 是 | $\mathbf{A}$（LRL矢量） |
> | 谐振子 | $SU(3)$ | 是 | Fradkin 张量 |
>
> **最深层的洞察**：LRL 矢量不对应构型空间的几何对称性（平移/旋转），而是**动力学对称性**——仅在 $F \propto -1/r^2$ 时出现的守恒量。Noether 定理的经典形式无法从 Lagrangian 对称性直接导出它（需要推广到含速度的变换），这使得 LRL 矢量成为连接经典力学、量子力学（氢原子 $SO(4)$ 对称性）、和可积系统理论的著名桥梁。

### 7.2 Euler 方程

**(a)** 推导 Euler 方程（刚体在无力矩情况下的转动方程）：

### 7.4 重对称陀螺

## 第八章 Hamilton 力学

> 本章训练 Legendre 变换、Hamilton 正则方程的建立与求解、Poisson 括号计算、以及 Liouville 定理。

### 8.1 Legendre 变换与 Hamilton 方程

**(a)** 从 Lagrangian $L(q,\dot{q},t)$ 出发，通过 Legendre 变换 $H = \sum p_i\dot{q}_i - L$ 构造 Hamiltonian。证明 $H(q,p,t)$ 是 $q$ 和 $p$ 的函数（$\dot{q}$ 已通过 $p = \partial L/\partial\dot{q}$ 消去）。

**(b)** 写出 Hamilton 正则方程：
$$\dot{q}_i = \frac{\partial H}{\partial p_i}, \quad \dot{p}_i = -\frac{\partial H}{\partial q_i}$$
证明相空间中任意函数 $F(q,p,t)$ 的全时间导数为：
$$\frac{dF}{dt} = \{F, H\} + \frac{\partial F}{\partial t}$$
其中 Poisson 括号定义为 $\{A,B\} = \sum_i (\frac{\partial A}{\partial q_i}\frac{\partial B}{\partial p_i} - \frac{\partial A}{\partial p_i}\frac{\partial B}{\partial q_i})$。

**(c)** 对以下系统，写出 Hamiltonian 和正则方程：
1. 简谐振子：$L = \frac{1}{2}m\dot{x}^2 - \frac{1}{2}kx^2$
2. 有心力问题：$L = \frac{1}{2}m(\dot{r}^2 + r^2\dot{\phi}^2) - V(r)$
3. 带电粒子在电磁场中：$L = \frac{1}{2}m\mathbf{v}^2 + q\mathbf{v}\cdot\mathbf{A} - q\Phi$ 

>[!s]- *(a) 构造 Hamiltonian*
>由定义
>$$p = \frac{\partial L}{\partial \dot{q}} \implies H := \sum_{i}p_{i}\dot{q}_{i} - L $$
>则其微分为
>
>$$\begin{align} dH & = \sum_{i}(dp_{i}\dot{q}_{i} - p_{i}d\dot{q}_{i}) - dL = \sum_{i}\left(  \dot{q}_{i}dp_{i} - \frac{\partial L}{\partial \dot{q}_{i}}d\dot{q}_{i}  \right) - \sum_{i}\left( \frac{\partial L}{\partial q_{i}}dq_{i} + \frac{\partial L}{\partial \dot{q}_{i}}d\dot{q}_{i} \right) - \frac{\partial L}{\partial t}dt \\ & = \sum_{i}\left(  \dot{q}_{i}dp_{i} - \frac{\partial L}{\partial q_{i}}dq_{i}  \right) - \frac{\partial L}{\partial t}dt \end{align} $$
>所以 $H$ 的自然变量是 $q,p,t$ 且
>
>$$\frac{\partial H}{\partial q_{i}} = -\frac{\partial L}{\partial q_{i}} = -\dot{p}_{i} ,\quad \frac{\partial H}{\partial p_{i}} = q_{i} $$

>[!S]- *(b) Poisson 括号与正则方程*
>相空间中由于 $F$ 的变量为 $q,p,t$ 所以
>
>$$dF = \sum_{i}\left( \frac{\partial F}{\partial q_{i}}dq_{i} + \frac{\partial F}{\partial p_{i}}dp_{i} \right) + \frac{\partial F}{\partial t}dt $$
>
>于是
>
>$$\frac{dF}{dt} = \sum_{i}\left( \frac{\partial F}{\partial q_{i}}\dot{q}_{i} + \frac{\partial F}{\partial p_{i}}\dot{p}_{i} \right) + \frac{\partial F}{\partial t} $$
>考虑到 $\dot{q}_i = \frac{\partial H}{\partial p_i}, \quad \dot{p}_i = -\frac{\partial H}{\partial q_i}$ 代入得
>
>$$\frac{dF}{dt} = \sum_{i}\left(  \frac{\partial F}{\partial q_{i}}\frac{\partial H}{\partial p_{i}} - \frac{\partial F}{\partial p_{i}}\frac{\partial H}{\partial q_{i}}  \right) + \frac{\partial F}{\partial t} = \{ F,H \} + \frac{\partial F}{\partial t} $$

>[!S]- *(c) 具体系统的哈密顿量与正则方程*
>1. $$p = \frac{\partial L}{\partial \dot{x}} = m\dot{x} \implies H = p\dot{x} - L = \frac{1}{2m}p^{2} + \frac{1}{2}kx^{2} $$
>2. $$p_{r}=\frac{\partial L}{\partial\dot{r}} = m\dot{r},p_{\phi}=\frac{\partial L}{\partial \dot{\phi}}=mr^{2}\dot{\phi} \implies H = p_{r}\dot{r}+p_{\phi}\dot{\phi} - L = \frac{p_{r}^{2}}{2m} + \frac{p_{\phi}^{2}}{2mr^{2}} + V(r) $$
>3. $$\mathbf{p} = \frac{\partial L}{\partial \mathbf{v}} = m\mathbf{v} + q\mathbf{A} \implies H = \mathbf{p}\cdot \mathbf{v} - L = \frac{1}{2m}(\mathbf{p}-e\mathbf{A})^{2} + q\Phi $$

### 8.2 Poisson 括号与守恒律

**(a)** 证明 Poisson 括号的基本代数性质：
1. 反对称性：$\{A,B\} = -\{B,A\}$
2. 线性：$\{A, \alpha B + \beta C\} = \alpha\{A,B\} + \beta\{A,C\}$
3. Jacobi 恒等式：$\{A,\{B,C\}\} + \{B,\{C,A\}\} + \{C,\{A,B\}\} = 0$
4. Leibniz 规则：$\{A, BC\} = \{A,B\}C + B\{A,C\}$

**(b)** 计算基本的 Poisson 括号：
$$\{q_i, q_j\} = 0, \quad \{p_i, p_j\} = 0, \quad \{q_i, p_j\} = \delta_{ij}$$

**(c)** 对有心力问题，用 Poisson 括号验证角动量的各分量满足：
$$\{L_i, L_j\} = \epsilon_{ijk}L_k$$
并证明 $L^2 = L_x^2 + L_y^2 + L_z^2$ 与所有 $L_i$ 对易：$\{L^2, L_i\} = 0$。

### 8.3 相空间与 Liouville 定理

### 8.4 作用量-角变量 $\star$

**(a)** 对一维周期运动系统，定义作用量变量 $J = \frac{1}{2\pi}\oint p\,dq$。证明 $J$ 是绝热不变量，并解释其与 "Ehrenfest 绝热假设"（早期量子论）的关系。

**(b)** 对简谐振子 $H = p^2/(2m) + \frac{1}{2}m\omega^2 q^2$：
- 计算 $J$ 作为能量的函数
- 证明 $\omega = \partial H/\partial J$（作用量-角量形式下的 Hamilton 方程）
- 由此得到 $E = (n + \frac{1}{2})\hbar\omega$ 的 Bohr-Sommerfeld 量子化条件

**(c)** 用作用量-角变量方法分析 Kepler 问题的量子化：写出径向作用量 $J_r$ 和角向作用量 $J_\phi$，验证 $E \propto -1/(J_r + J_\phi)^2$，从而得到 Balmer 公式。

>[!s]- **(a) 作用量变量的定义与绝热不变性**
>
> **Step 1：一维周期运动的作用量变量**
>
> 对于一维束缚运动，粒子在 $q_1$ 和 $q_2$（转向点）之间做周期性运动。在相空间 $(q,p)$ 中，轨迹为闭合曲线。定义作用量变量：
>
> $$J \equiv \frac{1}{2\pi}\oint p\,dq$$
>
> 其中 $\oint$ 表示沿一个完整周期的积分。对简谐振子，相轨迹为椭圆 $p^2/(2mE) + q^2/(2E/(m\omega^2)) = 1$，面积 $= \pi\cdot\sqrt{2mE}\cdot\sqrt{2E/(m\omega^2)} = 2\pi E/\omega$。故 $J = E/\omega$。
>
> **Step 2：绝热不变性的证明思路**
>
> 若 Hamiltonian 的参数（如振子频率 $\omega$、势的形状）随时间缓慢变化（变化时间尺度远大于运动周期），则 $J$ 近似维持不变。
>
> 证明的核心论据：
> 1. 参数变化时，$p(q,t)$ 不再只是 $q$ 的函数，$H$ 也不再严格守恒
> 2. 但考虑 $J$ 在一个周期内的变化率 $\dot{J}$，将其对快变周期做平均
> 3. 因为参数变化缓慢，$\langle \dot{J} \rangle$ 中周期性项在平均后为零
> 4. 剩余的非零项是 $\mathcal{O}(\epsilon^2)$ 量级（$\epsilon$ 为变化的缓变参数）
>
> 严格的数学表述：$\Delta J \sim \mathcal{O}(e^{-T/\tau})$（指数小量），其中 $T$ 为运动周期，$\tau$ 为参数变化的特征时间尺度。
>
> **Step 3：与 Ehrenfest 绝热假设的关系**
>
> Ehrenfest 在早期量子论中提出：在参数绝热变化（无限缓慢）下，允许的量子态连续地演化为对应的量子态——即量子数不改变。$J$ 恰好是经典力学中在绝热变化下守恒的量，因此 Bohr-Sommerfeld 量子化条件 $J = n\hbar$ 具有物理一致性：如果参数缓慢改变，量子数 $n$ 不会跳变，这对应于经典 $J$ 的绝热不变性。
>
> **经典例证**：长度为 $l$ 的单摆，$J = E/\omega \propto E\sqrt{l}$。缓慢缩短摆长，$E$ 和 $\omega$ 均变化，但 $J \propto E\sqrt{l}$ 维持不变 → $E \propto 1/\sqrt{l}$：摆越短，能量越高（你做功于系统）。这类似于光子在两面缓慢靠近的镜子间被"蓝移"。

>[!s]- **(b) 简谐振子的作用量-角变量与 Bohr-Sommerfeld 量子化**
>
> **Step 1：计算 $J$ 作为 $E$ 的函数**
>
> 简谐振子：$H = p^2/(2m) + \frac{1}{2}m\omega^2 q^2 = E$。在相空间 $(q,p)$ 中，轨迹满足：
>
> $$\frac{p^2}{2mE} + \frac{q^2}{2E/(m\omega^2)} = 1$$
>
> 这是一个椭圆，半轴为 $a = \sqrt{2E/(m\omega^2)}$（沿 $q$ 轴）和 $b = \sqrt{2mE}$（沿 $p$ 轴）。椭圆的面积为 $\pi a b = \pi \sqrt{2E/(m\omega^2)} \cdot \sqrt{2mE} = 2\pi E/\omega$。
>
> $$J = \frac{1}{2\pi}\oint p\,dq = \frac{1}{2\pi} \times (\text{相面积}) = \frac{1}{2\pi} \cdot \frac{2\pi E}{\omega} = \frac{E}{\omega}$$
>
> $$\boxed{J = \frac{E}{\omega}}$$
>
> **Step 2：验证 $\omega = \partial H/\partial J$**
>
> 由 $J = E/\omega$ 得 $E = \omega J$。故 $H(J) = \omega J$。（注意这里 $\omega$ 是参数，$H$ 只依赖于 $J$。）
>
> $$\frac{\partial H}{\partial J} = \omega$$
>
> 角变量 $\theta$ 满足 $\dot{\theta} = \partial H/\partial J = \omega$ → $\theta(t) = \omega t + \theta_0$。这正是我们期待的：角变量以恒定角频率均匀增加。这个结果也可通过直接构造正则变换 $(q,p) \to (\theta, J)$ 得到验证：
>
> $$q = \sqrt{\frac{2J}{m\omega}}\sin\theta, \quad p = \sqrt{2m\omega J}\cos\theta$$
>
> 验证 $\{q,p\} = \frac{\partial q}{\partial\theta}\frac{\partial p}{\partial J} - \frac{\partial q}{\partial J}\frac{\partial p}{\partial\theta} = \sqrt{\frac{2J}{m\omega}}\cos\theta \cdot \sqrt{\frac{m\omega}{2J}}\cos\theta - \frac{1}{\sqrt{2m\omega J}}\sin\theta \cdot (-\sqrt{2m\omega J}\sin\theta) = \cos^2\theta + \sin^2\theta = 1$ ✓。
>
> **Step 3：Bohr-Sommerfeld 量子化条件**
>
> Bohr-Sommerfeld 条件：$J = n\hbar$（其中 $n = 0, 1, 2, \ldots$）。
>
> $$E_n = \omega J = n\hbar\omega$$
>
> 但这缺少了零点能 $1/2\hbar\omega$。准确的半经典条件是 $\oint p\,dq = (n + \frac{1}{2})h$，即：
>
> $$J = \left(n + \frac{1}{2}\right)\hbar$$
>
> 则 $E_n = (n + \frac{1}{2})\hbar\omega$，与 Schrödinger 方程的严格解吻合。额外的 $1/2$ 来自 Maslov 指数（每个软转向点贡献 $1/2$，谐振子有两个软转向点 → 共贡献 1 → $n+1/2$）。
>
> **物理注释**：简谐振子之所以成为经典-量子对应的完美范例，是因为其 $H(J)$ 恰好是 $J$ 的线性函数。一般而言 $H(J)$ 可以非线性，但 $\partial H/\partial J$ 仍给出角变量的频率——这是作用量-角变量方法的核心价值：它将任意（可分离的）周期系统映射到一个"刚性旋转"系统。

>[!s]- **(c) Kepler 问题的作用量-角变量与 Balmer 公式**
>
> **Step 1：分离变量与作用量定义**
>
> Kepler 问题在球坐标下的 Hamiltonian：
> $$H = \frac{p_r^2}{2\mu} + \frac{p_\theta^2}{2\mu r^2} + \frac{p_\phi^2}{2\mu r^2\sin^2\theta} - \frac{k}{r}$$
>
> 其中 $p_\phi = \mu r^2\sin^2\theta\,\dot{\phi} = L_z$（守恒量），$p_\theta = \mu r^2\dot{\theta}$。
>
> 轨道具有完全可分离性（Liouville 可积）。定义三个作用量：
> $$J_\phi = \frac{1}{2\pi}\oint p_\phi\,d\phi = L_z$$
> $$J_\theta = \frac{1}{2\pi}\oint p_\theta\,d\theta$$
> $$J_r = \frac{1}{2\pi}\oint p_r\,dr$$
>
> **Step 2：$J_\theta$ 的计算**
>
> 在球坐标下总角动量 $L^2 = p_\theta^2 + p_\phi^2/\sin^2\theta$ 守恒。$J_\theta$ 的积分可通过 $\theta$ 的转向点关系和 $L$ 来表达。结果（经典推导，此处给出结论）：
>
> $$J_\theta = L - |L_z|$$
>
> 其中 $L = \sqrt{p_\theta^2 + p_\phi^2/\sin^2\theta}$ 为总角动量大小。当轨道在赤道面内时（$L_z = L$），$J_\theta = 0$。
>
> **Step 3：$J_r$ 的计算**
>
> 径向运动由有效势 $V_{\text{eff}}(r) = -k/r + L^2/(2\mu r^2)$ 决定。$p_r = \sqrt{2\mu(E + k/r) - L^2/r^2}$。转向点 $r_{1,2}$ 是 $p_r=0$ 的解（对束缚态 $E<0$）。
>
> $$J_r = \frac{1}{2\pi}\oint p_r\,dr = \frac{1}{\pi}\int_{r_1}^{r_2} \sqrt{2\mu\left(E + \frac{k}{r}\right) - \frac{L^2}{r^2}}\,dr$$
>
> 此积分可用复变函数方法计算（Sommerfeld 的经典结果）：
>
> $$\oint p_r\,dr = -2\pi L + \frac{\pi k\sqrt{2\mu}}{\sqrt{-E}}$$
>
> 因此：
> $$J_r = -L + \frac{k\sqrt{2\mu}}{2\sqrt{-E}}$$
>
> 但需注意 $L = J_\theta + J_\phi$（因为 $L = |L_z| + (L-|L_z|) = J_\phi + J_\theta$）。
>
> **Step 4：总作用量与能级**
>
> 总作用量 $J_{\text{tot}} = J_r + J_\theta + J_\phi$：
> $$J_{\text{tot}} = J_r + L = \frac{k\sqrt{2\mu}}{2\sqrt{-E}}$$
>
> 反解 $E$：
> $$\boxed{E = -\frac{\mu k^2}{2\,J_{\text{tot}}^2} = -\frac{\mu k^2}{2(J_r + J_\theta + J_\phi)^2}}$$
>
> 这正是 $E \propto -1/(J_r + J_\phi)^2$（当轨道在赤道面内时 $J_\theta=0$）。
>
> **Step 5：Bohr-Sommerfeld 量子化 → Balmer 公式**
>
> 量子化条件：$J_r = n_r\hbar$，$J_\phi = n_\phi\hbar$（$n_r, n_\phi = 0, 1, 2, \ldots$）。令主量子数 $n = n_r + n_\phi$：
>
> $$E_n = -\frac{\mu k^2}{2\hbar^2 n^2}$$
>
> 对氢原子，$k = e^2/(4\pi\epsilon_0)$，$\mu \approx m_e$。能级差：
>
> $$\Delta E_{n\to n'} = \frac{\mu k^2}{2\hbar^2}\left(\frac{1}{n'^2} - \frac{1}{n^2}\right)$$
>
> 用 $E = h\nu = hc/\lambda$ 得：
>
> $$\boxed{\frac{1}{\lambda} = R_\infty\left(\frac{1}{n'^2} - \frac{1}{n^2}\right), \quad R_\infty = \frac{\mu k^2}{4\pi\hbar^3 c}}$$
>
> 这就是 **Balmer 公式**（$n'=2$ 给出可见光 Balmer 线系）。$R_\infty \approx 1.097\times 10^7\,\text{m}^{-1}$ 与实验观测的 Rydberg 常数高度吻合。
>
> **物理注释**：作用量-角变量方法的优美之处在于：
> 1. $E$ 只依赖于 $J_{\text{tot}} = J_r + J_\theta + J_\phi$ → 能级是简并的（$n_r$ 和 $n_\phi$ 的不同组合可给出相同 $n$）
> 2. 这个简并性反映了 Kepler 问题的隐藏 $SO(4)$ 对称性（Runge-Lenz 矢量守恒）
> 3. 角频率 $\nu_r = \partial H/\partial J_r = \partial H/\partial J_\theta = \partial H/\partial J_\phi$（三者相等）→ 轨道闭合（Bertrand 定理的作用量-角量版本）
> 4. 量子力学中此简并性在类氢原子中依然存在（能量只取决于 $n$，不取决于 $l$）

### 9.1 正则变换的判定

**(a)** 变换 $(q,p) \to (Q,P)$ 是正则变换，当且仅当它保持 Poisson 括号的基本关系：
$$\{Q_i, Q_j\} = 0, \quad \{P_i, P_j\} = 0, \quad \{Q_i, P_j\} = \delta_{ij}$$
或等价地，存在一个函数使得在变换下 $p\,dq - P\,dQ$ 是全微分。

**(b)** 判断以下变换是否为正则变换：
1. $Q = \log(1 + \sqrt{q}\cos p)$，$P = 2(1 + \sqrt{q}\cos p)\sqrt{q}\sin p$
2. $Q = q$，$P = p + aq$（$a$ 为常数）
3. $Q = \sqrt{2q}\,e^t\cos p$，$P = \sqrt{2q}\,e^{-t}\sin p$（显含时间的变换）

**(c)** 对上述显含时间的变换 (3)，若要保持正则性，如何处理含时情形？

### 9.2 生成函数方法

**(a)** 写出四种类型的生成函数及其变换关系：
$$\begin{aligned}
F_1(q,Q,t)&: \; p = \frac{\partial F_1}{\partial q},\; P = -\frac{\partial F_1}{\partial Q} \\
F_2(q,P,t)&: \; p = \frac{\partial F_2}{\partial q},\; Q = \frac{\partial F_2}{\partial P} \\
F_3(p,Q,t)&: \; q = -\frac{\partial F_3}{\partial p},\; P = -\frac{\partial F_3}{\partial Q} \\
F_4(p,P,t)&: \; q = -\frac{\partial F_4}{\partial p},\; Q = \frac{\partial F_4}{\partial P}
\end{aligned}$$

**(b)** 给定生成函数 $F_2(q,P) = qP + \frac{1}{2}\epsilon q P^2$（$\epsilon$ 为小参数），求 $(Q,P)$ 和新的 Hamiltonian $K(Q,P)$。

**(c)** 对简谐振子 $H = \frac{1}{2m}p^2 + \frac{1}{2}m\omega^2 q^2$，构造生成函数 $F_1(q,Q)$ 使新坐标下的 $K(Q,P) = \omega P$（即 $Q$ 为循环坐标），并写出变换公式。

>[!S]- *(b)*
>$$p = \frac{\partial F_{2}}{\partial q} = P + \frac{1}{2}\varepsilon P^{2} ,\quad Q = \frac{\partial F_{2}}{\partial P} = q + \varepsilon q $$
>我们可以反解出来
>
>$$p = P + \frac{1}{2}\varepsilon P^{2} ,\quad q = \frac{Q}{1+\varepsilon} $$
>
>于是
>
>$$K(Q,P) = H(q,p) = H\left( \frac{Q}{1+\varepsilon} , P + \frac{1}{2}\varepsilon PSr \right) $$
>

>[!S]- *(c)*
>由题意，我们希望
>
>$$H\left( p,\frac{\partial F_{1}}{\partial q} \right) = \omega\left( -\frac{\partial F_{1}}{\partial Q} \right) $$
>
>我们取 $F_{1}=\frac{1}{2}m\omega^{2}q\cot Q$ 于是
>
>$$p = \frac{\partial F_{1}}{\partial q} = \frac{1}{2}m\omega^{2}\cot Q ,\quad P = -\frac{\partial F_{1}}{\partial Q} = \frac{1}{2}m\omega^{2}q\csc ^{2}Q $$
>即
>
>$$q = \sqrt{ \frac{2P}{m\omega} }\sin Q ,\quad p = \sqrt{ 2m\omega P }\cos Q $$

### 9.3 无穷小正则变换与对称性 $\star$

**(a)** 证明：无穷小正则变换 $Q_i = q_i + \epsilon\frac{\partial G}{\partial p_i}$，$P_i = p_i - \epsilon\frac{\partial G}{\partial q_i}$（$G$ 为生成函数）在 $\epsilon \to 0$ 下保持 Poisson 括号不变。

**(b)** 对于空间平移 $G = P_x$，验证该无穷小正则变换确实生成 $x \to x + \epsilon$ 的平移。对于空间旋转 $G = L_z = x p_y - y p_x$，验证生成绕 $z$ 轴的转动。

**(c)** 利用 $\{G, H\} = 0$ 是 $G$ 守恒的充要条件，结合 (b) 的结果，获得与对称性-守恒律（Noether 定理的 Hamilton 版本）的联系。

>[!S]- *(a) 无穷小正则变换*
>$$\{ Q_{i},Q_{j} \} = \left\{  q_{i} + \varepsilon \frac{\partial G}{\partial p_{i}} , q_{j} + \varepsilon \frac{\partial G}{\partial p_{j}}  \right\} = \{ q_{i} , q_{j} \} + \varepsilon( \{ q_{i},\tilde{\partial}_{j}G \} + \{ \tilde{\partial}_{i}G , q_{j} \} ) + \mathcal{O}(\varepsilon^{2}) $$
>其中
>
>$$\{ q_{i} , \tilde{\partial}_{j}G \} = \sum_{k}\left( \frac{\partial q_{i}}{\partial q_{k}}\frac{\partial (\tilde{\partial}_{j}G)}{\partial p_{k}} \right) = \sum_{k}\delta_{ik}\frac{\partial^{2} G}{\partial p_{j}\partial p_{k}} = \frac{\partial^{2}G}{\partial p_{i}\partial p_{j}} $$
>$$\{ \tilde{\partial}_{i}G , q_{j} \} = -\frac{\partial^{2}G}{\partial p_{j}\partial p_{i}} $$
>而 $G$ 是性质良好的，所以偏导可交换，这两个结果大小一样。从而
>
>$$\{ Q_{i} , Q_{j} \} = \{ q_{i} , q_{j} \} $$

>[!s]- *(b) 平移与旋转变换*
>取 $G = P_{x}$ 则
>
>$$\frac{\partial G}{\partial p_{x}} = 1 ,\quad \frac{\partial G}{\partial p_{y,z}} = \frac{\partial G}{\partial x_{i}} = 0 ,\quad i=x,y,z $$
>所以
>
>$$X = x+ \varepsilon , \quad Y = y ,\quad Z = z ,\quad P_{x} = p_{x} , \quad P_{y} = p_{y} ,\quad P_{z} = p_{z} $$
>
>这确实生成 $x \to x + \epsilon$ 的平移。
>
>取 $G = xp_{y} - yp_{x}$ 则
>
>$$\frac{\partial G}{\partial p_{x}} = -y ,\quad \frac{\partial G}{\partial p_{y}} = x ,\quad \frac{\partial G}{\partial p_{z}} = 0 ,\quad \frac{\partial G}{\partial x} = p_{y} , \quad \frac{\partial G}{\partial y} = -p_{x} , \quad \frac{\partial G}{\partial z} = 0 $$
>
>所以
>
>$$X = x-\varepsilon y ,\quad Y = y+\varepsilon x ,\quad Z = z ,\quad P_{x} = p_{x} + \varepsilon p_{y} ,\quad P_{y} = p_{y} - \varepsilon p_{x} ,\quad P_{z} = p_{z} $$
>
>这生成绕 $z$ 轴的转动。

## 第十章 Hamilton-Jacobi 理论

> 本章训练 Hamilton-Jacobi 方程的建立与分离变量解法、作用量函数的构造、以及向 Schrödinger 方程的过渡。

### 10.1 Hamilton-Jacobi 方程

**(a)** 从 Hamilton 原理出发，推导 Hamilton-Jacobi 方程。引入 Hamilton 主函数 $S(q,t)$（作用量），满足：
$$\frac{\partial S}{\partial t} + H\!\left(q, \frac{\partial S}{\partial q}, t\right) = 0$$
其中 $p_i = \partial S/\partial q_i$。解释 $S$ 的物理含义：$S$ 是沿经典路径的作用量泛函在其上端点取值。

**(b)** 若 $H$ 不显含 $t$（保守系统），分离变量 $S(q,t) = W(q) - Et$，得到定态 Hamilton-Jacobi 方程：
$$H\!\left(q, \frac{\partial W}{\partial q}\right) = E$$
其中 $W(q)$ 称为 Hamilton 特征函数（简化的作用量）。

>[!s]- **(a) 从 Hamilton 原理推导 Hamilton-Jacobi 方程**
>
> **Step 1：Hamilton 原理的回顾**
>
> Hamilton 原理（最小作用量原理）：
> $$\delta S[q] = \delta \int_{t_1}^{t_2} L(q,\dot{q},t)\,dt = 0$$
>
> 其中变分在固定端点 $q(t_1)=q_1$，$q(t_2)=q_2$ 处为零（$\delta q(t_1)=\delta q(t_2)=0$）。
>
> 对于连接 $(q_1,t_1) \to (q_2,t_2)$ 的经典路径，作用量取某个值 $S(q_2,t_2; q_1,t_1)$。现在将上端点 $(q,t)$ 视为变量，下端点固定。问：$S$ 如何随上端点变化？
>
> **Step 2：沿经典路径的 $dS$**
>
> 经典路径由 Euler-Lagrange 方程决定。沿该路径，作用量 $S$ 作为上端点 $(q,t)$ 的函数。它的全微分由边界贡献给出：
>
> 取两个相邻的经典路径：一条连接 $(q_1,t_1) \to (q,t)$，另一条连接 $(q_1,t_1) \to (q+\delta q, t+\delta t)$。二者之差为：
>
> $$\delta S = \left[L\,\delta t + \sum_i \frac{\partial L}{\partial \dot{q}_i}\,\delta q_i\right]_{t_1}^{t} - \int_{t_1}^{t} \sum_i \left[\frac{d}{dt}\!\left(\frac{\partial L}{\partial \dot{q}_i}\right) - \frac{\partial L}{\partial q_i}\right]\delta q_i\,dt$$
>
> 因为路径满足 Euler-Lagrange 方程，积分项为零。下端点固定（$\delta q(t_1)=\delta t(t_1)=0$）。上端点贡献：
>
> $$dS = L\,dt + \sum_i \frac{\partial L}{\partial \dot{q}_i}\,dq_i - \sum_i \frac{\partial L}{\partial \dot{q}_i}\,\dot{q}_i\,dt$$
>
> 注意 $dq_i|_{\text{上端点}}$ = 真正的 $dq_i$ 减去 $\dot{q}_i dt$（因为 $q$ 的新值和旧值之差由两部分组成：时间变化 $dt$ 带来的 $\dot{q}_i dt$ 位移，加上路径的变化 $\delta q_i$）。这里 $dq_i$ 是总位移。
>
> 最干净的方法：将经典作用量写成 $S = \int L\,dt$。若上端点从 $(q,t)$ 变到 $(q+\Delta q, t+\Delta t)$，且新的路径依然是经典路径（满足运动方程），则：
>
> $$\Delta S = L\Delta t + \sum_i\frac{\partial L}{\partial \dot{q}_i}\bigg|_t \underbrace{(\Delta q_i - \dot{q}_i\Delta t)}_{\delta q_i \text{ at } t} + \mathcal{O}(\Delta^2)$$
>
> 取全微分：
> $$dS = L\,dt + \sum_i \frac{\partial L}{\partial \dot{q}_i}\big(dq_i - \dot{q}_i dt\big) = \left(L - \sum_i p_i\dot{q}_i\right)dt + \sum_i p_i\,dq_i$$
>
> 其中 $p_i \equiv \partial L/\partial \dot{q}_i$。
>
> **Step 3：识别 Hamiltonian 与完成推导**
>
> 括号中的量 $L - \sum_i p_i\dot{q}_i = -H$（Legendre 变换的逆）。故：
>
> $$dS = \sum_i p_i\,dq_i - H\,dt$$
>
> 这意味着：
> $$\frac{\partial S}{\partial q_i} = p_i, \qquad \frac{\partial S}{\partial t} = -H$$
>
> 将 $p_i = \partial S/\partial q_i$ 代入第二个方程，并注意 $H = H(q_1,\ldots,q_n, p_1,\ldots,p_n, t)$：
>
> $$\boxed{\frac{\partial S}{\partial t} + H\!\left(q_1,\ldots,q_n, \frac{\partial S}{\partial q_1},\ldots,\frac{\partial S}{\partial q_n}, t\right) = 0}$$
>
> 这就是 **Hamilton-Jacobi 方程**——关于 $S(q,t)$ 的一阶非线性偏微分方程。
>
> **Step 4：$S$ 的物理含义**
>
> 由 $dS = p\,dq - H\,dt$ 沿经典路径积分：
> $$S(q,t) = \int_{t_0}^{t} \left(\sum_i p_i\dot{q}_i - H\right)dt' = \int_{t_0}^{t} L\,dt'$$
>
> $S$ 正是沿经典路径的作用量泛函，取值取决于上端点 $(q,t)$。换言之，$S(q,t)$ 是这样一个函数：如果知道它，那么每个时刻的 $p_i = \partial S/\partial q_i$ 可直接求导得到——无需解微分方程。
>
> **类比**：Hamilton-Jacobi 方程在力学中的地位，相当于 eikonal 方程在几何光学中的地位——它们都是各自领域中描述"波前"传播的一阶 PDE。当 $H$ 不显含 $t$ 时，$S$ 可分离为 $S = W - Et$，其中 $W$ 满足 $|\nabla W| = \sqrt{2m(E-V)}$——这正是光学中 eikonal 方程 $|\nabla S| = n$ 的力学版本。

>[!s]- **(b) 保守系统的分离变量与 Hamilton 特征函数**
>
> **Step 1：时间分离**
>
> 若 $H$ 不显含 $t$（$\partial H/\partial t = 0$），则能量守恒。H-J 方程为：
>
> $$\frac{\partial S}{\partial t} + H\!\left(q, \frac{\partial S}{\partial q}\right) = 0$$
>
> 分离变量假设 $S(q,t) = W(q) + T(t)$。代入：
>
> $$T'(t) + H\!\left(q, \frac{\partial W}{\partial q}\right) = 0$$
>
> 第一项只依赖于 $t$，第二项只依赖于 $q$。等式对所有 $q,t$ 成立意味着两项各自为常数且互为相反数：
>
> $$T'(t) = -E, \quad H\!\left(q, \frac{\partial W}{\partial q}\right) = E$$
>
> 故 $T(t) = -Et + \text{const}$（常数可吸收到 $W$ 中），得：
>
> $$\boxed{S(q,t) = W(q) - Et}$$
>
> **Step 2：定态 Hamilton-Jacobi 方程**
>
> 代入 $p_i = \partial W/\partial q_i$：
>
> $$\boxed{H\!\left(q_1,\ldots,q_n, \frac{\partial W}{\partial q_1},\ldots,\frac{\partial W}{\partial q_n}\right) = E}$$
>
> 这就是**定态 H-J 方程**（时间无关的 H-J 方程）。$W(q)$ 称为 **Hamilton 特征函数**。
>
> **Step 3：$W$ 的几何意义**
>
> $dW = \sum p_i\,dq_i$ → $W(q) = \int_{q_0}^{q} \mathbf{p}\cdot d\mathbf{q}$（沿构型空间中的路径积分）。
>
> 这是作用量的"截断"版本（减去了 $Et$ 部分）。在构型空间中，等 $W$ 曲面以法向速度 $u = E/|\nabla W|$ 传播——与光学中波前传播完全一致。
>
> **Step 4：与经典作用量的关系**
>
> $$S(q,t) = \int_{t_0}^{t} L\,dt' = W(q) - Et$$
>
> 所以 $W(q) = \int_{t_0}^{t} (L + E)\,dt' = \int_{t_0}^{t} (T + V + E)\,dt'$。对保守系统 $E = T + V$，$L+E = 2T$：
>
> $$W(q) = \int_{t_0}^{t} 2T\,dt' = \int_{t_0}^{t} \mathbf{p}\cdot\dot{\mathbf{q}}\,dt' = \int_{q_0}^{q} \mathbf{p}\cdot d\mathbf{q}$$
>
> 这与 $dW = p\,dq$ 完全一致 ✓。

### 10.2 分离变量法

**(a)** 对以下系统，写出 Hamilton-Jacobi 方程并用分离变量法求解：
1. 一维简谐振子：$H = \frac{p^2}{2m} + \frac{1}{2}m\omega^2 q^2$
2. 一维粒子在均匀重力场中：$V = mgz$
3. Kepler 问题（球坐标下分离 $r$ 和 $\theta,\phi$）

**(b)** 对 Kepler 问题，证明 $S$ 可完全分离为：
$$S = -Et + W_r(r) + W_\theta(\theta) + \alpha_\phi\phi$$
写出 $W_r(r)$ 满足的方程，以及该方程的积分形式。

>[!s]- **(a) 三个系统的 H-J 方程与分离变量解**
>
> **1. 一维简谐振子**
>
> Hamiltonian：$H = \frac{p^2}{2m} + \frac{1}{2}m\omega^2 q^2$
>
> 定态 H-J 方程（$S = W(q) - Et$）：
> $$\frac{1}{2m}\left(\frac{dW}{dq}\right)^2 + \frac{1}{2}m\omega^2 q^2 = E$$
>
> 直接解出 $p(q) = dW/dq$：
> $$\frac{dW}{dq} = \pm\sqrt{2mE - m^2\omega^2 q^2}$$
>
> 积分：
> $$W(q) = \int \sqrt{2mE - m^2\omega^2 q^2}\,dq = \frac{1}{2}q\sqrt{2mE - m^2\omega^2 q^2} + \frac{E}{\omega}\arcsin\!\left(q\sqrt{\frac{m\omega^2}{2E}}\right) + \text{const}$$
>
> 转向点 $q_{\pm} = \pm\sqrt{2E/(m\omega^2)}$。完整的 $S(q,E,t) = W(q,E) - Et$。由 Jacobi 定理，$\beta = \partial S/\partial E = \text{const}$ 给出运动方程：
> $$\beta = \frac{\partial W}{\partial E} - t = \frac{1}{\omega}\arcsin\!\left(q\sqrt{\frac{m\omega^2}{2E}}\right) - t$$
>
> 反解得 $q(t) = \sqrt{\frac{2E}{m\omega^2}}\sin(\omega t + \omega\beta)$——恰为简谐振动解。
>
> **技术要点**：即使不做显式积分，也可通过替换 $q = \sqrt{2E/(m\omega^2)}\sin\theta$ 将 $dW/dq$ 化为三角积分。这是作用量-角变量方法的雏形。
>
> ---
>
> **2. 一维均匀重力场**
>
> $V = mgz$（取 $z$ 向上为正）。$H = \frac{p_z^2}{2m} + mgz$。
>
> 定态 H-J 方程：
> $$\frac{1}{2m}\left(\frac{dW}{dz}\right)^2 + mgz = E$$
>
> $$\frac{dW}{dz} = \pm\sqrt{2m(E - mgz)}$$
>
> 转向点 $z_{\max} = E/(mg)$（粒子能到达的最高点）。积分：
> $$W(z) = \int \sqrt{2m(E - mgz)}\,dz = -\frac{2}{3mg}\big[2m(E - mgz)\big]^{3/2} + \text{const}$$
>
> Jacobi 定理 $\beta = \partial W/\partial E - t = \text{const}$：
> $$\beta = \int \frac{m\,dz}{\sqrt{2m(E - mgz)}} - t = -\frac{1}{g}\sqrt{\frac{2(E - mgz)}{m}} - t$$
>
> 反解：
> $$z(t) = \frac{E}{mg} - \frac{1}{2}g(t + \beta)^2$$
>
> 匀变速运动公式（取 $\beta=0$ 使 $t=0$ 为最高点）。H-J 方法在此虽"杀鸡用牛刀"，但展示了分离变量法对可积系统的普适性。
>
> ---
>
> **3. Kepler 问题（球坐标）**
>
> $$H = \frac{1}{2\mu}\left(p_r^2 + \frac{p_\theta^2}{r^2} + \frac{p_\phi^2}{r^2\sin^2\theta}\right) - \frac{k}{r}$$
>
> 定态 H-J 方程（$S = -Et + W(r,\theta,\phi)$）：
> $$\frac{1}{2\mu}\left[\left(\frac{\partial W}{\partial r}\right)^2 + \frac{1}{r^2}\left(\frac{\partial W}{\partial \theta}\right)^2 + \frac{1}{r^2\sin^2\theta}\left(\frac{\partial W}{\partial \phi}\right)^2\right] - \frac{k}{r} = E$$
>
> 完全分离 $W = W_r(r) + W_\theta(\theta) + W_\phi(\phi)$。逐层分离：
>
> - **$\phi$**：循环坐标 → $\partial W/\partial \phi = \boxed{\alpha_\phi = L_z}$（常数）
> - **$\theta$**：仅含 $\theta$ 的项必须等于常数 $\alpha_\theta^2 = L^2$（角动量平方）：
>   $$\left(\frac{dW_\theta}{d\theta}\right)^2 + \frac{\alpha_\phi^2}{\sin^2\theta} = \alpha_\theta^2$$
> - **$r$**：剩余方程为等效一维径向方程：
>   $$\frac{1}{2\mu}\left[\left(\frac{dW_r}{dr}\right)^2 + \frac{\alpha_\theta^2}{r^2}\right] - \frac{k}{r} = E$$
>
> 三个分离常数 $E, L^2, L_z$ 使 Kepler 问题成为 Liouville 完全可积系统（3 个自由度，3 个 Poisson-对易的守恒量）。

>[!s]- **(b) Kepler 问题完全分离与 $W_r$ 积分**
>
> **Step 1：完全分离的 $S$**
>
> 由 (a) 的分离过程：
> $$\boxed{S = -Et + W_r(r) + W_\theta(\theta) + \alpha_\phi\phi}$$
>
> 三个分离常数：$E$（能量）、$\alpha_\theta^2 = L^2$（角动量平方）、$\alpha_\phi = L_z$（角动量 $z$ 分量）。这是 Liouville 可积性的直接体现。
>
> **Step 2：$W_r(r)$ 满足的方程**
>
> $$\boxed{\frac{1}{2\mu}\left(\frac{dW_r}{dr}\right)^2 + \frac{L^2}{2\mu r^2} - \frac{k}{r} = E}$$
>
> 其中 $L^2 = \alpha_\theta^2$。有效势 $V_{\text{eff}}(r) = L^2/(2\mu r^2) - k/r$ 正是等效一维问题的势。
>
> **Step 3：积分形式**
>
> $$\frac{dW_r}{dr} = \pm\sqrt{2\mu\left(E + \frac{k}{r}\right) - \frac{L^2}{r^2}}$$
>
> $$W_r(r) = \int \sqrt{2\mu\left(E + \frac{k}{r}\right) - \frac{L^2}{r^2}}\,dr$$
>
> 转向点 $r_{1,2}$ 是被积函数根号内表达式的零点。对束缚态 $E<0$，存在 $0 < r_1 \leq r \leq r_2$ 的有限运动区间（近日点和远日点）。
>
> **Step 4：径向作用量（通往量子化）**
>
> $J_r = \frac{1}{2\pi}\oint p_r\,dr = \frac{1}{\pi}\int_{r_1}^{r_2}\sqrt{2\mu(E + k/r) - L^2/r^2}\,dr$。复变积分给出 $J_r = -L + k\sqrt{2\mu}/(2\sqrt{-E})$。结合 $J_\theta = L - |L_z|$，$J_\phi = |L_z|$，总作用量 $J_{\text{tot}} = J_r + J_\theta + J_\phi = k\sqrt{2\mu}/(2\sqrt{-E})$ → **Balmer 公式**。

### 10.3 作用量函数与几何光学类比 $\star$

**(a)** 证明 $S(q,t) = \text{constant}$ 的曲面在构型空间中以法向速度 $u = E/|\nabla S|$ 传播。这一行为类似于几何光学中的波前传播——由此可建立经典力学与几何光学之间的类比：

| 经典力学                       | 几何光学               |
| -------------------------- | ------------------ |
| Hamilton 主函数 $S$           | 光程函数 / $eikonal$   |
| $\nabla S= \sqrt{2m(E-V)}$ | $\nabla S= n$（折射率） |
| 粒子轨道                       | 光线                 |
| Fermat 原理（最小作用量）           | Fermat 原理（最小光程）    |

**(b)** 基于此类比，解释 Schrödinger 为何猜测波动力学应满足 $S = -i\hbar\ln\psi$——即从 Hamilton-Jacobi 方程通过代换过渡到 Schrödinger 方程。

>[!s]- **(a) 等 $S$ 曲面的传播速度与几何光学类比**
>
> **Step 1：$S$ 曲面在构型空间中的运动**
>
> 对保守系统 $S(q,t) = W(q) - Et$。取等 $S$ 面 $S(q,t) = \text{const}$。在 $dt$ 时间内，曲面上一点 $q$ 以速度 $\mathbf{u}$ 沿法向移动，使 $S$ 值保持不变：
>
> $$dS = \frac{\partial S}{\partial t}dt + \nabla S \cdot d\mathbf{q} = -E\,dt + \nabla S \cdot (\mathbf{u}\,dt) = 0$$
>
> 其中 $\mathbf{u} = d\mathbf{q}/dt$ 是曲面在该点的法向移动速度。设 $\mathbf{u} \parallel \nabla S$（沿法向），则：
>
> $$\nabla S \cdot \mathbf{u} = |\nabla S|\,u = E \quad \Rightarrow \quad \boxed{u = \frac{E}{|\nabla S|}}$$
>
> 这正是波前传播的速度公式。
>
> **Step 2：类比的建立**
>
> 由定态 H-J 方程 $|\nabla W|^2 = 2m(E-V)$，得 $|\nabla S| = |\nabla W| = \sqrt{2m(E-V)}$。故：
>
> $$u = \frac{E}{\sqrt{2m(E-V)}}$$
>
> 粒子本身的经典速度为 $v = \sqrt{2(E-V)/m} = |\nabla S|/m$。比较知 $u$ 与 $v$ 不同。对于势阱中的运动（$E-V$ 越小，即靠近经典转向点），$|\nabla S| \to 0$，$u \to \infty$——曲面传播极快。这和几何光学中折射率 $n \propto 1/u$ 在焦散面附近的行为一致。
>
> **Step 3：力学-光学对应表**
>
> | 量 | 经典力学 | 几何光学 |
> |---|---------|---------|
> | 传播函数 | Hamilton 主函数 $S$ | eikonal / 光程函数 |
> | 梯度方程 | $|\nabla S| = \sqrt{2m(E-V)}$ | $|\nabla S| = n$（折射率） |
> | 轨迹 | 粒子轨道 $\perp$ 等 $S$ 面 | 光线 $\perp$ 等相位面 |
> | 变分原理 | Hamilton 原理 $\delta\int L\,dt = 0$ | Fermat 原理 $\delta\int n\,ds = 0$ |
> | 波长 | $\lambda = h/p = h/|\nabla S|$（量子） | $\lambda = \lambda_0/n$ |
>
> **深度理解**：几何光学是波动光学在 $\lambda \to 0$ 极限下的近似——eikonal 方程正是波动方程在短波长极限下的结果。同样，经典力学是量子力学在 $\hbar \to 0$（或 $S \gg \hbar$）极限下的近似。这不是巧合，而是 Hamiltonian 力学与波动理论的深层结构统一性（辛几何 ↔ 辛对称 ↔ 波前的切触几何）。
>
> 本表最核心的一行是 $|\nabla S| = \sqrt{2m(E-V)} \leftrightarrow |\nabla S| = n$。把力学中的 $\sqrt{2m(E-V)}$ 看成光学中的折射率 $n$，粒子轨道就是构型空间中的"光线"。

>[!s]- **(b) 从 H-J 方程到 Schrödinger 方程**
>
> **Step 1：Schrödinger 的猜测**
>
> 1926 年，Schrödinger 注意到经典力学（H-J 方程）与几何光学（eikonal 方程）之间的完全对应。既然几何光学是波动光学的短波极限，那么经典力学也应该是某种"波动力学"的短波极限。令：
>
> $$\boxed{\psi(\mathbf{x},t) = \exp\!\left(\frac{i}{\hbar}S(\mathbf{x},t)\right)}$$
>
> 即 $S = -i\hbar\ln\psi$。此处 $\hbar$ 是新引入的常数（具有作用量量纲），相当于光学中的波长——它控制经典极限何时有效。
>
> **Step 2：代入 H-J 方程**
>
> H-J 方程：$\frac{\partial S}{\partial t} + \frac{1}{2m}(\nabla S)^2 + V = 0$（取最简单的单个粒子）。
>
> 计算 $\psi$ 的导数：
> $$\frac{\partial\psi}{\partial t} = \frac{i}{\hbar}\frac{\partial S}{\partial t}\,\psi, \qquad \nabla\psi = \frac{i}{\hbar}\nabla S\,\psi, \qquad \nabla^2\psi = \left[\frac{i}{\hbar}\nabla^2 S - \frac{1}{\hbar^2}(\nabla S)^2\right]\psi$$
>
> 由后两式解出 $(\nabla S)^2$：
> $$(\nabla S)^2 = -\hbar^2\frac{\nabla^2\psi}{\psi} + i\hbar\frac{\nabla^2 S}{\psi}\cdot\psi \quad \text{——这不是实用的形式。}$$
>
> 更好的做法：直接从 $\nabla\psi = (i/\hbar)\nabla S\,\psi$ 出发，再作用一次 $\nabla$：
> $$\nabla^2\psi = \frac{i}{\hbar}\nabla^2 S\,\psi - \frac{1}{\hbar^2}(\nabla S)^2\,\psi$$
>
> 乘以 $-\hbar^2/(2m)$：
> $$-\frac{\hbar^2}{2m}\nabla^2\psi = -\frac{i\hbar}{2m}\nabla^2 S\,\psi + \frac{1}{2m}(\nabla S)^2\,\psi$$
>
> 同时 $i\hbar\,\partial\psi/\partial t = -\frac{\partial S}{\partial t}\,\psi$。
>
> **Step 3：重组为 Schrödinger 方程**
>
> $i\hbar\,\partial\psi/\partial t = \left[-\frac{\hbar^2}{2m}\nabla^2 + V\right]\psi + \frac{i\hbar}{2m}\nabla^2 S\,\psi$。
>
> 这里多出一项 $\frac{i\hbar}{2m}\nabla^2 S\,\psi$。在经典极限 $\hbar \to 0$ 下该项消失，H-J 方程精确恢复。Schrödinger 的勇敢之处在于：**他直接丢弃了这项**，得到了：
>
> $$\boxed{i\hbar\frac{\partial\psi}{\partial t} = -\frac{\hbar^2}{2m}\nabla^2\psi + V\psi}$$
>
> 这不是 H-J 方程的严格等价物，而是一个全新的动力学方程——它的解 $\psi$ 携带波动行为（干涉、衍射、隧道效应），这些在经典 H-J 框架中完全不存在。
>
> **Step 4：物理含义**
>
> 代换 $S = -i\hbar\ln\psi$ 的深层意义：
> - 经典 $S$ 是**实函数**（对应波动方程中的 eikonal / 相位）
> - 量子 $\psi$ 是**复函数**，$S = -i\hbar\ln\psi$ 自动使 $S$ 为复数——虚部对应振幅，实部对应相位
> - $\hbar \to 0$ 时 $\psi$ 的相位变化极快，波包沿经典轨道运动（通过定态相位近似 / WKB 方法恢复经典力学）
> - $\hbar$ 扮演的角色完全类似于光学中的波长 $\lambda$：$\lambda \to 0$ 使波动光学退化为几何光学，正如 $\hbar \to 0$ 使量子力学退化为经典力学
>
> 这一类比是 20 世纪理论物理学最深远的洞察之一：**物质波的本质是将力学纳入波动理论的框架，而 Hamilton-Jacobi 方程正是连接二者的"Rosetta Stone"。**

### 10.4 时间无关 Hamilton-Jacobi 方程与作用量-角变量

**(a)** 对分离后的 Hamilton 特征函数 $W(q)$，定义作用量变量 $J_i = \frac{1}{2\pi}\oint p_i\,dq_i$。证明 $H$ 最终只依赖于 $J_i$：$H = H(J_1,\ldots,J_n)$。角变量 $\theta_i = \partial W/\partial J_i$ 满足 $\dot{\theta}_i = \partial H/\partial J_i = \nu_i(J)$（常数）。

**(b)** 对 Kepler 问题，用作用量-角变量方法求出 $\nu_r$ 和 $\nu_\phi$，并证明只有当 $\nu_r/\nu_\phi$ 为有理数时轨道才闭合——这与 Bertrand 定理的结论一致。

>[!s]- **(a) 作用量变量的独立性与角变量的均匀演化**
>
> **Step 1：分离变量回顾**
>
> 对完全可分离的 Liouville 可积系统，Hamilton 特征函数 $W$ 可分离为：
> $$W(q_1,\ldots,q_n;\alpha_1,\ldots,\alpha_n) = \sum_{i=1}^n W_i(q_i;\alpha_1,\ldots,\alpha_n)$$
>
> 每个 $p_i = \partial W_i/\partial q_i$ 在 $q_i$ 的转向点之间振荡。$n$ 个分离常数 $\alpha_1,\ldots,\alpha_n$ 中，一个为能量 $E = \alpha_1$，其余为各广义动量的守恒分量。
>
> **Step 2：作用量变量的定义**
>
> $$J_i \equiv \frac{1}{2\pi}\oint p_i\,dq_i = \frac{1}{2\pi}\oint \frac{\partial W_i(q_i;\alpha)}{\partial q_i}\,dq_i$$
>
> 关键观察：因为 $p_i$ 在每个分离方程中只通过分离常数 $\alpha_j$ 依赖于其他坐标，所以每个 $J_i$ 的积分后**只是分离常数 $\alpha_1,\ldots,\alpha_n$ 的函数**：
>
> $$J_i = J_i(\alpha_1,\ldots,\alpha_n)$$
>
> 反过来，如果 Jacobian $\det(\partial J_i/\partial\alpha_j) \neq 0$（非退化条件），可以反解出：
> $$\alpha_i = \alpha_i(J_1,\ldots,J_n)$$
>
> **Step 3：Hamiltonian 只为 $J$ 的函数**
>
> 特别地，能量 $E = \alpha_1(J_1,\ldots,J_n) = H(J_1,\ldots,J_n)$。Hamiltonian 在新变量 $(J_i,\theta_i)$ 下**只依赖于 $J_i$，不依赖于 $\theta_i$**：
>
> $$\boxed{H = H(J_1,\ldots,J_n)}$$
>
> 这意味着所有 $\theta_i$ 都是循环坐标——这是作用量-角变量方法之所以强大的根本原因。
>
> **Step 4：角变量的演化**
>
> 在作用量-角变量 $(J_i,\theta_i)$ 下的 Hamilton 正则方程：
> $$\dot{J}_i = -\frac{\partial H}{\partial \theta_i} = 0, \qquad \dot{\theta}_i = \frac{\partial H}{\partial J_i} \equiv \nu_i(J)$$
>
> 因为 $H$ 不依赖于 $\theta$，$J_i$ 严格守恒。因为 $H$ 不依赖于 $\theta$ 且 $J_i$ 守恒，$\nu_i(J)$ 是**常数**。对每个自由度积分：
>
> $$\boxed{\theta_i(t) = \nu_i(J)\,t + \theta_i(0)}$$
>
> 角变量以恒定频率均匀增加——运动在 $n$ 维环面上等价于 $n$ 个解耦的均匀圆周运动。
>
> **Step 5：证明 $\theta_i = \partial W/\partial J_i$ 确实给出角变量**
>
> 定义 $\theta_i = \partial W(q,J)/\partial J_i$（注意这里的 $W$ 以 $J$ 而非 $\alpha$ 为变量）。验证它满足 Hamilton 方程：
> $$\dot{\theta}_i = \frac{d}{dt}\frac{\partial W}{\partial J_i} = \sum_j \frac{\partial^2 W}{\partial J_i\partial q_j}\dot{q}_j = \sum_j \frac{\partial p_j}{\partial J_i}\dot{q}_j = \frac{\partial}{\partial J_i}\!\left(\sum_j p_j\dot{q}_j\right) - \sum_j p_j\frac{\partial\dot{q}_j}{\partial J_i}$$
>
> 更简洁：从 Legendre 变换角度，$W$ 是 $F_2(q,J)$ 型生成函数。$(q,p) \to (\theta,J)$ 是 $F_2(q,J) = W(q,J)$ 生成的正则变换。由生成函数理论，$\theta_i = \partial W/\partial J_i$ 且 $K(\theta,J) = H(q,p) = H(J)$。正则方程 $\dot{\theta}_i = \partial K/\partial J_i = \partial H/\partial J_i$ 直接得证。
>
> **物理注释**：作用量-角变量将任意完全可积系统映射为一个在 $n$ 维环面 $\mathbb{T}^n$ 上的匀速直线流——这正是 Liouville-Arnold 定理的动力学实质。频率矢量 $\boldsymbol{\nu}(J)$ 完全决定了运动的定性行为：$\nu_i/\nu_j$ 为有理数则轨道封闭，否则准周期遍历环面。

>[!s]- **(b) Kepler 问题频率比与 Bertrand 定理**
>
> **Step 1：Kepler 问题的作用量变量（回顾）**
>
> 由 8.4(a) 和 10.2 的结果：
> $$J_\phi = L_z, \quad J_\theta = L - |L_z|, \quad J_r = -L + \frac{k\sqrt{2\mu}}{2\sqrt{-E}}$$
>
> 其中 $L = \sqrt{p_\theta^2 + p_\phi^2/\sin^2\theta}$ 为总角动量大小。总作用量：
> $$J_{\text{tot}} = J_r + J_\theta + J_\phi = J_r + L = \frac{k\sqrt{2\mu}}{2\sqrt{-E}}$$
>
> **Step 2：$H(J)$ 的表达式**
>
> 反解 $E$：
> $$H(J) = E = -\frac{\mu k^2}{2\,(J_r + J_\theta + J_\phi)^2} = -\frac{\mu k^2}{2\,J_{\text{tot}}^2}$$
>
> $H$ 只依赖于 $J_{\text{tot}} = J_r + J_\theta + J_\phi$，而不依赖于三者的单独分配——这是 Kepler 问题高度简并的数学根源。
>
> **Step 3：频率的计算**
>
> $$\nu_r = \frac{\partial H}{\partial J_r} = \frac{\mu k^2}{J_{\text{tot}}^3}$$
> $$\nu_\theta = \frac{\partial H}{\partial J_\theta} = \frac{\mu k^2}{J_{\text{tot}}^3}$$
> $$\nu_\phi = \frac{\partial H}{\partial J_\phi} = \frac{\mu k^2}{J_{\text{tot}}^3}$$
>
> $$\boxed{\nu_r = \nu_\theta = \nu_\phi = \frac{\mu k^2}{J_{\text{tot}}^3}}$$
>
> 三个频率**完全相等**！这意味着在任意束缚轨道上：
> $$\frac{\nu_r}{\nu_\phi} = \frac{\nu_r}{\nu_\theta} = 1 \in \mathbb{Q}$$
>
> **Step 4：轨道闭合性的判据**
>
> 在作用量-角变量框架下，运动是多周期性的。经过时间 $\Delta t$，各角变量的增量为 $\Delta\theta_i = \nu_i\Delta t$。物理运动是真实的 $q(t)$（在构型空间中），而构型坐标是角变量的周期函数（周期 $2\pi$）。轨道闭合当且仅当存在 $T$ 使得所有 $\Delta\theta_i$ 均为 $2\pi$ 的整数倍。
>
> 必要且充分条件是：所有频率比 $\nu_i/\nu_j$ 均为**有理数**。对 Kepler 问题，$\nu_r = \nu_\theta = \nu_\phi$ → 比值为 $1$ → 所有束缚轨道闭合（一个径向周期恰好对应一个角向周期）。
>
> **Step 5：Bertrand 定理的验证**
>
> 现在考虑一般幂律势 $V(r) = -\kappa/r^n$（不包含谐振子）。对于任意 $n \neq 1$，径向作用量积分给出：
> $$J_r = -L + f_n(E,L)$$
>
> 其中 $f_n$ 不再是简单的 $1/\sqrt{-E}$ 形式。$J_\theta + J_\phi = L$ 如旧。总作用量 $J_{\text{tot}} = f_n(E,L)$。$H(J)$ 将同时依赖于 $J_r$ 和 $J_\theta+J_\phi$。由此：
> $$\nu_r = \frac{\partial H}{\partial J_r}, \quad \nu_\phi = \frac{\partial H}{\partial J_\phi} = \frac{\partial H}{\partial(J_\theta+J_\phi)}$$
>
> 对一般的 $n$，$\nu_r/\nu_\phi$ 依赖于 $J$（即依赖于能量和角动量），且对大多数 $E,L$ 是无理数 → 轨道不闭合。只有当该比值对所有 $E,L$ 均为有理数时，所有束缚轨道才是闭合的。
>
> Bertrand 严格证明了：在所有球对称有心力势中，**仅有 $V \propto -1/r$（Kepler）和 $V \propto r^2$（谐振子）这两种情况**满足此条件。在作用量-角变量语言中：
> - **Kepler**：$H \propto -1/(J_r+J_\theta+J_\phi)^2$ → $\nu_r = \nu_\theta = \nu_\phi$ → 比值为 $1$
> - **谐振子**：$H \propto 2J_r + J_\theta + J_\phi$（直角坐标系中三个独立的谐振子） → $\nu_r : \nu_\theta : \nu_\phi = 2:1:1$ → 比值为有理数，轨道仍闭合（但闭合方式不同：在二维各向同性谐振子中，轨道是以原点为中心的椭圆，粒子经过两个径向周期完成一圈）
>
> **物理注释**：Kepler 问题中 $\nu_r = \nu_\phi$ 是 $SO(4)$ 隐藏对称性（Runge-Lenz 矢量守恒）的直接后果——它导致能级对 $l$ 的简并（量子力学中 $E_n$ 不依赖于 $l$）。谐振子中 $\nu_r : \nu_\phi = 2:1$ 则反映 $SU(3)$ 隐藏对称性。Bertrand 定理本质上陈述了一个群论事实：只有这两种有心力势拥有比 $SO(3)$ 更大的对称群。

### 10.5 半经典量子化 $\star$

**(a)** 写出 Bohr-Sommerfeld 量子化条件：
$$\oint p_i\,dq_i = (n_i + \gamma_i)h$$
其中 $\gamma_i$ 为 Maslov 指数（与转向点的个数有关，硬壁为 $0$，软转向点为 $1/2$）。对简谐振子，验证 $E_n = (n + 1/2)\hbar\omega$。

**(b)** 对一维方势阱 $V(x) = 0$（$0 < x < L$），$V = \infty$（边界），用 WKB + Bohr-Sommerfeld 量子化条件求出能级，并与严格量子力学结果比较。

**(c)** 对双阱势 $V(x) = \lambda(x^2-a^2)^2$，用 Bohr-Sommerfeld 条件估算低能级的分裂（$\Delta E \propto e^{-S_0/\hbar}$，其中 $S_0$ 为隧道作用量）。讨论 WKB 方法在经典禁止区域的适用性。

**Hamilton-Jacobi 方程**：$\frac{\partial S}{\partial t} + H(q, \partial S/\partial q, t) = 0$
