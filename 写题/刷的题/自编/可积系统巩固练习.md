# 可积系统巩固练习

> 共 3 道题。覆盖 Liouville 可积性判定、Hamilton-Jacobi 分离变量、作用量-角变量、以及可积性的破缺。
> 建议在完成 [[理论力学基础计算习题册]] 第十章（Hamilton-Jacobi 理论）之后练习。
> 标 $\star\star$ 为挑战。
>
> **前置概念**：[[理论力学基础计算习题册]] 10.5 中 Kepler 问题作为 Liouville 完全可积系统的例子——3 个自由度对应 3 个 Poisson-对易的守恒量 $(E, L^2, L_z)$，H-J 方程在球坐标下完全分离。本题集以此为基础展开。

---

## 第一题 Liouville 完全可积性的判定与 H-J 分离

> 本题训练用 Poisson 括号验证守恒量的对易性，以及 Hamilton-Jacobi 方程的可分离性判据。

考虑二维各向同性谐振子：

$$H = \frac{1}{2m}(p_x^2 + p_y^2) + \frac{1}{2}m\omega^2(x^2 + y^2)$$

这是 $n=2$ 自由度的系统，Liouville 完全可积需要找到 **2 个相互 Poisson-对易的独立守恒量**。

**(a)** 写出系统的四个候选守恒量：$H$、角动量 $L_z = x p_y - y p_x$、以及两个"单模能量"

$$E_x = \frac{p_x^2}{2m} + \frac{1}{2}m\omega^2 x^2,\qquad E_y = \frac{p_y^2}{2m} + \frac{1}{2}m\omega^2 y^2$$

计算以下 Poisson 括号：$\{E_x, E_y\}$、$\{E_x, H\}$、$\{E_x, L_z\}$、$\{H, L_z\}$。画出这些守恒量之间的对易关系图。

**(b)** 由 (a) 的结果找出**两组不同的**"最大对易守恒量集合"（每组含 2 个相互 Poisson-对易的独立守恒量）。每组对应一种 H-J 分离变量的坐标系。判断该系统是否为 Liouville 完全可积。

**(c)** 在极坐标 $(r,\phi)$ 下写出定态 Hamilton-Jacobi 方程，并验证它可以分离变量 $W(r,\phi) = W_r(r) + W_\phi(\phi)$。分离常数是什么物理量？对照 (b) 问的结论，说明分离变量成功与 Liouville 可积性之间的本质联系。

>[!success]- *(a) Poisson 括号计算*
>
> 基本 Poisson 括号：$\{x, p_x\} = 1$，$\{y, p_y\} = 1$，其余为零。
>
> **$\{E_x, E_y\}$**：
> $E_x$ 只含 $x,p_x$，$E_y$ 只含 $y,p_y$，故
> $$\{E_x, E_y\} = 0 \quad \text{✓ 对易}$$
>
> **$\{E_x, H\}$**：
> $H = E_x + E_y$，利用双线性：
> $$\{E_x, H\} = \{E_x, E_x\} + \{E_x, E_y\} = 0 \quad \text{✓ 对易}$$
>
> **$\{E_x, L_z\}$**：
> $$\{E_x, L_z\} = \left\{\frac{p_x^2}{2m} + \frac{1}{2}m\omega^2 x^2,\; x p_y - y p_x\right\}$$
> 逐项计算：
> $$\left\{\frac{p_x^2}{2m}, x p_y\right\} = \frac{1}{2m} \cdot 2p_x\{p_x, x\}p_y = -\frac{p_x p_y}{m}$$
> $$\left\{\frac{p_x^2}{2m}, -y p_x\right\} = 0$$
> $$\left\{\frac{1}{2}m\omega^2 x^2, x p_y\right\} = 0$$
> $$\left\{\frac{1}{2}m\omega^2 x^2, -y p_x\right\} = \frac{1}{2}m\omega^2 \cdot 2x\{x, p_x\}(-y) = -m\omega^2 x y$$
> 故：
> $$\{E_x, L_z\} = -\frac{p_x p_y}{m} - m\omega^2 x y \neq 0 \quad \text{✗ 不对易}$$
>
> **$\{H, L_z\}$**：
> $$\{H, L_z\} = \{E_x, L_z\} + \{E_y, L_z\}$$
> 由对称性 $\{E_y, L_z\} = +\frac{p_x p_y}{m} + m\omega^2 xy$，故
> $$\{H, L_z\} = 0 \quad \text{✓ 对易}$$
>
> **对易关系图**：
> ```
>     E_x ──[0]── E_y
>      │          │
>     [0]        [0]
>      │          │
>      H ──[0]── L_z
> ```
> 其中 $[0]$ 表示 Poisson-对易，$\{E_x, L_z\} \neq 0$（图中未连线）。

>[!success]- *(b) 两组最大对易守恒量集合*
>
> **方案一：$\{H, E_x\}$ —— 直角坐标分离**
> - $\{H, E_x\} = 0$，二者函数独立（$E_x \neq f(H)$，因为 $H = E_x + E_y$ 涉及 $y$ 自由度）
> - $n=2$，恰好 2 个对易守恒量 $\implies$ Liouville 完全可积
> - 对应 H-J 分离：$W(x,y) = W_x(x) + W_y(y)$（直角坐标）
>
> **方案二：$\{H, L_z\}$ —— 极坐标分离**
> - $\{H, L_z\} = 0$，二者函数独立
> - $n=2$，2 个对易守恒量 $\implies$ Liouville 完全可积
> - 对应 H-J 分离：$W(r,\phi) = W_r(r) + W_\phi(\phi)$（极坐标）
>
> **关键洞见**：同一物理系统可以有多组不同的最大对易守恒量集合——即多种"可积结构"。每组对应 H-J 方程的一种分离变量坐标系。这一事实在 Liouville 定理中常被忽略，但在理解 [[经典力学的数学方法_Arnold]] 第 10 章中"可积系统在环面上的坐标选择"时非常有用。

>[!success]- *(c) 极坐标下的 H-J 分离*
>
> 极坐标下 $p_r$ 和 $p_\phi$ 的 Hamiltonian：
> $$H = \frac{1}{2m}\left(p_r^2 + \frac{p_\phi^2}{r^2}\right) + \frac{1}{2}m\omega^2 r^2$$
>
> 定态 H-J 方程（令 $p_r = \partial W/\partial r$，$p_\phi = \partial W/\partial \phi$）：
> $$\frac{1}{2m}\left[\left(\frac{\partial W}{\partial r}\right)^2 + \frac{1}{r^2}\left(\frac{\partial W}{\partial \phi}\right)^2\right] + \frac{1}{2}m\omega^2 r^2 = E$$
>
> 试分离 $W(r,\phi) = W_r(r) + W_\phi(\phi)$，代入并移项：
> $$\left(\frac{dW_\phi}{d\phi}\right)^2 = r^2\left[2mE - m^2\omega^2 r^2 - \left(\frac{dW_r}{dr}\right)^2\right]$$
>
> 左边只含 $\phi$，右边只含 $r$ $\implies$ 两边 = 常数，记为 $\ell^2$。于是：
> $$\frac{dW_\phi}{d\phi} = \ell \implies W_\phi = \ell\phi$$
> $$\frac{1}{2m}\left(\frac{dW_r}{dr}\right)^2 + \frac{\ell^2}{2mr^2} + \frac{1}{2}m\omega^2 r^2 = E$$
>
> **分离常数 $\ell$ 就是角动量 $L_z$**。
>
> **本质联系**：H-J 方程可分离 $\iff$ 存在 $n$ 个相互 Poisson-对易的守恒量（分离常数） $\iff$ Liouville 完全可积。当你分离变量，你就是在"提取"系统的对易守恒量。这是 [[理论力学基础计算习题册]] 10.5 中 Kepler 问题能在球坐标下完全分离的根本原因——它恰好有 $(E, L^2, L_z)$ 三个对易的分离常数。

## 第二题 一维非谐振子的作用量-角变量与微扰修正 $\quad \star\star$

> 本题展示：一维自治系统自动可积（$E$ 守恒），微扰理论（[[微扰展开]]）和周期修正（[[非线性振子周期修正]]）之所以有效，正是因为系统保持着可积性。同时训练作用量-角变量的构造与微扰展开。

考虑一维非谐振子：

$$H(p,q) = \frac{p^2}{2m} + \frac{1}{2}m\omega_0^2 q^2 + \frac{\lambda}{4} q^4$$

**(a)** 当 $\lambda = 0$ 时引入作用量-角变量 $(I, \theta)$：

$$q = \sqrt{\frac{2I}{m\omega_0}}\sin\theta,\qquad p = \sqrt{2m\omega_0 I}\cos\theta$$

验证该变换是正则的（$\{q, p\}_{(I,\theta)} = 1$），并证明 $H_0 = \omega_0 I$。解释 $(I,\theta)$ 的物理意义：$I$ 的量纲是[作用量] = [能量] × [时间]，角变量 $\theta$ 均匀旋转 $\dot\theta = \omega_0$。

**(b)** $\lambda \neq 0$ 时系统仍是一维，能量 $H(p,q)$ 守恒确保系统依然可积，作用量-角变量仍存在。但在 $\lambda \ll 1$ 下 $H(I)$ 的形式发生变化。在零阶变换下计算微扰项在 $\theta$ 上的周期平均：

$$\langle q^4 \rangle_\theta = \frac{1}{2\pi}\int_0^{2\pi} q^4(\theta)\,d\theta$$

由此导出微扰修正后的 Hamiltonian：

$$H(I) = \omega_0 I + \frac{3\lambda}{8m^2\omega_0^2} I^2 + \mathcal{O}(\lambda^2)$$

并计算修正后的频率：

$$\omega(I) = \frac{\partial H}{\partial I} = \omega_0 + \frac{3\lambda}{4m^2\omega_0^2}I + \mathcal{O}(\lambda^2)$$

频率依赖于 $I$（即依赖于振幅）——这是非线性系统的标志。这与 [[非线性振子中的时间重整化]] 中 Duffing 振子的频率修正本质相同（`ω → ω(I)` 而非 `ω = ω₀`）。

**(c)** （思考题）为什么一维自治系统自动可积？在相空间 $(q,p)$ 中，轨道是闭曲线。$\lambda=0$ 时轨道是椭圆；$\lambda>0$ 时轨道虽然不再是椭圆，但仍然是闭曲线（$\mathbb{T}^1$ 环面）。这一事实意味着微扰展开在**任意能量**下都有效（不存在共振破坏）——这与第三题的多维情况形成鲜明对比。

>[!success]- *(a) 正则变换验证*
>
> $$\{q, p\}_{(I,\theta)} = \frac{\partial q}{\partial \theta}\frac{\partial p}{\partial I} - \frac{\partial q}{\partial I}\frac{\partial p}{\partial \theta}$$
>
> $$\frac{\partial q}{\partial \theta} = \sqrt{\frac{2I}{m\omega_0}}\cos\theta,\quad \frac{\partial q}{\partial I} = \frac{1}{\sqrt{2m\omega_0 I}}\sin\theta$$
> $$\frac{\partial p}{\partial \theta} = -\sqrt{2m\omega_0 I}\sin\theta,\quad \frac{\partial p}{\partial I} = \sqrt{\frac{m\omega_0}{2I}}\cos\theta$$
>
> 代入：
> $$\{q, p\}_{(I,\theta)} = \sqrt{\frac{2I}{m\omega_0}}\cos\theta \cdot \sqrt{\frac{m\omega_0}{2I}}\cos\theta - \frac{1}{\sqrt{2m\omega_0 I}}\sin\theta \cdot (-\sqrt{2m\omega_0 I}\sin\theta) = \cos^2\theta + \sin^2\theta = 1$$
>
> **零阶 Hamiltonian**：
> $$H_0 = \frac{1}{2m}(2m\omega_0 I\cos^2\theta) + \frac{1}{2}m\omega_0^2\left(\frac{2I}{m\omega_0}\sin^2\theta\right) = \omega_0 I(\cos^2\theta + \sin^2\theta) = \omega_0 I$$
>
> **物理解释**：$I = E/\omega_0$ 是**作用量**（相空间面积 $/2\pi$），$\theta$ 是**角变量**（轨道的参数化角度）。运动方程：
> $$\dot\theta = \frac{\partial H_0}{\partial I} = \omega_0,\qquad \dot I = -\frac{\partial H_0}{\partial \theta} = 0$$
> 即 $\theta(t) = \omega_0 t + \theta_0$（匀速旋转），$I$ = 常数。

>[!success]- *(b) 微扰展开与频率修正*
>
> 将零阶变换代入微扰项 $\frac{\lambda}{4}q^4$：
> $$q^4 = \left(\frac{2I}{m\omega_0}\right)^2 \sin^4\theta = \frac{4I^2}{m^2\omega_0^2}\sin^4\theta$$
>
> $$H_1 = \frac{\lambda}{4}q^4 = \frac{\lambda I^2}{m^2\omega_0^2}\sin^4\theta$$
>
> 对 $\theta$ 做周期平均：
> $$\langle \sin^4\theta \rangle = \frac{1}{2\pi}\int_0^{2\pi}\sin^4\theta\,d\theta = \frac{3}{8}$$
>
> 故：
> $$\langle H_1 \rangle = \frac{\lambda I^2}{m^2\omega_0^2} \cdot \frac{3}{8} = \frac{3\lambda}{8m^2\omega_0^2}I^2$$
>
> 有效 Hamiltonian（平均后 $H$ 不再显含 $\theta$）：
> $$H(I) = \omega_0 I + \frac{3\lambda}{8m^2\omega_0^2}I^2 + \mathcal{O}(\lambda^2)$$
>
> 修正频率：
> $$\omega(I) = \frac{\partial H}{\partial I} = \omega_0 + \frac{3\lambda}{4m^2\omega_0^2}I + \mathcal{O}(\lambda^2)$$
>
> **$\omega$ 依赖于 $I$ 的物理含义**：振幅 $A \propto \sqrt{I}$，故 $\omega$ 依赖于振幅。这就是 [[非线性振子周期修正]] 中计算的核心量——非线性导致不同能量的等时性破缺（isochronicity breaking）。
>
> 这也直接关联到 [[非线性振子中的时间重整化]]：在朴素的"裸频率 $\omega_0$"下做微扰会产生久期项，正确的做法是使用 dressed 频率 $\omega(I)$，这本质上是**作用量-角变量框架下的自然结果**。

>[!success]- *(c) 一维系统自动可积*
>
> 一维自治 Hamiltonian 系统 $H(p,q)$ 必有守恒量 $H$ 自身。$n=1$，1 个守恒量 = $n$ 个守恒量 $\implies$ Liouville 完全可积。
>
> 相空间 $(q,p)$ 是二维的，能量曲面 $H(p,q) = E$ 是一维闭曲线（只要运动有界）。这些闭曲线就是不变环面 $\mathbb{T}^1$。
>
> - $\lambda=0$：椭圆（谐振子）
> - $\lambda>0$：非椭圆闭曲线（非谐振子）
>
> **对比多维**：二维以上系统 ($n \geq 2$) 不再自动可积——$H$ 只提供 1 个守恒量，远不够 $n$ 个。此时微扰可能引发**共振**破坏不变环面，这正是 KAM 定理讨论的核心问题（见第三题）。

## 第三题 可积性的破缺：共振与通向混沌 $\quad \star\star$

> 本题从可积出发讨论微扰如何破坏可积性，建立与 [[微扰展开]] 中"零阶可积 + 微扰"框架的联系，并引出 KAM 定理的基本图景。

考虑两个弱耦合的谐振子：

$$H = \underbrace{\frac{1}{2}(p_1^2 + p_2^2) + \frac{1}{2}(\omega_1^2 q_1^2 + \omega_2^2 q_2^2)}_{H_0} + \underbrace{\varepsilon q_1^2 q_2}_{H_1}$$

**(a)** 当 $\varepsilon = 0$ 时（$H = H_0$），引入作用量-角变量：

$$q_i = \sqrt{\frac{2I_i}{\omega_i}}\sin\theta_i,\qquad p_i = \sqrt{2\omega_i I_i}\cos\theta_i \quad (i=1,2)$$

写出 $H_0(I_1, I_2) = \omega_1 I_1 + \omega_2 I_2$，验证系统是 Liouville 完全可积的（找出 2 个相互 Poisson-对易的独立守恒量）。

**(b)** $\varepsilon \neq 0$ 时系统不再是显然可积的。将 (a) 中的变换代入 $H_1$：

$$H_1(I_1,I_2,\theta_1,\theta_2) = \varepsilon \cdot \frac{4I_1 I_2^{1/2}}{\omega_1 \sqrt{\omega_2}} \sin^2\theta_1 \sin\theta_2$$

利用 $\sin^2\theta_1 = \frac{1-\cos 2\theta_1}{2}$，将 $H_1$ 展开为角变量的 Fourier 级数：

$$H_1 = \varepsilon \sum_{m,n} h_{mn}(I_1,I_2) \, e^{i(m\theta_1 + n\theta_2)}$$

找出所有的整数向量 $(m,n)$（即**共振阶**）。当 $\omega_1/\omega_2$ 为有理数时，某些 Fourier 分量变得"缓慢"（频率 $m\omega_1 + n\omega_2 \approx 0$），导致微扰展开的**小分母问题**。

**(c)** （讨论题）KAM 定理的核心结论：

> 对于充分小的 $\varepsilon$，满足 Diophantine 条件 $|m\omega_1 + n\omega_2| > \frac{K}{|m|+|n|}$ 的不变环面在微扰下**形变但存活**；而有理频率比（共振）附近的环面被**破坏**，产生混沌层。

对照你在 [[理论力学基础计算习题册]] 中对 Kepler 问题（完全可积）和微扰 Kepler 问题（如添加 $1/r^3$ 项或外场）的理解：为什么 Kepler 问题在添加小外电场（Stark 效应）后变成不可积？思考 H-J 方程分离变量的失败与 KAM 定理的关联。

>[!success]- *(a) 零阶可积性*
>
> 引入作用量-角变量后：
> $$H_0 = \frac{1}{2}\left[(2\omega_1 I_1 \cos^2\theta_1 + 2\omega_2 I_2 \cos^2\theta_2) + \left(\omega_1^2 \cdot \frac{2I_1}{\omega_1}\sin^2\theta_1 + \omega_2^2 \cdot \frac{2I_2}{\omega_2}\sin^2\theta_2\right)\right]$$
> $$= \omega_1 I_1(\cos^2\theta_1 + \sin^2\theta_1) + \omega_2 I_2(\cos^2\theta_2 + \sin^2\theta_2) = \omega_1 I_1 + \omega_2 I_2$$
>
> **守恒量集合 $\{I_1, I_2\}$**：
> $$\dot I_1 = -\frac{\partial H_0}{\partial \theta_1} = 0,\quad \dot I_2 = -\frac{\partial H_0}{\partial \theta_2} = 0$$
>
> Poisson-对易性：
> $$\begin{aligned}
> \{I_1, I_2\}_{(q,p)} &= \{I_1(q_1,p_1), I_2(q_2,p_2)\} = 0 \quad \text{(不同自由度)}\\
> \{H_0, I_1\} &= 0,\quad \{H_0, I_2\} = 0
> \end{aligned}$$
>
> 取 $\{I_1, I_2\}$ 或 $\{H_0, I_1\}$ 都是 2 个对易守恒量，$n=2 \implies$ Liouville 完全可积。
>
> 相空间是 $\mathbb{R}^4$，能量面 $H_0 = E$ 是三维的。每条轨道躺在二维不变环面 $\mathbb{T}^2$ 上，以两个频率 $(\omega_1, \omega_2)$ 准周期运动。

>[!success]- *(b) 微扰的 Fourier 展开与共振条件*
>
> 代入变换并展开：
> $$\sin^2\theta_1 \sin\theta_2 = \frac{1}{2}(1 - \cos 2\theta_1)\sin\theta_2 = \frac{1}{2}\sin\theta_2 - \frac{1}{4}\sin(2\theta_1 + \theta_2) - \frac{1}{4}\sin(2\theta_1 - \theta_2)$$
>
> 写成指数形式：
> $$H_1 = \varepsilon \cdot \frac{2I_1 I_2^{1/2}}{\omega_1\sqrt{\omega_2}} \Big[e^{i\theta_2} - e^{-i\theta_2} - \frac{1}{2}e^{i(2\theta_1+\theta_2)} + \frac{1}{2}e^{-i(2\theta_1+\theta_2)} - \frac{1}{2}e^{i(2\theta_1-\theta_2)} + \frac{1}{2}e^{-i(2\theta_1-\theta_2)}\Big]$$
>
> 出现的指数为 $e^{i(m\theta_1 + n\theta_2)}$，其中：
> $$(m,n) = (0,\pm 1),\; (\pm 2,\pm 1),\; (\pm 2,\mp 1)$$
>
> **共振条件**：当 $m\omega_1 + n\omega_2 = 0$ 时，该 Fourier 分量在时间演化中不振荡（永年项），导致微扰展开发散。对于这些 $(m,n)$：
> $$(0,\pm 1): \omega_2 = 0 \text{（平凡）}$$
> $$(\pm 2, \pm 1): 2\omega_1 + \omega_2 = 0 \text{（频率需异号）}$$
> $$(\pm 2, \mp 1): 2\omega_1 - \omega_2 = 0 \implies \boxed{\omega_1 : \omega_2 = 1 : 2}$$
>
> 当 $\omega_1/\omega_2 = 1/2$（或 $2/1$）时，发生**参数共振**（parametric resonance）——$H_1$ 的 $(\pm 2, \mp 1)$ 分量与 $H_0$ 的环面流共振，小分母 $\to 0$。这与 [[非线性振子周期修正]] 中讨论的共振机制本质相同。

>[!success]- *(c) 从可积通向混沌的物理图景*
>
> **KAM 定理的核心图景**（三分相空间）：
> 1. **充分无理**的频率比 $\to$ 环面形变但存活（"KAM 环面"），运动仍准周期
> 2. **有理**频率比（共振）$\to$ 环面被破坏，形成 Poincaré-Birkhoff 岛链
> 3. 不同共振之间的**重叠**（Chirikov 判据）$\to$ 大范围混沌
>
> **Kepler → Stark 的例子**：Kepler 问题（$1/r$ 势）在球坐标下 H-J 可分离因为有 3 个对易守恒量 $(E, L^2, L_z)$。加上外电场 $-\varepsilon z$ 后，$L^2$ 不再守恒（电场方向破坏了球对称），守恒量只剩 $E$ 和 $L_z$——不足 3 个。H-J 方程仅在抛物坐标下可分离（还差一个具体的守恒量：广义 Runge-Lenz 矢量分量）。系统从完全可积变成**部分可积**——这是通向混沌的中间站。
>
> 更深层的观点：[[微扰展开]] 的成功依赖于零阶系统可积 + 远离共振。当共振出现时（如 $\omega_1/\omega_2 \in \mathbb{Q}$），平凡的微扰展开失效，需要 KAM 型或 Birkhoff 正规型的方法处理。
>
> 这也解释了为什么 [[经典力学的数学方法_Arnold]] 将可积系统作为整个哈密顿力学的理论基石——理解可积系统是理解混沌的前提。
