# 1. 非微扰QFT

- 希尔伯特空间：闵可夫斯基时空被分层为等时曲面，并且对每个时间切片，我们关联一个量子态的希尔伯特空间


- 局域算符：存在许多（事实上是无穷多个）局域算符作用在这个希尔伯特空间上。例如，取 $\phi(x)$ 为在时间 $t = x^0$ 处作用在希尔伯特空间上的一个算符。我们称这个算符为局域的，是因为我们要求它与插入在同一时间切片上不同点 $\\vec{x}' \\neq \\vec{x}$ 处的任何其他局域算符对易$$[\phi(x),\phi(x')] = 0 ,\quad x^{0} = x'^{0} \text{ and  } \vec{x}\neq \vec{x}' $$


- 对称性：理论中的局域算符之一就是能量-动量张量，我们可以从中定义**守恒荷**，包括 $P_\mu$ 和 $M_{\mu\nu}$


在一般的 QFT 中，能量-动量张量不一定无迹，因此无法考虑荷 $D$ 和 $K_\mu$。

$P_\mu$ 和 $M_{\mu\nu}$ 在时间上是守恒的，因此它们是在每个时间 $t$ 的所有希尔伯特空间上都有效的全局算符。然而，每当在某个点 $x$ 插入一个算符时 (相当于引入一个局部扰动，研究态 $\ket{\psi}=\phi(x)\ket{0}$ )，它们的值就会改变。我们要求这种变化编码在对易子中$$[P^{\mu},\phi(x)]=i\partial^{\mu}\phi(x) $$该方程的解是$$\phi(x) = e^{ -ix\cdot P }\phi(0)e^{ ix\cdot P } $$
	当用全局算符 $P^{\mu}$ 去敲击(对易)局域算符 $\phi(x)$ 时其结果 $i\partial^{\mu}\phi(x)$ 只和该点处相关


我们说 $P_\mu$ 是平移的生成元，它作为算符上的幺正变换作用（注意 $P_\mu$ 是厄米的）。洛伦兹变换同样通过荷 $M_{\mu\nu}$ 生成为幺正变换。我们可以选择将插入时空原点的局域算符按洛伦兹群的不可约表示分解，并将它们记为 $\phi_a(0)$，其中 $a$ 代表一组洛伦兹指标，使得$$[M^{\mu \nu},\phi^{a}(0)] = i(S^{\mu \nu})^{a}{}_{b}\phi^{b}(0) $$其中 $(S_{\mu\nu})_{ab}$ 是一个满足洛伦兹代数的矩阵。对于标量算符，$S_{\mu\nu}$ 为零；对于带有一个洛伦兹指标的矢量算符，它由$$(S^{\mu \nu})_{ab} = \delta^{\mu}_{a}\delta^{\nu}_{b} - \delta^{\mu}_{b}\delta^{\nu}_{a} $$给出等等。当与式 (3.3) 结合，并要求 $P_\mu$ 和 $M_{\mu\nu}$ 满足庞加莱代数 (2.34) 时，这意味着$$[M^{\mu \nu},\phi^{a}(x)] = -i(x^{\mu}\partial^{\nu}-x^{\nu}\partial^{\mu})\phi^{a}(x) + i(S^{\mu \nu})^{a}{}_{b}\phi^{b}(x) $$注意，$P_\mu$ 和 $M_{\mu\nu}$ 不是局域算符，但它们与任何局域算符的对易子仍然是局域的（同样的情况之后也会适用于生成元 $D$ 和 $K_\mu$）。


- 真空态：希尔伯特空间包含一个真空态 $|0\rangle$，我们假定它在庞加莱变换（以及之后的共形变换）下保持不变$$P^{\mu}\ket{0} = M^{\mu \nu}\ket{0} = 0 $$
 
理论中的其他态是通过将局域算符的乘积作用在真空上得到的（更精确的陈述见下文）。原则上每个时间切片对应一个希尔伯特空间，但由于时间平移是由 $P_0$ 生成的对称性，演化算符 $U(t) = e^{i t P_0}$ 是幺正的，所有希尔伯特空间都是等价的。我们还要求真空是希尔伯特空间中能量最低的态。这意味着，如果我们可以构造一个能量的本征态，$$P^{0}\ket{\Psi} = E\ket{\Psi}  $$那么它的本征值必须满足 $E \geq 0$。


这四点基本上给出了量子场论最一般的非微扰定义。它们几乎等价于所谓的 Wightman 公理（但这里的表述没有太多数学上的严谨性）。一个显著的区别是，Wightman 公理不依赖于能量-动量张量的存在，而是直接假定庞加莱变换在希尔伯特空间上实现为幺正变换。

局域性条件 (3.1) 通常以洛伦兹不变的方式表述
$$[\phi(x),\phi(y)]=0 ,\quad\text{if }(x-y)^{2}>0 $$
指出只要局域算符是类空间隔的，它们就对易，这被称为微观因果性公理。类似地，当可以处理能量和动量的本征态时，
$$P^{\mu}\ket{\Psi} = p^{\mu}\ket{\Psi}  $$
那么，关于能量正定性的洛伦兹不变条件就变成了
$$p^{0}\geq|\mathbf{p}| \Leftrightarrow p^{2} \leq 0\text{ and } p^{0}\geq 0 $$
即动量 $p^\mu$ 包含在前向光锥内。这样的 $P_\mu$ 本征态可以通过局域算符的傅里叶变换来构造
$$\tilde{\phi}(p) = \int d^{d}x\ \phi(x)e^{ ip\cdot x } $$
并作用在真空上。这意味着
$$\tilde{\phi}(p)\ket{0} = 0 ,\quad \text{if } p^{0} < |\mathbf{p}| $$
以及它对多个局域算符乘积的推广。
$$\tilde{\phi}_{1}(p_{1})\dots \tilde{\phi}_{n}(p_{n})\ket{0} =0,\quad \text{if } p_{1}^{0} + \dots + p_{n}^{0} < |\mathbf{p}_{1}+\dots \mathbf{p}_{n}| $$
这有时被称为谱条件。


# 2. Wightman 函数

从这些公理出发，接下来我们可以计算局域算符乘积的真空期望值。
$$\braket{ 0 |\phi_{1}(x_{1})\dots \phi_{n}(x_{n})| 0 }  $$
这可以看作真空态 $\langle 0|$ 与通过一系列局域算符作用在真空上所产生的态之间的重叠。需要注意的是，这些算符不一定按时间排序：时间演化算符是幺正的，因此它可以双向演化。因此，这个对象不同于从路径积分中得到的时间序关联函数。

这类关联函数称为 Wightman 函数。它们是非微扰量子场论中的基本可观测量。事实上，甚至可以通过 Wightman 函数来完全定义一个量子场论：Wightman 重构定理指出，一个量子场论的希尔伯特空间可以由其所有 Wightman 函数构造出来。因此，一个方便的视角是暂时忽略希尔伯特空间，而将注意力集中在关联函数上。

这些关联函数的对称性编码在“Ward 恒等式”中：给定一个湮灭真空的守恒荷 $G$，即 $G |0\rangle = 0$（可以是 $P_\mu$ 或 $M_{\mu\nu}$），则必须满足以下方程：
$$\begin{align}
 &\quad \braket{ 0 |[G,\phi_{1}(x_{1})]\phi_{2}(x_{2})\dots \phi_{n}(x_{n})| 0 }  \\
  & + \braket{ 0 | \phi_{1}(x_{1})[G,\phi_{2}(x_{2})]\dots \phi_{n}(x_{n})| 0 } \\
   & +\dots \\
    & + \braket{ 0 |\phi_{1}(x_{1})\phi_{2}(x_{2})\dots[G,\phi_{n}(x_{n})]| 0 } = 0  
\end{align} $$
这个方程在希尔伯特空间图像中是显而易见的，但它作为 Wightman 函数的微分方程同样有效，因为每个对易子都与局域算符相关。让我们看一些例子。

最简单的 Wightman 函数涉及单个标量算符，
$$\braket{ 0 |\phi(x)| 0 }  $$
考虑道平移不变性，由 Ward 恒等式
$$\braket{ 0 |[P^{\mu},\phi(x)]| 0 } = 0 \implies \frac{\partial }{\partial x^{\mu}}\braket{ 0 |\phi(x)| 0 } = 0  $$
换句话说，该算符的真空期望值在整个时空中是一个常数。洛伦兹对称性并没有给出关于该常数的更多信息，但它禁止所有在洛伦兹群下非平凡变换的算符具有非零的真空期望值。

接下来我们考虑相同标量算符的 Wightman 两点函数，
$$\braket{ 0 |\phi(x)\phi(y)| 0 }  $$
平移不变性告诉我们
$$\left( \frac{\partial }{\partial x^{\mu}} + \frac{\partial }{\partial y^{\mu}} \right)\braket{ 0 |\phi(x)\phi(y)| 0 } = 0  $$
如果我们把关联函数看作是 $x+y$ 和 $x-y$ 的函数，那么这些 Ward 恒等式表明它不依赖于前者，即
$$\braket{ 0 |\phi(x)\phi(y)| 0 } = W(x-y) $$

一般而言，平移对称性的结果在动量空间中更容易看出，这可以通过对局域算符进行傅里叶变换来实现。根据方程 (3.12)，我们可以确定
$$[P^{\mu} ,\tilde{\phi}(p)] = p^{\mu}\tilde{\phi}(p) $$
所以
$$(p^{\mu}+q^{\mu})\braket{ 0 |\tilde{\phi}(p)\tilde{\phi}(q)| 0 } = 0 $$
由此
$$\braket{ 0 |\tilde{\phi}(-p)\tilde{\phi}(q)| 0 } = (2\pi)^{d}\delta^{(d)}(p+q)\widetilde{W}(q) $$
其中是对 $W(x-y)$ 进行了一个傅里叶变换即
$$\widetilde{W}(q) = \int d^{d}x\ e^{ -iq\cdot x }W(x) $$


考虑到洛伦兹对称性，还可以确定 Wightman 函数 $W(x)$ 只能依赖于洛伦兹不变距离 $x^2$，但有一个微妙之处：根据 $x$ 是类空还是类时（未来指向或过去指向），该函数会有所不同，因为洛伦兹变换分别作用于这些区域。在动量空间中，同样的论证表明 $\widetilde{W}(q)$ 必须是 $q^2$ 的函数。在这种情况下，只有正能量态存在的条件要求 $\widetilde{W}(q)$ 在 $q^0 \geq |\mathbf{q}|$ 时非零，因此我们可以明确地写出：
$$\widetilde{W}(q) = (2\pi)\theta(q^{0}-|\mathbf{q}|)\rho(-q^{2})$$

Wightman 两点函数 (3.24) 与 delta 函数成正比这一事实引发了一个重要的关注：尽管名称如此，Wightman 函数并非函数，而是分布（这也是 Wightman 公理的一部分：它们实际上是缓增分布）。另请注意，同一个函数计算的是两个态之间的重叠：
$$\tilde{\phi}(q)\ket{0} \text{ and } \tilde{\phi}(-p)\ket{0}   $$
（$\tilde{\phi}^{\dagger}(p)=\tilde{\phi}(-p)$）。因此，极限 $p \to -q$ 对应于这两个态中任意一个的范数。但这个极限显然是不连续的，或者说该态的范数是无穷大。这一问题的解决方法是：对象 $\phi(x)$ 及其傅里叶变换 $\tilde{\phi}(p)$ 并非算符，而是**算符值分布**。换句话说，$\phi(x)|0\rangle$ 和 $\tilde{\phi}(p)|0\rangle$ 并不是理论中的态，因为它们实际上具有无穷大的范数。形式上说，这些算符值分布只有与测试函数积分时才有意义，从而定义出
$$\phi[f] = \int d^{d}x\ f(x)\phi(x) ,\quad \tilde{\phi}[\tilde{f}] = \int d^{d}p\ \tilde{f}(p)\tilde{\phi}(p) $$
其中 $f$ 和 $\tilde{f}$ 是 Schwartz 类的测试函数（在无穷远处衰减速度快于任意幂次的光滑函数）。当作用在真空上时，这些涂抹后的算符给出定义良好的态，具有有限的范数。例如，我们有
$$\|\tilde{\phi}[\tilde{f}]\ket{0}  \|^{2} = \int d^{d}pd^{d}q\ \tilde{f}^{*}(p)\tilde{f}(q)\braket{ 0 |\tilde{\phi}(-p)\tilde{\phi}(q)| 0 } = (2\pi)^{d+1} \int_{q^{0}>|\mathbf{q}|} d^{d}q\ |\tilde{f}(q)|^{2} \rho(-q^{2}) $$
在接下来的讲座中，测试函数将不再出现。对于物理学家来说，它们大多只是我们宁愿避开的麻烦。然而，了解存在一种数学上严谨的处理 Wightman 函数的方法是很重要的。首先，这为为什么在位置空间和动量空间表示之间进行傅里叶变换总是可行的提供了恰当的理由，因为缓增分布总是允许傅里叶变换。但请记住，这仅对 Wightman 函数成立，而对时间序关联函数则不成立。


# 3. 谱表示

范数 (3.30) 也揭示了重要信息：对于任意测试函数 $f$，只有当函数 $\rho$ 为正时，该范数才能为正
$$\rho(\mu^{2})>0 ,\quad \forall \mu^{2}>0 $$
$\rho(\mu^2)$ 实际上就是标准量子场论教科书中遇到的谱密度，在那里我们经常看到它的形式为
$$\braket{ 0 |\phi(x)\phi(y)| 0 } = 2\pi\int \frac{d^{d}k}{(2\pi)^{d}} \int_{0}^{\infty} d\mu^{2}\ e^{ ik\cdot(x-y) }\theta(k^{0})\delta(k^{2}+\mu^{2})\rho(\mu^{2}) $$
谱密度是非微扰量子场论中的一个基本工具。例如，它可以用于构造时间序关联函数
$$\braket{ \phi(x)\phi(y) }_{T} = \theta(x^{0}-y^{0})\braket{ 0 |\phi(x)\phi(y)| 0 } + \theta(y^{0}-x^{0})\braket{ 0 |\phi(y)\phi(x)| 0 }   $$
与 Wightman 函数不同，这不是一个缓增分布，因为 $\\theta$ 函数在原点处不可微。尽管如此，时间序乘积仍允许一个简单的表示：
$$\braket{ \phi(x)\phi(y) }_{T} = \int \frac{d^{d}k}{(2\pi)^{d}} \int_{0}^{\infty}d\mu^{2}\ e^{ ik\cdot(x-y) } \frac{i}{-k^{2}-m^{2}+i\varepsilon} \rho(\mu^{2}) $$
其中隐含了极限 $\varepsilon \to 0^+$。这就是时间序两点函数的 Källén-Lehmann 表示

两点函数的谱表示在非相互作用理论中给出了熟悉的结果。例如，一个有质量标量场的谱密度为
$$\rho(\mu^{2}) = \delta(\mu^{2}-m^{2}) $$
由此我们恢复出已知的有质量传播子
$$\braket{ \phi(x)\phi(y) }_{T} = \int \frac{d^{d}k}{(2\pi)^{d}} e^{ ik\cdot(x-y) } \frac{i}{-k^{2}-m^{2}+i\varepsilon}  $$
在相互作用理论中，谱密度将获得对应于超过某一阈值的粒子产生过程的贡献（见图 3.1）。到目前为止的讨论适用于没有共形对称性的一般量子场论。现在让我们考察尺度和特殊共形不变性的作用，首先从尺度不变性开始。
