# 流程

## 一. 宏观控制参数（Control Parameters）

**核心思想**：系综是用来描述大量可观测系统的统计平均状态，**不同系综由不同的宏观约束条件决定**。系统的宏观条件决定了系综类型和微观加权方式。

|            系综类型             |              控制宏观量               |      系统允许波动的量       |                                典型生成函数                                 |
| :-------------------------: | :------------------------------: | :-----------------: | :-------------------------------------------------------------------: |
|  微正则系综<br>(Microcanonical)  |     能量 $E$、体积 $V$、粒子数 $N$ 固定     |       能量严格固定        |                        微观态数<br>$\Omega(E,N,V)$                        |
|    正则系综 <br>(Canonical)     | 温度 $T$ (由热库控制)、体积 $V$、粒子数 $N$ 固定 |     能量 $E$ 可涨落      |            配分函数<br>$Z_N(\beta,V) = \sum_r e^{-\beta E_r}$​            |
| 巨正则系综 <br>(Grand Canonical) |    温度 $T$、化学势 $\mu$、体积 $V$ 固定    | 能量 $E$ 与粒子数 $N$ 可涨落 | 巨正则配分函数<br>$\Xi(\beta,\mu,T)=\sum_{N}Z_{N}(\beta,V)e^{ \beta \mu N }$ |

控制什么量 → 允许什么量波动 → 选择对应系综。系综的生成函数总是**对系统所有微观状态求和（或积分）**，并引入对应的权重因子（指数因子）来反映控制参数。

## 二. 系综选择（Ensemble）

根据控制参数选择合适的统计集合：
```flowchart
flowchart TD
    A[开始: 分析系统约束] --> B{粒子数 N 是否固定?};
    B -- 是 --> C{能量 E 是否固定?};
    B -- 否 --> D[选择巨正则系综<br>T, V, μ 固定];
    C -- 是 --> E[选择微正则系综<br>E, V, N 固定];
    C -- 否 --> F[选择正则系综<br>T, V, N 固定];
```



## 三. 微观权重因子（Weight Factors）

每个微观状态 $r$ 根据宏观条件被赋予一个概率权重：

$$\omega_{r} = \begin{cases}
1 & 微正则系综 \\
e^{ -\beta E_{r} }  & 正则系综 \\
e^{ -\beta(E_{r}-\mu N) } & 巨正则系综 
\end{cases} $$

权重因子反映了宏观控制参数对微观态的重要性，直接影响生成函数。

## 四. 生成函数（Partition / Generating Function）

### 离散

将所有微观权重加总得到生成函数：

微正则
$$\Omega = \sum_{r}\omega_{r} $$
正则
$$Z = \sum_{r} \omega_{r} = \sum_{r} e^{ -\beta E_{r} } $$
巨正则
$$\Xi = \sum_{r} \omega_{r} = \sum_{r} e^{ -\beta E_{r} } e^{ \beta \mu N } $$
生成函数是**宏观量与微观加权的桥梁**

### 连续

微正则
$$\Omega(N,V,E) = \frac{1}{N!h^{f}} \int_{E-\frac{\Delta}{2}\leq H\leq E+\frac{\Delta}{2}} d\omega = \frac{1}{N!h^{f}} \int_{E-\frac{\Delta}{2}\leq H\leq E+\frac{\Delta}{2}} d^{f}qd^{f}p $$
- 准确的说，累积态数$$\Gamma(E) = \frac{1}{N!h^{f}} \int_{H\leq E} d\Gamma , \quad d\Gamma = d^{f}qd^{f}p $$态密度$$g(E) = \frac{\partial \Gamma}{\partial E} $$
  
正则
$$Z(N,V,\beta) = \int_{0}^{\infty} g(N,V,E) e^{ -\beta E } dE $$
巨正则
$$\Xi(\mu,V,\beta) = \sum_{N=0}^{\infty} Z(N,V,\beta) e^{ \beta \mu N }  $$


## 五. 宏观热力学量（Thermodynamic Quantities）

每个系综的生成函数直接关联于一个**特征热力学势**（Fundamental Thermodynamic Potential）。该势能对其自然变量的微分，给出了所有其他热力学量。

|   系综    |          生成函数          |      关联的热力学势      |         自然变量          |            热力学势的微分关系             |
| :-----: | :--------------------: | :---------------: | :-------------------: | :------------------------------: |
| **微正则** | 微观态数 $\Omega(E, V, N)$ |     **熵** $S$     |     $S(E, V, N)$      |    $dE = TdS - pdV + \mu dN$     |
| **正则**  |  正则配分函数 $Z(T, V, N)$   |   **兹自由能** $F$    |     $F(T, V, N)$      |    $dF = -SdT - pdV + \mu dN$    |
| **巨正则** | 巨配分函数 $\Xi(T, V, \mu)$ | **巨势** $\Omega_G$ | $\Omega_G(T, V, \mu)$ | $d\Omega_G = -SdT - pdV - Nd\mu$ |

微正则

$$S(E, V, N) = k \ln \Omega(E, V, N)$$
$$\frac{1}{T} = \frac{\partial S}{\partial E},\quad \frac{p}{T} = \frac{\partial S}{\partial V},\quad \frac{\mu}{T} = -\frac{\partial S}{\partial N}$$

正则

$$F(T, V, N) = -k_B T \ln Z(T, V, N)$$
$$S = -\frac{\partial F}{\partial T} ,\quad p = -\frac{\partial F}{\partial V},\quad \mu = \frac{\partial F}{\partial N} $$

巨正则

$$\Omega_G(T, V, \mu) = -k_B T \ln \Xi(T, V, \mu) $$
$$S = -\frac{\partial \Omega_G}{\partial T},\quad p = -\frac{\partial \Omega_G}{\partial V} = -\frac{\Omega_G}{V},\quad N = -\frac{\partial \Omega_G}{\partial \mu} $$

- 对于简单流体，巨势 $\Omega_G = -pV$。

**注**：能量 $E$ (或内能 $U$) 在正则和巨正则系综中通过平均获得：
- 正则：$U = \langle E \rangle = -\frac{\partial}{\partial \beta} \ln Z$
- 巨正则：$U = \langle E \rangle = -\frac{\partial}{\partial \beta} \ln \Xi \bigg|_{\beta \mu = const.}$, $N = \langle N \rangle = \frac{1}{\beta} \frac{\partial}{\partial \mu} \ln \Xi$

>Statistical mechanics is a theory of generating functions:  
>microcanonical defines the density of states, canonical performs a Laplace transform, and grand canonical adds an exponential generating transform over particle number. Thermodynamics emerges through Legendre duality.
