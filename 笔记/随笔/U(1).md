# 李群既是群又是流形

$U(1)$ 顾名思义，定义是

$$U(1) = \{ U\in \mathbb{C} \mid  \|U\|^{2} =1 \} $$

群运算是复数乘法

由其定义马上能知道它作为流形同胚于环 $S^{1}$：
$$\mathrm{Re}^{2}U + \mathrm{Im}^{2}U = 1 $$


# 李代数

$U(1)$ 的李代数 $\mathfrak{u}(1)$ 是一维实向量空间，由虚数单位 $i$ 生成

$$X = i\alpha \in \mathfrak{u}(1) ,\quad \alpha\in \mathbb{R} $$

李代数与李群间有指数映射关系，所以

$$U = e^{ X } = e^{ i\alpha } \in U(1) $$

李代数的李括号始终是零，因为 李代数是一维的实向量空间

$$[X,Y] \equiv 0 $$

这个对易关系很奇妙，它告诉我们电磁理论是阿贝尔的


# 表示论

$U(1)$ 的不可约表示都是一维的，标记为整数 $n$ 物理中叫“电荷”或“量子数”）：

$$\rho_{n} : e^{ i\theta } \longmapsto e^{ in \theta } ,\quad n\in \mathbb{Z} $$

在量子力学和粒子物理中，$U(1)$ 表示对应电荷守恒，$n$ 表示带电量大小（量子化）


# 规范群

$U(1)$ 是最简单的规范群，也是 Abel 群。

作为规范群，它给出了 Maxwell 方程的对称性：
$$A_{\mu} \longmapsto A_{\mu} + \partial_{\mu}\alpha(x) $$
