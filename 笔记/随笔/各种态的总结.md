# Fock 态

就是多粒子态，在QO中多是用来承载多光子的空间，光子是玻色子所以不用考虑反交换的事情。于是可以简单用产生湮灭算符来生成：
$$\begin{align}
a^{\dagger}\ket{n} &  = \sqrt{ n+1 } \ket{n+1}   \\
a\ket{n} & = \sqrt{ n }\ket{n-1} \\
a\ket{0} & = 0   
\end{align}$$
可以递推得到
$$\ket{n} = \frac{(a^{\dagger})^{n}}{\sqrt{ n! }} \ket{0}   $$

主要用于：记数光子数，单光子试验，强非经典效应
# 相干态

相干态是湮灭算符 $a$ 的本征态，QO研究的光子属于玻色子可对比[[费米相干态]]
$$a\ket{\alpha} = \alpha \ket{\alpha}  $$
对于这种态，它的光子数的满足泊松分布：
$$c_{n} = \braket{ n | \alpha } = \braket{ 0 \mid\frac{a^{n}}{\sqrt{ n! }}\mid \alpha } = \frac{\alpha^{n}}{\sqrt{ n! }} \braket{ 0 | \alpha }  $$
于是
$$P_{n} = |c_{n}|^{2} = \frac{|\alpha|^{2n}}{n!}|\braket{ 0 | \alpha } |^{2} $$
考虑到归一化条件，可以把常数 $\braket{ 0 | \alpha }$ 计算出来：
$$\sum_{n=0}^{\infty} P_{n} = 1 \implies |\braket{ 0 | \alpha } |^{2} = \exp\left( - |\alpha|^{2} \right) $$
$$c_{n} = e^{ -\frac{1}{2}|\alpha|^{2} } \frac{\alpha^{n}}{\sqrt{ n! }} ,\quad P_{n} = e^{ -|\alpha|^{2} } \frac{|\alpha|^{2n}}{n!} $$
可见光子数分布满足泊松分布。


主要用于：腔中的稳定场，JC模型，半经典极限(把场当作经典电磁波)
# 压缩态

被定义为真空经过平移得到的态
$$\ket{\xi} = D(\xi)\ket{0} ,\quad D(\xi) = \exp\left[  \frac{1}{2}(\xi^{*}a^{2} - \xi a^{\dagger 2})  \right]   $$


主要用于：信息降噪
# 薛定谔猫态

这是两个宏观可分辨的相干态的量子叠加，如
$$\ket{\psi} = N(\ket{\alpha} + e^{ i\phi }\ket{-\alpha}  ) $$
1. 它是 $a^{2}$ 的本征态，即
   $$a^{2}\ket{\psi} = \alpha^{2}\ket{\psi}  $$
2. 它的光子数分布满足类泊松分布
   $$P_{n} = \begin{cases}
0 & ,n\text{为偶} \\
\dfrac{2e^{ -|\alpha|^{2} }}{1-e^{ -2|\alpha|^{2} }} \dfrac{|\alpha|^{2n}}{n!}  & ,n\text{为奇}
\end{cases} $$

通过取不同的 $\phi$ 可以得到不同的结果


主要用于：量子叠加的宏观效应
# 热态

是混态，用密度矩阵描述
$$\rho = \sum_{n} \frac{\bar{n}^{n}}{(1+\bar{n})^{n+1}} \ket{n} \bra{n}  $$
其中 $\bar{n}=\frac{1}{e^{ \beta \hbar \omega }-1}$ 它是源于普朗克研究黑体辐射导出的

# 缀饰态

在研究[[量子光学模型总结#Jaynes-Cummings 模型|JC模型]]时，我们有两套的基底 $\ket{e,n},\ket{g,n+1}$ 和能量的本征态，这两个能量的本征态就叫缀饰态。
$$\begin{gather}
\ket{n,+} = \cos \theta_{n} \ket{e,n} + \sin \theta_{n}\ket{g,n+1} \\
\ket{n,-} = -\sin \theta_{n} \ket{e,n} + \cos \theta_{n}\ket{g,n+1}    
\end{gather}  $$
$$\tan(2\theta_{n})=\frac{2g\sqrt{ n+1 }}{\omega-\omega_{0}} $$
当处于共振时
$$\ket{n,+} =\frac{\ket{e,n} + \ket{g,n+1}  }{\sqrt{ 2 }} ,\quad \ket{n,-} = \frac{\ket{e,n} - \ket{g,n+1}  }{\sqrt{ 2 }}  $$
而称 $\ket{e,n},\ket{g,n+1}$ 为裸态，此裸并非重整化的裸。


主要用于：全量子效应，原子与场不可区分
