# 1. 几何定义与嵌入

de Sitter 空间被定义为 $n+1$ 维闵可夫斯基空间 $\mathbb{R}^{1,n}$ 中的一个超曲面（类时双曲面），其方程为： $$-(x^0)^2 + \sum_{i=1}^n (x^i)^2 = \alpha^2$$ 其中 $\alpha$ 是一个非零实常数。它在几何上是一个具有常数正标量曲率的流形。

# 2. 局部静态坐标

通过以下变换定义 $dS_n$ 的局部静态坐标 $(t, r, z_2, \dots, z_n)$：

- $x^0 = \sqrt{\alpha^2 - r^2} \sinh(t/\alpha)$
- $x^1 = \sqrt{\alpha^2 - r^2} \cosh(t/\alpha)$
- $x^i = r z_i$ （对于 $2 \le i \le n$，其中 $z_i$ 是半径为 1 的 $n-2$ 维球坐标）

# 3. 物理意义与场方程

- **宇宙常数**：dS 空间是带正宇宙常数 $\Lambda$ 的爱因斯坦真空场方程的精确解：$R_{\mu\nu} - \frac{1}{2}g_{\mu\nu}R + \Lambda g_{\mu\nu} = 0$。
- **Einstein 度规**：它满足 Einstein 度规条件 $R_{\mu\nu} = K g_{\mu\nu}$，其中 $K$ 为常数。
- **宇宙学应用**：它描述了一个由暗能量主导、且没有物质存在的加速膨胀宇宙模型。

# 4. 运算技巧

- **诱导度规**：计算时需将嵌入坐标的微分（如 $dx^0$）代入闵氏度规 $ds^2 = -(dx^0)^2 + \sum (dx^i)^2$ 中。
- **曲率计算**：由于其高度的对称性，许多里奇张量分量为零，且标量曲率 $R$ 与宇宙常数的关系为 $R = 2n\Lambda/(n-2)$ (在 $n=4$ 时 $R=4\Lambda$)。
