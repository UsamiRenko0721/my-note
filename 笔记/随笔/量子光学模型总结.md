# 半经典理论

## 原子-经典场

原子视作量子力学系统，其有分立能级，并且简化为二能级系统：基态 $\ket{g}$ 激发态 $\ket{e}$。光子视作经典电磁场，考虑到磁场强度比电场小得多，只考虑电场作用 $E$ 。在电场的作用下，原子极化，于是可以和电场耦合，设原子的极化矩为 $\mathbf{d}$ 则相互作用能为
$$V = -\mathbf{d}\cdot \mathbf{E} $$
于是全哈密顿量为
$$H = H_{\text{atom}} - \mathbf{d}\cdot \mathbf{E} $$

## Rabi 模型

### 构建哈密顿量
由于原子简化为二能级，所以其哈密顿量为
$$H_{a} = E_{e}|e\rangle\langle e| + E_{g}|g\rangle\langle g| $$
考虑提取其整体能量
$$H_{a} = \frac{E_{e} + E_{g}}{2}I + \frac{E_{e}-E_{g}}{2}(\ket{e} \bra{e} - \ket{g} \bra{g} ) := \frac{E_{e}+E_{g}}{2}I + \frac{\hbar \omega_{0}}{2}\sigma_{3} $$
其中的 $\frac{E_{e}+E_{g}}{2}I$ 是常数，相当于整体的能量，至多对波函数产生一个相位，故可设定为零；$\sigma_{3}$ 是一个角动量算符，再取 $\sigma_{+}=\ket{e} \bra{g},\sigma_{-}=\ket{g} \bra{e}$ 则它们三个满足角动量代数
$$[\sigma_{\pm},\sigma_{3}]= \pm \sigma_{\pm} ,\quad [\sigma_{+},\sigma_{-}]=2\sigma_{3} $$

原子的极化矩 $\mathbf{d}$ 应当满足宇称奇，考虑其量子化后的矩阵元的宇称，而由于 $\ket{g}$ 为基态是宇称偶，$\ket{e}$ 宇称为奇，于是
$$P: \braket{ e |\mathbf{d}| e } \to-\braket{ e |\mathbf{d}| e } \implies \braket{ e |\mathbf{d}| e } = 0 $$
$$P: \braket{ e |\mathbf{d}| g } \to \braket{ e |\mathbf{d}| g }   $$
不妨记 $\mu=\braket{ e |\mathbf{d}| g }$ 则可以将 $\mathbf{d}$ 表达为
$$\mathbf{d}\ket{\psi} = \begin{pmatrix}
0 & \mu \\ \mu^{*} & 0
\end{pmatrix} \ket{\psi} ,\quad \psi =e,g   $$
$$\mathbf{d} = \mu \sigma_{+} + \mu^{*}\sigma_{-} $$
而简化光场，考虑单色光场，于是 $\mathbf{E}=\mathbf{E}_{0}\cos(\omega t)$ 所以相互作用项可以写为
$$V = -\mathbf{d}\cdot \mathbf{E} = -\mu\cdot \mathbf{E}_{0} (\sigma_{+} + \sigma_{-})\cos(\omega t) := -\frac{\hbar \Omega_{R}}{2}(\sigma_{+}+\sigma_{-})(e^{ -i\omega t } + e^{ i\omega t }) $$


现在由于相互作用项是含时的，所以考虑相互作用绘景是最好的，于是
$$\sigma_{+}^{I} = \sigma_{+}e^{ i\omega_{0}t } ,\quad \sigma_{-}^{I} = \sigma_{-}e^{ -i\omega_{0}t } $$
$$V^{I} = -\frac{\hbar \Omega_{R}}{2}(\sigma_{+}+\sigma_{-})(e^{ -i(\omega-\omega_{0})t } + e^{ i(\omega+\omega_{0})t }) $$
其中的 $\omega_{0}+\omega$ 项由于相较 $\omega-\omega_{0}$ 项大得多，于是在时间尺度 $t\sim \frac{1}{\omega+\omega_{0}}$ 下其平均为零，于是将这个项舍去，此即旋转波近似，此时的模型称为 Rabi 模型，其相互作用绘景的哈密顿量为
$$H = \frac{\hbar \omega_{0}}{2}\sigma_{3} + \frac{\hbar \Omega_{R}}{2}(\sigma_{+}e^{ -i\omega t } + \sigma_{-}e^{ i\omega t }) $$


### 解薛定谔方程
在相互作用绘景中，设系统的态矢量为
$$\ket{\psi} = c_{g}(t)\ket{g} + c_{e}(t)\ket{e}  $$
代入相互作用绘景的运动方程 $i\hbar \frac{\partial \ket{\psi}}{\partial t} = V^{I}\ket{\psi}$ 于是
$$\begin{gather}
i \dot{c}_{e} = \frac{\Omega_{R}}{2}e^{ -i(\omega-\omega_{0})t } c_{g} \\
i \dot{c}_{g} = \frac{\Omega_{R}}{2}e^{ i(\omega-\omega_{0})t } c_{e}
\end{gather} $$
解得（设初始态为激发态）
$$c_{e}(t) = e^{ -i(\omega-\omega_{0})t /2 }\left[  \cos\left( \frac{\Omega t}{2}\right) + \frac{i(\omega-\omega_{0})}{\Omega} \sin\left( \frac{\Omega t}{2} \right)  \right] $$
其中 $\Omega=\sqrt{ (\omega-\omega_{0})^{2} + \Omega_{R}^{2} }$ 于是可以计算出激发态的粒子数布局（概率）
$$P_{e}(t) = |c_{e}|^{2} = \cos^2\left( \frac{\Omega t}{2} \right) + \frac{(\omega-\omega_{0})^{2}}{\Omega^{2}}\sin^2\left( \frac{\Omega t}{2} \right) $$

### 物理结果
1. 在共振时 ($\omega=\omega_{0}$) 会出现粒子数反转，也就是说 $P_{e}$ 是个纯正弦函数，会在 0 到 1 间震荡
2. 当存在失谐时 ($\omega\neq \omega_{0}$) 会导致震荡频率加快 $\Omega>\Omega_{R}$ ，但是原子无法全部的转换到某一个态上
3. 如果没有外部驱动 $\Omega_{R}=0$ 那么 $P_{e}\equiv 1$ 这是不合理的，原子不应该一直保持在激发态，这就是模型的不合理之处

# 全量子理论

## 简述光场的量子化

在QED中我们可以得到电磁场的精准的量子化表达
$$\mathcal{L}_{QED} = -\frac{1}{4}F^{\mu \nu}F_{\mu \nu} + \bar{\psi}(i\gamma^{\mu}D_{\mu}-m)\psi $$
这是一个相对论的理论，而QO通常将原子固定住绝非相对论性的，所以简单化处理，直接取原子的静止参考系，原子依旧简单的视作一个二能级系统，于是问题变为如何将光场量子化。

由于我们常常考虑设计一个腔，让电磁波在腔内与原子相互作用。所以自然选择箱归一化条件。在箱条件下，光子的动能不能随意取值，必须满足驻波条件即
$$k_{n} = \frac{n\pi}{L} $$
于是我们可以将QED中场的傅里叶展开离散化
$$A^{\mu} = \sum_{\lambda}\int \frac{d^{3}k}{(2\pi)^{3}\sqrt{ 2E_{k} }}[ \varepsilon^{\mu}_{\lambda}a_{\mathbf{k},\lambda}e^{ -ik\cdot x } + hc. ] \to A^{\mu} \propto \sum_{\lambda,n} \sqrt{ E_{k_{n}} }[ \varepsilon^{\mu}_{\lambda}a_{n,\lambda}e^{ -ik_{n}\cdot x } + hc. ] $$
$$\mathbf{E} = \nabla\cdot \mathbf{A} \propto \sum_{\lambda,n} \sqrt{ E_{n} }[ \varepsilon_{n,\lambda}a_{n,\lambda}e^{ -ik_{n}\cdot x } + hc. ] $$
又考虑到 $\int E^{2}dV$ 是空间内电磁总能量，所以应当有 $E\propto V^{-1/2}$ 这不重要。简而言之我们可以对不同的模态 $n$ 得到不同的量子化的电场 $\mathbf{E}$ ，其空间取向同 Rabi 模型，于是相互作用项为
$$H_{\text{int}} \propto \mathbf{p}\cdot \mathbf{E}(\sigma_{+}+\sigma_{-})(a^{\dagger} + a) $$
将它拆开来有四项
- $\sigma_{+}a^{\dagger}$ 原子从基态到激发态且产生一个光子
- $\sigma_{+}a$ 原子从基态到激发态且湮灭一个光子
- $\sigma_{-}a^{\dagger}$ 原子从激发态到基态且产生一个光子
- $\sigma_{-}a$ 原子从激发态到基态且湮灭一个光子

## Jaynes-Cummings 模型

与 Rabi 模型一样，进行旋转波近似，忽略掉 $\sigma_{+}a^{\dagger}$ 这样的看似违反能量守恒的项，那么哈密顿量写为
$$H_{\text{JC}} = \omega a^{\dagger}a + \frac{\omega_{0}}{2}\sigma_{3} + g(a^{\dagger}\sigma_{-} + a\sigma_{+}) $$

显然有两个物理意义的态 $\ket{e,n},\ket{g,n+1}$ 通过定义激发数算符 $N = \sigma_{+}\sigma_{-} + a^{\dagger}a$ 发现 $[H,N]=0$ ，在 $N$ 的本征态表示下
$$H \to \begin{pmatrix}
n\omega+\frac{\omega_{0}}{2} & g\sqrt{ n+1 }  \\
g\sqrt{ n+1 } & (n+1)\omega - \frac{\omega_{0}}{2}
\end{pmatrix} $$
可以解得本征能量为
$$E_{\pm} = \left( n+\frac{1}{2} \right)\omega \pm \frac{1}{2}\sqrt{ (\omega-\omega_{0})^{2} + 4g^{2}(n+1) } := \left( n+\frac{1}{2} \right)\omega \pm \frac{1}{2}\Omega_{n} $$
这个和 Rabi 模型的区别就是它对于每种模态 $n$ 都给出不同的能量，且有劈裂，劈裂大小随着失谐量和模态上升而变大。下面解本征方程以得到哈密顿量的本征态
$$H\ket{n,\pm} = E_{n}\ket{n,\pm} $$
于是
$$\begin{gather}
\ket{n,+} = \cos \theta_{n} \ket{e,n} + \sin \theta_{n}\ket{g,n+1} \\
\ket{n,-} = -\sin \theta_{n} \ket{e,n} + \cos \theta_{n}\ket{g,n+1}    
\end{gather} $$
其中 $\tan(2\theta_{n})=\frac{2g\sqrt{ n+1 }}{\omega-\omega_{0}}$。下面解薛定谔方程以观察动力学演变过程，不妨设初态为 $\ket{e,n}$ 将 $\ket{\psi}$ 按 $\ket{e,n}$ 和 $\ket{g,n+1}$ 为基进行展开
$$\ket{\psi} = c_{e}(t)\ket{e,n} + c_{g}(t)\ket{g,n+1}  $$
$$i\frac{\partial }{\partial t}\ket{\psi} = H\ket{\psi}  $$
解得
$$c_{e} = e^{ i(\omega-\omega_{0})t/2 }\left[  \cos\left( \frac{\Omega_{n}t}{2} \right) - \frac{i(\omega-\omega_{0})}{\Omega_{n}}\sin\left( \frac{\Omega_{n}t}{2} \right) \right] $$
$$P_{e}(t) = |c_{e}|^{2} = \cos ^{2}\left( \frac{\Omega_{n}t}{2} \right) + \frac{(\omega-\omega_{0})^{2}}{\Omega_{n}^{2}}\sin ^{2}\left( \frac{\Omega_{n}t}{2} \right) $$
在共振时 $P_{e}=\cos^2(g\sqrt{ n+1 }t)$ 

### 真空 Rabi 震荡
分析可见，即使在真空的情况下，仍然会有基态-激发态的震荡切换现象。
$$ P_{e,n=0}=\cos^2(gt)$$
这样就很好的修补了 Rabi 模型中第三点的不足。此时的物理图景是原子从激发态回到基态，同时产生了一个光子，这个光子可以再次将原子从基态激发到激发态，在腔的限制下这个过程必然周期性发生。
## Weisskopf-Wigner 理论

该模型区别于 JC 模型，它的腔很大 $L\gg 1$ 于是模谱趋于连续，也就是在原子的尺寸内理解为光场是自由的无边界约束的。于是离散变为连续即可
$$H_{\text{WW}} = \int d^{3}k\ \omega_{k}a_{k}^{\dagger}a_{k} + \frac{\omega_{0}}{2}\sigma_{3} + g\int d^{3}k\ g_{k}(\sigma_{+}a_{k} + \sigma_{-}a_{k}^{\dagger}) $$
我们说有这样的两个“不违反能量守恒”的物理的态 $\ket{e,0}$ 处于基态且无光子，$\ket{g,1_{k}}$ 处于基态且有一个模(动量)为 $k$ 的光子，后一种显然有无穷多种因为 $k$ 是连续的。

设
$$\ket{\psi} = c_{e}\ket{e,0} + \int d^{3}k\ c_{k}\ket{g,1_{k}}  $$
代入薛定谔方程得到
$$\dot{c}_{e} = -i \int d^{3}k\ g_{k}e^{ i(\omega_{0}-\omega)t }c_{k} ,\quad \dot{c}_{k} = -ig_{k}e^{ -i(\omega_{0}-\omega)t }c_{e} $$
于是
$$\dot{c}_{e} = -\int_{0}^{t} d\tau\ \int d^{3}k\ |g_{k}|^{2} e^{ i(\omega_{0}-\omega)(t-\tau) } c_{e}(\tau) $$
为了解得方程，我们使用 Markov 近似，即假设 $\rho(\omega)|g(\omega)|^{2}$ 在 $\omega_{0}$ 附近平滑且系统无记忆 $c_{e}(t)\approx c_{e}(t-\tau)$ 于是可以延拓积分上限为无穷，于是就得到了局域方程
$$\begin{align}
\dot{c}_{e}(t) &  = -c_{e}(t) \int_{0}^{\infty} d\tau \int d^{3}k |g_{k}|^{2}e^{ i(\omega_{0}-\omega)\tau } = -c_{e}(t) \int d^{3}k|g_{k}|^{2} \int_{0}^{\infty} d\tau \ e^{ i(\omega_{0}-\omega)\tau } \\ & =^{*} -c_{e} \int d^{3}k|g_{k}|^{2}\pi\delta(\omega-\omega_{0}) \\ & =-\frac{\Gamma}{2}c_{e}
\end{align} $$
也就是说这个一个衰变的概率幅
$$c_{e}(t) = e^{ i\delta }e^{ -\Gamma t/2 } $$

### 衰变率
定义
$$\Gamma = 2\pi\int d^{3}k|g_{k}|^{2}\delta(\omega-\omega_{0}) $$
实际上这里是进行了一个态密度的转换的，$\rho(\omega)d\omega = d^{3}k$ 代入得到
$$\Gamma = 2\pi \rho(\omega_{0})|g(\omega_{0})|^{2} $$
对于光子 $\omega=|\mathbf{k}|$ 于是 $d^{3}k=4\pi k^{2}dk=4\pi \omega^{2}d\omega\implies \rho(\omega)=4\pi \omega^{2}$ 
(所谓费米黄金准则是也，当然它那里还考虑到实空间的体积，在系数上有所不同，但总体上差不多)

### Lamb 位移
实际上对于积分
$$\int_{0}^{\infty}d\tau\ e^{ i(\omega_{0}-\omega)\tau } = \pi\delta(\omega-\omega_{0}) + \frac{i\mathcal{P}}{\omega_{0}-\omega} $$
才是对的，主值部分实际上会导致
$$\dot{c}_{e}(t) = -\left( \frac{\Gamma}{2} + i\delta \omega \right)c_{e}(t) \implies c_{e} = e^{ -i\delta \omega t }e^{ -\Gamma t/2 } $$
可见它就是在 Rabi 模型的基础上进行了扩展，还原了在无边界的情况下的衰变过程，意思就是在无边界的情况下原子会自发辐射光子。

# 耗散与退相干理论

## 开放量子系统建模

在实际物理过程中，系统 $S$（如原子或腔场）不可避免地与拥有无穷自由度的环境库 $B$ 发生相互作用。总哈密顿量可表示为： $$H = H_S + H_B + V$$ 其中 $V$ 为系统与环境的相互作用项，通常描述为系统算符与库算符的线性耦合。

## Born-Markov 近似

为了从全系统的密度矩阵 $\rho_{SR}$ 中提取系统自身的演化 $\rho_S = \text{Tr}_B(\rho_{SR})$，需要引入两个关键近似：

- **玻恩近似**：假设系统与环境耦合较弱，库的规模巨大，以至于系统的影响不会改变库的状态，即 $\rho_{SR}(t) \approx \rho_S(t) \otimes \rho_B$。
- **马尔可夫近似**：假设库的关联时间远短于系统特征演化时间，系统失去了对过去状态的“记忆”，演化仅取决于当前瞬时状态。

## Lindblad 主方程

在上述近似下，描述单模腔场损耗（处于温度 $T=0$ 的库中）的标准主方程形式为： $$\frac{d\rho}{dt} = -i[H, \rho] + \frac{\gamma}{2} (2a\rho a^\dagger - a^\dagger a \rho - \rho a^\dagger a)$$
- **相干演化项**：$-i[H, \rho]$ 描述由系统自身哈密顿量引起的幺正演化。
- **耗散项（Lindblad 项）**：描述由于光子从腔内向环境流失导致的非幺正过程。

## 物理结论

1. **退相干 (Decoherence)**：主方程预言了密度矩阵的非对角元（相干项）会随时间迅速衰减，这是量子系统向经典统计演化的关键机制。
2. **能量耗散**：对于初始处于激发态的二能级原子，其布居数按 $\rho_{22}(t) = e^{-\Gamma t}$ 规律呈指数衰减，这与 Weisskopf-Wigner 理论的结论完全一致。
3. **稳态趋向**：当 $t \to \infty$ 时，系统最终将演化至与其所处环境热平衡的稳态。
