# 1

准备丘赛 [[Yau 广义相对论]] 要计算很多的度规，其中又因为静态球对称的情况很常见，故专门总结

# 正文

满足条件的一般的度规的形式为

$$\boxed{ ds^{2} = B(r)dt^{2} - A(r)dr^{2} - r^{2}(d\theta^{2} + \sin^2\theta d\phi^{2}) } $$

这里的闵式度规是 $(+ ---)$ ，直接给出结果
$$\begin{gather}
R_{tt} = -\frac{B''}{2B} + \frac{B'}{4A}\left( \frac{A'}{A} + \frac{B'}{B} \right) - \frac{B'}{rA} \\
R_{rr} = \frac{B''}{2B} - \frac{B'}{4B}\left( \frac{A'}{A} + \frac{B'}{B} \right) - \frac{A'}{rA} \\
R_{\theta \theta} = -1 + \frac{r}{2A}\left( -\frac{A'}{A} + \frac{B'}{B} \right) + \frac{1}{A} \\
R_{\phi \phi} = R_{\theta \theta}\sin^2\theta
\end{gather} $$
