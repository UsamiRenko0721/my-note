# Grassmann 代数

## Grassmann 数
Grassmann 数是一种特殊的数，实数复数这些有乘法交换律的数称为c-数(commuting-number)，Grassmann 数是反交换律，也就是说对于两个 Grassmann 数有
$$\theta_{1}\theta_{2} = -\theta_{2}\theta_{1} $$

让 $n$ 个满足反交换律的生成元 $\{ \theta_{1},\dots ,\theta_{n} \}$ ，也就是
$$\{ \theta_{i} , \theta_{j} \} = 0 ,\quad \forall i,j. $$
然后以c-数为系数的这组生成元的线性组合称为 Grassmann 数。由 $\{ \theta_{i} \}$ 生成的代数称为 Grassmann 代数。一些有用的性质是
$$\boxed{ \begin{align}
\theta^{2}_{k} &= 0 \\
\theta_{k_{1}}\theta_{k_{2}}\dots \theta_{k_{m}} &= \varepsilon_{k_{1}k_{2}\dots k_{m}}\theta_{1}\theta_{2}\dots \theta_{n} \\
\theta_{k_{1}}\theta_{k_{2}}\dots \theta_{k_{m}} &= 0 \qquad (m>n)
\end{align} } $$
其中 $\varepsilon_{k_{1}\dots k_{m}}$ 的定义是：当排列是偶的时候取 $+1$ 为奇时取 $-1$ 其它时候取 $0$ 

复共轭映射是连接了两组独立的 Grassman 数的生成元 $\{ \theta_{i} \},\{ \theta_{i}^{*} \}$，通过定义 $\theta_{i}$ 的复共轭是 $\theta_{i}^{*}$ 以及 $(\theta_{i}^{*})^{*}=\theta_{i}$ 并且定义
$$(\theta_{i}\theta_{j})^{*} = \theta_{j}^{*}\theta_{i}^{*} $$
而另一方面作为实c-数的 $\theta_{i}\theta^{*}_{i}$ 其复共轭则不会受影响
$$(\theta_{i}\theta^{*}_{i})^{*} = \theta_{i}\theta^{*}_{i} $$

## Grassmann 函数
Grassmann 数的函数被函数的泰勒级数所定义，比如当 $n=1$ 时
$$e^{ \theta } = 1 + \theta + \frac{\theta^{2}}{2} + \dots = 1 + \theta $$
其中的高阶项会由于第三条性质归零，实际上所有的单元 Grassmann 函数都是至多为一阶的。


## Grassmann 微积分
我们假定微分算符是作用在函数的左边的，也就是说
$$\frac{\partial \theta_{i}}{\partial \theta_{j}} = \frac{\partial}{\partial \theta_{j}} \theta_{i} = \delta_{ij} $$
而莱布尼兹规则就是
$$\frac{\partial}{\partial \theta_{i}}(\theta_{j}\theta_{k}) = \frac{\partial \theta_{j}}{\partial \theta_{i}}\theta_{k} + \theta_{j} \frac{\partial \theta_{k}}{\partial \theta_{i}} $$
如果我们记积分操作为 $I$ 微分操作为 $D$ 则有
$$ID=DI=0 $$
$$D(A)=0 \implies I(BA)=I(B)A $$
如果我们让 $I\propto D$ 进一步得归一化为 $I=D$ 即我们定义了
$$\int \mathrm{d}\theta \ f(\theta) = \frac{\partial f(\theta)}{\partial \theta} $$
对于高斯积分
$$\int \mathrm{d}\theta_{1}^{*}\mathrm{d\theta_{1}\dots}\mathrm{d\theta}_{n}^{*}\mathrm{d\theta}_{n} \exp\left( -\sum_{ij} \theta_{i}^{*}M_{ij}\theta_{j} \right) $$
$$\begin{align}I&=\det M \int \mathrm{d\theta}_{1}^{*}\mathrm{d\theta}_{1}'\dots \mathrm{d\theta}^{*}_{n}\mathrm{d\theta}_{n}'\exp\left( -\sum_{i} \theta_{i}^{*}\theta_{i}' \right) \\
&=\det M \left[  \int \mathrm{d\theta}^{*}\mathrm{d\theta} (1+\theta'\theta^{*}) \right]^{n} \\
&=\det M\end{align} $$


# 相干态

费米产生湮灭算符 $c^{\dagger}$ 和 $c$ 满足反对易关系 $\{ c,c \}=\{ c^{\dagger},c^{\dagger} \}=0,\quad \{ c,c^{\dagger} \}=1$ 并且数算符 $N=c^{\dagger}c$ 有本征态 $\ket{0}$ 和 $\ket{1}$ 。我们来考虑这两个态所张成的 Hilbert 空间
$$\mathcal{H} = \text{Span}\{ \ket{0} , \ket{1}  \} $$
任意 $\mathcal{H}$ 中的态 $\ket{f}$ 可以被表达为 $\ket{f}=\ket{0}f_{0} + \ket{1}f_{1}$ 其中 $f_{0},f_{1}\in \mathbb{C}$ 。现在考虑这样的态：
$$\begin{align}\ket{\theta}&=\ket{0}+\ket{1}\theta  \\
\bra{\theta}&=\bra{0}+\theta^{*} \bra{1}     \end{align} $$
其中 $\theta,\theta^{*}$ 是 Grassmann 数，这些态被称为相干态，它们是产生湮灭算符的本征态
$$c\ket{\theta}=\ket{0}\theta=\ket{\theta}\theta,\quad \bra{\theta} c^{\dagger}=\theta^{*}\bra{0}=\theta^{*}\bra{\theta}      $$

这个态有以下的一些性质
$$\boxed{\begin{align}\braket{ \theta' | \theta } &= 1 + \theta'^{*}\theta = e^{ \theta'^{*}\theta } \\
\braket{ \theta | f } &= f_{0} + \theta^{*}f_{1} \\
\braket{ \theta | c^{\dagger} | f  } &= \braket{ \theta | 1 } f_{0} = \theta^{*}f_{0} = \theta^{*}\braket{ \theta | f }  \\
\braket{ \theta | c | f  } &= \braket{ \theta | 1 } f_{1} = \frac{\partial}{\partial \theta^{*}} \braket{ \theta | f }  \end{align}} $$

取 $c$ 和 $c^{\dagger}$ 的任意函数 $h(c,c^{\dagger})=h_{00} + h_{10}c^{\dagger} + h_{10}c + h_{11}c^{\dagger}c$ 其中 $h_{ij}=\braket{ i |h| j }\in \mathbb{C}$ 则
$$\braket{ \theta |h| \theta' } = (h_{00} + \theta^{*}h_{10} + h_{01}\theta' + \theta^{*}\theta'h_{11}) e^{ \theta^{*}\theta' } $$

相干态的完备性关系是
$$\boxed{\int \mathrm{d\theta^{*}d\theta} \ket{\theta} \bra{\theta} e^{ -\theta^{*}\theta } = I } $$

# 费米谐振子的配分函数

费米谐振子的哈密顿量是 $H=(c^{\dagger}c-1 /2)\omega$ 有本征值 $\pm \omega /2$ 配分函数是
$$Z(\beta) = \mathrm{Tr}e^{ -\beta H } = \sum_{n=0,1} \braket{ n | e^{ -\beta H } | n } = e^{ \beta \omega/2 } + e^{ -\beta \omega/2 } = 2\cosh \frac{\beta \omega}{2} $$
现在使用路径积分的语言重现这个过程。

首先说明
$$\mathrm{Tr}e^{ -\beta H } = \int \mathrm{d\theta^{*}d\theta}\ \braket{ -\theta |e^{ -\beta H }|\theta  } e^{ -\theta^{*}\theta } $$
这个直接把相干态的定义带进去就行了。可见迹里面的参数是取在一个反周期的轨道上的，也就是说在 $\tau=0$ 时为 $\theta$ 在 $\tau=\beta$ 时为 $-\theta$ 。使用表达式以插入完备性关系：
$$e^{ -\beta H } = \lim_{ n \to \infty } \left(  1- \frac{\beta H}{n}  \right)^{n} $$
$$\begin{align} Z(\beta) &= \lim_{ n \to \infty }  \int \mathrm{d\theta^{*}d\theta} \ \braket{ -\theta | (1-\beta H /n)^{n} | \theta  } \\
&= \lim_{ n \to \infty } \int \mathrm{d\theta^{*}d\theta} \prod_{k=1}^{n-1} \int \mathrm{d\theta^{*}_{k}d\theta_{k}} \exp\left( -\sum_{m=1}^{n-1} \theta^{*}_{n}\theta_{n} \right) \\
& \quad \times \braket{ -\theta | (1-\varepsilon H) | \theta_{n-1}  } \bra{\theta_{n-1}} \dots \ket{\theta_{1}} \braket{ \theta_{1} | (1-\varepsilon H) |
\theta } \\
& = \lim_{ n \to \infty } \int \prod_{k=1}^{n} \mathrm{d\theta^{*}_{k}d\theta_{k}} \exp\left( -\sum_{m=1}^{n} \theta^{*}_{n}\theta_{n} \right)  \\
& \quad \times \braket{ \theta_{n} | (1-\varepsilon H) | \theta_{n-1}  } \bra{\theta_{n-1}} \dots \ket{\theta_{1}} \braket{ \theta_{1} | (1-\varepsilon H) |
-\theta_{n} }  \end{align} $$
其中的每个矩阵元是这样的
$$\begin{align} \braket{ \theta_{k} |(1-\varepsilon H)| \theta_{k-1} } & = \braket{ \theta_{k} | \theta_{k-1} } \left[  1 - \varepsilon \frac{\braket{ \theta_{k} |H|\theta_{k-1}  }}{\braket{ \theta_{k} | \theta_{k-1} } }   \right] \\
& \simeq  \braket{ \theta_{k} | \theta_{k-1} } \exp\left[ - \varepsilon \frac{\braket{ \theta_{k} |H|\theta_{k-1}  }}{\braket{ \theta_{k} | \theta_{k-1} } }   \right]  \\
&= \exp(\theta^{*}_{k}\theta_{k-1}) \exp\left(  -\varepsilon \frac{\braket{ \theta_{k} |H|\theta_{k-1}  }}{\braket{ \theta_{k} | \theta_{k-1} } } \right) \\
& = e^{ \varepsilon \omega /2 } e^{ (1-\varepsilon \omega)\theta^{*}_{k}\theta_{k-1} } \end{align} $$
于是
$$\begin{align} Z(\beta) &= \lim_{ n \to \infty } e^{ \beta \omega /2 } \prod_{k=1}^{n} \int \mathrm{d\theta^{*}_{k}d\theta_{k}} e^{ -\sum_{m=1}^{n} \theta^{*}_{m}\theta_{m} } e^{ (1-\varepsilon \omega)\sum_{m=1}^{n}\theta^{*}_{m}\theta_{m-1} } \\  & = e^{  \beta \omega/2 } \lim_{ n \to \infty } \prod_{k=1}^{n} \int \mathrm{d\theta^{*}_{k}d\theta_{k}} e^{ -\sum_{m=1}^{n} [ \theta^{*}_{n}(\theta_{n}-\theta_{n-1})+\varepsilon \omega \theta^{*}_{n}\theta_{n-1} ] } \\

& = e^{ \beta \omega /2 } \lim_{ n \to \infty } \prod_{k=1}^{n} \int \mathrm{d\theta^{*}_{k}d\theta_{k}} e^{ -\theta ^{\dagger}B\theta } \end{align} $$
其中
$$\theta = \begin{pmatrix}\theta_{1} \\
\dots \\
\theta_{n}\end{pmatrix},\quad\theta ^{\dagger}=\begin{pmatrix}\theta^{*}_{1},\dots,\theta^{*}_{n} \end{pmatrix} ,\quad B_{n}=\begin{pmatrix}1 & 0 & 0 & \dots & 0 & -y \\
y & 1 & 0 & \dots & 0 & 0 \\
0 & y & 1 & \dots & 0 & 0 \\
\dots & \dots & \dots & \dots & \dots  \\
0 & 0 & 0 & \dots & y & 1\end{pmatrix},\quad y=\varepsilon \omega-1 $$
于是
$$Z(\beta) = e^{ \beta \omega/2 } \lim_{ n \to \infty } \det B_{n} = e^{ \beta \omega/2 } \lim_{ n \to \infty } [1+(1-\beta \omega /n)^{n}] = 2\cosh \frac{\beta\omega}{2} $$

关注第二行
$$\begin{align} Z(\beta)  & = e^{  \beta \omega/2 } \lim_{ n \to \infty } \prod_{k=1}^{n} \int \mathrm{d\theta^{*}_{k}d\theta_{k}} e^{ -\sum_{m=1}^{n} [ \theta^{*}_{n}(\theta_{n}-\theta_{n-1})+\varepsilon \omega \theta^{*}_{n}\theta_{n-1} ] } \\ & e^{  \beta \omega/2 } \lim_{ n \to \infty } \prod_{k=1}^{n} \int \mathrm{d\theta^{*}_{k}d\theta_{k}} \exp\left[  -\sum_{m} \varepsilon \theta^{*}_{m}\left(  \frac{\theta_{m}-\theta_{m-1}}{\varepsilon} + \omega \theta_{m} \right) \right] \\

 & = e^{ \beta \omega/2 } \int \mathcal{D\theta^{*}D\theta} \ \exp\left[  -\int_{0}^{\beta} d\tau\ \theta^{*} \left(  \frac{\mathrm{d}}{\mathrm{d}\tau}  + \omega \right) \theta \right] \\
 & =  e^{ \beta \omega/2 } \det_{APBC} \left( \frac{\mathrm{d}}{\mathrm{d\tau}} + \omega \right) \end{align} $$
 对于这个微分算符，在反周期的边条下特征系统是
 $$\exp\left(  \frac{\pi i(2n+1)\tau}{\beta}  \right) ,\quad \frac{\pi i(2n+1)}{\beta} + \omega $$
 其中 $n=0,\pm1,\pm 2,\dots$
